# 307D:097E 指令覆蓋說明

差異測試的覆蓋率是 78/79 指令（98.7%）。未覆蓋的 1 條是不可達的死碼：

| 位移 | 指令 | 原因 |
|---|---|---|
| +0x24（`307D:09A2`，IDA `loc_3DCE2`） | `jmp loc_3DD8C` | 見下 |

函式開頭用 `rand()` 的最低位決定分支：

```
call rand
cwd                  ; rand 回 0..0x7FFF，dx = 0
xor ax, dx
and ax, 1
add dx, ax           ; dx = rand & 1
mov [bp+0], dx
or dx, dx
jz  loc_3DCE5        ; 0 → 原地以外的分支
cmp dx, 1
jnz loc_3DCE2        ; 不是 0 也不是 1 → +0x24 的 jmp
jmp loc_3DD65        ; 1 → 另一個分支
```

`dx` 只可能是 0 或 1，所以 `jnz loc_3DCE2` 永遠不跳，`+0x24` 的 `jmp loc_3DD8C`（直接結束）到不了。
這是編譯器對 `if / else if` 或 `switch` 產生的第三條路徑（假說：編譯器行為的推測，沒有同版編譯器可驗證），沒有來源狀態能走到，不是測試輸入不足。
分支 0 與分支 1 以及兩者之間的記憶體別名互動，都有 seeds 與突變覆蓋（26 個突變，存活 0）。
