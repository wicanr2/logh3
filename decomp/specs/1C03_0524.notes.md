# 1C03:0524 指令覆蓋說明

差異測試的覆蓋率是 70/72 指令（97.2%）。未覆蓋的 2 條是同一處不可達的死碼：

| 位移 | 指令 | 原因 |
|---|---|---|
| +0x7D | `xor ax, ax` | 見下 |
| +0x7F | `jmp short loc_29148` | 同上 |

多步轉向的分支用 `d` 的正負決定轉向量的符號：

```
    cmp word ptr [bp+2], 0
    jle short loc_2913B        ; d > 0 → ax = 1
    mov ax, 1
    jmp short loc_29148
loc_2913B:                      ; +0x77
    cmp word ptr [bp+2], 0
    jnz short loc_29145         ; +0x7B  d != 0 → ax = 0xFFFF
    xor ax, ax                  ; +0x7D  d == 0 → ax = 0
    jmp short loc_29148         ; +0x7F
loc_29145:                      ; +0x81
    mov ax, 0FFFFh
loc_29148:
```

`d == 0` 才會走 `+0x7D`。但這個分支（多步轉向）的進入條件是 `|d| > rate`（無號比較，`rate` 是 byte，最小 0），
所以 `|d| >= 1`，`d` 不可能是 0。`+0x7D` 與 `+0x7F` 因此永遠到不了。

分母 72 − 2 條不可達指令 ＝ 70 條可達指令，分子也是 70，所以每一條可達指令都被執行過。這 2 條不可能被覆蓋，
所以未覆蓋的 2 條只能是它們，不是漏測。

另有三個等價的語意差異無法用突變驗證（都已寫在 C 檔檔頭或此處）：

- `imul byte ptr` 把 `+0x4D` 當有號 byte，但能走到該分支時 `rate < |d| <= 128`，所以 `rate <= 127`，有號與無號相同。
- 額度比較的常數是 `0x00080000`，低字為 0，所以「32 位元有號比較」等價於「高字（有號）< 8」。
- 「`|d| <= rate`」的無號與有號比較等價：`|d| <= 128`、`rate <= 255`，兩者都小於 `0x8000`。

死碼是否真的存在以位元組為準，不是推論：`decomp/tools/asm.sh 1C03:0524` 的 `loc_2913B` 區段。
