## 結果

**治安% ＝ (200 − 星域記錄 `+0x7D`) / 2**，六個帝國星域全對：

|---:|---|---:|---:|---:|
| 0 | 瓦爾哈拉 | 36 | 82 | 82% |
| 1 | 亞爾迪巴朗 | 38 | 81 | 81% |

| 7 | 亞爾維斯 | 44 | 78 | 78% |
| 9 | 亞凡海爾 | 50 | 75 | 75% |

`+0x7D` 是星域記錄的**最後一個 byte**，語意是「未安定度」——越大治安越差。
無主星域一律 100（＝ 50%），但畫面上不印數字。

**只有自己這一方的星域才顯示數字**：程式先拿 `+0x12`（擁有者）跟
`ds:8F1D`（玩家陣營）比，不同就印 `----`。

## 順帶解出來的三件事

同一支面板常式裡還有三件：

**陣營的文字色**在 `ds:6096`，存的是 `96 95 97`——文字系統的顏色跳脫碼是
`0x90 + 色號`，所以帝國 6、同盟 5、中立 7，與四份收據上量到的墨色一致。

**行星 `n/m`** 的分子取 `記錄[0x16 + 玩家陣營]`：

```
C4 5E 04     les bx,[bp+04]
83 C3 16     add bx,16          ; 三個計數器的起點
8A 0E 1D 8F  mov cl,[8F1D]      ; 玩家陣營
03 D9        add bx,cx
26 8A 07     mov al,es:[bx]     ; ← 玩家陣營在該星域的行星數
```

**艦隊 `a：b`** 讀的是 `+0x28`–`+0x2B` 四個 byte，而且**兩邊看到的不是
同一組**：

| 玩家 | 自己 | 敵方 |
|---|---|---|
| 帝國（陣營 0）| `+0x28` | `+0x2B` |
| 同盟（陣營 1）| `+0x2A` | `+0x29` |

`0xFF` 代表看不到，畫面上印 `--`。796 年 1 月四個 byte 全是 0，
與畫面上的「艦隊 0：0」和空的艦隊一覽表一致。

## 四段門檻

同一段程式用三個比較把未安定度分成四段，寫進一個輸出用的位元組：

| 未安定度 | 跳脫碼 | 色號 | 換算成治安 |
|---|---|---:|---|
| ≤ 40 | `0x96` | 6 | ≥ 80% |
| ≤ 80 | `0x97` | 7 | ≥ 60% |
| ≤ 120 | `0x95` | 5 | ≥ 40% |
| > 120 | `0x92` | 2 | < 40% |

那是**治安那個數字用什麼顏色印**，實測對得上：未安定度 36／38／27／32
的四張收據印色 6，44／50 的兩張印色 7。

戰略情報報告那張的地圖依治安換色（`strmap-regions.json` 的
`colour_796_01_security`）是另一套，**還沒對過**。

## 開局值是算出來的（找到那一段了，算式未解）

`+0x7D` 的開局值（帝國星域 27–56、無主一律 100）**不等於四個
`STELLAR.DT*` 的最後一個 byte**（DT8 是 13–43、DT9 是 0–43、DTA 是 2–40、
DTX 全 0），也不是行星表某一格的平均或總和（82 個位移都掃過）。

監看那個 byte 的寫入（`-watch 5F349`）看到三次：檔案載入寫進 `0F`、
一次 memset 清 0、最後 `2703:0EF3` 寫進 `24`（＝ 36，就是畫面上的 82%）。

寫入點那一段（線性 `27F16` 起）是：

```
B0 C8           mov al,0C8          ; 200
2A 46 00        sub al,[bp+00]      ; 200 − 分數
C4 5E 10        les bx,[bp+10]
26 88 47 7D     mov es:[bx+7D],al   ; 寫進未安定度
```

所以**未安定度 ＝ 200 − 分數**，而治安 ＝ (200 − 未安定度) / 2 ＝ 分數 / 2。

分數（`[bp+00]`）是往前一整段累積出來的（線性 `27E60` 起）：先乘上某記錄的
`+0x0E` 再除以 100、夾在 200 以內，接著加上 `2703:10FC` 與 `2703:11EA`
兩支的傳回值、再夾一次，某個條件成立時整個減半，最後對每顆行星
（記錄 `+0x11`）扣掉 `2B99:0450` 傳回值的兩倍、負的夾成 0。

**四支子函式都還沒看**，所以算式未解。想繼續的話從 `27E60` 那段的
`bp` 參數開始：`[bp+02]`、`[bp+10]`／`[bp+12]` 是三個 far 指標。

## 未安定度怎麼算出來的（骨架已解，見 [`docs/re/33`](33-planet-growth-and-tax.md)）

`2703:0DA1`：無主星域一律 100；其餘是四支子函式加減出來的基底，
星域記錄 `+0x13` 的 bit 2 再 −30、夾到 >= 0，最後乘上**統治者提督**的
`+0x0E` 除以 100、夾到 <= 200。四支子函式還沒解。

這解釋了為什麼在星域記錄裡怎麼找都找不到——它是算出來的，而且要用到提督表。
