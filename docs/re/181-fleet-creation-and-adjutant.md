# 181 — 新編一支艦隊：配槽、寫回提督、配副官

`docs/re/180` 把階段一停在「`2D76:0611` 形狀是新編一支艦隊（強推論）」。
這一輪讀完，推論變成事實，順帶解掉提督記錄的另一個欄位。

## 先講一個工具上的洞

`07F9:023B`／`07F9:03AC` 的線性位址是 `0x81CB`／`0x833C`，
**在 `workplace/codeall.bin` 的 `0x09000`–`0x3E000` 之外**。
`docs/re/175` 已經在 `farcall_to.py` 上踩過同一個洞。

解法很簡單：**這些腳本都吃 `<dump> <base>`，直接拿 1 MB 的完整傾印
（`workplace/s3ai6.bin`，base 0）掃就好。** 驗證過——用完整傾印重掃
`2D10:0005` 的呼叫者，`0x052CA` 這次找得到。
**下結論「沒有呼叫者」之前先換成完整傾印重掃一次。**

## `2D76:0611(提督編號) → 0 或非 0`

```
提督 = ds:B77C + 編號 × 28
若 07F9:023B(提督) == 0：回 0                 ; 不能編
提督[+0x09] &= 7Fh
槽 = 07F9:03AC(提督)
提督[+0x09] = 槽                              ; ★ 寫回去
若 提督[+0x07] == 0FFh：提督[+0x07] = ds:5F78[編號]      ; 預設副官
若 07F9:033A(提督) != 0：
    副官 = ds:B77C + 提督[+0x07] × 28
    副官[+0x09] = 提督[+0x09]                 ; 副官掛同一支艦隊
否則：（清成 0:0）
```

`2E54:0513` 接著就拿 `提督[+0x09]` 當艦隊槽去寫 `+0x08 = 5`
（`docs/re/180`）——兩邊對上了，**`2D76:0611` 確實是「新編一支艦隊」**。

## `07F9:03AC(提督) → 艦隊槽`

```
基底 = (提督[+0x01] == 0) ? 0 : 16
若 艦隊表[基底 + 提督[+0x09]][+0x04] == 0FFh：回 提督[+0x09]   ; 原本那個就空著
否則掃自己陣營的 16 個槽，回第一個空的
```

先看提督原本掛的槽，空著就重用——所以**提督換艦隊不會換槽號**。

## `07F9:023B(提督) → 能不能編`

```
星域 = ds:A79C + 提督[+0x0A] × 126             ; +0x0A ＝ 所在星域（docs/re/77）
若 07F9:02CB(星域, 提督[+0x01], 提督[+0x08] & 0Fh) == 0：回 1
…（後半未讀）
```

提督 `+0x08` 的低四位是另一個沒解的欄位。

## 提督 `+0x07` ＝ 副官，`ds:5F78` ＝ 預設副官表

`ds:5F78` 是 **82 個 byte**（一個提督一格，接著就是下一張表——邊界
互相印證，同 `docs/re/179`）。全表只有六筆不是 `0xFF`：

| 提督 | 預設副官 |
|---|---|
| 41 | 75 |
| 42 | 63 |
| 43 | 73 |
| 46 | 69 |
| 47 | 64 |
| 53 | 56 |

**其餘 76 個提督沒有預設副官**（`0xFF`）。這六對是原版寫死的搭檔。

副官掛上去之後 `副官[+0x09] = 提督[+0x09]`，兩個提督指同一支艦隊——
與艦隊記錄 `+0x05`「副官的提督索引」（`docs/internals/33`）是同一件事的
兩端。

## `ds:8F48` ＝ 費沙進入戰局

```
2AF5:0036(0Eh, 0)                              ; 0Eh ＝ 14 ＝ 費沙
遠指標 = ds:CFF8
若 參數星域[+0x12] == 0（帝國）：用 ds:3280、目標 31（巴拉特）
否則：                          用 ds:3284、目標 0
… 32 位元乘 80（3CC9:0009）…
```

**是費沙的事件沒錯**（`docs/re/179` 標的強推論成立），細節未讀。
