這一輪把 `2E54:143F` 與它呼叫的評分函式 `2E54:1574` 讀完。

## `2E54:143F(星域, 模式)`

**回分數最高的那一支艦隊**（`AX` ＝ 段、`BX` ＝ 位移；一支都沒有回 `0:0`），
不是迭代器。

進門先依模式填一組參數：

| 模式 | 四個權重 | 完整度門檻 | 要求 `+0x0F == +0x0E` | 第四個參數 |
|---|---|---|---|---|
| 0 | 3 2 8 1 | 50 | 否 | 0 |
| 1 | 4 6 1 2 | 90 | 是 | 0 |
| 2 | 3 4 0 0 | 80（艦隊已在目標星域時改成 50）| 是 | 4 |

接著掃 `ds:C074` 的 32 個槽（`+122` 一筆）：

```
若 艦隊[+0x04] == 0FFh：跳過                  ; 沒在用
若 艦隊[+0x01] != ds:8F1D：跳過               ; 不是這個陣營
若 艦隊[+0x79] != 0FFh：跳過                  ; 這回合已經決定過
若 艦隊[+0x3C] < 門檻：跳過                   ; 編制完整度
若 這一組要求「編制不缺」且 艦隊[+0x0F] != 艦隊[+0x0E]：跳過
分數 = 2E54:1574(艦隊遠指標, 星域, 四個權重遠指標, 第四個參數)
若 分數 > 目前最佳：記下這一支
```

`2E54:0AAB` 用的是模式 1。

### `+0x79 == 0FFh` 就是迭代器

`+0x79` 是「這回合的決定」，一趟開始時填 `0xFF`（`docs/internals/33`、
`docs/re/79`）。`2E54:143F` 把「還是 `0xFF`」當成過濾條件，`2E54:0AAB`
每取到一支就把它改寫成 4 或 6——同一支不會被取第二次，整趟的游標就存在
艦隊記錄裡，不需要另外的狀態。

## `2E54:1574(艦隊, 目標星域, 權重表, 主力門檻)` ＝ 評分

```
若 艦隊[+0x00] bit0（無法戰鬥）：回 0
若 2B99:028F(艦隊[+0x06], 目標星域, 艦隊[+0x01] 那個 word) >= 0800h：回 0   ; 走不到

艘數 = 0；主力槽數 = 0
對 i = 0 … 艦隊[+0x0F]−1：                     ; 逐編制槽，每槽 4 bytes
    艦艇 = ds:CFB4 遠指標 + 槽[0..1] × 78
    艘數 += 艦艇[+0x08]                        ; 現有艦數
    若 艦艇[+0x04]（艦種）是 0 或 1：主力槽數++

分數 = (艘數 ÷ 10) × 艦隊[+0x3C] ÷ 100        ; 32 位元（3CC9:0009 乘、3CC9:0020 除）
分數 = 分數 × 艦隊[+0x0F] ÷ 艦隊[+0x0E]        ; 16 位元，捨去
分數 = 分數 × 權重表[ ds:5F52[艦隊[+0x09]] ]   ; 艦隊類別，見 docs/re/169
若 艦隊[+0x08] != 5 且 艦隊[+0x07] == 目標星域：分數 × 2      ; 已經在往那裡走
分數 = 分數 ÷ (2B99:0450(目標星域, 艦隊[+0x06], 艦隊[+0x01]) × 2 + 1)   ; 距離
若 主力槽數 < 主力門檻：分數 ÷ 4
若 分數 == 0：分數 = 1
```

所以分數 ＝ **戰力 × 類別權重 × 順路加成 ÷ 距離**，而「戰力」是
艘數、士氣（`+0x3C`）與編制完整度（`+0x0F ÷ +0x0E`）的乘積。
模式 2 的主力門檻 4 是唯一會用到 `÷ 4` 那條的模式。

`3CC9:0009`／`3CC9:0020` 是 `AX:BX` 為高低字的 32 位元乘除
（`docs/internals/51`），所以 `(艘數 ÷ 10) × 完整度` 不會在 16 位元溢位，
除以 100 之後才落回一個 word。

## `+0x0E`

模式 1／2 要求 `+0x0F == +0x0E`，評分又用 `+0x0F ÷ +0x0E`。
`+0x0F` 是「這一支有幾組編制」（`docs/internals/33`）；`+0x0E` 在同一份
文件裡標「建立艦隊時會寫，語意未解」。兩個讀取點都把它當**分母**且
「相等 ＝ 滿」，形狀是「**編制槽的應有數**」（假說，還沒用資料驗）。
