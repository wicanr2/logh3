# 191 — 建艦隊挑提督時會刻意不總是選最好的

`docs/re/190` 讀完 `2D76:0434`（提督對某個類別的分數）。
分數存進 `提督[+0x1A]` 之後，`2D76:02FA` 排序、然後挑一個——
挑法比「取第一名」有意思。

## `2D76:02FA(類別)` 的後半

```
qsort(清單, 筆數, 1, 2D76:04FD)          ; 依 提督[+0x1A] 排序
r = 3CD5:000C()                          ; 亂數 0–7FFFh
若 r >= 7000h 且 筆數 >= 4 且 清單[3] 的等級 >= 16：選第四名
否則若 r >= 6000h 且 筆數 >= 3 且 清單[2] 的等級 >= 16：選第三名
…（往下應該還有第二名與第一名，未讀完）
```

`0x7000`–`0x7FFF` 是 `0x8000` 的 **1／8**，`0x6000`–`0x6FFF` 又是 1／8。
所以大約：

| 亂數落點 | 機率 | 選誰 |
|---|---|---|
| `>= 7000h` | 1／8 | 第四名 |
| `6000h`–`6FFFh` | 1／8 | 第三名 |
| `< 6000h` | 3／4 | 第二名或第一名（未讀完）|

而且**降格只對等級 ≥ 16 的提督開放**：清單[3]／清單[2] 的
`提督[+0x06]`（等級）不到 16 就退回上一層。

**電腦不會每次都派最強的那個提督**，但也不會亂派——被降格選中的
那個人自己要夠強。
