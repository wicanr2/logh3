```

```

點兩下才會動：第一下選、第二下確認（開新遊戲那條路也是這樣，
先前的收據點兩次 `300,170` 就是這個原因）。

## 這解開了什麼

`docs/re/37` 卡住的地方是「開局沒有艦隊，所以清單都是空的，也就沒得追」。
現在有兩個有艦隊的局面可以進去：

- 一覽表的五張清單應該會有內容 → 追得到執行期的艦隊表；
- 戰鬥（`COMANI.BMG`）在 S3「巴米利恩會戰」那個局面應該一開打就看得到；
- 規格 001／002 多一組**差很遠**的狀態可以驗（796/1/1 vs 798/11/19）。

`SAVEDATA.IDX` 與那三個槽的存檔本體也是存檔格式的入口。
