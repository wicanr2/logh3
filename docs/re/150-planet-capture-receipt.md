# 一顆行星真的被打下來了，還順帶抓到一個索引錯覺

收據 `s3assault`：S3「巴米利恩會戰」不必 poke 任何東西——**帝國的雷奧米爾
（全域第 63 顆）在第八個回合被同盟打下來**。做法是把打行星那一步
（`181B:03D0` ＝ 一回合八步的第六步）前後各倒一份 1 MB，時點用
`-regs-at 20B4:000C,181B:03EF` 量（第 1,496,151,955 與 1,895,887,711 道
指令）。

## `ds:CFF8` 不是「行星表」，是「目前星域的行星切片」

`aspre` 裡 `ds:CFF8`／`ds:CFFA` ＝ `5313:1430`（線性 `0x54560` ＝ 全域第
63 顆）、`ds:CFFC` ＝ **3**。而戰略地圖上（`mem-main`，796/1，選著星域 0）
是 `5313:0002`、`ds:CFFC` ＝ **4**——正好是
[`docs/internals/29`](../internals/29-planets-and-economy.md) 檔頭
`4 3 2 3 …` 的第 0 與第 26 項。

所以走這組遠指標的每一個迴圈**只掃目前那個星域的行星**：

```
181B:0385   要塞砲開火（docs/re/145）
2264:000A   要塞砲倒數（docs/re/145）
20B4:0059   打行星的標記（docs/re/149）
```

而且**艦隊 `+0x5A` 存的是切片內的序號，不是全域索引**。這一份收據裡
四支艦隊的 `+0x5A` 都是 0，而換手的是全域第 63 顆——0 就是區域 26 的
第一顆。差點把它讀成「打的是全域第 0 顆行星（奧丁）」，而那顆離戰場
一千一百像素。

remake 這邊本來就是逐星域建 `battlePlanets`，所以行為一致；要改的是
文件與「`+0x5A` 是哪一種索引」的理解。

## 換手的效果，逐一相符

[`docs/spec/019`](../spec/019-planet-assault.md) 早就記下換手會做什麼，
但一直沒有實證。這一份對上了：

| 欄位 | 前 | 後 | 規格 |
|---|---|---|---|
| `+0x11` 擁有者 | 0 | **1** | ← 攻方陣營 |
| `+0x14` 防衛力 | 2852 | 428 | — |
| `+0x20`–`+0x3B` 補充存量 | 全 0 | 全 0 | ← 0（本來就是 0）|
| `+0x3C` 飛彈 | 40000 | **20000** | **右移一位** ✔ |
| `+0x40` 艦載機 | 40000 | **0** | ← 0 ✔ |

## 換手不是「防衛力歸零」

打完之後防衛力還有 **428**，擁有者已經換了。所以條件在 `20B4:0503`
的回值，不是「`+0x14` 減到 0」。那一支還沒讀。

## 標記與實扣不是同一組

這一步之後五支同盟艦隊的 `+0x70` 都是 `03`（16、17、28、29、31），
但實際掉艘數的只有 16、17、31 三支（合計 632 艘，分佈在 17 個分隊上）。
對得上 [`docs/re/149`](149-planet-assault-gating.md) 讀到的兩道閘門：
`20B4:038F` 看 bit 0 決定「這顆行星要不要結算」，`20B4:08B1` 看 bit 1
決定「這一支要不要打」。

分數：`ds:8FE4[1]` ＋449、`[0]` ＋22。規格裡的「換手加 `+0x16` ÷ 10」
＝ 3300 ÷ 10 ＝ 330 只佔其中一部分，剩下的還沒拆開。

## 還缺什麼

| 問題 | 卡在哪 |
|---|---|
| 換手的條件 | `20B4:0503` 的回值 |
| 這一輪打掉多少防衛力 | 算式已知（`docs/re/146`），但要按五支艦隊的順序把亂數接上才驗得了 |
| 行星反擊怎麼分攤到 17 個分隊 | `20B4:0486` 之後那幾支 |
| 分數的其餘部分 | 同上 |

## 可重用的規則

- **「表的遠指標」與「表」不是同一件事。** `ds:CFF8` 看起來像行星表的
  指標，實際上是**目前星域的切片**；跟著它走的索引全都是區域內序號。
  判準：切片長度（`ds:CFFC`）如果會變，那就不是整張表。
- **有些局面不必 poke。** 這一場的換手是劇本自己走出來的；先跑一遍看
  「會不會自己發生」比先設計一組 poke 便宜得多。
