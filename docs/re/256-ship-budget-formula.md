# 256 — 船艦建造費的基數會扣維持費與移動經費；百分比在 `ds:8F92`

`docs/re/255` 把月底閘門打開之後，整段本體可以無頭跑完（座位 poke 成電腦，
三支月報會直接返回）。這一篇把「月底軍事費的完整算式」那一格從
「已逆向、未對數字」推到有兩組數字對上。

## 收據

批次 `monthmoney`：S3「巴米利恩會戰」載入後 poke `ds:8F23[0] = 1`（座位 0
改電腦）與 `ds:8FF4/8FF5 = 01 01`（開閘），在 `#243674000`（進 `0654:0034`
之前）與 `#244300000`（本體跑完之後）各倒一份 1 MB。

| 欄位 | 帝國前 | 帝國後 | 同盟前 | 同盟後 |
|---|---:|---:|---:|---:|
| `ds:8F52` 軍事費 | 160000 | **173131** | 30000 | 30000 |
| `ds:8F5A` 下期船艦建造費 | 0 | 0 | 7532 | 7532 |
| `ds:8F62` 原定軍事費 | 160000 | **173131** | 30000 | 30000 |
| `ds:8F6A` 總稅收 | 13131 | **12776** | 9748 | 9748 |
| `ds:8F72` 本回合維持費 | 2342 | 2342 | 951 | 951 |
| `ds:8F82` 本回合移動經費 | 665 | 665 | 1133 | 1133 |
| `ds:8FF4/8FF5` | `01 01` | **`00 01`** | | |

`ds:8F1D` ＝ 0（帝國），**同盟那一欄一個位元組都沒動**——結算只碰
`ds:8F1D` 那一格。`173131 ＝ 160000 ＋ 13131`，就是 `2703:03AF` 的
`軍事費 += 總稅收`；`ds:8F62` 抄的是加完之後的值；`ds:8FF4[0]` 被清掉。
總稅收從 13131 變 12776，是共同尾巴那一趟重算的結果
（中間 `2703:03AF` 把星域的 `+0x26` 抄進了 `+0x27`）。

## `090A:0E88(陣營)` 的算式

```
09F33  ax:bx = 297B:10DE(陣營)              ; 維持費與移動經費一起算
09F41  ds:8F72/74[陣營] = ax:bx
09F49  ax:bx = ds:8F52/54[陣營]             ; 軍事費
09F51  + ds:8F6A/6C[陣營]                   ; ＋ 總稅收
09F59  − ds:8F72/74[陣營]                   ; − 本回合維持費
09F61  − ds:8F82/84[陣營]                   ; − 本回合移動經費
09F78  比 0：負的 → ds:8F5A/5C[陣營] = 0，離開
09F9D  比 0147AE14h（＝ 2³¹ ÷ 100）：
         ≥ → 先 ÷100 再 × ds:8F92[陣營]
         < → 先 × ds:8F92[陣營] 再 ÷100
       → ds:8F5A/5C[陣營]
```

`ds:8F92` 是**每個陣營一個 byte 的造船百分比**（`mov cl,[si+8F92]`，
`si` 就是陣營）。收據上是 `00 14` ＝ 帝國 0%、同盟 20%：

| | 軍事費 ＋ 總稅收 − 維持費 − 移動經費 | × `ds:8F92` | ＝ `ds:8F5A` |
|---|---:|---:|---:|
| 帝國 | 170124 | 0% | **0** |
| 同盟 | 37664 | 20% | **7532** |

兩組都精確落地（`37664 × 20 ÷ 100 = 7532.8` 捨去）。

## 這推翻了 remake 的一條算式

remake 本來是 `船艦建造費 ＝ (國庫 ＋ 預估徵稅額) × 百分比`
（`docs/re/12` 量自 796/1 的徵稅計劃）。那張收據上維持費與移動經費**都是
0**，所以兩條算式給同一個數；S3 那組就分得開了——不扣的話同盟會算成
`39748 × 20% ＝ 7949`，收據是 7532。

**畫面上的「預估軍事費」不扣那兩項**：`docs/internals/27` 的
`55933 ＝ 45592 ＋ 10341` 與 `剩餘軍事費 41950 ＝ 55933 − 13983` 都還成立。
兩項只進建造費的基數。

新遊戲兩邊都是 25，所以 remake 目前寫死的 25 對新遊戲是對的。
**電腦那一方怎麼調自己的百分比還沒解**——同一個劇本裡同盟從 20 變 7、
從 25 變 11，顯然是 AI 每個月在動它。
