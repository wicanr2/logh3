# 144 — 戰場的行星情報視窗

行星選單第一項「情報」開的是 `1373:1CBC`。它自己開一個視窗：

```
3603:0006(&視窗 = NULL, 色 0x97, 格 (3,4), 內容 22 × 10 格, 旗標 1)
    → 實際 24 × 12 格 ⇒ 像素 (48, 120) 起、384 × 240
```

## 印的東西

```
星域 = ds:A79C ＋ ds:8F17 × 0x7E          ; ds:8F17 ＝ 目前星域

視窗[+1] = ds:6096[星域 +0x12]
3617:003A(ds:3A70 "%s星系  ", 名字表 ds:60AE[星域 +0x12])
視窗[+1] = 0x97
3617:003A(ds:3A79 "%s\n", 星域)            ; 星域記錄開頭就是名字

視窗[+1] = ds:6092[行星 +0x11] | 0x90
3617:003A(ds:3A87 "%s%s  ",
          行星 +0x12 != 0 ? "要塞" : "行星", 名字表 ds:60AE[行星 +0x11])
視窗[+1] = 0x97
3617:003A(ds:3A8E "%s\n", 行星)            ; 行星名
3617:003A(ds:3A92 "\n")

行星 +0x11 == ds:8F1D（玩家陣營）：
    成長率 = 2703:0D47(行星)，除 10 取商與餘
    3617:003A(ds:3A94 "經濟力    %10lu﹕成長率  %2d.%1d%% \n",
              行星 +0x1A（32 位元）, 商, 餘)
    3617:003A(ds:3AB9 "防衛力   %5u/%5u﹕回復率  %2d.0%% \n",
              行星 +0x14, +0x16, +0x18)
    3617:003A(ds:3ADD "  Ｂ    Ｈ    Ｃ    Ａ    Ｄ    Ｔ    Ｅ\n")
    七次 3617:003A(ds:3B07 "%4d  ", 各艦種的補充存量)
    3617:003A(ds:3B0D "\n  飛彈          戰鬥機\n")
    3617:003A(ds:3B26 "    %10lu    %10lu", 飛彈, 戰鬥機)
否則：
    3617:003A(ds:3B39 "經濟力    %10lu﹕成長率  ----\n", …)
    3617:003A(ds:3B58 "防衛力   %5u/%5u﹕回復率  ----\n", …)
    後面幾段不印
```

**這裡的分行是格式字串自己帶的 `\n`**，不是像補給面板那樣靠「剛好佔滿
一列」。同一套引擎，兩種排版習慣。

`  Ｂ    Ｈ    Ｃ    Ａ    Ｄ    Ｔ    Ｅ` 是七個艦種的字首（全形），
對應行星記錄 `+0x20 + 艦種 × 4` 那七格補充存量（`docs/re/134`）。

## 兩張顏色表

| 位址 | 內容 | 用法 |
|---|---|---|
| `ds:6092` | `06 05 07` | 字色（帝國 6、同盟 5、中立 7），用的時候 `| 0x90` |
| `ds:6096` | `96 95 97` | 整個顏色位元組 |

兩者是同一件事的兩種寫法：`ds:6092[n] | 0x90` ＝ `ds:6096[n]`。

名字表 `ds:60AE` ＝ 帝國軍／同盟軍／中立軍，**沒有跳脫碼**——與補給面板
用的 `ds:60F4`（`\x03[150,帝國軍\x03[151,`）是兩張不同的表，同樣三個詞，
一張自己帶顏色、一張不帶。

## 收據怎麼做出來的

星域 26 的三顆行星裡，第一顆（全域索引 63）**正好被第 31 艦隊的旗艦
壓在同一格**——點下去會被分隊吃掉。所以把它的座標
（記錄 `+0x46`／`+0x48`，線性 `0x545A6`）poke 到畫面上空的位置再點。

全域索引由檔頭算出來：`PLADAT.DAT` 前 32 個 word 是每個星域的行星數，
星域 26 之前累計 63 顆。

## 對拍

收據 `s3plinfo`，整個 24 × 12 格（92,160 個像素）**逐位元組相同**，
包括框、內容與壓在左上角的滑鼠游標。

量到的值（行星 63「雷奧米爾」，記錄倒在 `workplace/pl63.bin`）：
擁有者 0、非要塞、防衛力 2687／3300、回復率 5、經濟力 4215、
七個艦種存量全 0、飛彈與戰鬥機各 40000；星域「達希利」，
**收據當下的星域擁有者是 2（中立）**。成長率印的是 6.4，也就是
`2703:0D47` 回 64。

## 一個差點對不出來的地方

`"%s%s  "` 的兩個參數是**擁有者名在前、要塞／行星在後**——原版的推入
順序是由後往前，`push 詞` 在 `push 名字` 之前，所以「詞」是第二個 `%s`。
照字面順序寫會得到「行星帝國軍」而不是「帝國軍行星」，畫出來整列往右
移兩格。

## 可重用的規則

- **同一個東西可能有兩張表。** 陣營名在 `ds:60AE` 與 `ds:60F4` 各存一份，
  差別只在後者夾了換色跳脫碼。看到「這個字串我已經抄過了」時，先確認
  是不是同一個位址——不是的話兩份都要留。
- **參數順序要從推入順序反推，不要從格式字串的字面順序猜。** Borland 的
  呼叫慣例由後往前推，所以**最先 push 的是最後一個參數**。這裡差點把
  「%s%s」的兩個參數寫反，而症狀是整列右移兩格——看起來像版面錯，
  其實是參數錯。
