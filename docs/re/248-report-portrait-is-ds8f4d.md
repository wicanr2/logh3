# 248 — 報告上的頭像是誰：`ds:8F4D[陣營]`

`docs/spec/034` 量了易主報告的版面，剩一項沒解：右邊那張臉是誰的。
解出來了，順帶把 `docs/re/245` 裡一句寫得太快的話修掉。

## 怎麼找的

`tools/scripts/face_find.py` 直接拿 83 張去比收據上的色號，但**一張都沒有
0 差異**——最好的第 9 張還差 2621 個像素。原因是**畫上去的不是整張**：
`FACE.AMG` 每張 80×100，而報告的框內只有大約 75×95。

改成滑動比對（每張 × 裁切位移 × 落點），一次就中：

```
第 13 張　落點 (544,180)　72×93 逐像素差 0
```

72×93 與 `docs/re/112` 量到的艦隊詳細資料那張頭像同尺寸，所以是同一套
「取左上 72×93」的畫法。

## 是誰

`FACE.AMG` 第 n 張 ＝ **提督索引 n**（`docs/spec/012`、`docs/re/65`）。
所以是提督 13。從同一份傾印讀幾個全域：

```
ds:8F1D  目前陣營       = 0（帝國，這一局的玩家座位）
ds:8F4D                 = 13  75  …
ds:8F4F  統治者編號     = 16  63  …
```

**`ds:8F4D[陣營]` ＝ 13**，正好就是那張臉。統治者是 `ds:8F4F` ＝ 16／63，
**不是同一個人**。提督 13 是帝國陣營、等級 16、統率 83、占領 121、運用 97；
同盟那一邊是 75。

所以：**報告的頭像 ＝ `FACE.AMG` 第 `ds:8F4D[座位陣營]` 張**。
`ds:8F4D` 是每個陣營一格的提督編號，看起來是「負責回報的那個人」
（幕僚一類），但這個名字還沒有證據，只寫位址與用途。

## 順帶修正 `docs/re/245`

那一篇讀 `2703:1789`（叛亂判定）時寫「查 `ds:8F4D[擁有者]` 那個提督編號」
——位址是對的，但同一段的敘述把它當成統治者。**`ds:8F4D` 不是統治者**，
統治者在 `ds:8F4F`。`docs/internals/22` 的 bit1 那一列同樣要改。

## 一條方法

**「一張都沒有 0 差異」先懷疑取樣範圍，不是資料。** `face_find.py` 假設
畫上去的是整張 80×100；報告只畫左上 72×93，於是 83 張全部落空，而且
「最接近的」看起來還很像答案。**比對前先量畫上去的那塊有多大。**
