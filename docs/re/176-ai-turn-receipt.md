# 176 — 讓電腦座位跑起來，整條算式對上了

`docs/re/175` 查出 AI 的閘門是 `ds:8F23[ds:8F1E] == 1`（這個座位是電腦），
而所有既有收據都停在座位 0。這一輪直接把那個位元組改掉，跑出第一份
**電腦回合真的動過**的收據。

## 收據 `s3aicomp`

沿用 `s3ai6` 的輸入序列，只多一個 `-poke`：

```
-poke lin:5DA53@280000000=01        ; ds:8F23[0] = 1，把座位 0 標成電腦
-peek lin:5DA4D:4,lin:5DA53:4,lin:6213E:2,lin:6203E:16
-dump-mem lin:0:1048576:…/s3aicomp.bin
```

（`lin:5DA53` ＝ `DS(0x54B3) × 16 + 0x8F23`。`report.txt` 第一行的
`#280000000 改記憶體 lin:5DA53（5DA53）1 bytes` 確認寫對位址。）

`workplace/oracle/s3aicomp/meta.txt` 記了 dosgolem HEAD `ef5be47`（工作樹
乾淨）與完整旗標；`workplace/s3aicomp.bin` 的 SHA-256 見 `WORKLOG`。

## 結果：AI 動了

| | `s3ai6` | `s3aicomp` |
|---|---|---|
| `ds:8F1E`（座位） | 0 | **1** |
| `ds:8F1D`（陣營） | 0 帝國 | **1 同盟** |
| `ds:D60E`（決定了幾支） | 0 | **5** |
| `ds:D50E` | 整張 0 | 13→682、15／22／28→2048 |
| 同盟艦隊的 `+0x07`／`+0x08` | 全 `0xFF`／5 | 四支改成目的地 ＋ 行動 0 |

同盟的六支艦隊：

```
槽16  星域 26→21  目的地 16  行動 0  +0x79 = 0
槽17  星域 26→19  目的地 24  行動 0  +0x79 = 0
槽29  星域 26→21  目的地 FF  行動 5  +0x79 = 0
槽30  星域 26→19  目的地 24  行動 0  +0x79 = 0
槽28  +0x3C 100→99   +0x79 = 1
槽31  +0x3C 100→95   +0x79 = 1
```

## 三條算式被資料對上

### `ds:D54E` ＝ 敵方艦隊的 `+0x0F` 總和（`docs/re/173`）

這一趟的敵方是帝國。帝國艦隊的所在星域與編制槽數：

| 星域 | 帝國艦隊（槽數） | Σ | `ds:D54E` |
|---|---|---|---|
| 13 | 槽7（5） | 5 | **5** |
| 14 | 槽9（8） | 8 | **8** |
| 25 | 槽0（10）2（9）3（7）4（8）5（8）8（8）11（8）14（5）15（6） | **69** | **69** |
| 26 | 槽12（8） | 8 | **8** |

四格全中，包含 69 這個不會巧合的數。

### `ds:D50E` ＝ (累積分 + 1) × (2048 ÷ (`ds:D54E` + 1))（`docs/re/174`）

| 星域 | `ds:D54E` | 2048 ÷ (D54E+1) | `ds:D50E` | 推回的累積分+1 |
|---|---|---|---|---|
| 15、22、28 | 0 | 2048 | 2048 | 1 |
| 13 | 5 | 341 | **682** | 2 |

星域 13 就是伊謝爾倫（`docs/re/167`），它是唯一累積分不為 0 的一格。

### `ds:D58E` ＝ 缺口 ÷ 5 ＋ `RNG % 4`（`2E54:08E3`，`docs/re/174`）

`ds:D5CE` 整張是 0，所以缺口 ＝ `ds:D54E`：

| 星域 | 缺口 ÷ 5 | `ds:D58E` | 推回的 `RNG % 4` |
|---|---|---|---|
| 13 | 5 ÷ 5 = 1 | 1 | 0 |
| 15 | 0 | 1 | 1 |
| 22 | 0 | 2 | 2 |
| 28 | 0 | 3 | 3 |

四格的亂數項落在 0–3，與 `% 4` 一致。

`ds:D5AE`（已指派）在 16、21、24 各 1——那是階段三（`2E54:07D8`）留下的，
階段四的 `2E54:08E3` 之後 `ds:D58E` 已經被重算成另一組格子，
兩張表對不起來**正是**「一回合裡算兩次」的直接證據。

## 意義

原版**有**電腦 AI，而且這一整條（兵力圖 → 優先度 → 要派幾支 → 挑候選 →
指派）在真機上跑得出來。`internal/ai` 的 `Original` 現在有東西可以對。

## 一個坑

`-dump-mem` 的 `/src/...` 在 dosgolem 容器裡指的是 **dosgolem 的工作副本**，
不是 logh3。檔案會落在 `~/cht/dosgolem-logh3/workplace/`，
`tools/oracle.sh` 不會幫忙搬。寫路徑之後要去確認檔案在哪。
