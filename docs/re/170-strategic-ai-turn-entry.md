# 170 — 戰略 AI 的回合進入點，與「先處理哪個星域」

`docs/re/167` 收尾時剩下的問題是「`2E54:0AAB` 自己的呼叫者——誰決定要處理
哪個星域、順序是什麼」。這一輪從 `ds:D50E`／`ds:D54E`／`ds:D58E` 三個
常數往回追，把上面那一整層讀出來了。

## 六張以星域為索引的表

追 `ds:` 常數比追欄位快：這三個位址在整份程式碼裡的讀寫點各只有十幾處，
而且彼此緊鄰，一次就能把版面拼出來。

| 位址 | 版面 | 內容 |
|---|---|---|
| `ds:D50E` | 32 × word | **這一格的優先度**；排序用的鍵 |
| `ds:D54E` | 32 × word | 另一組計數；`>= 12` 就不再派支援（`docs/re/169`）|
| `ds:D58E` | 32 × byte | **這一格要幾支** |
| `ds:D5AE` | 32 × byte | **這一格有幾支** |
| `ds:D5CE` | 32 × word | 回合開頭一起清 0，還沒追到讀取點 |
| `ds:D60E` | byte | 回合開頭寫 0 |

`D58E`／`D5AE` 是一對，判準是 `2E54:088F(星域)`：

```
若 D58E[星域] <= D5AE[星域]：回 0FFh          ; 夠了
若 星域是 0 或 31（兩邊的首都）：回 0
回 D5AE[星域] × 100 ÷ D58E[星域]              ; 滿足率（百分比）
```

「要幾支 vs 有幾支」是**強推論**——名字是從這個算式與 `2E54:0978` 的
「`D58E != 0` 才處理」推的，還沒有直接寫入點的證據。

## `2E54:000C` ＝ 回合進入點

```
3C9C:000A(ds:D50E, 0, 64)      ; 32 word
3C9C:000A(ds:D5CE, 0, 64)
3C9C:000A(ds:D54E, 0, 64)
ds:D60E = 0
2E54:005D()                    ; 逐艦隊決定（docs/re/79）
2E54:1A76()                    ; 未讀
2E54:019F()                    ; 填 ds:D50E
```

## `2E54:019F` ＝ 算每一格的優先度

```
首都 = 3982:0329(ds:8F1D)
2B99:0392(首都, ds:8F1D, &旗標[32])          ; 從首都能不能走到
對 i = 0 … 31：
    若 旗標[i] == 0：D50E[i] = 0
    否則若 星域[i][+0x12]（擁有者） != ds:8F1D：D50E[i] = 0
    否則 D50E[i] = 2E54:0222(星域記錄)        ; 未讀
```

只有**與首都連通的我方星域**會拿到非 0 的優先度。

## `2E54:0978` ＝ re/167 缺的那個呼叫者

```
陣列 = [0, 1, 2, … 31]
3C6A:000D(陣列, 32, 1, 2E54:09EE)            ; qsort
對排序後的每個星域 r：
    若 ds:D58E[r] != 0：2E54:0AAB(r)
```

比較函式 `2E54:09EE` 比的是 `ds:D50E[星域]`，**降冪**——
**優先度最高的星域先派兵**。

它自己被 `2E54:08D2` 呼叫，那支只有三行：

```
2D54:0000()      ; 也會清並填 ds:D50E，另一條路（未讀）
2E54:08E3()      ; 未讀
2E54:0978()
```

## `2E54:0BEB` ＝ 第三條路

`docs/re/167` 說 `2E54:0AAB` 差得多時走 `2E54:0BEB`。它很短：

```
2E54:0BEB(陣列, 個數, 目標星域):
    若 3CD5:000C() % 5 == 0：2E54:0C27(陣列, 個數, 目標)   ; 五分之一
    否則：                    2E54:0C83(陣列, 個數, 目標)
```

兩支的差別只有篩不篩：

| | 條件 | 動作 |
|---|---|---|
| `2E54:0C27` | 只對 `+0x79 == 6`（已經到了）的 | `+0x08 = 1`、`+0x07 = 目標`、`+0x79 = 1` |
| `2E54:0C83` | 陣列裡每一支 | 同上 |

所以「差得多」的時候有五分之一的機率**只叫得動已經在那裡的**，
其餘五分之四整批派過去。
