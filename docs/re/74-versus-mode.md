# 主選單第 2 列「對戰」通到哪裡

主選單四列是 **帝國／同盟／對戰／取進度**（`docs/internals/data/screen-main-menu.json`）。
第 2 列一直沒走過，這一輪走完前兩步。

執行器 dosgolem-logh3 `20e4583`。

## 第一步：一樣要過防拷（收據 `vs1`）

點第 2 列（滑鼠 `300,210` ＝ 畫面 `300,250`）之後開出的是**防拷問答**，
與第 0／1 列同一張版面（`docs/re/08`）：

```
請查閱提督資料表
輸入照片上帝國軍提督
占領能力數值：            ▕確認▏
```

照片是萊因哈特，問的是**占領**（`ADMIRAL.DT*` 的 `+0x19`）＝ 126。
第 0 列那張問的是別的欄位（答案 138），所以**問題是隨機或輪替的**，
不是固定一題——remake 目前只實作了收據上那一題，這裡要放寬。

## 第二步：兩邊輪流下命令（收據 `vs2`）

答對之後進的是**戰略地圖介面**，上面疊一個視窗：

```
帝國軍的戰略輸入
                          ▕確認▏
```

視窗約 (128,180)–(479,287)，「確認」在 (400,262) 那一帶。

所以「對戰」＝ 兩個人輪流玩：先跳「帝國軍的戰略輸入」，
帝國那邊下完命令按確認，再換同盟。地圖、命令列、右側面板與單人模式
看起來是同一套。

## 還沒做

- 按下「確認」之後是不是換「同盟軍的戰略輸入」（假設待驗）。
- 兩邊的命令怎麼交替、實行的時機。
- 防拷問答的題目是怎麼選的（哪一位提督、哪一個欄位）——
  這條擋著 remake 走這條路，因為現在只答得出一題。
