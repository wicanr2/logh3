# 133 — 戰場上點行星開的命令選單（`1D9E:01F1`）

`docs/re/117` 記下「行星另有 `ds:42EA` 與 `ds:4318` 兩張表、分派用
`ds:4396` 的跳躍表，開的時機還沒查」。這一輪把那一段讀完。

## 怎麼找到的

`ds:42EA`／`ds:4318`／`ds:4396` **沒有任何 `mov r16, imm16` 或 `push imm16`
載入它們**——先拿已知答案做正對照（`ds:C074` 97 處、`ds:4120` 1 處、
`ds:59BA` 1 處，`tools/scripts/find_imm.py`），確認掃描器沒壞，再改掃
原始的兩個位元組（`tools/scripts/find_word.py`）：

```
線性 1DC00   C7 46 0A EA 42     mov word ptr [bp+0Ah], 42EAh
線性 1DC12   C7 46 0A 18 43     mov word ptr [bp+0Ah], 4318h
線性 1DD26   FF A7 96 43        jmp word ptr [bx+4396h]
```

**表位址是寫進區域變數的，不是載進暫存器**，所以只掃 `mov reg, imm`
會得到假零。

段值也要從跳躍表反推：表裡是 `0348 0357 0366 0375`（四個近位移，
間隔 15），而那四個 case 在線性 `1DD28`／`1DD37`／`1DD46`／`1DD55`。
`1DD28 − 0348` ＝ `1D9E0`，所以這一段的段值是 **`1D9E`**，
整支函式從 `1D9E:01F1` 開始。

## 開哪一張

```
行星 = ds:CFF8 + (索引 & 0x7FFF) × 0x52     ; 行星記錄 82 bytes
若 行星[+0x12] == 0：表 = ds:42EA、3 項、內寬 2
否則              ：表 = ds:4318、4 項、內寬 3
```

`+0x12` 是**要塞旗標**：81 顆行星裡有 8 顆非 0——伊謝爾倫、連典貝爾克、
禿鷹之城、格魯米遜、葛羅斯達、帕謬爾、梅爾格利德、魯德米拉。
同一格戰損那邊讀成「除數從 10 變 20」（`docs/internals/29`），
兩個讀法指的是同一件事：**那顆有要塞**。

四項那張的前三個名稱在**字串裡就補了半形空白**（`情報  `、`補給  `、
`補充  `），不是繪製時補的——內寬 3 要湊滿 6 個半形格。

## 哪一項可以選

```
三（或四）項先全開
若 行星[+0x11]（擁有者）!= ds:8F1D（玩家陣營）：
    關掉「補給」「補充」（有要塞的連「要塞砲」一起關）
否則若 行星[+0x12] != 0 且 行星[+0x45] != 0 且 行星[+0x45] != 3：
    關掉「要塞砲」
```

所以**別人的行星只剩「情報」**。`+0x45` 是要塞砲自己的狀態，開局那份
81 顆全是 0（也就是可以打）；它什麼時候變成別的值還沒解。

點得動的條件沒有陣營限制——`docs/re/117` 記的「索引最高位元設起來
代表點到的是行星，一律可以」在這裡對上了。

## 四項各自去哪

`ds:4396` 是四個近位移的跳躍表，對到本段的四個 stub：

| 項目 | stub | 呼叫 |
|---|---|---|
| 情報 | `1D9E:0348` | `1373:1C71(行星)` |
| 補給 | `1D9E:0357` | `1930:0DA2(行星)` |
| 補充 | `1D9E:0366` | `1AAB:0A33(行星)` |
| 要塞砲 | `1D9E:0375` | `2264:0049(行星)` |

補給落在 `1930`（戰場「補給」同一段）、補充落在 `1AAB`（「修理」同一段），
分工與艦艇那邊對稱。**四支都還沒逆向。**
