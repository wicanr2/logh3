# 237 — 艦隊 `+0x0C`（移動一格的花費）就是「另一項費用」那條算式

`docs/internals/33` 早就記著「`+0x0C` ＝ 移動一格的花費，從
`ds:8F52[陣營]` 那筆存量扣（`113A:06C3`）」，但**那個數怎麼來的**沒解；
`docs/re/218` 解出維持費算式時順手看到艦種列還有第二個「每艘費用」
（`+0x05`），remake 把它做成 `rules.FleetOtherCost`，註解寫「項目名稱
還沒解」。兩件事是同一件。

## 三個數把它釘死

收據 `turn260mem` 的三支艦隊記錄：

| 提督 | `+0x0A`（維持費）| `+0x0C` |
|---|---|---|
| 47 | 217 | **263** |
| 52 | 85 | **95** |
| 55 | 124 | **134** |

收據 `monthend` 對軍事費設監看，第一個 AI 回合之後：

```
#216008954  45848 → 45631   −217   ← 056A:0A3C   維持費
#216011252  45631 → 45546   −85    ← 056A:0A3C
#216013520  45546 → 45422   −124   ← 056A:0A3C
#216019528  45422 → 45159   −263   ← 113A:0729   移動
#216275108  45159 → 45064   −95    ← 113A:0729
#216524280  45064 → 44930   −134   ← 113A:0729
```

remake 的 `rules.FleetOtherCost`（同一條算式，只是讀艦種列的 `+0x05`
而不是 `+0x04`）對那三支算出來是 **95／134／263**——與 `+0x0C` 逐一
相同，也與監看到的三筆扣款相同。

```
花費 = Σ(艦種列[+0x05] × 艘數) ÷ 1000 × (200 − 艦隊[+0x47]) ÷ 100
```

**營運越高，走一格越便宜**，與維持費同一個係數。

## remake

`Game.advanceTurn` 原本呼叫 `StarGraph.MoveFleets`（只回「幾支動了」），
改成逐支 `Advance`，動了就扣：

```go
g.military[f.Faction] -= rules.FleetOtherCost(
    g.res.ShipKinds, f.Faction, f.Composition, f.Operations)
```

接上兩筆扣款之後，第一個 AI 回合跑完同盟的軍事費是

```
45848 − 426（維持費）− 492（移動）= 44930
```

**44930 正是第二個 AI 回合那份傾印（`refit2_pre.bin`）裡
`ds:8F52[同盟]` 的值**，釘在 `TestFirstAITurnMatchesReceipt`。

## 一條方法

**「這個欄位怎麼算的」與「這條算式是算什麼的」常常是同一題的兩半。**
`+0x0C` 有名字沒算式，`FleetOtherCost` 有算式沒名字，兩邊各掛了幾個月。
接起來只花了一次比對——**手上未命名的算式與未解的欄位，值得先兩兩對一遍。**
