# RE 16 — 命令介面打不開的兩個原因，以及右鍵

日期：2026-09-07
執行器：dosgolem-logh3（本輪加了 `-rclicks`，見 `dosgolem docs/spec/016`）
輸入：原版未修改 `GIN3.COM`（SHA-256 見 re/01）
狀態：**已解**。開局的月初報告關得掉了，命令列三個項目都點得到。

## 問題

`docs/internals/23` 解出 25 份熱區清單，標籤看得出遊戲還有戰略命令、
一覽表、系統指令、艦隊編成、出擊、陣形、占領／待命一整套介面。
但拿規則算出來的座標去點，**全部 0 差異**。

## 先把「清單怎麼被選中」搞清楚

命中測試是 `call far 37A9:01F9`（`9A F9 01 A9 37`）。掃整份記憶體找到
**27 處呼叫**，每一處都在前 40 bytes 內用 `1E BB <位移> 53`
把清單位移**寫死**（`tools/scripts/hittest_scan.py`）。

所以沒有「目前視窗」這種變數可以改。要讓另一份清單生效，
只能走到那一段程式碼所在的迴圈裡。

參數順序是「清單先 push、視窗後 push」；視窗本身也可能是靜態結構、
用同一個寫法 push，所以同時抓到兩個時，清單是**位址較小**的那一個。
第一版沒分這件事，`0C52` 那一處被讀成 `955C`——那是它的視窗，不是清單。

## 命中測試會先問「這個座標最上層是誰」

`37A9:01F9` 的前 20 個位元組就講完了：

```
mov di,[bp+14] / push [bp+16] / push di
call far 341B:039D          ; 用座標找視窗
mov cx,[bp+0E] / mov si,[bp+0C]
cmp ax,cx / cmp bx,si
jne → xor ax,ax; xor bx,bx  ; 找到的視窗 ≠ 傳進來的視窗 → 回 0
```

`341B:039D` 沿視窗串列走，回傳第一個滿足
`+0 == 2 且 格x ∈ [+5, +5++7) 且 格y ∈ [+6, +6++8)` 的視窗。
串列頭在 `ds:D804`／`ds:D806`，下一個在結構的 `+0x16`／`+0x18`。

走一遍（`tools/scripts/window_list.py`）：開局有 6 個視窗，
最上層是月初報告視窗，命中範圍 x 144–495、y 40–359。

**兩個原因同時成立**：命令列 (352,80)、(448,80) 被報告視窗蓋住；
(544,80) 雖然露在外面，但那時跑的是報告視窗自己的 modal 迴圈，
它傳進去的視窗是報告視窗，對不上。

## 右鍵

報告視窗的迴圈長這樣：

```
06CF0  push 0 / push ss / push bp
       call far 3765:0036        ; 取事件
       cmp ax,1 → 命中測試
       cmp ax,2 → si=1（跳出迴圈）
       or si,si / jz 回去等下一個事件
```

`type` 由滑鼠回呼從按鍵狀態位元換算（`36FA7`）：bit7 換出 1／4，
bit5 換出 2／8。bit5 就是右鍵，**`type==2` ＝ 右鍵放開 ＝ 離開這個畫面**。

`dosgolem` 當時只送左鍵，所以這條路整個走不到。加上右鍵
（`-rclicks`，`docs/spec/016`）之後：

| 動作 | 結果 |
|---|---|
| 主畫面右鍵 ×1 | 會計報告 → 船艦訂造報告 |
| 主畫面右鍵 ×2 | 報告視窗關掉，**露出完整的戰略地圖介面** |
| 再右鍵 | 0 差異（主畫面沒有上一層可回）|

關掉之後點命令列：

| 點 | 開出什麼 |
|---|---|
| (352,80) | **情報收集／徵稅計劃／生產計劃** |
| (448,80) | 一覽表選單 |
| (544,80) | **取進度／存進度／設定／結束** |

## 主畫面有什麼

報告關掉之後看得到的東西（`workplace/bp/r2.png`）：

```
帝國軍  宇宙曆 796 年 1 月 1 日
軍事費  45592   總稅收 10341
[戰略命令] [一覽表] [系統指令]
帝國軍星系 瓦爾哈拉
  治安 82%   行星 4/4   艦隊 0:0
  防衛力 27300
  經濟力 82302  成長率 4.5%
  徵稅額 2633   稅率 3.2%
```

**日期就在畫面上**（796 年 1 月 1 日），所以推進月份不再需要先找出
回合計數存在哪——先走完一個月的命令流程就會知道它怎麼變。

## 教訓

「畫面完全不動」在這個遊戲有四種成因（事件沒進佇列、modal 迴圈不認、
座標最上層是別的視窗、清單裡沒有那一格），四種的外觀完全一樣。
之前把它們當成同一件事在掃座標，掃再多也不會中——
**要先把「一次點擊要過幾關」畫出來，再決定量哪一關**。
