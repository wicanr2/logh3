# 179 — 選哪一組路線：伊謝爾倫 × 費沙 × 一個旗標，十二種態勢

`docs/re/178` 把進軍路線表走出來，但「選哪一組」的 `2D54:0163()` 沒讀，
而且當時假定表有 8 組。兩件事這一輪都有答案：**表有 12 組**，
而 `2D54:0163()` 回的就是 0–11 的**戰略態勢碼**。

## `2D54:0163() → 0–11`

它只看三件事：**伊謝爾倫（星域 13，`ds:AE02`）在誰手上、
費沙（星域 14，`ds:AE80`）在誰手上、`ds:8F48` 有沒有設**。

**整個戰略 AI 的「現在該打哪裡」只由這兩顆星域的歸屬決定。**
路線表對得上：

- 帝國 `n=0`（伊謝爾倫已是自己的、費沙還沒開放）→ 三條直取巴拉特的路線
- 帝國 `n=4`／`n=8`（伊謝爾倫在同盟手上／不在自己手上）→ 只有 `[13]`
- 同盟 `n=0`（伊謝爾倫是帝國的）→ 只有 `[13]`
- 同盟 `n=4`（伊謝爾倫是自己的）→ 兩條打向瓦爾哈拉

**兵推的第一目標永遠是伊謝爾倫，拿到才談推進**——這不是設計者另外寫的
規則，是態勢碼與路線表的組合。

## 更正 `docs/re/178`

那一篇寫「各 8 組」。實際是 **12 組**：`ds:5EF2` 佔
`0x5EF2`–`0x5F21`（12 × 4），接著 `ds:5F22` 佔 `0x5F22`–`0x5F51`，
再接著就是 `ds:5F52`（艦隊類別表，`docs/re/169`）——三張表首尾相接，
邊界互相印證。`tools/scripts/ai_script_lists.py` 與
`data/ai-advance-routes.json` 已經改成 12 組。

## `ds:8F48` 是誰設的

唯一寫入點在 `0x12397`，而且是它所在那支常式（`0x1238D`）的**第一件事**：

```
0x1238D: push bp/si/di; sub sp,22h; mov bp,sp
         ds:8F48 = 1
         2AF5:0036(&緩衝, 0Eh, 0)        ; 0Eh ＝ 14 ＝ 費沙
         …
```

一開頭就設旗標、緊接著處理費沙——**這是「費沙進入戰局」的事件**
（強推論；那支常式本身還沒讀完）。

## `2E54:13A8(星域)` ＝ 前進基地

`docs/re/177` 留下的階段五目標：

```
鄰居 = 2B99:03D9(星域, …, ds:8F1D)
首都 = 3982:0329(ds:8F1D)
最佳 = 0FFFFh
對每個鄰居 r：
    d = 2B99:028F(r, 首都, ds:8F1D)
    若 d >= 最佳：跳過
    若 星域[r][+0x12] != ds:8F1D：跳過        ; 只挑自己的
    最佳 = d；答案 = r
回 答案
```

**在目標格的鄰居裡挑「屬於自己、離自己首都最近」的那一格**——
與 `2E54:1955`（沒事做就往首都方向退一格，`docs/re/164`）是同一個形狀，
方向相反：那一支是退，這一支是找**前進基地**。
