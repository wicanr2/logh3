# RE 79 — 一支逐艦隊決定要做什麼的迴圈（`2E54:005D`）

執行器 dosgolem-logh3 `20e4583`；材料是 `s2ai0` 的 1 MB dump，
工具 `tools/scripts/find_writers.py`（找寫 `+0x07`／`+0x08` 的指令）、
`callchain.py`（往上追）、`ida_trace.py`（反組譯）。

`docs/re/78` 列的候選名單裡，`2E65F`（寫 `+0x07`）與 `2E656`（寫 `+0x08 = 3`）
落在同一支函式 `2E54:005D`。

## 它做什麼（從程式讀出來，**confirmed**）

```
0069  指標 = ds:C074，i = 0
0071  i < 32
007F  +0x04 == FF → 跳過
008C  cmp 艦隊的 +0x01, ds:8F1D      ; ★ 只處理這個陣營的艦隊
0098  +0x79 = 0FFh                   ; 先標成「還沒決定」
00A1  星域記錄 = ds:A79C + [+0x06]×126
00B9  if +0x08 == 4 → +0x79 = 0、ds:D60E++、下一支
00D1  test 艦隊 +0x00, 1
      ├─ bit0 = 1：
      │   00DE  對方在這一格的艦隊數（陣營 0 讀 +0x29、陣營 1 讀 +0x28）
      │   00F7  test 星域 +0x13, 14h
      │   00FE  對方艦隊數 == 0？
      │   0104  星域擁有者 +0x12 == 自己？
      │        三個條件都成立 →  +0x08 = 3
      │                          +0x07 = +0x06   ★ 目的地 ＝ 現在這一格
      │        否則 → call 2E54:1955、+0x79 = 0、ds:D60E++
      └─ bit0 = 0：
          0143  test 星域 +0x13, 4
          014A  call 2E54:16F5 → ax
                ax != 0 → +0x79 = 3、`[星域×2 - 2A32h]`++、ds:D60E++
                ax == 0 → call 2E54:1955、+0x79 = 0、ds:D60E++
0191  指標 += 7Ah，下一支
```

## 讀出來的新事實

- **`+0x79`（記錄的最後一個 byte）是「這回合的決定」**：先填 `0xFF`，
  再依情況改成 0 或 3。
- **`ds:8F1D` 是「現在處理哪一個陣營」**（`docs/re/48` 早就注意到它與
  玩家有關）。這一趟是**逐陣營跑的**。
- **`+0x08` 還有 3 與 4 兩種狀態**：4 在這裡被當成「跳過」，3 是這一支
  自己寫的。加上先前確認的 5（不動）與 0／1（會走），至少五種。
- `+0x08 = 3` 那一支同時把 **`+0x07` 設成自己現在的星域**——等於
  「就地待命」。發生條件是：這一格是自己的、對方在這一格沒有艦隊、
  而且星域 `+0x13` 的 bit2／bit4 都沒設。
- `ds:D60E` 是這一趟「決定了幾支」的計數器。
- `[星域×2 - 0x2A32]` 是一張**依星域索引的 word 陣列**，某個條件成立時 ++。

## 這是不是 AI

形狀完全吻合：**逐陣營、逐艦隊、看敵我與地盤、寫出一個決定碼**。
但「這就是電腦的 AI」目前是 **strong inference，不是 confirmed**——
還沒有證據說明這一趟只在電腦那一方跑、或者玩家那一方也走同一支。

要釘死的作法：對 `ds:8F1D` 與 `ds:D60E` 設監看跑一個局面，看它在
「實行」的哪個階段被設成 0 與 1、各跑幾次。

## `2E54:16F5`：先看是不是在自己首都，再比周邊

```
1700  星域記錄 = ds:A79C + 艦隊 +0x06 × 126
171B  陣營 == 0 且 星域 == 0   → 回 1        ; 帝國在瓦爾哈拉
1735  陣營 == 1 且 星域 == 1Fh → 回 1        ; 同盟在巴拉特
174D  否則：
      call 297B:131C(緩衝區, 星域, 1)        ; 蒐集這一格的某種清單
      call 297B:131C(緩衝區2, 星域, 2)       ; 另一種
      call 3982:0250(陣營)                   ; 陣營相關（3982:0329 是首都）
      call 2E54:1876(星域, 陣營, 緩衝區) ×2  ; 兩邊各算一次再比
```

前兩個分支是「這一支就在自己的首都」。之後那一段**蒐集這一格的周邊
資料，對兩個陣營各算一次再比**——形狀就是「這裡我方還是敵方佔優」。
`docs/re/79` 上面那個迴圈拿它的回值決定 `+0x79` 要不要填 3。
