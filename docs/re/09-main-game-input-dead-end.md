# RE 09 — 遊戲本體的輸入：事件送得進去，畫面不動

日期：2026-09-06
執行器：dosgolem-logh3（`-watch-screen`／`-keys-at`／`-dump-at` 這批工具）
狀態：**未解**。這一篇記的是已經排除掉什麼，免得下一輪重走。

## 現象

走到 796 年 1 月的主畫面之後（會計報告蓋在上面），畫面在第 124M 道指令
穩定下來，之後**對任何輸入都沒有反應**。

## 事件確實送到了（confirmed）

遊戲有自己的事件佇列，不是直接讀 `int 33h`：

```
3765:00BF  取事件
  00CC  cmp word [F24C],0    ; 佇列長度
  00D1  jnz 00D6             ; 空的就回傳「沒有事件」
  00D6  les bx,[F248]        ; 頭指標，一筆 12 bytes
  0110  add word [F248],0C
36AD:0568  mov [F24C],ax     ; 入隊（環狀，容量 16）
```

滑鼠回呼與鍵盤 ISR 都會入隊。實測點擊 (448,350)，佇列裡拿到：

```
筆 0：type=1（按下） 448 350
筆 1：type=4（放開） 448 350
```

座標正確、型別正確、主迴圈也把它取走了（`[F24C]` 從 1 變回 0）。
`0654:07B0` 的主迴圈對 type 1 會呼叫 `0654:07F7` 處理。

## 已經排除的（都有實驗反證）

| 假說 | 反證 |
|---|---|
| 點擊沒送到 | 佇列裡有正確的 type 與座標 |
| 沒送移動事件、游標位置不同步 | 補送 `EvMove` 之後行為不變 |
| 位置不對 | 7×4 網格共 28 個位置全掃過，畫面零變化 |
| 星球圖示才是熱區 | 8 個星球位置全試過 |
| 要按鍵 | space／esc／enter／方向鍵／數字全試過 |
| 音樂沒跑起來 | `-adlib` 後行為不變 |
| 垂直回掃卡住 | `3DAh` 的回掃位元本來就會變（machine_test 有釘） |

## 順帶拿到的兩張畫面

- **輸入中的回饋**：防拷問答打字時，數字顯示在提示下方
  （收據 `typed138`，量到 x 243 起、字距 16、y 267）。
- **主畫面的中間幀**：地圖與面板畫好、報告視窗還沒蓋上去的那一格
  （第 167–172M 之間）。一開始誤以為是「關掉報告之後的畫面」——
  其實遊戲從來沒讓人關掉它。

## 下一步的方向

反組譯 `0654:07F7`（事件處理）與它拿到的 `[bp+14..1A]`（handler 指標），
看主畫面到底把事件派給誰。目前的猜測是那裡根本沒有註冊 handler，
也就是遊戲還在等別的東西才會進入可互動狀態——但那是**猜測**，
還沒有證據。
