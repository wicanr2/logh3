## 二、第 2 回合：同盟新建的艦隊不同

`fcx-funds2-*` 倒艦隊表（`lin:60BA4:3904`）與維持費／移動費累計（`ds:8F7A`、`ds:8F8A`）：原版第 2 回合同盟在槽 20 新建第５艦隊，
提督 44、七組（艦種 0／0／0／2／4／4／6）、維持費 144、移動費 167；remake 選提督 43、七組（1×5／5／6）、210／238。
兩項差 66 ＋ 71 ＝ 137，正是軍事費的差（P）。remake 的候選提督過濾原本就標著未解（`internal/ai/original_buildpass.go`

（原版 `747E527D`，P）。兩者都還沒處理（issue）。

## 三、第 3 回合：電腦的艦隊走不進無主星域

原版第 3 回合同盟第 13、16 艦隊（槽 28、31）從 29 走進馬爾・亞迪特（24，無主），命令 `+0x08 = 1`（占領）；remake 的兩支停在 29、
目的地清掉。成因：`Game.runBrain` 套 `ai.Order` 時只寫 `Target` 與 `Parked = false`，**沒寫 `+0x08`**，所以電腦的艦隊命令一直是
開局的 5；走一格的判定（`113A:047D +0514`）下一格不是自己的、命令又不是占領 → 「無法前往敵方的星系」清命令停駐（P，remake 行為）。

原版每一條下命令的路都寫 `+0x08`（`docs/internals/54`，位元組先前已讀）：

| 路 | 原版 | 寫的命令 |
|---|---|---|
| 逐艦隊決定，退一格 | `2E54:1955` | 0（找不到就 5） |
| 逐艦隊決定，原地出擊 | `2E54:005D` | 3、`+0x07 ← +0x06` |
| 階段二，打最近的無主星域 | `2E54:1108` → `1B17(f, 1, 星域)` | 1 |
| 階段三，按缺口補 | `2E54:07D8` → `1B17(f, 0, 星域)` | 0 |
| 階段五，回首都 | `2E54:1243` → `1B17(f, 2, 首都)` | 2 |
| 階段五，往前進基地 | `2E54:1243` → `1B17(f, 3 或 0, 目標)` | 士氣 < 60 或原本是 3 → 3，否則 0 |

`2E54:1B17(艦隊, 行動, 星域)`：艦隊已在那一格 → `+0x08 = 5`、`+0x07 = 0xFF`（原本不是 5 才寫）；否則照寫。

## 四、remake

- `ai.Order` 加 `Move`（寫進 `+0x08` 的值）與 `Direct`（逐艦隊決定那兩條直接寫，其餘走 `1B17`）；`original_turn.go` 各階段照上表填；
  `fleetAction` 回艦隊記錄的命令（原本只分 5／0）。
- `Game.runBrain`：`1B17` 那幾條在目標格就停駐，否則寫 `Target`／`Move`／`Parked`。
- 效果：電腦的艦隊會走進無主與敵方星域、打行星、拿下行星（易主報告與攻占訊息框會出現）。月底兩支收據測試裡星域 24／28 的擁有者
  與原版一致了；無主星域 23 換成被 remake 的同盟艦隊走過（付移動費，經濟力、成長率、稅率跟著變），因為第二節的建艦隊還沒對齊——
  測試改成「同盟艦隊待過的格子只印不比」（`markAllianceVisits`）。
