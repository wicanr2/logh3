# 129 — 行程額度逐位元對上了（轉向與前進在同一次呼叫裡）

`docs/re/128` 拿三個假設去湊十一份傾印，最接近的一個差 0.02，並把那 0.02
講成開根號的捨去。實際上差 0.02 的那個假設是錯的：把 `1C03:01B5` 逐行讀完
之後算出來的數字與收據**完全相同**。

## 一次呼叫做兩件事

`1C03:01B5` 讀到底：

```
方位 = 2BE1:011D(目的地 − 現在)
若 方位 != +0x4A：
    1C03:0524(艦隊, 方位)            ; 轉一步
    回 1 → +0x49 |= 1
                                     ; ← 不管回什麼，都往下走
若 (32 位元) +0x58:+0x56 < 8：結束
距離 = 3310:0006(現在, 目的地)
若 距離 > 8：(nx,ny) = 2BE1:026F(現在, +0x4A, 8)
否則        ：(nx,ny) = 目的地
d = 3310:0006(現在, (nx,ny))；d = 0 就當 1
+0x58:+0x56 −= d
r = 2583:040C(nx, ny, +0x01)
若 r == 0     ：+0x5C/+0x5E ← (nx,ny)
否則若 r == FFFF：2583:0451(&+0x5C, &+0x5E, 8, 陣營)   ; 地形擋住時的處置
```

`+0x0214` 的 `jnz` 跳到 `+0x0222`，而那正是不跳也會走到的地方——**轉向之後
不會回去，同一次呼叫接著就前進**。所以前進用的是**轉完之後**的朝向。

## 轉一步（`1C03:0524`）

```
差 = 2BE1:021B(方位, +0x4A)          ; (方位 − 朝向) 正規化到 −128..127
若 |差| <= +0x4D（回轉速度）：
    +0x4A += 差                      ; 一次轉到位，回 1，**不扣**
否則：
    若 +0x58:+0x56 < 8：回 0         ; 不轉也不扣
    +0x4A += sign(差) × +0x4D
    +0x58:+0x56 −= 8.0               ; sub si / sbb cx，si=0、cx=8 → 0x00080000
    回 1
```

`2BE1:021B(a, b)` 就是 `a − b` 之後，≥ 0x80 減 0x100、≤ 0xFF80 加 0x100。

每回合行程 160.0）。目的地 (1240,840) 減現在 (1330,941) ＝ (−90,−101)，
方位 163；開場朝向 190。

(−3,−7) ＝ 7.6157 與後面 18 次的 7.8102 差不多，所以用平均步長去湊會得到
「20 步、轉向不扣」這種看起來只差 0.02 的假答案。

## 距離的捨去

`3310:0006` ＝ `M × √(1 + (m/M)²)`，`M` 是兩軸差的大者：

```
q = (m << 16) / M          ; 39B5:005C，截斷
r = 1.0 + (q × q >> 16)    ; 39B5:000C，截斷
d = M × sqrt16(r)          ; 3310:014B
```

`sqrt16` 就是 `docs/re/94` 已經逆向過的那支牛頓法（remake 的
`rules.fixSqrt`），拿這一回合的兩個值餵進去**逐位元相同**：
`r` ＝ 77572 → 71300（浮點 71300.44）、`r` ＝ 111046 → 85308
（浮點 85307.98）。一個往下一個往上，所以不是截斷；牛頓法收在
「下一次不再變小」那一步，剛好落在這兩個值上。

## 位置為什麼一格沒動

`+0x02EE` 先扣、`+0x0303` 才問 `2583:040C`。這一回合 19 次前進全部被擋
（回傳非 0），所以額度燒光而 `+0x5C`／`+0x5E` 沒變。被擋的原因（地形
還是有單位）沒分開——`r == 0xFFFF` 那條會再叫 `2583:0451`，那支還沒讀。

## 這一輪學到的

**「差 0.02」不是吻合，是還沒讀完。** 定點運算的答案要嘛逐位元相同，
要嘛就是模型不對；拿「捨去累積」去解釋殘差，等於替錯的模型找台階。
`s3fltseq` 那十一份傾印一開始就足以判定，缺的是把 `1C03:01B5` 讀到底。
