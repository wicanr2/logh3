## 結論

1. 清單那一列「第」前面的記號是**字**，不是圖：`ds:1A66` 那張 3 bytes 一格的
   表依艦隊 `+0x08` 查（移動 ☆、占領 紅☆、駐留 ＊、輸送 ◎、返航 ○），停駐再看
   星域旗標（有戰鬥 紅▼、bit4 紅▽、否則空白）；右邊那個數字是**士氣值**
   `+0x3C`（低於 50 變紅）。
2. 目的地選現在位置再按決定 ＝ 取消命令，但**不算「有改」**：視窗留著
   （`fcmd-self-done` 與 `fcmd-win` 只差游標）。駐留是另一段程式：不看現在位置、
   一律寫 `+0x08 ← 2` 並關窗。輸送與移動同段，寫 3。
3. 下了命令按「實行」：走一格到亞爾提那、`+0x07 ← 0xFF`、`+0x08 ← 5`，**沒有**
   出發／到達的報告（`fcmd-exec`）。那一回合裡多了兩件先前 remake 沒有的事：
   - **軍事費花出去的錢流進行星的經濟力**（`2703:1C11`）：維持費的一半付給艦隊
     所在（自己的）星域、移動經費整筆付給離開的那一格（不是自己的就付給走到的
     那一格）；`090A:0E6D` 把行星加總回星域，首都 82302 → 82339、徵稅額
     2633 → 2634、總稅收 10341 → 10342。
   - **有自軍艦隊的星域在地圖上換另一張色表**（`3705:037F`）：擁有者色
     `ds:8BD2` {1, 12, 3} 換成 `ds:8BD6` {0, 2, 15}——帝國自己的星域駐了艦隊就
     **變黑**；反白格 `ds:F182` 用 `ds:8BDA` {6, 5, 7}。`docs/re/17` 只讀到

### 3.1 錢流進行星（`2703:1C11`）

監看首都四顆行星的記錄（線性 `53132` 起 4 × 82），只有 `+0x1A` 經濟力被
`2703:1CA4`／`1CCC` 加：兩趟，第一趟 6＋1＋1＋3 ＝ 11，第二趟 16＋3＋3＋2＋2 ＝ 26。
11 ＝ 維持費 22 的一半、26 ＝ 移動經費。呼叫者兩處（掃 `9A 11 1C 03 27`）：

- `056A:0A8D`（維持費常式 `056A:09EB` 裡）：`ds:8F52[陣營] -= +0x0A`、
  `ds:8F7A[陣營] += +0x0A`，然後**所在星域 `+0x12` == 艦隊陣營**才
  `2703:1C11(星域, +0x0A >> 1)`。
- `113A:0786`（`113A:06C3(艦隊, 現在格, 下一格)`，走一格的付費）：存量不夠回 0
  （呼叫端跳「由於移動經費不足無法移動」）；否則 `-= +0x0C`、`ds:8F8A += +0x0C`，
  **自己擁有現在這一格就付給它，否則付給下一格**，整筆。

`2703:1C11(星域, 金額)`：對那一格每顆行星 `經濟力 += 金額 × 行星[+0x13] ÷ 100`
（`+0x13` ＝ 佔該星域經濟力的整數百分比），餘數全給百分比最大的那一顆
（`jb` 嚴格小於才跳過 ＝ 相同時取後面那顆）。remake：`Planets.PayIntoRegion`。

星域記錄的 `+0x1A` 不是那裡改的：`090A:0E6D` → `2703:02E5` 每次都把行星
加總回去（`2703:034E`）、把預估稅 `ds:8F6A`／`8F6E` 歸零重累（`2703:0AB8`）、
再算未安定度——監看 `5F2E6` 只看到 `2703:0324` 一次寫入 7E → A3。remake：
`rules.ResumRegionEconomy` ＋ `refreshTaxEstimate` 併進 `recomputeUnrest`。

### 3.2 地圖顏色（`3705:037F`，`workplace/ida/fcx3705-map.txt`）

`fcmd-exec` 的亞爾提那那一格塗的是色 0（底圖的 3 與塗上去的 0 交錯成網點），
`tools/go.sh run ./cmd/mapcolours` 從畫面反推 32 格：`fcmd-exec` 只有星域 2 是 0；
S2 帝國視角（`s2empire`）的 2／7／8 是 0——正是艦隊表裡帝國艦隊所在的三格
（首都 0 另有反白色）。

```

    ds:8F1D 不是 0／1 → 色 0
    n = 星域[+0x28 + ds:8F1D]                 ; 看地圖那一方在這一格的艦隊數
    表 = n != 0 ? ds:8BD6 : ds:8BD2

3705:02BA()：ds:F182 != 0xFF 就用 8BD2／8BD6 把那一格塗回去；ds:F182 ← 0xFF
3705:0349(全部)：32 格各 037F；ds:F182 ← 0xFF；參數非 0 就 3705:0418（重畫視窗 F144）
```

`ds:8BD2` ＝ {01, 0C, 03}、`ds:8BD6` ＝ {00, 02, 0F}、`ds:8BDA` ＝ {06, 05, 07}。
目的地選取結束時（§四 of `re/312`）`3705:0349(0)` ＋ `3705:0284(ds:9588)`：
