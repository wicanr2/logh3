# 236 — 軍事費的收支帳：加稅收、扣造船、扣維持費、扣移動

`docs/spec/030` 把「電腦那一方的造船支出」記成「沒有模型」，
remake 只是讓兩邊跑同一套規則、開局的數字剛好對上。
對兩個陣營的軍事費設監看跑十二個回合，整本帳都出來了。

## 收據 `monthend`

`-watch 5DA82-5DA89`（`ds:8F52[0]` 與 `ds:8F52[1]`，各 32 位元），
5×10⁸ 條指令，走到第 7 回合。

```
#68622954   兩邊都設成 C350h ＝ 50000        ← 63A1:011B（載入）
#155493242  帝國 50000 → 60741               ← 2703:0430（＋總稅收）
#155493263  帝國 60741 → 45592               ← 0654:00D4（−造船費）
#210263317  同盟 50000 → 61087               ← 2703:0430
#210263338  同盟 61087 → 45848               ← 0654:00D4
```

**兩個陣營跑的是同一套開局結算**，只是各在自己的階段做。
同盟的 45848 與 remake 算出來的完全相同，所以那個「沒有模型」的
擔心可以收起來——**電腦那一方用的就是玩家那一套**。

## 每個回合還要扣兩筆

第一個 AI 回合（`#213725680`）建了三支艦隊之後：

```
#216008954  45848 → 45631   −217   ← 056A:0A3C
#216011252  45631 → 45546   −85    ← 056A:0A3C
#216013520  45546 → 45422   −124   ← 056A:0A3C
#216019528  45422 → 45159   −263   ← 113A:0729
#216275108  45159 → 45064   −95    ← 113A:0729
#216524280  45064 → 44930   −134   ← 113A:0729
```

**217／85／124 就是那三支的維持費**（`ds:8F72[同盟]` 合計 426，
`docs/re/218`、`docs/re/224`）。剩下的 263／95／134 是移動花費。
44930 與第二個 AI 回合的傾印一致（`refit2_pre.bin`）。

### `056A:09EB()` — 逐支扣維持費

線性 `0x0608B`，唯一呼叫者 `056A:002A`：

```
090A:0E6D()                               ; 顯示層
對 32 個艦隊槽：
    艦隊[+0x04] == 0FFh → 跳過
    n = 艦隊[+0x0A]（維持費，有號擴展成 32 位元）
    陣營 = 艦隊[+0x01]
    ds:8F52[陣營] -= n                    ; ← 0x060D8，監看抓到的那一行
    ds:8F7A[陣營] += n                    ; 已支付累計
    …（還有一段用星域表，沒讀）
```

**兩個陣營一起處理**——扣的是那一支艦隊自己的 `+0x01`，不是
`ds:8F1D`。所以這一支是回合結算的一部分，不是 AI 專屬。

### `113A:0729` — 移動花費

線性 `0x11A29`，在艦隊移動那一段（`docs/internals/33` 記過
「移動一格的花費，從 `ds:8F52[陣營]` 那筆存量扣（`113A:06C3`）」）。
六次扣款分散在 50 萬條指令裡，形狀就是逐支動畫移動。

## 順序

```
AI 回合（2D10:0005）
→ 056A:09EB 逐支扣維持費           #216.0M
→ 艦隊移動，逐支扣移動花費          #216.0M–#216.5M
→ 下一次「實行」
```

**`Blend` 的階梯讀的是扣款之前的軍事費**：第二個 AI 回合開頭量到的是
44930（`docs/re/222` 的分段函式回 1），與監看一致。

## remake

`Game.advanceTurn` 在 `runBrain()` 之後、艦隊移動之前補上

```go
for f := 0; f < 2; f++ { g.military[f] -= g.fleetUpkeep(f) }
```

釘在 `TestFirstAITurnMatchesReceipt`：第一個 AI 回合之後同盟的軍事費
是 45848 − 426 ＝ **45422**。

**移動花費還沒接**：remake 的艦隊移動沒有花費模型，艦隊記錄的 `+0x0C`
也還沒填。那是下一步。

## 一條方法

**「沒有模型」有兩種：不知道規則，和知道規則但沒接。** 這一格原本被
記成前者，量完發現是後者——電腦那一方的開局結算與玩家一模一樣，
只是還多兩筆每回合的扣款沒接。**分清楚這兩種，才知道下一步是去讀
還是去寫。**
