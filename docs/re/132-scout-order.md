# 132 — 艦隊選單的「索敵」（`1CC5:0966`）

三項裡最短的一支。讀完之後發現它其實是**放偵察隊 ＋ 借用分隊的
「移動」**，沒有自己的選點邏輯。

## 整支

```
1CC5:0966(艦隊 far ptr)
    艦隊[+0x3A] = 0
    艦隊[+0x3B] = 0                       ; ＝「已經放出去了」
    偵察隊 = ds:CFB4 + 艦隊[+0x38] × 78    ; +0x38 是索敵分遣隊的池索引
    偵察隊[+0x1E] = 3                      ; 行動 ← 歸隊
    偵察隊[+0x19] = 0x80                   ; 要畫航跡
    1727:0207(偵察隊)                      ; 下第一個航跡點
    25DB:0514(偵察隊)
    1CC5:0D1C(偵察隊)                      ; ← 分隊「移動」的選點常式
```

最後那一支就是命令選單「移動」用的同一個（`docs/internals/44`），所以
索敵之後畫面上會等玩家點一個目的地，點下去寫進偵察隊的
`+0x28`／`+0x2A` 並把 `+0x1E` 設成 0。

**偵察隊不在艦隊的編制表裡**（`+0x10` 那十個 4-byte 的槽），它單獨掛在
`+0x38`，所以開戰佈陣的時候不會出現在戰場上——下了「索敵」才登場。

`+0x3A`／`+0x3B` 是「能不能再索敵」的判準：`+0x3A == 0xFF && +0x3B == 0`
才算沒放過（`docs/internals/33`），所以寫 0 之後選單那一項就關掉了。

## 航跡：艦艇 `+0x19`

> 後續：`+0x19` 不是航跡而是**小地圖標記的狀態機**（bit7 要點、
> bit6 目前點著、低 4 位是點下去的顏色），`1727:0298` 是把同一點
> XOR 回去**擦掉**，不留線；下面「對不上的是 y」那 40 列的偏移在
> `3C5B:00B2` 裡面，代回去就是 `docs/re/89` 量到的小地圖座標
> （[`docs/re/154`](154-minimap-marker-not-a-trail.md)）。

`1727:0207(艦艇)`：

```
若 +0x19 bit7 沒設：回
若 +0x19 bit6 已設：回
若 ds:A426 == 0：回
色 = 陣營 0 → 5、陣營 1 → 9、其他 → 4
1727:0324(艦艇 +0x34, 艦艇 +0x36, 色)     ; 在那個點畫一下
+0x19 = 色 | 0xC0                          ; bit7 與 bit6 都設起來
+0x1A = 艦艇 +0x34
+0x1C = 艦艇 +0x36                         ; 記下畫在哪
```

所以 `+0x19` 是一個小狀態機：bit7「要畫」、bit6「畫過了」、低位是顏色；
`+0x1A`／`+0x1C` 是上一個航跡點。偵察隊一路走過去會留下一條線。

### `1727:0324`：一個點畫在縮小 1/16 的地方

```
1727:0324(x, y, 色)
    若 ds:A426 == 0：回
    39D7:08F4((x >> 4) + 0x1E0, (y >> 4) + 0x24, 色)
```

**不是畫在戰場上，是畫在縮小 16 倍的那一份。** 兩個線索指向小地圖：
`0x1E0` ＝ 480 正好是小地圖的 x（`docs/internals/34`），而顏色 5／9
就是小地圖畫分隊用的 `unit_ink`（帝國 5、同盟 9）。

`39D7:08F4(x, y, 色)` 本身沒有再加偏移：`3C5B:00B2(x, y)` 直接算出
framebuffer 位移，然後照 `2376:1810` 那一套 XOR 寫進去
（bit mask ＝ `0x80 >> (x & 7)`，`docs/re/135`）。

對不上的是 y：小地圖在畫面 y ＝ 75，這裡加的是 `0x24` ＝ 36。拿一個
世界 y ＝ 941 的單位算：航跡落在 941 ÷ 16 ＋ 36 ＝ **94**，而小地圖
自己畫那個單位是在 75 ＋ (941 ÷ 20) × 5/4 ≈ **134**——**差 40**。

40 這個數字在這個專案裡出現過好幾次（滑鼠的 `screen_y = mouse_y + 40`，
`docs/re/52`；戰場背景畫在 y ＝ 40）。但**範圍圖形那一條路徑沒有這個
偏移**（`3870:0296` 算出來的畫面座標與收據逐點對得上，`docs/re/135`），
所以不能直接套。**目標畫布與 y 的對應還沒定案**，remake 先不畫航跡；
要一張偵察隊走過幾步、航跡看得見的收據才能分開。
