## 結論

1. 艦隊編成視窗（`07F9:05B4`，出擊那條路與「變更 → 副官」共用）的「副官」鈕開
   兩項小選單 變更／卸任（`07F9:0A80`，框在格 (25,14)）。**卸任**：提督記錄
   `+0x07 ← 0xFF`、舊副官 `+0x09 ← 0x80`（閒置）、視窗上副官那兩列印成空白、頭像
   清掉、能力九格只看提督。**變更**：開「待命中副官資料」清單 → 點一列開那一位的
   提督詳細資料（與出擊命令那張同一支 `0D92:000D`，鈕仍印 經歷／中止／出擊）→
   「出擊」＝ 決定：`+0x07 ← 新副官`、舊副官 `+0x09 ← 0x80`、新副官 `+0x09 ← 提督
   的 +0x09`（同一個艦隊槽）；中止／右鍵不換。兩種都回艦隊編成視窗。
2. 候選 ＝ `28E0:0103(&清單, 提督[+0x0A], 0x65, 提督[+0x06])`：**同一個星域、同陣營、
   沒有職務（`+0x00 == 0xFF`）、閒置（`+0x09` bit7）、等級（`+0x06`）比帶隊提督低**，
   照提督表順序。萊因哈特（等級 29）在瓦爾哈拉有 35 人合格：在職幕僚（梅克林格、
   克斯拉、奧貝斯坦，`+0x09` ＝ 0x7F）與現任副官修特萊（`+0x09` ＝ 0x00）被 bit7 擋掉。
3. 只改**提督記錄**。艦隊記錄 `+0x05` 要到關掉「變更 → 副官」那張（`297B:04EF`
   抄 `+0x07`、`297B:0546` 重算營運、維持費、速度）才變；出擊那條路「決定」建艦隊
   時抄。卸任後營運 100（只剩提督）、維持費 30；換成米達麥亞後營運 102、維持費 29。
4. 出擊那條路的艦隊編成視窗**一開就把提督與副官的 `+0x09` 寫成這一支會拿到的槽**

   不是「決定」才寫。取消出擊時還原成什麼沒讀（remake 寫回 0x80，假設待驗）。
5. 清單元件（`0C0A`）在這條路上關掉之後，艦隊視窗右上角的**提督頭像不見**——頭像是
   直接貼的，不在視窗的文字緩衝區裡，清單關掉時底下從緩衝區重畫；要到關窗
   `0DEA:1846` 的 `3958:0215` 才重貼。

## 六、清單的右鍵（沒解）

同一個清單元件在出擊命令那條路右鍵就關（探索批次 `fcx-s3list-rclick`：`0C0A:0139`
那一支跑到、回地圖）。從「副官」進來的這一份，右鍵之後**清單留在畫面上、之後的
左鍵（點列、點結束）都沒有反應**，左下角摘要還被抹白（收據 `fcmd-adj-change-rclick`；
探索 `fcx-adj-list-rr`／`-rr-close`／`-rr-row`）。`-regs-at` 看到清單迴圈一直在
`3765:0036` 輪詢、每次回碼 0（沒有事件），`0C0A:0139`／`015D` 都沒跑到，而
int 33h 那邊的事件（右按 8、右放 16、之後的左按 2、左放 4）都送出去了；結束時
事件佇列 `ds:F244`／`F248` 相等、`ds:F24C` ＝ 0。事件去了哪裡沒讀。
remake 照元件本身的規則：右鍵關清單回視窗；那一批收據不比（規格 013 已知差異）。

事件佇列的形狀（`3765:00BF`，`0036` 只是它的包裝）：16 筆 × 12 bytes 的環在
`ds:F184`，`F248` 讀、`F244` 寫、`F24C` 筆數；碼 1 左按、2 右按、4 左放、8 右放，
一筆帶座標；佇列空時回碼 0 並填目前的游標位置。`3765:0255(鈕)` ＝「還按著？」：
掃佇列找那顆鈕的按／放，找到就回 0 並把兩筆清掉（`0307`）。
