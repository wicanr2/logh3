## COMANI記錄與消費端

proven：1DD6:0A17建立記錄，3958:0041實際讀取以下欄位。

| 記錄位移 | 來源／用途 |
|---|---|
| +0 | SHIP陣營；0畫左、其他畫右 |
| +1 | SHIP艦種 |
| +2 | 行動0攻擊、1中彈 |
| +3 | 攻擊取武器0／1／2；中彈取損失百分比<20／<40／其餘的0／1／2 |
| +4 | SHIP分隊序號；零走旗艦名字，非零走艦種名字 |
| +5 | FLEET提督+04，查DS:8E34；不是副官 |
| +6 | 音效byte，完整動畫且非FF才交3B74:031A；聲音內容仍未驗 |

初始靜圖不初始化+3／+6；本輪觀測到的殘留byte沒有作用，不能硬編碼88為音效。
static旗標使名字尾碼為D0；animate旗標決定畫首格或整段。
動畫關閉DS:8F36=0時3958直接返回，不讀圖段、播音效或畫圖。
完整中彈若actual=0，0A17:0AEC把animate清零，0B76直接跳過3958呼叫。
不能解釋成「零傷害重畫第0格」；這點由原始bytes確認，未另做零傷害完整場景動態樣本。
