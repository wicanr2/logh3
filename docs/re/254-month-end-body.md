# 254 — 月底結算的主體是 `2703:02E5`；`docs/re/35` 的「兩種稅」是兩趟不同的呼叫

`docs/re/253` 收回了「月底掛在 `2703:03AF`」。這一篇找到真正每個月會跑的
那一支，順帶解釋了 `docs/re/35` 量到的「兩種稅」為什麼會是兩個數。

## 怎麼找的

不追函式，追**變數**。`ds:8F6A` 是總稅收，月底一定會被歸零再累加，
所以直接監看它（`-watch 5DA9A-5DA9D`）跑一段真的會跨月的序列
（批次 `monthgate7`，用 `s3ai6` 那組已知可靠的點擊，另 poke
`ds:8F18 = 9` 讓第一次「實行」就跨月）。159 筆寫入，寫入者只有四種：

```
2703:02F7    6 次   ← 歸零
2703:0BC1  140 次   ← 逐格累加
2703:000F / 2703:0013  3 次   ← 載入時
```

`2703:02F7` 往回找函式開頭 → **`2703:02E5`（線性 `0x27315`）**。

## `2703:02E5`：月底結算的主體

```
2731C  ds:8F6A / ds:8F6C = 0            ; 總稅收歸零
27327  ds:8F6E / ds:8F70 = 0
2732E  for 星域 i in 0..31:             ; **32 格全部，不分陣營**
27341    ax:bx = 2703:034E(i)           ; 成長後的經濟力
2734B    星域[+1Ah] = ax:bx             ; 寫回
2735A    2703:0AB8(星域記錄, 0)          ; 收稅並累加到 ds:8F6A
27366    2703:0DA1(星域記錄)             ; 未安定度重算
```

逐格三件事的順序與 `docs/re/33` 從程式讀出來的完全一致
（成長 → 稅 → 星域經濟力），未安定度也在同一圈裡（`docs/re/43`）。

## 「兩種稅」是兩趟不同的呼叫

`docs/re/35` 量到「從行星身上扣的稅」與「進國庫的稅」不是同一個數，
差 9。結構上的原因看得到了——**`2703:0AB8` 被呼叫兩次，旗標不同**：

| 呼叫者 | 旗標 | 範圍 | 之後做什麼 |
|---|---|---|---|
| `2703:02E5` | **0** | 32 格全部 | 只累加到 `ds:8F6A` |
| `2703:03AF` | **1** | 只有 `+0x12 == ds:8F1D` 的 | `+0x26` 抄進 `+0x27`；**`軍事費 += 總稅收`** |

`docs/re/29` 記的「第一趟（實際收的）`2703:03D5` → `2703:0BC1` → 10813」
就是後者那一趟。

## `090A:0E6A`：月底的財務收尾

`2703:02E5` 靜態只有一個呼叫者，**`090A:0E6A`（線性 `0x09F0A`）**：

```
09F0A  2703:02E5()          ; 上面那一支
09F0F  090A:0E88(0)         ; 帝國
09F19  090A:0E88(1)         ; 同盟
```

`090A:0E88(陣營)`：

```
09F33  ax:bx = 297B:10DE(陣營)                  ; 這一方的維持費
09F41  ds:8F72 / ds:8F74[陣營] = ax:bx          ; 本回合維持費（docs/internals/27）
09F49  ax:bx = ds:8F52[陣營]                    ; 軍事費
09F51  + ds:8F6A[陣營]                          ; ＋ 總稅收
09F59  − ds:8F72[陣營]                          ; − 維持費
09F61  − ds:8F82[陣營]                          ; − 移動經費
       …夾限…
       → ds:8F5A / ds:8F5C[陣營]
```

**算的是下一期的可用額度（`ds:8F5A`），不是直接記進軍事費**——記進軍事費
的是 `2703:03AF` 那一趟。

## 閘門還是沒定位

觀測到的觸發（批次 `monthgate8`，`-regs-at 2703:02E5,090A:0E6A`
＋ 監看回合計數器）：

```
#240055147  ds:8F18 ← 017Ch (380)   ← 3D08:001A   載入 S3 劇本
#243674291  2703:02E5                             載入後算一次
#295000000  ds:8F18 ← 9             ← poke
#330061123  2703:02E5                             按「實行」之後
#70888537   090A:0E6A                             只在最初的設定跑過一次
```

所以 **`2703:02E5` 有不只一條進入路徑**——`090A:0E6A` 是靜態掃得到的那個，
另外還有走模組管理器間接向量的。閘門條件仍未定位；**下一輪要追的是
`2703:02E5` 的間接呼叫者，不是 `2703:03AF`**（`docs/re/253` 已收回那一條）。

## 順帶

S3 劇本載入時 `ds:8F18` ← **380**（`3D08:001A` 寫的）。一個月十回合，
所以 380 ＝ 第 38 個月。

## 一條方法

**追函式追不到就追變數。** 月底那幾支的呼叫者全走間接向量，怎麼掃都是
0 處；但「總稅收一定會先歸零再累加」是它必然的副作用，監看那四個位元組
一次就把歸零點、累加點與時機全撈出來，而且順便得到寫入者的 `seg:off`
——那正是掃不到的東西。
