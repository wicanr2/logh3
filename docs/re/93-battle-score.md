# 93：狀態欄那三個數字怎麼來的

`docs/re/92` 把三個數字的位址定出來（`ds:8FE4`／`ds:8FE8` 兩個 32 位元
分數，勝利點現算）之後，剩下的問題是**分數怎麼累加**。

## 累加點在善後常式裡

搜 `8FE4` 當立即數的地方，五個寫入點形狀都一樣：

```
add [si+8FE4h], bx
adc [si+8FE6h], ax
add [si+8FECh], bx      ; 另有一份複本
adc [si+8FEEh], ax
```

`si` 前面是 `shl si,1` 兩次，所以 `si ＝ 索引 × 4`——兩個陣營各一個
32 位元的槽。

其中一個（線性 `20AA A`，在 `203A:06C0` 這支善後常式裡）前後文完整：

```
sub  es:[bx+8],  ax        ; 目標的現有艘數 −= 量
sub  es:[bx+0Ch], cx       ; +0x0C 同步減
...
push es:[bx]               ; 被扣一方的陣營
call far 3982:0250         ; → 索引
mov  [bp+0], al
mov  ax, [bp+2]            ; 剛剛扣掉的量
mov  cx, 14h               ; 20
div  cx                    ; 量 ÷ 20
mov  bx, ax
mov  cl, [bp+0]            ; 索引
shl  si,1 / shl si,1
add  [si+8FE4h], bx        ; 分數[索引] += 量 ÷ 20
adc  [si+8FE6h], ax
```

## `3982:0250` 只是把陣營反過來

```
mov cl,[bp+6]
or  cl,cl
jnz +5
mov ax,1        ; 陣營 0 → 1
jmp +2
xor ax,ax       ; 陣營 1 → 0
```

所以索引 ＝ `1 − 被扣一方的陣營` ＝ **對手**。

## 規則

```
每扣一個分隊：分數[1 − 被扣一方的陣營] += 扣掉的艘數 ÷ 20
勝利點 ＝ 分數[0] − 分數[1]
```

除法是**逐個分隊**做的，不是把總損失除一次——截斷點不同，數字會差。

## 對得上量到的數

`docs/re/85` 量過 `s3fight` 那一場同盟兩支艦隊的損失：第 13 艦隊
27,000 → 26,785（−215）、第 16 艦隊 22,000 → 21,602（−398），合計
**−613**。`613 ÷ 20 ＝ 30.65`，而畫面上「帝國軍」印的是 **31**
（逐分隊截斷會與整批除略有出入，而且同盟不只這兩支在扣）。

所以「帝國軍」那一行是**帝國打掉的量**，不是帝國自己的損失；
「同盟軍」同理。`s3fight` 是 31 比 30，勝利點 1。

## 收據

`s3fight`、`s3kinds2` 的畫面與記憶體傾印，數字用
`TestBattleStatusReadBack` 反推。這一輪沒有跑新的收據。
