# 156 — 熱區清單要從呼叫點去解，掃形狀會漏

`docs/re/19` 為了找下拉選單的熱區，把資料段整份倒出來掃「長得像熱區
清單」的資料，找到 25 份，於是下了兩個結論：選單那一份不在資料段，
而唯一一處「把清單當參數收」的命中測試就是它。

**兩個都不成立。**

## 掃描漏了七份

命中測試的呼叫點自己寫死了清單位移（`hittest-sites.json`，27 處裡 26 處
是 `1E BB <位移> 53`）。拿那些位移當種子逐一解開——呼叫點是程式自己
寫的位址，不會漏——去比對 `hotspot-lists.json`：

```
呼叫點引用的清單 22 份，既有 JSON 25 份，缺 8 份：
  0x3D8 0xBEE 0xDA2 0x1BF2 0x1CCE 0x1E04 0x34CE 0x96EE
```

其中七份在 `s3fight` 那份傾印裡就解得開，只有 `0x96EE` 是空的（執行期
才填）。所以「掃到 25 份、沒有多出來的」這句話**不能拿來當「某份清單
不在資料段」的證據**——它只說明那個形狀判準有洞。

補回來的內容（`tools/scripts/hotspot_from_sites.py`）：

| 位移 | 筆數 | 是什麼 |
|---|---|---|
| `0x03D8` | 22 | **遊戲設定畫面**：MIDI／ＦＭ／關閉、九首曲目、開啟／關閉、普通／快速／最快、結束、`BUG!`、MIDI I/F |
| `0x0BEE` | 5 | 一覽表的頁籤：艦隊／行星／敵艦隊／提督，加一塊 18×5 的內容區 |
| `0x0DA2` | 1 | 結束 |
| `0x1BF2` | 3 | 17×16 的內容區 ＋ 兩個 1×1（捲動）|
| `0x1CCE` | 6 | 士氣／部隊／作戰 ＋ 同一組內容區 |
| `0x1E04` | 6 | 艦隊／配屬／稅金 ＋ 同一組內容區 |
| `0x34CE` | 6 | 艦隊／行星／敵艦隊 ＋ 25×14 的內容區 |

`0x03D8` 裡有一筆標籤是 **`BUG!`**（格 (14,0)、2×1、啟用、索引 20，
字串在 `ds:03CA` ＝ `42 55 47 21 00`）——原版設定畫面裡留下來的除錯項目。

## 熱區記錄的 `+0x06` 是元件種類

`docs/internals/23` 把 `+0x06`／`+0x07` 記成未知。`37A9:004C` 讀的就是
`+0x06`：拿它去查 `ds:8BE4[種類]`，再依它分派怎麼算矩形。傾印裡看得到
四種：

| 值 | 出現在 |
|---|---|
| 0 | 一般按鈕（設定畫面整排、確認、結束）|
| 4 | 框／內容區（`0x1BF2`、`0x1CCE` 那塊 17×16）|
| 5 | 頁籤（艦隊／行星／敵艦隊、士氣／部隊／作戰）|
| 6 | 上下箭頭（設定畫面的兩個 1×1）|

## 那處「清單當參數」的呼叫是共用的對話框

`hittest-sites.json` 裡位移是 `null` 的那一處在 `3826:023B`，而
`3826:023B` **只有一個呼叫者**：`3826:0005`。

```
3826:0005(樣式, 色, 訊息far)
    si = ds:8BEC + 樣式 × 6              ; 四種樣式，一筆 6 bytes
    ds:F24E／ds:F250 ← ds:8CFA[樣式]      ; 元件清單的 far 指標
    3603:0006(描述, 色, 表[+0]…表[+4])    ; 在**呼叫者的堆疊**上建視窗（[bp+2]，0x28 bytes）
    3617:000A(描述, 訊息far)              ; 放訊息
    37A9:000F(描述, 元件清單far)          ; 依元件清單算熱區，寫進描述
    341B:0145(描述)                       ; 畫
    3826:023B(描述)                       ; modal：等到點中一筆
    3603:00B4(描述)                       ; 收掉視窗
    回 熱區[+0x05]                        ; 項目索引
```

四份元件清單是**對話框的按鈕**：`ds:8C0A`「確認」、`ds:8C2C`「決定／
中止」（索引 0 決定、1 中止）、`ds:8C56`、`ds:8C78`。`3826:0005` 有
**18 個以上的呼叫者**——它是全遊戲共用的確認／選擇對話框，不是下拉選單。

`37A9:000F(描述, 清單far)` 走 12 位元組一筆、`FF FF` 結束的清單，每筆
交給 `37A9:004C` 算矩形填進描述。所以那一處的清單住在堆疊上，靜態掃
不到——**但那是對話框，不是下拉選單**。
