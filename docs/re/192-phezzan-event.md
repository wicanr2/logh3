# 192 — 費沙事件：八成的經濟力搬到對手的首都

`docs/re/179`／`docs/re/181` 把 `ds:8F48`（費沙進入戰局）的唯一寫入點
定位到 `0x1238D` 那支常式的第一行，但沒讀本體。這一輪讀了前半。

## `0x1238D(星域記錄)`

```
ds:8F48 = 1
2AF5:0036(0Eh, 0)                         ; 把「目前星域的行星切片」切到費沙（14）
費沙行星 = ds:CFF8                         ; 切片的第 0 顆

若 參數星域[+0x12] == 0（帝國）：
    目標星域 = 31（巴拉特）、目標行星 = 第 4 顆、清單 = ds:3280
否則：
    目標星域 =  0（瓦爾哈拉）、目標行星 = 第 0 顆、清單 = ds:3284

值 = 費沙行星[+0x1A] × 80 ÷ 100            ; 32 位元（3CC9:0009／3CC9:0070）
費沙行星[+0x1A] −= 值
2AF5:0036(目標星域, 0)
目標行星[+0x1A] += 值
…（接著走 清單 那串 0xFF 結尾的星域，未讀）
```

行星記錄 `+0x1A` 是**經濟力**（32 位元，`docs/internals/29`）。

**費沙八成的經濟力會整個搬到對手陣營的首都行星上。**
方向是反的很有意思：費沙落在帝國手上，錢流向**巴拉特**（同盟首都）；
反過來則流向**瓦爾哈拉**（帝國首都）。

## 兩張星域清單

| 常數 | 星域 |
|---|---|
| `ds:3280` | 10 杜威爾格、11 優茲黑姆、12 赫爾森 |
| `ds:3284` | 15 艾爾•法西爾、22 蘭提馬利歐、23 波列多、24 馬爾•亞迪特、25 干達巴爾、28 巴米利恩、29 流卡斯、30 艾流塞拉 |

`ds:3284` 的八格正是帝國進軍路線上的那幾格（`docs/re/178`）。
清單拿去做什麼還沒讀——那一段從 `es:[bx] != 0FFh` 開始，
把每個編號 × 126 加上 `ds:A79C` 去查星域記錄。

## 還沒讀

`0x1238D` 走清單那一段、`2AF5:0036` 本身（切片切換）、
以及誰呼叫 `0x1238D`（也就是費沙事件的觸發條件）。
