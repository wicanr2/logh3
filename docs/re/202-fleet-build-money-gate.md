# 202 — 建艦隊的錢那道閘門：維持費 × 20 追上總稅收就不建

`2D76:0060` 是建艦隊的守門人，`docs/internals/54` 之前只讀到一半
（「…看陣營的錢與 `ds:8FD4[陣營]`…（未讀）」）。整支讀完了。

## 反組譯

線性 `0x2D7C0` 起（段 `2D76`）：

```
2D76:0060():
  bl = ds:8F1D                                   ; 陣營
  ds:8F49[陣營] >= 16 → 回 0FFFFh                 ; 上限，每邊 16 個艦隊槽
  n = 2D76:011C()                                ; 現有艦隊數，順便填 ds:D506
  n < 3 → 回 n                                   ; 少於三支不看錢

  錢 = ds:8F6A[陣營 × 4]（32 位元，8F6A 低字、8F6C 高字）
  若 ds:8FD4[陣營] >= 3：錢 = 錢 × 3 ÷ 4

  維持 = ds:8F72[陣營 × 4]（32 位元）
  維持 × 20 >= 錢 → 回 0FFFFh                     ; 不建
  否則           → 回 n
```

`ds:8F6A` ＝ **總稅收**、`ds:8F72` ＝ **艦隊維持費**（`docs/internals/27`、
`docs/spec/003`）。所以整條規則是：

> **艦隊維持費乘二十追上總稅收，就不再建新艦隊。**
> `ds:8FD4[陣營]` 到 3 以上時預算先打七五折，門檻跟著變嚴。

## 長整數是靠三支輔助函式做的

`2D76:0060` 的算術全走 `3CC9:*`，三支都讀了，慣例是
**AX ＝ 高字、BX ＝ 低字；右運算元在 CX:DX**：

| 位址 | 做什麼 |
|---|---|
| `3CC9:0009` | `AX:BX × CX:DX → AX:BX`（三次 `mul` 加起來的標準 32 位元乘）|
| `3CC9:0070` | 有號除法（先取絕對值，轉呼叫 `3CC9:0020`）|
| `3CC9:00B9` | **有號比較**：只設旗標、`pop ax` 把 AX 還回去，呼叫端用 `jge`／`jl` 判 |

`3CC9:00B9` 的形狀值得記一下——它**看起來**像是把 −1／0／1 算進 `AX`，
但最後一個 `pop ax` 把那個值丟掉了。真正的輸出是旗標。
照「回傳值在 AX」的直覺讀會得到相反的結論。

## 還沒解的一格

`ds:8FD4[陣營]` 是個 byte，拿去和 3 比，效果是把預算打七五折。
它是什麼還沒查——**不猜**。

## 對 remake 的意義

`2D76:0060` 現在是完整的：上限、少於三支的豁免、稅收與維持費的比例
門檻都有了。剩下擋著 `2D76:0002`（主動建艦隊）的只有 `2D76:02FA`
排序之後往下的挑法（`docs/re/191` 讀到前兩層）。

## 一條方法

**看到 `call` 進 runtime helper 就把那幾支也讀掉。** 這一支的結論
（`>=` 還是 `<`、誰是左運算元）完全取決於 `3CC9:00B9` 的慣例；
不讀它，`jge` 那一行有兩種讀法，而兩種都「講得通」。
三支 helper 加起來不到六十個位元組。
