# 124 — 距離、落點、分隊的行程額度

`docs/re/123` 列了四項未解。這一輪解掉兩項，第三項發現**早就寫在
`docs/internals/33` 裡**，只剩一項。

## 落點站不站得住（`2583:040C`）

```
1588:04EA(x, y)              ; 地形通不通
  回 0 → 回 0FFFF（不能站）
17A0:06D7(x, y, 陣營)        ; 這個點有沒有被佔著
  回 0FFFF（沒有）→ 回 0     ; ← 呼叫端就是拿「回 0」當可以走
否則 → 回 佔著的那個東西
```

所以判準是**地形過得去，而且那個點沒有別人**。`17A0:06D7` 那支
（給一個點與陣營、回佔用者）還沒讀。

## 兩點距離（`3310:0006`）

```
dx = |x1 − x2|；dy = |y1 − y2|
dx == 0 → 回 dy
dy == 0 → 回 dx
否則（設 M ＝ 大的、m ＝ 小的）：
    q = 39B5:005C(m, M)          ; 16.16 定點除法
    t = 39B5:000C(q, q) + 0x10000 ; 16.16 平方 ＋ 1.0
    r = 3310:014B(t)              ; 16.16 開平方
    回 39B5:000C(r, M)            ; × M
```

也就是 **M × √(1 + (m/M)²)** ——歐氏距離，用 16.16 定點算的。
remake 目前用 `isqrt(dx² + dy²)`（同一個量，捨去方式不同）；
`3310:014B` 的捨去還沒讀，所以邊界上可能差 1。

## 分隊也有自己的行程額度

`1C61:0005`（每回合、每支艦隊叫一次）掃該艦隊的分隊
（`+0x0F` 是分隊數、`+0x10` 起是每 4 位元組一筆的分隊表）：

```
al = 艦艇 +0x21（巡航速度）
32 位元左移 19 位 → 這回合的行程（16.16 定點，＝ 速度 × 8）
ax:bx = 艦艇 +0x26:+0x24            ; 這一回合剩下的行程
與 8 比、與 0 比 …
```

**艦艇記錄 `+0x24`／`+0x26` 是分隊這一回合剩下的行程**，補法與艦隊那份
同一條規則（速度左移 19 位 ＝ 速度 × 8 的 16.16 表示）。`docs/internals/38`
先前沒有這一格。

## 艦隊的行程額度：早就寫在文件裡了

`docs/internals/33` 已經記著：`+0x52`／`+0x54` 是每回合的行程
（開戰時由 `307D:1468` 把 `+0x4E` 左移 19 位寫進去），`+0x56`／`+0x58`
是這一回合剩下的、每回合開頭複製過來。這一輪從 `1C03:0040` 那個迴圈
又推了一次，結論相同。

## 只剩一項

「艦隊拿到目的地（`+0x64`／`+0x66`）之後，各分隊的目的地
（`+0x28`／`+0x2A`）是誰寫的」——`1C61:0005` 是逐分隊走自己的目的地，
所以中間一定有一步把艦隊的目的地散成隊形。那一步還沒找到。

找到它，旗艦的「移動」就能接（互動兩段在 `docs/re/121`、`122`，
轉向與前進的算術在 `docs/re/123`，落點與距離在本篇）。
