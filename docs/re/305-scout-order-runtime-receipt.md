## 原始欄位

第 28 艦隊記錄在線性 `0x618FC`：

```text
+0x38 = 6e 00   偵察隊池索引 110
+0x3A = 00
+0x3B = 00      已經放出，不能再執行索敵
```

`ds:CFB4` 位於線性 `0x61AE4`，值 `668B:0002`，所以艦艇池線性基底是
`0x668B2`；索引 110 的 78-byte 記錄在 `0x68A36`。關鍵原始值：

| 位移 | bytes | 意義 |
|---|---|---|
| `+0x00/+0x01` | `01 1c` | 陣營 1、艦隊 28 |
| `+0x04` | `07` | 偵察艇 |
| `+0x19` | `C9` | bit7 仍為 1，已由小地圖點狀態機加上 bit6 與色碼 9 |
| `+0x1E` | `00` | 選完目的地後改成移動 |
| `+0x28/+0x2A` | `D8 04 48 03` | 目的地 `(1240,840)` |
| `+0x34/+0x36` | `32 05 AD 03` | 從旗艦位置 `(1330,941)` 出發 |

remake 測試 `TestScoutOrderMatchesOriginalReceipt` 讀這份 1 MB 收據，反解同一
鏡頭 `(66,32)`，走旗艦 → 第三列 → 同一目的地的玩家路徑，逐欄比較上述
艦隊與偵察隊狀態。
