# 238 — 月底那條 `Blend` 分支的收據；三個財政欄位的語意

`docs/spec/030` 有一條沒有收據：`2D10:0319` 在 AI 回合**結尾**呼叫時，
`回合數 % 10 == 9`（月底）走的是「照軍事費重算」而不是「歸零」。
跑到第 9 回合要 7×10⁸ 條指令；直接把回合計數器 poke 成 9 只要 2.6×10⁸。

## 收據 `monthblend`

輸入序列與 `refit4` 相同，只加一個注入：

```
-poke 'lin:5DA48@230000000=09 00'      ; ds:8F18 ＝ 回合計數器 → 9
-watch 5DB04-5DB05                      ; Blend
-dump-mem-at '246000000:…'
```

監看：

```
[watch] #212204751 5DB05: 02 → 01  ← 2D10:042A   ; 回合 0 開頭
[watch] #214183027 5DB05: 01 → 00  ← 2D10:042A   ; 回合 0 結尾（非月底 → 0）
#230000000 改記憶體 lin:5DA48（5DA48）2 bytes
[watch] #242013911 5DB05: 00 → 01  ← 2D10:042A   ; 回合 9 開頭
                                                  ; ★ 結尾那一次不見了
```

**結尾沒有寫入**，因為月底那一條算出來的還是 1（軍事費 44930 → 等級 1），
與開頭寫進去的相同，監看只報變動。

傾印（`#246000000`，AI 回合都結束了）與對照組並排：

| | 回合 | `Blend[同盟]` | 總稅收[同盟] |
|---|---|---|---|
| `refit4_post`（對照）| 1 | **0** | 6696 |
| `monthblend` | 9 | **1** | 10213 |

同一條序列、同一個時點，只差一個回合計數器。**月底那一條把稅率留在
等級 1，平時那一條把它壓到等級 0**——總稅收 10213 對 6696。

跑完的回合計數器是 **10**，所以那一跑真的跨了月。

## 順帶：三個財政欄位

跨五份傾印比對（同盟那一欄）：

| 傾印 | 回合 | `ds:8F72` | `ds:8F7A` | `ds:8F82` |
|---|---|---|---|---|
| `t260_pre` | 0 | 0 | 0 | 0 |
| `t260_post` | 0 | **426** | 0 | **492** |
| `refit2_pre` | 1 | 497 | **426** | 458 |
| `monthblend` | 9 | 528 | **954** | 615 |

- **`ds:8F72` ＝ Σ 艦隊 `+0x0A`**（本回合的艦隊維持費）——已知
  （`docs/re/218`），426 與三支的 217／85／124 相符。
- **`ds:8F82` ＝ Σ 艦隊 `+0x0C`**（本回合的移動經費）。`t260_post` 的
  492 正是收據 `monthend` 監看到的三筆移動扣款總和
  （263＋95＋134，`docs/re/237`）。`docs/internals/27` 記的
  「項目名稱未定」可以填上了。
- **`ds:8F7A` ＝ 累計已支付的艦隊維持費**。`refit2_pre` 的 426 是回合 0
  付掉的那一筆；`monthblend` 的 954 ＝ 426 ＋ 528（回合 9 的 `ds:8F72`）。
  與 `056A:09EB` 的 `add [bx+8F7A], si`（si ＝ 艦隊 `+0x0A`）一致
  （`docs/re/236`）。

  `docs/internals/27` 把它標成「移動經費」——**那個標籤不成立**：
  累計移動費會是 492 ＋ 615 ＝ 1107，不是 954。

## remake

`Game.runBrain` 的收尾本來就照 `docs/spec/030` 寫著

```go
level := 0
if g.turn%10 == 9 {
    level = rules.BlendForFunds(g.military[foe])
}
g.refreshBlend(foe, level)
```

現在有收據了，釘在 `TestMonthEndKeepsBlend`。

## 一條方法

**要一個難走到的局面，先問「哪一個數決定它」。** 走到第 9 回合要跑
7×10⁸ 條指令、而且回合推進的節奏不穩；決定那條分支的只是
`ds:8F18 % 10`，poke 一個 word 就到了，成本剩三分之一。
**規則讀懂了，局面就可以用最短的路造出來**——這正是
`docs/spec/014`「要某個局面就直接改記憶體」的用法。
