# RE 107 — 打行星：換手、清空、加分

`docs/re/106` 收尾時列出行星 `+0x11`（擁有者）的三個寫入點。這一輪把
其中兩處的上下文讀出來——**只靜態反組譯，沒有開收據**。

## 進入點：先比機動力與防衛力

線性 `0x21064` 一帶（段 `2100` 的 `+0x0064`）：

```
bx ＝ 行星[+0x14] × 100 ÷ 行星[+0x16]      ; 防衛力的百分比（3CC9:0009 乘、3CC9:0020 除）
al ＝ 艦隊[+0x3C]                           ; 機動力（實測一律 100，docs/re/102）
if al < bx:  先 20B4:08B1 再 20B4:0681
else:        先 20B4:0681，回值 > 0 就跳過 20B4:08B1
```

兩支的先後由「機動力有沒有壓過防衛力百分比」決定。

## 換手那一段

`20B4:0681` 的回值：

| 回值 | 意思 |
|---|---|
| `0xFFFF` | 沒打（下面說條件）|
| `0` | 打了但沒拿下 |
| 其餘 | 拿下了 |

拿下之後（線性 `0x2110C` 與 `0x2231B` 兩處，形狀相同）：

```
行星[+0x11] ← 艦隊[+0x01]           ; 陣營（docs/internals/33）
3C9C:000A(行星 + 0x20, 0, 0x1C)      ; 把 +0x20 起的 28 個 byte 清成 0
行星[+0x3C..+0x3F] >>= 1             ; shr 高位 +0x3E、rcr 低位 +0x3C ＝ 32 位元右移一位
行星[+0x40] ← 0 ; 行星[+0x42] ← 0
ds:8FE4[陣營 × 4] += 行星[+0x16] ÷ 10   ; 32 位元
```

最後那一條的位移在反組譯裡是 `add [bx-701Ch], si`——`-0x701C` 當無號
就是 **`0x8FE4`**，正是 `docs/re/92` 量到的兩邊分數
（`ds:8FE4` 帝國、`ds:8FE8` 同盟，32 位元、間隔 4）。

> **打下一顆行星 ＝ 該陣營加「行星 `+0x16` ÷ 10」分。**

第三個寫入點（線性 `0x28B16`）是單獨一支小函式的開頭，把
`行星[+0x11]` 寫成常數 **2（無主）**。

## `20B4:0681` 的開頭

```
回值預設 0xFFFF
if !(艦隊[+0x70] & 1): 直接回 0xFFFF        ; 這一支不參與
[bp+8] ← 203A:0424(艦隊, …)
[bp+4] ← 20B4:0D96(艦隊, 行星, …)
ax     ← 203A:04D1(行星, …) ÷ 6
```

`203A:04D1` 就是 `docs/re/99` 那支——**加總行星附近艦種 0／1 的存活艘數**。
所以打行星與戰鬥的總損失**共用同一組原始件**，不是另一套系統。

## 上面那三層：`+0x5A` 是「這一支在打哪一顆行星」

沿著 far call 往上追（掃 `9A` 位元組樣式，每一層都只有**一個**呼叫者）：

```
20B4:0286  逐顆行星的驅動
   └ 20B4:038F(行星索引, &清單, …)      挑出能打這顆的艦隊，回數量
   └ 20B4:0486(行星索引, 清單, 數量, …)  讓那些艦隊打這顆
        └ 20B4:0503(艦隊, 行星)          一支打一顆 ← docs/re/106 的換手點
```

`20B4:0286` 的樣子：

```
i ＝ 0
while i < ds:CFFC:                      ; 這個星域有幾顆行星
    n ＝ 20B4:038F(i, &清單, …)
    if n != 0:
        1DD6:0152()                      ; 還沒解（看起來是畫面／訊息）
        20B4:0486(i, 清單, n, …)
    i++
```

挑艦隊那一段走的是艦隊表（`ds:C074`，一筆 122），判準是

```
艦隊[+0x5A] != 0xFF          → 收進清單
艦隊[+0x5A] == 行星索引       → 這一支打的是這一顆
艦隊[+0x01] != 行星[+0x11]    → 陣營不同才打
```

所以

> **艦隊記錄 `+0x5A` ＝ 這一支正在攻打哪一顆行星；`0xFF` ＝ 沒有。**

收據 `s3tgt` 的傾印裡十八支在用的艦隊 `+0x5A` **全部是 `0xFF`**——
那一場沒有人在打行星，與「現有收據裡沒有任何一次行星換手」相符。

## `+0x5A` 是自動填的，不是另一個玩家命令

照上一節說的做——靜態掃 `mov [?+5Ah], al` 的位元組樣式，整份記憶體
只有四處，其中兩處就在 `20B4:038F`（挑艦隊）裡面：

挑艦隊那一支（`20B4:0176` 一帶）逐一走過艦隊：

```
艦艇 ＝ ds:CFB4 + 艦隊[+0x10] × 78          ; 這一支的第一組
if 艦艇[+0x08] == 0: 跳過                    ; 沒有存活艘數
if 行星[+0x11] == 艦隊[+0x01]: 跳過          ; 同陣營不打
d ＝ 3310:0006(行星[+0x46], 行星[+0x48],
               艦隊[+0x5C], 艦隊[+0x5E])     ; 歐氏距離，16.16

; 第一種
if d ≤ 150.0
   and !(艦隊[+0x00] & 1)
   and (艦隊[+0x48] & 0x0F) == 1:
        艦隊[+0x70] |= 1
        艦隊[+0x5A] = 行星索引

; 第二種
if d ≤ <參數>
   and (行星[+0x12] == 0 或 行星[+0x45] != 3):
        艦隊[+0x70] |= 2
        艦隊[+0x5A] = 行星索引
```

座標用的是**行星的戰場座標 `+0x46`／`+0x48`**（`docs/re/99` 解出來的
那一對）與**艦隊的戰場座標 `+0x5C`／`+0x5E`**（`docs/internals/34`）。

門檻 **150** 與 `docs/re/99` 總損失距離衰減用的 150 是同一個數。
第二種的門檻是傳進來的參數，來源還沒讀。

所以**攻打行星不是一個要玩家下的命令**：每個回合走到這裡時，符合條件的
艦隊會自動被標上 `+0x70` 的位元與 `+0x5A`，然後 `20B4:0486` 讓它們開火。
`docs/re/107` 前面說 `20B4:0681` 要 `艦隊[+0x70] & 1` 才會打——那個位元
就是在這裡設的。

`+0x00 bit0`（`docs/re/79` 記過它把艦隊分成兩類）與 `+0x48`
（`docs/re/80` 記過它在戰鬥中 4→0）在這裡都是判準，兩個都還沒解。

另外兩個寫入點：`20B4:004C` 寫常數（看起來是清成 `0xFF`）、
線性 `0x2A0C5` 在別的子系統，還沒讀。
