# 246 — 整條歸屬鏈的同狀態收據，以及易主會跳報告

`docs/spec/033` 把「佔領寫回 → 依行星重算 `+0x12` → 重建路徑表 → 態勢」
接了起來，但每一環各有收據、整條鏈沒有。做出來了，而且中途撞到一件
`docs/re/244` 沒看到的事：**星域易主會跳一則報告，擋住後面的處理**。

## 局面怎麼造

新遊戲（`ADMIRAL.DTX`／`STELLAR.DTX`）按一次「實行」。行星記錄陣列的基底
先從傾印裡定出來：`PLADAT.DAT` 的 64 位元組表頭（32 個 word 的每星域行星
數）在線性 `0x61AE8`，但記錄陣列不接在它後面。改用簽章掃——「81 筆的
`+0x11` 都在 0/1/2，而且照表頭切開之後與 32 格 `+0x12` 一致」——
**基底 ＝ 線性 `0x53132`（＝ `5313:0002`），82 位元組一筆，32／32 全中**。

星域 4 只有一顆行星、擁有者是帝國，所以翻它一個位元組就整格易主：

```
-poke lin:5351B@218000000=01
```

（收據 `report.txt` 記的是 `改記憶體 lin:5351B（5351B）1 bytes`，兩個數字
相同。）

## 撞到的事：易主會跳報告

第一次跑（批次 `chain3`）的結果很怪：

```
2703:159B 執行時的暫存器（前 37 次）  ← 32 次是新遊戲初始化，只多了 5 次
2703:08DE 執行時的暫存器（前 0 次）   ← 完全沒跑
```

多出來的 5 次是星域 0、1、2、3、**4**——**正好停在被 poke 的那一格**。
畫面說明了原因：

```
戰略模式處理中
菲列亞星系
已被敵軍占領。
```

`056A:0855`（易主處理）跳出這則報告，整段回合結束處理停在那裡等玩家按掉。
所以那一趟 `+0x12` 已經翻成 1，`+0x24` 還是舊擁有者的 14——不是算錯，
是後半段根本沒跑。

補三次右鍵（批次 `chain4`）把報告按掉之後，`2703:159B` 64 次、
`2703:08DE` 1 次，鏈就走完了。

## 收據

`chain_post`（不 poke）與 `chain4_post`（poke 之後）兩份 1 MB 傾印，
32 筆星域記錄只有三格不同：

| 星域 | 基準 `+0x12` `+0x24` `+0x13` | poke 後 |
|---:|---|---|
| 0 | 0　　0　00 | 0　　0　**08** |
| 2 | 0　 15　00 | 0　 15　**08** |
| 4 | **0**　**14**　**08** | **1**　**4218**　**09** |

逐項都對得上 `docs/re/243`／`244`：

- 星域 4 依行星重算成同盟（`docs/re/17`：全屬同一方才算那一方的）。
- `+0x24` 從 14 變 **4218 ＝ 1024 × 4 ＋ 122**——它現在算的是到巴拉特
  （同盟首都）的成本，路上有四條邊的兩端不全是同盟的。
- `+0x13` bit0 跟著起來（4218 ≥ `0x400`）。
- 星域 0 與 2 是 4 的鄰居，擁有者變得跟自己不同，所以 **bit3（前線）**
  從 0 變 1。星域 3 也是鄰居，但它本來就是前線。

## 模型逐格重現

`rules.StarGraph.BuildTables` ＋ `Postures` ＋ `Occupations` 拿這兩份傾印
自己的擁有者與艦隊重算：

```
基準   ：+0x24 對不上的 0／32
poke 後：+0x24 對不上的 0／32
```

`+0x13` 的 bit0–bit4 也逐格相同（`TestPosturesMatchOracleReceipts`）。
連同 `docs/re/244` 的 `s3ai6`，**三個不同局面**——S3 中局（18 支艦隊）、
新遊戲第一回合（3 支）、以及同一局面 poke 之後——全部逐格相同。

## remake 缺的

**易主報告沒有做。** 原版每有一格易主就跳一則「XX星系 已被敵軍占領。」，
而且是**擋住回合結束處理**的模態報告。remake 的 `recomputeRegions` 只回
「有幾格易主」，沒有把它變成畫面。這是新的缺口，記進 `docs/spec/033`。

## 一條方法

**poke 出來的局面會把沒走過的分支叫醒。** 這一輪本來只想驗算式，結果
`2703:08DE` 零次執行——那不是量壞了，是原版多了一段從來沒被觸發過的
報告流程。**「跑出來的數字不對」與「跑到一半停住」要分開看**：先確認
該跑的東西跑了幾次，再談值對不對。
