# 提督詳細資料那張畫面，把 14 個能力欄位的名字給了出來

`docs/internals/08` 對 `ADMIRAL.DT*` 的 `+11…+24` 只寫得出「能力值，
實測值域 80–140」，十四個欄位對應哪些能力一直是未知。

從「出擊命令」的待命中提督清單點一位提督，會開出一張**提督詳細資料**，
上面把能力逐項標了名字。兩張收據（`adm1e` ＝ 萊因哈特、`adm2e` ＝
吉爾菲艾斯）就把對應釘死了。

## 畫面

視窗 (96,80)–(543,359)，右上角是那位提督的頭像（`FACE.AMG` 第 n 張，
n ＝ 提督索引），下緣三顆按鈕：**經歷／中止／出擊**（熱區清單 `1F34`，
`docs/internals/23`）。

```
    萊因哈特　　上將
    現在位置　瓦爾哈拉：待命中
    旗艦　　　伯倫希爾
    提督的等級   等級 29    經驗值 0
    艦隊運用能力 統率力 138  移動 110
                 運用   115  回轉 118
                 營運   100
    戰鬥能力     光線砲 119  占領 126
                 飛彈   114  防禦 117
                 戰鬥機 110
```

## 十個能力欄位（confirmed，兩個資料點）

| 位移 | 名稱 | 萊因哈特 | 吉爾菲艾斯 |
|---:|---|---:|---:|
| `+11` | 統率力 | 138 | 110 |
| `+12` | 移動 | 110 | 108 |
| `+13` | 回轉 | 118 | 105 |
| `+14` | 營運 | 100 | 120 |
| `+15` | 光線砲 | 119 | 112 |
| `+16` | 飛彈 | 114 | 118 |
| `+17` | 戰鬥機 | 110 | 111 |
| `+18` | 防禦 | 117 | 110 |
| `+19` | 占領 | 126 | 116 |
| `+23` | 運用 | 115 | 113 |

`+11…+19` 照記錄順序就是畫面上那九項（畫面的排法是兩欄交錯，不是
記錄順序），`+23` 是運用。**`+20`、`+21`、`+22`、`+24` 這張畫面沒有印**
——`docs/internals/08` 量到 `+21`／`+22`／`+24` 在四個版本完全相同，
比較像固定屬性。

萊因哈特那筆有兩個 110（`+12` 與 `+17`），單看一位分不出哪個是移動、
哪個是戰鬥機；吉爾菲艾斯那筆是 108 與 111，把它分開了。

## 等級與經驗值

`+6` 就是**等級**（萊因哈特 29、吉爾菲艾斯 20），軍階是從它分段推出來的
（`docs/internals/08` 的 `RankOf`，門檻 0/2/4/…/28）。先前寫「`+6` 比較像
戰功或年資」，現在有畫面上的字：它叫等級。

經驗值兩位都是 0。`+2…+5` 四個位元組在所有 82 筆都是 0，像是一個
32 位元的計數器（假設待驗——需要一局玩到有人升級才驗得了）。

## 與防拷問答的矛盾

防拷問答問的是「占領能力數值」，答案是 `ADMIRAL.DTX` 第 0 筆的 `+11`
＝ 138（`docs/re/08`，實測輸入 138 過關）。但這張畫面把 `+11` 標成
**統率力**，把占領標在 `+19` ＝ 126。

兩件事都是量到的，不互相推翻。最可能的解釋是**紙本資料表的欄名與畫面
不同**——防拷要玩家查的是說明書附的提督資料表，不是遊戲裡這張畫面
（假設待驗，手上沒有那份紙本）。
