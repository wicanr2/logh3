# 提督詳細資料那張畫面，把 14 個能力欄位的名字給了出來

`docs/internals/08` 對 `ADMIRAL.DT*` 的 `+11…+24` 只寫得出「能力值，
實測值域 80–140」，十四個欄位對應哪些能力一直是未知。

從「出擊命令」的待命中提督清單點一位提督，會開出一張**提督詳細資料**，
上面把能力逐項標了名字。兩張收據（`adm1e` ＝ 萊因哈特、`adm2e` ＝
吉爾菲艾斯）就把對應釘死了。

## 畫面

視窗 (96,80)–(543,359)，右上角是那位提督的頭像（`FACE.AMG` 第 n 張，
n ＝ 提督索引），下緣三顆按鈕：**經歷／中止／出擊**（熱區清單 `1F34`，
`docs/internals/23`）。

```
    萊因哈特　　上將
    現在位置　瓦爾哈拉：待命中
    旗艦　　　伯倫希爾
    提督的等級   等級 29    經驗值 0
    艦隊運用能力 統率力 138  移動 110
                 運用   115  回轉 118
                 營運   100
    戰鬥能力     光線砲 119  占領 126
                 飛彈   114  防禦 117
                 戰鬥機 110
```

## 十個能力欄位（confirmed，兩個資料點）

| 位移 | 名稱 | 萊因哈特 | 吉爾菲艾斯 |
|---:|---|---:|---:|
| `+11` | 統率力 | 138 | 110 |
| `+12` | 移動 | 110 | 108 |
| `+13` | 回轉 | 118 | 105 |
| `+14` | 營運 | 100 | 120 |
| `+15` | 光線砲 | 119 | 112 |
| `+16` | 飛彈 | 114 | 118 |
| `+17` | 戰鬥機 | 110 | 111 |
| `+18` | 防禦 | 117 | 110 |
| `+19` | 占領 | 126 | 116 |
| `+23` | 運用 | 115 | 113 |

`+11…+19` 照記錄順序就是畫面上那九項（畫面的排法是兩欄交錯，不是
記錄順序），`+23` 是運用。**`+20`、`+21`、`+22`、`+24` 這張畫面沒有印**
——`docs/internals/08` 量到 `+21`／`+22`／`+24` 在四個版本完全相同，
比較像固定屬性。

萊因哈特那筆有兩個 110（`+12` 與 `+17`），單看一位分不出哪個是移動、
哪個是戰鬥機；吉爾菲艾斯那筆是 108 與 111，把它分開了。

## 等級與經驗值

`+6` 就是**等級**（萊因哈特 29、吉爾菲艾斯 20），軍階是從它分段推出來的
（`docs/internals/08` 的 `RankOf`，門檻 0/2/4/…/28）。先前寫「`+6` 比較像
戰功或年資」，現在有畫面上的字：它叫等級。

經驗值兩位都是 0。`+2…+5` 四個位元組在所有 82 筆都是 0，像是一個
32 位元的計數器（假設待驗——需要一局玩到有人升級才驗得了）。

## 與防拷問答的矛盾

防拷問答問的是「占領能力數值」，答案是 `ADMIRAL.DTX` 第 0 筆的 `+11`
＝ 138（`docs/re/08`，實測輸入 138 過關）。但這張畫面把 `+11` 標成
**統率力**，把占領標在 `+19` ＝ 126。

兩件事都是量到的，不互相推翻。最可能的解釋是**紙本資料表的欄名與畫面
不同**——防拷要玩家查的是說明書附的提督資料表，不是遊戲裡這張畫面
（假設待驗，手上沒有那份紙本）。

## 「經歷」按下去是人物傳

詳細資料左下角那顆「經歷」開出的畫面（收據 `keireki1e`）把
`KEIREKI.DAT` 那一段文字印出來：視窗 (80,85)–(559,359)、
文字從 (96,222) 起、一列 20 像素、**一列 28 個全形字**，六列。
萊因哈特那一段 337 bytes 剛好排滿六列。

`KEIREKI.DAT` 本身早就解開了（`docs/internals/15`，可讀版本在
`docs/lore/character-biographies.md`），缺的只是這張畫面。

## 旗艦

畫面上印「旗艦　伯倫希爾」（萊因哈特）、「旗艦　巴爾巴洛沙」
（吉爾菲艾斯），對上 `GIN3PS.EXE` 資料段 `0x6570` 起那 34 個旗艦名的
第 0、1 筆（`docs/internals/15`）。索引解出來了：資料段有**兩張 16 個 far 指標的表**——`0x66A8` 帝國、
`0x6748` 同盟——指向 `0x6570` 起那批旗艦名，索引是**該提督在自己陣營裡的
序號**（帝國 ＝ 提督索引、同盟 ＝ 提督索引 − 40）。

新遊戲開局時艦隊表（`ds:C074`）32 筆全是 `FF`（一支艦隊都沒有），
所以旗艦不可能從那裡來——這一條先排除了艦隊表。

對出來的名字與原著逐一相符：米達麥亞人狼、羅嚴塔爾托利斯坦、
畢典菲爾特王虎、亞典波羅特里古拉夫、比克古利歐格朗特、
楊威利休伯利安。**24 位有艦隊的提督裡，只有梅爾卡茲（提督 80）的
陣營內序號是 40，超出 16 個槽**——資料段裡另有兩個旗艦名
（馬奧里亞、姆夫維瑟）被別處引用，可能是他的，未解。

## 數值全部靠右對齊，`+7` 是艦隊編號

第三張收據（`adm15e` ＝ 待命清單第 14 列的錦茲少校）把兩件事釘下來：

- **靠右對齊**：等級 6 印在 x=328、29 印在 x=320，右緣都是 336；
  右欄同理，右緣 480（占領 82 在 x=464、105 在 x=456）。
- **`+7` 是艦隊編號**：錦茲那張**沒有「旗艦」那一行**，而他的 `+7` ＝
  `0xFF`；萊因哈特 `+7` ＝ 32、吉爾菲艾斯 ＝ 17，兩位都有旗艦。
  `0xFF` ＝ 沒有，正是這個遊戲一貫的「沒有」表示法（`FleetsUnknown`
  同樣是 `0xFF`）。旗艦名多半要再從艦隊記錄（`ds:C074`）查一次，
  34 個旗艦名對不上 82 位提督也是因為這樣（**假設待驗**）。

用能力值反查，錦茲是提督 17（等級 6），與畫面上的軍階「少校」相符。
