## 三、電腦座位的艦隊；更正 `docs/re/322` §一 的 `+060F`

位元組（P）：

```
060F cmp ds:8F20, 2 ; jz 0628
0616 3982:022D(艦隊+1) ; or al,al ; jz 062F（呼叫 0B46）
0628 test ds:8F1C, 1 ; jz 0648（不呼叫）
062F call 113A:0B46
```

條件 ＝ `(8F20 != 2 且 022D == 0) 或 (8F1C & 1)`。`docs/re/322` §一寫成「`8F20 != 2 且（022D == 0 或 8F1C bit0）`」，
括號位置不對：`8F20 == 2` 時 bit0 仍會叫 `0B46`。`0797`／`0A4E` 進門 `3982:022D(陣營) == 1` 就回；`0899` 同樣回 1（當占領）（P）。
