# 92：一場戰鬥最多九個回合

戰鬥結束條件之前追過兩條路都沒結果（`docs/spec/018` 記著）。這一輪換個
入口：**先把畫面上印的數字讀回來**，再拿它們去記憶體裡定位。

## 用 remake 自己的字反推收據上的數字

右側狀態欄的四個數字（回合、勝利點、帝國軍、同盟軍）都是全形字，肉眼
看得出來但不好抄。remake 的 `DrawBattleStatus` 已經與收據逐位元組相同，
所以可以**反過來用**：逐一試值，畫出來與收據那一列完全一樣的就是它
（`TestBattleStatusReadBack`，設 `LOGH3_READ_STATUS=<批次>` 才跑）。

| 收據 | 回合 | 勝利點 | 帝國軍 | 同盟軍 |
|---|---:|---:|---:|---:|
| `s3ai6` | 1 | 0 | 0 | 0 |
| `s3turn2` | 3 | 0 | 0 | 0 |
| `s3fight` | 5 | 1 | 31 | 30 |
| `s3kinds2` | 5 | 199 | 229 | 30 |

`s3kinds2` 是 `s3fight` 加上七個艦種注入——**帝國軍那個數字跟著從 31 跳到
229**，所以它跟艦種有關，是戰果不是艘數。

## 定位

四份傾印同時比對，一次就中：

| 位址 | 是什麼 |
|---|---|
| `ds:8F1A` | **回合，word，0 起算**（畫面印的是 ＋1）|
| `ds:8FE4`／`ds:8FE6` | 帝國軍的分數（32 位元）|
| `ds:8FE8`／`ds:8FEA` | 同盟軍的分數（32 位元）|

勝利點在記憶體裡**找不到**——因為它是現算的：`13581` 那一段是
`帝國 − 同盟` 的 32 位元減法。`1 ＝ 31 − 30`、`199 ＝ 229 − 30`，兩份收據
都合。

`ds:8F1A` 之前用 byte 搜（3 → 11）沒中，是兩個原因疊在一起：它是 word，
而且 `s3fight` 的回合是 **5** 不是 11——八對雙擊沒有八次都算數。

## 主迴圈：`12AA:...`

```
回合 ds:8F1A ← 參數（0xFF 就當 0）
while ds:8F1A < 9:                    ; ← cmp word ptr ds:8F1A, 9 / jnb
    ds:9B7E ← 0
    12AA:0245(旗標)                    ; 跑一個回合
    把 ds:8FE4／ds:8FE8 存進局面記錄的 +0x2C／+0x2E
    if 12AA:0286() != 0: break         ; 有一方結束了
    12AA:02BD()
    if ds:9B7E == 0:
        26E5:0003(0xFF, 0, 0)
        if 181B:000A() != 0: break
        ds:8F1A ++
    else:
        185C:0ADA(); break
```

**所以一場戰鬥最多九個回合**（顯示的第 1 到第 9），另外有兩個提早離開的
出口。

`12AA:0286` 就是「有一方結束了嗎」：它把 `ds:8F1E` 設成 0 再設成 1，各問
一次 `12AA:02D4(陣營)`，任一邊回非 0 就結束。

`12AA:02D4(陣營)` 讀下來是**問人**，不是算出來的：

```
if ds:8F23[陣營] != 0:  回 0          ; 這一邊不問，直接繼續
把 ds:8F25[陣營] 存進 ds:8F1D
（ds:8F20 == 2 時先叫 1588:02CE 處理 ds:8F3A[陣營] 的 32 位元值）
26E5:0003(陣營, 一段字串 ds:334F)      ; 顯示
12F1:0539(1) / 3765:0003(0)
di ＝ 12F1:0002()                     ; 收輸入
把 ds:9BF4／ds:9BF6 存回 ds:8F3A[陣營]
回 di                                 ; 非 0 → 戰鬥結束
```

所以**提早結束的出口是一個選單**——`ds:334F` 那段字串是
「戰術：實行／資料／撤退／取進度／存進度／設定／結束」（`docs/re/98`）。
選「實行」回 0、迴圈繼續；選其餘六項回非 0、跳出迴圈去處理那個命令，
其中一項就是**撤退**。`ds:8F23[陣營]` 是「這一邊要不要問」的旗標。

一場戰鬥要嘛打滿九個回合，要嘛玩家從選單裡選了實行以外的東西。

## 還沒解

- `12AA:02D4` 判定一邊「結束」的條件（`ds:8F23`／`ds:8F25` 是什麼）。
- 分數 `ds:8FE4`／`ds:8FE8` 怎麼累加（跟艦種有關，見上面的注入對照）。
- `ds:9B7E` 這個旗標由誰設。

## 收據

`s3ai6`、`s3turn2`、`s3fight`、`s3kinds2` 的畫面與 1 MB 記憶體傾印。
這一輪沒有跑新的收據。
