# 行星的反擊：方向表與兩段捨去的分攤

[`docs/spec/019`](../spec/019-planet-assault.md) 的最後兩項。

## `20B4:0E7E(艦隊, 行星, 旗標)`

```
基準 ＝ (203A:04D1(行星) ＋ 行星[+0x14]) ÷ (行星[+0x12] ? 20 : 10)
基準 −= 基準 × (距離 ÷ 150) ÷ 5                    ; 與 20B4:0D96 同一形狀
向   ＝ 3982:0022(|atan2(行星 − 艦隊) − 艦隊[+0x4A]|)
基準 ＝ 基準 × ds:47D0[向] ÷ 100
量   ＝ 基準 × 100 ÷ (艦隊[+0x40] × 艦隊[+0x41] ÷ 100) ＋ rand() % 100
20B4:103D(艦隊, 量, 旗標)
```

`3982:0022(a)` ＝ `(((a >> 4) + 1) >> 1) & 7`，也就是把一整圈 256 的角度
四捨五入到最近的 32 再取 0–7。`ds:47D0` 是八個 word：

```
80  85  90  95  100  95  90  85
```

索引 0 是「艦隊正面對著行星」——**正面最耐打（80%）、背面最痛（100%）**，
兩側對稱。除數 `艦隊[+0x40] × 艦隊[+0x41] ÷ 100` 就是
[`docs/internals/33`](../internals/33-fleet-table.md) 早就記下的防禦係數。

## `20B4:103D(艦隊, 量, 旗標)`：分攤

```
第一遍：總 ＝ Σ 各分隊艘數；記下艘數最多的那一支（同值取先出現的）
第二遍（依分隊序）：
    這一支 ＝ ⌊量 × ⌊艘數 × 100 ÷ 總⌋ ÷ 100⌋
    旗標 0 時夾成 ≤ 艘數 − 1                      ; 不打光
    實扣 ＝ 203A:0593(艦艇, 這一支, NULL)
    餘 −= 實扣
收尾：餘 > 0 就丟給艘數最多的那一支（旗標 0 時同樣夾成 ≤ 艘數 − 1）
```

> ⚠ 收尾那一句被 [`docs/re/330`](330-strategic-planet-assault.md) §3.4 推翻：夾值寫進 `[bp+2]`，呼叫 `203A:0593`
> 時 push 的是 `[bp+6]`（剩餘量），尾段實際不夾。remake 的 `spreadOverFleet` 仍照舊寫法（戰場層另案）。

**兩段整數捨去**是關鍵：先把艘數換成百分比（丟掉小數）、再乘上量（又丟
一次）。換成 `量 × 艘數 ÷ 總` 一次算完會差幾艘，而餘數又全部堆到最大的
那一支，看起來就會像「某一個分隊莫名多掉十幾艘」。

順帶：`203A:0593` 對艦種 7（索敵分遣隊）**回它現有的艘數而不扣**，所以
它會從餘額裡吃掉那麼多——不過索敵分遣隊不在編制槽裡，實際碰不到。

## 對拍

收據 `s3assault` 走一次 production path（`rules.PlanetAssault`）：

```
4 支艦隊出手：打掉防衛力 2424、挨反擊 642 艘，逐一相同
```

行星的擁有者（0 → 1）、防衛力（2852 → 428）、飛彈（40000 → 20000）與
艦載機（40000 → 0），以及在場五支艦隊 33 個分隊的艘數與 `+0x0C`
**全部逐一相同**。三支被反擊的艦隊分攤出來的量是 278／166／198。

## 可重用的規則

- **「按比例分攤」要看它分幾段捨去。** 一次乘除與「先算百分比再乘」在
  整數下不是同一個函式；差別會集中在拿餘數的那一支上，從結果看起來像
  某個分隊有特殊待遇。
