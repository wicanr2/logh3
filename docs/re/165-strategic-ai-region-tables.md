# 165 — 戰略 AI 的四張星域表

`docs/re/163`／`docs/re/164` 把守勢那一半讀完了，剩下的問題是「`+0x07`
被設成**敵方**星域是哪一支寫的」。線索是 `docs/re/79` 看到的那張
`[星域×2 − 0x2A32]`。這一輪把那一帶掃乾淨：**不是一張表，是四張**，
而且有一支專門算「還缺幾支」的常式。

## 四張表（都以星域 0–31 為索引）

| 位址 | 型別 | 誰清 | 誰寫 | 目前知道的 |
|---|---|---|---|---|
| `ds:D50E` | word | `2E54:0013` `memset(…, 0, 0x20×2)` | `2E54:020F` | 被 `>>1` 之後夾到 1 當一個加項；也被拿來排序比大小 |
| `ds:D54E` | word | `2E54:003B` | `lin 30048` 的 `add [bx-2AB2h], al` | 與 0、4、0x0C 比大小；是下面那個差的被減數 |
| `ds:D5CE` | word | `2E54:0027` | `2E54:016B` 的 `inc`（艦隊「有事做」時，`docs/re/79`）| 該星域已經有幾支艦隊有事做 |
| `ds:D58E` | **byte** | `2E54:074A` | `2E54:0730`／`2E54:08E3` | **這一格還缺幾支**（見下）|

四張的清空都在同一支的開頭（`2E54:0005` 那一段連續三個 `3C9C:000A`
memset），所以它們是**同一趟的暫存**，不是存檔裡的東西。

## `2E54:0730` ＝ 算「還缺幾支」

```
memset(ds:D58E, 0, 32)
對 r = 0 … 31：
    星域 = ds:A79C + r × 126
    若 星域[+0x12] != ds:8F1D：跳過          ; 只算自己的星域
    n = ds:D50E[r] >> 1 ; 若 n >= 2：n = 1
    若 ds:D5CE[r] >= ds:D54E[r]：
        ds:D58E[r] = 0
    否則：
        ds:D58E[r] = (ds:D54E[r] − ds:D5CE[r]) >> 2
    ds:D58E[r] += n
```

`2E54:08E3` 是同一個形狀的第二支，差在最後一步是 **÷5**（`mov cx,5;
div`）而不是 `>>2`，而且進迴圈前多一個 `ds:D50E[r] != 0` 的閘。
兩支各自 memset `ds:D58E` 再重填，所以是**兩種算法擇一**（**待驗**：
什麼時候用哪一支）。

## 排序用的比較函式

`2E54:0A43` 一帶有四段一模一樣的形狀：

```
al = 表[清單[i]] ; cl = 表[清單[j]]
cmp al, cl
jbe/jnb → ax = 0FFFFh 或 1
```

兩段比 `ds:D58E`（缺幾支）、兩段比 `ds:D50E`，回 ±1——**是排序的比較器**。
所以這一趟的形狀是「**算出每一格缺幾支 → 依缺口排序 → 分配**」。
