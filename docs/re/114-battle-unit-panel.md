# 114 — 戰場上選中一個分隊時的右側面板

`docs/re/113` 收斂到最後只剩一件沒見過的事：戰場右側狀態欄換成選中
分隊的資料。這一輪把它與旁邊那一串東西一起讀出來。

## 字串（線性 `0x58C80` 一帶）

```
ds:41A4  '%-8s    %4d'          ← 艦種名 ＋ 艘數
ds:41B0  '艦隊士氣值  '          ds:41BD  '部隊士氣值  '
ds:41CA  ' %3u'
ds:41CF  '無法戰鬥        '
ds:41E0  '艦隊行動    \x03[%d,%4s'   ds:41F5  '部隊行動    %4s'
ds:4205  '最高修理數  %4lu'      ds:4216  '剩餘燃料  %3d 回'
ds:4227  '補給物資\n'
ds:4231  '光線砲    %6lu'        ds:4240 ＋ ds:424B  '飛彈      %6lu'
ds:4250 ＋ ds:425B  '戰鬥機    %6lu'
```

同一塊還有一串命令名：**移動／編隊／修理／歸隊／情報／補給／補充／
要塞砲**——戰場上對單位下的命令，這個 remake 還完全沒碰。

## 誰印的（`0x1CD1F` 起）

```
les  bx,[bp+2Eh]                 ; 艦艇記錄
push es:[bx+8]                   ; 艘數
mov  bl, es:[bx+4]               ; 艦種 → 名字表 ds:613A
印 "%-8s    %4d"

mov  bl, es:[bx]                 ; 艦艇 +0x00 ＝ 陣營
mov  al, [bx+6096h]              ; **陣營色表**
設成文字顏色
cmp  byte es:[bx+3],0            ; 艦艇 +0x03 ＝ 分隊序號
  ＝ 0（旗艦）→ 印 "艦隊士氣值" ＋ 艦隊記錄 +0x3C
  ≠ 0        → 印 "部隊士氣值" ＋ 艦艇記錄 +0x06
cmp  值,50
  < 50 → 顏色 0x92（色 2）   否則 → 0x97（色 7）

艦艇 +0x1E ＝ 0x7F ？
  是 → 看艦隊 +0x00 bit0：立起來就印 "無法戰鬥"（色 2）
       否則印 "艦隊行動" ＋ 艦隊記錄 **+0x48 的低四位**查表
  否 → 印 "部隊行動" ＋ 艦艇 **+0x1E** 查另一張表
```

## 兩張行動名稱表

**艦隊行動**（`ds:691C`，遠指標 × 4，索引 ＝ 艦隊記錄 `+0x48` 低四位）：

| 值 | 名稱 |
|---:|---|
| 0 | 移動 |
| 1 | 戰鬥 |
| 2 | 防禦 |
| 3 | 占領 |
| 4 | 待命 |

顏色表在 `ds:6930`：`97 92 97 97 97` ——**「戰鬥」用色 2，其餘色 7**。

**部隊行動**（`ds:694A`，索引 ＝ 艦艇記錄 `+0x1E`）：

| 值 | 名稱 |
|---:|---|
| 0 | 移動 |
| 1 | 編隊 |
| 2 | 索敵 |
| 3 | 歸隊 |

`+0x1E` ＝ `0x7F` 是「沒有自己的命令」，這時改印艦隊的行動。

## 陣營色的原始出處

`ds:6096` ＝ `96 95 97 AB`：低四位就是顏色，**陣營 0 → 6、陣營 1 → 5**。
先前這兩個數字是從畫面量出來的（`docs/re/111`），現在有了一手來源。

## 收據對得上

`s3detail_back` 那張面板：

```
帝國軍  第13艦隊        ← 陣營名用色 6（陣營色表）
第５部隊
戰艦          3000      ← 艦種名 ＋ 艦艇 +0x08
部隊士氣值     100      ← 分隊序號 ≠ 0，值 ≥ 50 所以色 7；標籤色 6
艦隊行動      待命      ← 艦隊 +0x48 低四位 ＝ 4
光線砲       18000
飛彈         12000
戰鬥機       36000
```

三組武器與艦隊詳細資料下半段的第一個數字相同（艘數 × 每艘幾件，
`docs/re/112`），但這裡沒有發射裝置那一組，也沒有「／最大」。

## 還沒解

- 觸發條件：是「資料」帶進去的，還是在戰場上選中一個單位本來就這樣。
- 面板的逐格版面（只讀出內容，還沒量 x／y）。
- 「最高修理數」「剩餘燃料」「補給物資」那三行什麼時候出現。
- 那一串命令（移動／編隊／修理／歸隊／情報／補給／補充／要塞砲）
  怎麼開出來、各自做什麼。**這是一整塊還沒碰的功能。**
