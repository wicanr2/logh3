# 要塞砲開火的算式，以及那一整套 16.16 定點數

[`docs/re/146`](146-battle-damage-helpers.md) 把 Borland 的 long 慣例釘死
之後，剩下兩支——防禦係數 `2264:0FC3` 與實扣艘數 `203A:0593`——就讀得
下去了。過程中順帶把「距離」與「橢圓」那一整套定點數函式也認出來。

## 16.16 定點數

| 位址 | 做什麼 |
|---|---|
| `39B5:000C(a, b)` | 16.16 乘：64 位元乘積取**中間 32 位**（bit 16–47）|
| `39B5:005C(a, b)` | 16.16 除（移位相減）|
| `3310:014B(v)` | 16.16 開方 |
| `3310:0006(x1, y1, x2, y2)` | 兩點距離，**回值是 16.16**：`|Δx|` 與 `|Δy|` 一開始就左移 16 位，短邊除長邊之後走 `√(1 ＋ t²) × 長邊` |
| `3870:0643(a, b)` | 橢圓的**離心率** e ＝ `√(1 − (b/a)²)`，16.16。b ≥ 256 時先把中間量縮成 12 位再補回去，避免溢位 |
| `3870:0614(a, b)` | **焦距** c ＝ `⌊a × e⌋`（取 16.16 乘積的高位字）|

`3310:0006` 回 16.16 這一點是解開後面兩條算式的關鍵：所有拿它去比大小的
地方，另一邊也是 16.16；拿它去乘除的地方，另一個運算元也會**一起帶上
65536**（例如 `20B4:0D96` 把除數寫成 `CX:DX ＝ 5:0`，也就是 5 × 65536，
兩邊的 65536 剛好抵消）。看到 `mov cx, <小數字>` 配 `xor si,si` 就是這個
意思，不要當成高位字寫錯。

## 橢圓判定（`2264:047C`）confirmed

```
ℓ ＝ b² × 65536 ÷ a                 ; 半正焦弦，16.16
e ＝ 3870:0643(a, b)                 ; 離心率，16.16
r ＝ ℓ ÷ (1 − e × cos Δ)             ; 39B5:000C 乘、39B5:005C 除
回 距離 ≤ r
```

也就是**以焦點為極點的圓錐曲線**。`cos Δ` 由 `ds:573A[(Δ ＋ 0x40) & 0xFF]`
（值 × 1024）左移 6 位變成 16.16。Δ 是 `2BE1:024A` 算的兩個 byte 角度的
正差（不折回 0–128）。

`docs/re/145` 把這一條標成 strong inference，現在**升為 confirmed**：
同一段程式碼在 `2264:0FC3` 又出現一次，而且那裡的 r 明確被當成半徑用。

## 防禦係數（`2264:0FC3`）confirmed

```
2264:0FC3(行星, 艦艇)：
    艦隊 ＝ ds:C074 ＋ 艦艇[+0x01] × 0x7A
    列   ＝ ds:4E3A ＋ 艦艇[+0x00] × 0xD0 ＋ 艦艇[+0x04] × 0x1A   ; 艦種表
    θ ＝ atan2(行星[+0x46] − 艦艇[+0x34], 行星[+0x48] − 艦艇[+0x36])
         ; **從艦艇看向行星**——砲從哪一邊來
    Δ ＝ |θ − 艦隊[+0x4A]|                ; 與艦隊朝向的夾角
    r ＝ ℓ ÷ (1 − e × cos Δ)              ; a ＝ 列[+0x16]、b ＝ 列[+0x18]
    回 ⌊r⌋ × 艦隊[+0x3D] ÷ 100
```

**每個艦種自己有一個裝甲橢圓**（艦種表的 `+0x16`／`+0x18` 是它的長短半軸），
判定時取「砲來的那個方向上的半徑」。Δ ＝ 0 是正面中彈，此時
`r ＝ ℓ ÷ (1 − e) ＝ a(1 ＋ e)` 最大——**正面裝甲最厚**。係數再乘上艦隊
能力的第 0 項（`+0x3D`）除以 100。

## 實扣艘數（`203A:0593`）confirmed

```
203A:0593(艦艇, 量, 記錄簿 far)：
    if 艦艇[+0x04] == 7: 回 艦艇[+0x08]          ; 索敵分遣隊不受損
    實扣 ＝ min(艦艇[+0x08], 量)
    ; 兩格存量按剩餘比例縮減（艦種 ≠ 5，而且艦種表對應欄位不是 0xFF）
    ; ⚠ 條件寫反了：艦種 5 無條件縮、其他艦種才看表（docs/re/330 §3.5，0620: cmp al,5; jz 062B）
    艦艇[+0x0E] ＝ 艦艇[+0x0E] ÷ 原艘數 × (原艘數 − 實扣)
    艦艇[+0x12] ＝ 同上
    艦艇[+0x08] −= 實扣
    艦艇[+0x0C] −= 實扣² ÷ 艦艇[+0x0A]           ; 滿編當分母，**平方**
    1261:0067(所屬艦隊)
    敵 ＝ 3982:0250(艦艇[+0x00])
    ds:8FE4[敵 × 4] += 實扣 ÷ 20                 ; 分數，兩份
    ds:8FEC[敵 × 4] += 實扣 ÷ 20
    if 記錄簿 != NULL: 203A:0743(記錄簿, 實扣 ÷ 2)
    回 實扣
```

`+0x0C` 掉的是**實扣的平方除以滿編**——一次被打掉一半的分隊，`+0x0C`
只掉四分之一；被打光才掉滿。要塞砲那條路第三個參數傳 NULL。

`ds:8FE4`／`ds:8FEC` 就是 `docs/re/92` 那兩個計分器。

## 湊起來：要塞砲打一支分隊

```
D    ＝ ⌊r(艦種裝甲橢圓, 砲來的方位 vs 艦隊朝向)⌋ × 艦隊[+0x3D] ÷ 100
基準 ＝ 艦艇[+0x08] × 40 × (行星[+0x16] ÷ D) ÷ 12800
量   ＝ 基準 ＋ rand() % 基準 − 基準 ÷ 2 ＋ rand() % 100      ; 基準 0 時第一項當 0
量   夾在 0 … 艦艇[+0x08]
實扣 ＝ 203A:0593(艦艇, 量, NULL)
```

分母 12800 是伊謝爾倫的防衛力上限，所以 `行星[+0x16] ÷ D ÷ 12800` 讀
起來就是「以伊謝爾倫正面全力一擊為 1.0 的火力比」。

## 還沒讀

（戰場佈置）——都是呈現，不影響數字。規則面剩下的是
[`docs/spec/019`](../spec/019-planet-assault.md) 的 `2583:0003` 與艦隊
`+0x70` bit 1。
