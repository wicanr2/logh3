# 98：戰術選單的七個選項

`docs/re/92` 讀到戰鬥主迴圈每一回合會呼叫 `12AA:02D4`，那支顯示一段字串
（`ds:334F`）再收輸入，回非 0 就跳出迴圈——當時只知道「是問人」，
不知道問什麼。

## 直接把字串倒出來

`ds:334F` 是線性 `57E7F`。倒出來按 NUL 切開，用倚天 Big5 解：

```
戰術 | 實行 | 資料 | 撤退 | 取進度 | 存進度 | 設定 | 結束
```

第一筆是標題，其餘七筆是選項；短的用全形空白補到等寬（「實行  」）。

## 所以那個「提早出口」是選單

戰鬥每一回合結束時，選單開在游標處，**第一項就是「實行」**——這正是
`docs/internals/34` 量到的「同一點連點兩下 ＝ 結束我方輸入」：第一下開
選單、第二下落在第一項上。

`12AA:02D4` 的回傳值就是選了哪一項：

- **實行** → 回 0，主迴圈繼續下一個回合；
- **其餘六項** → 回非 0，跳出主迴圈去處理那個命令。

所以先前寫的「提早結束的出口是有一方選擇退出」只對了一半：跳出迴圈的
**條件**是「選了實行以外的任何一項」，而**撤退**是其中一項。取進度、
存進度、設定、結束這四項會離開戰場去別的畫面，資料與撤退則是戰鬥本身
的功能。

## 還沒解

選單的**版面**（開在游標處的哪個相對位置、幾列、框怎麼畫）還沒量。
量法：在 `s3fight` 的序列上，第一下點擊（第 1,080,000,000 步）之後、
第二下（第 1,095,000,000 步）之前用 `-dump-at` 取一張畫面。

`ds:8F23[陣營]` 那個「這一邊要不要問」的旗標由誰設，也還沒解——
電腦控制的一方應該就是靠它跳過選單。
