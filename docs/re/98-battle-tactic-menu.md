# 98：戰術選單的七個選項

`docs/re/92` 讀到戰鬥主迴圈每一回合會呼叫 `12AA:02D4`，那支顯示一段字串
（`ds:334F`）再收輸入，回非 0 就跳出迴圈——當時只知道「是問人」，
不知道問什麼。

## 直接把字串倒出來

`ds:334F` 是線性 `57E7F`。倒出來按 NUL 切開，用倚天 Big5 解：

```
戰術 | 實行 | 資料 | 撤退 | 取進度 | 存進度 | 設定 | 結束
```

第一筆是標題，其餘七筆是選項；短的用全形空白補到等寬（「實行  」）。

## 所以那個「提早出口」是選單

戰鬥每一回合結束時，選單開在游標處，**第一項就是「實行」**——這正是
`docs/internals/34` 量到的「同一點連點兩下 ＝ 結束我方輸入」：第一下開
選單、第二下落在第一項上。

`12AA:02D4` 的回傳值就是選了哪一項：

- **實行** → 回 0，主迴圈繼續下一個回合；
- **其餘六項** → 回非 0，跳出主迴圈去處理那個命令。

所以先前寫的「提早結束的出口是有一方選擇退出」只對了一半：跳出迴圈的
**條件**是「選了實行以外的任何一項」，而**撤退**是其中一項。取進度、
存進度、設定、結束這四項會離開戰場去別的畫面，資料與撤退則是戰鬥本身
的功能。

### `ds:8F23[陣營]` 解出來了

搜寫入點找到 `0439F` 一帶（依選的陣營走跳躍表的不同分支），那裡把
`ds:8F20`–`ds:8F28` 整批填掉：

```
xor ax,ax                    ; al ＝ 0
mov ds:8F20, al   ; 0
mov ds:8F21, al   ; 0
mov cl, 1
mov ds:8F22, cl   ; 1
mov ds:8F23, al   ; 0   ← 帝國
mov ds:8F24, cl   ; 1   ← 同盟
mov ds:8F25, al   ; 0
mov ds:8F26, cl   ; 1
mov ds:8F27, al   ; 0
mov byte ptr ds:8F28, 1Fh
```

`s3fight` 選的是帝國，而 `8F23`（帝國）＝ 0、`8F24`（同盟）＝ 1。
配上 `12AA:02D4` 的 `cmp byte ptr [bx+8F23h], 0 / je 去問`：

**`ds:8F23[陣營]` ＝ 0 表示那一邊由玩家操作**（回合結束要開戰術選單），
非 0 表示電腦，跳過不問。同一個區塊裡 `8F21`／`8F22`、`8F25`／`8F26`
也是成對的每陣營旗標，語意還沒分。

## 版面

在 `s3fight` 的序列上，第一下點擊（第 1,080,000,000 步）之後、第二下
（第 1,095,000,000 步）之前用 `-dump-at` 取一張畫面（收據 `s3menu`，
游標在畫面 (240,240)）：

| 量到的 | 值 |
|---|---|
| 外框 | (225,221) 126×196 |
| 相對游標 | 左上角 (−15,−19)；**第一項的列頂剛好等於游標的 y** |
| 項目 | 7 列，第一列從 y=240 起，**間距 20** |
| 反白條 | x 253 起、寬 83、高 20，色 2 |
| 顏色 | 底色 9、文字 3、框用 15／7／8／3 |

> 這一節的外框高度 196 是量錯的（下面那一截是面板自己的花紋），
> 逐層結構、字色與反白帶都在 `docs/re/101` 拆完了：實際是
> (225,221) 126×178，框與主選單同一組，本體色 7、立體邊色 3。

> `-dump-at` 寫出來的是 **PNG**（即使副檔名寫 `.bin`），而且落在
> dosgolem 那一側的 `workplace/`——`tools/oracle.sh` 是 `cd` 進 dosgolem
> 再跑的，容器裡的 `/src` 是它。要量色號得先解回索引，
> `tools/scripts/png_indices.py` 就是幹這個的。
