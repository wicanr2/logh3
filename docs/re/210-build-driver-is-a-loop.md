# 210 — `2D76:0002` 是一個迴圈，所以一個 AI 回合可以建很多支

`docs/re/209` 量到同盟在第一個 AI 回合建了**三支**，但 `docs/internals/54`
把 `2D76:0002` 記成「照類別順序試建，成功就停」——那是一支的份量。
兩支讀完就對上了：**外面還有一圈**。

## `2D76:0002`

線性 `0x2D762`：

```
2D76:0002():
    首都 = (ds:8F1D == 0) ? 0 : 31
    星域[首都][+0x12] != ds:8F1D → 回                 ; 首都不是自己的就不建
  外圈:
    n = 2D76:0060()                                  ; 閘門
    n == 0FFFFh → 回                                 ; 擋下來就結束
    r = 2D76:01A5(n)                                 ; 配額 ＋ 試建
    r != 0 → 跳回 外圈                                ; ★ 建成了就再來一輪
    回
```

`2D9AC` 那個 `75 e7`（`jnz`）跳回 `2D79B`，也就是閘門那一行。

## `2D76:01A5` 不只是「減配額」

它的後半（`0x2D97F` 起）才是重點：

```
2D76:01A5(總數):
    ds:D506[0..3] -= 總數 × 40／45／5／10 ÷ 100        ; 配額（整數捨去）
    qsort(索引 0..3, 4, 1, 2D76:0251)                 ; 依「現有 − 應有」升冪
    對 i = 0..3：
        2D76:02FA(排序後的類別[i]) != 0 → break        ; 成功一類就跳出
    回 (i < 4) ? 1 : 0                                ; 有沒有建成
```

所以回傳值就是「這一輪有沒有建成一支」，而 `2D76:0002` 拿它決定要不要
再繞。

## 三支的算式全部對得上

收據 `turn260mem`（`docs/re/209`）：

| 輪 | 閘門 `2D76:0060` | 結果 |
|---|---|---|
| 1 | n ＝ 0 < 3 → 放行 | 建成第一支 |
| 2 | n ＝ 1 < 3 → 放行 | 建成第二支 |
| 3 | n ＝ 2 < 3 → 放行 | 建成第三支 |
| 4 | n ＝ 3，看錢：維持費 426 × 20 ＝ 8520 ≥ 總稅收 7852 | **擋下來，結束** |

亂數也對得上：三輪各兩次（`2D76:02FA` 挑名次、`2D76:0576` 抽鍵）
＝ 6，第四輪連 `2D76:02FA` 都沒走到所以不耗，再加階段四那一次 ＝ **7**，
與量到的種子步數相同。

**「少於三支不看錢」那個豁免因此是有意義的**：它保證電腦開局一定湊得出
三支，之後才受財政限制。

## remake 改了什麼

`ai.BuildPass` 原本一趟只建一支。改成照原版繞外圈，並補一件原版靠副作用
達成的事：**同一趟裡用掉的提督（與他的副官）不再是候選**——原版是
`2D76:0611` 清掉 `+0x09` 的 bit7，下一輪重建清單時他就被 bit5 濾掉了
（`docs/re/208`）。不補這一條，同一位提督會被連續挑中十幾次。

## ⚠ 這讓「換掉 `Original`」多一個風險

閘門靠**艦隊維持費**收手，而 **remake 還沒有算維持費**
（`Support.Money` 一律回 0，`docs/internals/27` 記著收據上帝國那一欄
也是 0）。維持費是 0 的話 `0 × 20 >= 總稅收` 永遠不成立，外圈就只會被
`FleetCap`（16）與「編不成」擋住——**電腦會一路建到十六支**，
而原版在同一個局面停在三支。

`ai.BuildPass` 的註解與 `docs/spec/029` 都標了這一條。
**要接近原版，先補 `ds:8F72` 的算式**；那個算式還沒逆向，
一個資料點（三支 ＝ 426）也推不出來。

## 一條方法

**「成功就停」這種話要確認停的是哪一層。** `docs/internals/54` 寫的
「照順序試建，成功就停」對 `2D76:01A5` 完全正確，錯的是把它當成整件事的
結束——而外面那圈只有一個 `jnz`。**收據上的三支就是這一層的證據**：
量出來的數字與讀出來的結構對不上時，先找有沒有漏掉一層迴圈。
