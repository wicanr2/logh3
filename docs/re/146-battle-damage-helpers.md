# 戰損那幾支輔助函式：先把 Borland 的 long 慣例釘死

> 2026-10-08 指標：本體的 C runtime 是 Datalight C 3.10 Large，不是 Borland（[`442`](442-compiler-is-datalight-c.md)）。下文的位址、呼叫慣例與讀出來的行為不受影響，「Borland」一詞照原文保留。

`docs/spec/019`（打行星）與 `docs/re/145`（要塞砲開火）卡在同一批沒讀完的
函式上。它們共同的障礙是同一件事：算式全走 Borland 的 32 位元輔助函式，
不知道參數怎麼傳就每一條都讀不下去。所以先讀那幾支。

## 呼叫慣例（confirmed）

`3CC9` 那一段是 Borland 的 long helper。逐行讀完之後：

**兩個運算元放 `AX:BX` 與 `CX:DX`（都是「高位字:低位字」），結果回
`AX:BX`。**

```
3CC9:0009   AX:BX × CX:DX → AX:BX          32 × 32 → 32 位元乘
3CC9:0020   AX:BX ÷ CX:DX → AX:BX          **無號**除，餘數在 CX:DX；
                                            除以 0 回 0xFFFFFFFF
3CC9:0070   同上但**有號**（先取絕對值，呼叫 0020，再依號數補回去）
3CC9:00B9   比較：高位字不同就直接帶著旗標回，相同時 AX ← −1／0／1
3CC9:00CC   亂數：ds:94DC 那個 32 位元種子 × 0x41C64E6D（`docs/re/87`）
```

編譯器產生的呼叫長這樣，看到就照上面套：

```
mov  bx, <低位>        ; AX:BX = 運算元一
xor  ax, ax
mov  cx, <高位>        ; CX:DX = 運算元二
mov  si, <低位>
xchg dx, si
call far 3CC9:xxxx
```

`xchg dx, si` 只是編譯器用 SI 當暫存把值搬進 DX，沒有別的意思。

## `203A:0424(艦隊)` ＝ 這一支的攻擊力（confirmed）

```
主力 ＝ Σ 這一支每個分隊裡艦種 0 或 1 的艘數（艦艇 +0x08）
        ; 走艦隊 +0x0F 個編制槽，每槽 4 bytes，前兩 byte 是艦艇池索引
攻擊力 ＝ 主力 × 艦隊[+0x40] ÷ 100 ÷ 15 ＋ 250
```

沒有亂數。`+0x40` 是艦隊能力那 11 個 byte 裡的一個（78–120）。

## `203A:04D1(行星)` ＝ 這顆行星旁邊的守軍（confirmed）

```
r ＝ 2AF5:01F7(行星)                       ; rules.PlanetQueryRadius
清單 ＝ 17A0:00AC(行星[+0x11], 行星[+0x46], 行星[+0x48], r, …)
        ; 只查**行星自己那一方**
守軍 ＝ Σ 清單裡艦種 0 或 1 的艘數 ÷ 100      ; 32 位元累加，溢位就夾 0xFFFF
```

## `20B4:0D96(艦隊, 行星)` ＝ 這一輪打掉多少防衛力（confirmed）

```
A  ＝ 203A:0424(艦隊)
d  ＝ 艦隊[+0x5C]／[+0x5E] 到 行星[+0x46]／[+0x48] 的距離（3310:0006）
B0 ＝ A − A × (d ÷ 150) ÷ 5                ; 距離衰減
量 ＝ B0 ÷ 2 ＋ rand() % (B0 ÷ 3)
```

`docs/spec/019` 的 `B` 就是它。距離用的是艦隊的**現在座標**
（`+0x5C`／`+0x5E`），不是那份舊筆記裡的 `+0x46`／`+0x48`。

## `20B4:0E7E(行星, …)` ＝ 行星的反擊基準（confirmed）

```
除數 ＝ 行星[+0x12] 非 0 ? 20 : 10          ; 有要塞就砍半
量   ＝ (203A:04D1(行星) ＋ 行星[+0x14]) ÷ 除數
```

`docs/re/86` 記的「`+0x12` 非 0 時除數從 10 變 20」是對的，但那兩格是
**行星**的（要塞旗標與防衛力），不是艦隊的——`docs/re/99` 已經把第一個
參數改判成行星記錄，這裡把欄位歸屬一起補上。

## `2264:0EE3(行星, 艦艇)` ＝ 要塞砲打掉幾艘（confirmed，除了防禦係數）

```
D    ＝ 2264:0FC3(行星, 艦艇)               ; 防禦係數，未解
基準 ＝ 艦艇[+0x08] × 40 × (行星[+0x16] ÷ D) ÷ 12800
量   ＝ 基準 ＋ rand() % 基準 − 基準 ÷ 2 ＋ rand() % 100
量   夾在 0 … 艦艇[+0x08]
實扣 ＝ 203A:0593(艦艇, 量)
```

基準為 0 時第一個 `rand() %` 那項當 0（原版先判 `bx == 0`）。

**這個形狀與艦隊戰鬥的損失公式是同一個**（`rules/losses.go` 的
「量 ＝ 基準 ＋ (亂數 % 基準) − 基準 ÷ 2 ＋ (亂數 % 100)」），所以要塞砲
不是另一套系統，只是換一個基準量。分母 12800 剛好是伊謝爾倫的防衛力
上限——`行星[+0x16] ÷ D ÷ 12800` 讀起來像「以伊謝爾倫為 1.0 的火力比」。

## 順手修掉的一處歸屬錯誤

`docs/internals/33`（艦隊表）「戰損用到的幾個欄位」那張表把
`+0x12`、`+0x14`、`+0x46`／`+0x48` 列成艦隊的欄位。那是 `docs/re/86` 把
第一個參數當成艦隊留下來的，`docs/re/99` 推翻之後那三列的歸屬沒跟著改。
它們是**行星記錄**的要塞旗標、防衛力與座標。
