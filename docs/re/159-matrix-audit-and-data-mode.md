一項在後面幾輪被解掉之後，解它的那一列會更新，**依賴它的那一列不會**。

## 順帶把「資料」那個模式量清楚

`docs/re/113` 說「單位畫成 16×16 的方塊，不是 sprite」，語氣像是整張
畫面換了模式。實際數一遍——找「外圈一整圈色 6、內圈一圈色 1」的 16×16
圖樣（`tools/scripts/detail_blocks.py`）：

```
s3data0        方塊 0 個
s3detail_back  方塊 4 個   (248,173) (220,215) (173,232) (240,240)
```

**四個，不是全部。** 所以那不是「顯示模式」，是四個分隊的顯示層級
（艦艇 `+0x17`）變成 2 而已——與 `docs/re/85` 的規則一致，remake 的
`rules.BattleSprite` 早就有這條。

`workplace/s3datamem.bin` 用不上**：那份是另一條序列的傾印，

## 教訓

**一列驗證矩陣的備註引用另一列的結論時，那是一個會過期的連結。**
解掉某項之後要往回走一遍「誰依賴它」——與 `docs/re/153` 那一輪
「推翻一個斷言要把依賴它的每一處都走一遍」是同一條，這次的形式是
**解決**而不是推翻，一樣會留下假的「未解」。
