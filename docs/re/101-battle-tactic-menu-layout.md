# RE 101 — 戰術選單的版面：逐位元組對上了

`docs/re/98` 解出戰術選單的七個選項與 `ds:334F` 的字串表，當時只量了外框
的粗略位置，寫著「框的逐層結構還沒拆」。這一輪把它拆完，remake 畫出來
與收據**逐位元組相同（0 ／ 22428）**。

## 收據

`s3menu` 的 `-dump-at` 在第一下點擊之後、第二下之前取了一張畫面
（第 1,090,000,000 步，滑鼠在 (240,200) ＝ 畫面 (240,240)）。

> `-dump-at` 寫出來的是 **PNG**，同時另存一份 `.bin` 的色號陣列，而且
> 落在 **dosgolem 的** `workplace/`。這一輪把它收進
> `workplace/oracle/s3menu/menu-open.bin`，測試直接讀它。

## 版面

先前記的外框 `(225,221) 126×196` 高度是錯的——下面那一截量到的是面板
自己的花紋。實際是：

| 量到的 | 值 |
|---|---|
| 外框 | (225,221) **126 × 178** |
| 相對游標 | 左上角 (−15,−19) |
| 內部（框 7 層之後）| (232,228) 112 × 164，底色 9 |
| 上下留白 | 各 12 列 |
| 左右留白 | 各 8 行 |
| 反白帶 | (240,240) **96 × 20**，色 2 |
| 字身 | 第一列 y ＝ **242**（比帶頂低 2 列），x ＝ 240，間距 16 × 20 |

反白帶寬 96 ＝ **6 × 16**，而字串表裡每一筆固定 6 個 byte：

```
BE D4 B3 4E 00                戰術（標題）
B9 EA A6 E6 20 20 00          實行␠␠
A8 FA B6 69 AB D7 00          取進度
```

兩個全形字的補兩個**半形**空白。原版拿 byte 數乘全形字寬去算帶寬，
所以帶子是文字的兩倍寬。**開出來的選單沒有畫標題**——內部最上面
那 12 列是純底色。

## 框就是主選單那個框

七層由外往內（Top, Right, Bottom, Left）：

```
{15,15, 8, 8}  {7,7,3,3}  {15,15,15,15}  {15,15,15,15}
{ 3, 3, 7, 7}  {8,8,8,8}  { 3, 3, 3, 3}
```

與 `ui.MenuFrame()`（量自主選單）**完全相同**，連四個角的 45° 切法用的
七個修正像素都成立。`docs/internals/07` 當時寫「換一個視窗尺寸一定要
重驗」——這是第二個樣本，過了。

> 後續（`docs/re/289`）：框根本不是線畫的，是 `FRAME.BLK` 的八張圖塊；
> 七層與那七個修正像素是重建版，與圖塊在框的矩形內逐像素相同。
> 本節量到的數字沒有變，變的是它們從哪裡來。
> 這一篇記的框位置公式「游標 ＋ (−15,−19)」也在那裡被換成格座標——
> 本篇的游標 (240,240) 剛好是 16 與 20 的整數倍，分不出兩個模型。

## 文字用的是遊戲既有的立體邊

一開始看到文字有色 3 與色 7 兩種，數量還是色 7 比較多（132 對 103），
所以不是「色 7 是色 3 的陰影」。實際是反過來：

- **本體色 7**，
- **立體邊色 3**，畫法是字模每一列**左移一位**再整體**上移一列**
  （`docs/internals/25` 那條既有規則），先畫立體邊再畫本體。

立體邊會被本體蓋掉一部分，所以剩下來的色 3 比色 7 少。六個選項逐點驗過，
全部吻合。

## 對拍

`internal/screen.DrawBattleMenu` 把框、反白帶與七行字畫進空白畫布，
再照收據的滑鼠座標畫游標（游標吃的是**滑鼠**座標，`offset_from_mouse`
的 40 就是滑鼠與畫面的差）。選單那個矩形整塊是選單自己的，所以可以
直接比：

```
選單 (225,221) 126×178：0／22428 個像素不同
```

游標壓在第一項上——那 76 個像素一度被當成差異，其實是原版自己畫的游標。

## 接進遊戲

`Game.battleClick`：沒開選單的時候左鍵在游標處開選單，開著的時候看點在
第幾項。實行 → 推一個回合並留在戰場（`12AA:02D4` 回 0，主迴圈繼續）；
撤退 → 結束戰鬥。取進度／存進度／設定／結束會離開戰場去別的畫面，
**那條路還沒逆向**，先只把選單關掉。

先前的「同一點連點兩下推一個回合」不是另一套契約，是這條規則的結果：
第一下開選單、第二下落在第一項上。
