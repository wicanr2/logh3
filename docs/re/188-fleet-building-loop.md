# 188 — 建艦隊：先問「還能不能建」，再從全部提督裡挑

`docs/re/169` 讀出建艦隊的配額（40／45／5／10％），但把
`2D76:0060`（回總數／`0xFFFF`）與 `2D76:02FA`（實際建一支）留著。
這一輪讀完。

## `2D76:0060() → 現有艦隊數 或 0FFFFh`

```
若 ds:8F49[ds:8F1D] >= 16：回 0FFFFh          ; 上限，不能再建
n = 2D76:011C()                               ; 數各類別現有數，順便填 ds:D506
若 n < 3：回 n                                ; 少於三支就不看錢
… 讀陣營的錢（ds:8F6A／ds:8F6C，32 位元）與 ds:8FD4[陣營] …（未讀）
```

`2D76:0002` 的迴圈就是「`2D76:0060()` 回 `0xFFFF` 就收工，否則把那個數
交給 `2D76:01A5` 去算配額」（`docs/re/169`）。**上限與錢是兩道獨立的閘門**，
而且**少於三支的時候不看錢**——開局艦隊少時 AI 會先把數量補上來。

## `2D76:02FA(類別) → 建成了沒`

```
筆數 = 28E0:0103(&清單, 0FFh, 25h, 0)          ; 全部提督（星域 0FFh ＝ 不限）
若 筆數 == 0：回 0
對每個提督：2D76:0434(提督, 類別)              ; 逐一評分（未讀）
依 2D76:04FD 排序
…（取最好的那些去建，未讀）
```

`28E0:0103` 的第三個參數 `0x25`（37）在 `2E54:0513` 也出現過
（`docs/re/180`）——兩處都是「取提督清單」，差別在第二個參數：
那邊給首都星域、這邊給 `0xFF`（不限）。**所以 `0x25` 是清單種類，
第二個參數才是星域。**

## 更正 `docs/re/169`

那一篇把「數各類別現有數」那支寫成 `2D76:011B`，正確是 **`2D76:011C`**
（`0x2D87C`；`0x2D87B` 是前一支的 `retf`）——`2D76:0060` 的呼叫是
`9a 1c 01 76 2d`。與 `docs/re/171` 更正 `08D2` → `08D3` 是同一種錯：
**用 `hexat` 手解時，函式起點要對齊到前一支的 `cb` 之後一個位元組。**

`2D76:02FA` 的後半、`2D76:0060` 看錢那一段、`ds:8FD4`。
