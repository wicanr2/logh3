# 216 — 艦種不夠就換：`0FF4:0E84` 數得出幾組，`ds:295C` 給替代順序

`docs/re/215` 把「一組編制怎麼變出艦艇」讀完了，但**那一組要哪個艦種**
還沒解——`0FF4:11F4` 的迴圈裡有兩支沒讀：`0FF4:0E84` 與 `0FF4:1350`。
這一輪讀完。

## `0FF4:0E84(艦種)`：那一格能編出幾組

```
存量 = ds:9872 指的星域 [+0x30 + ds:8F1D × 28 + 艦種 × 4]   ; 32 位元
滿編 = ds:4E3A[ds:8F1D][艦種] 的 word 0
回 存量 ÷ 滿編（形狀是 32 位元除法）
```

`ds:9872` 是 `0FF4:11F4` 一開始存下來的「這支艦隊所在星域」的遠指標。
**陣營取的是 `ds:8F1D`（目前處理中的那一方），不是艦隊記錄的 `+0x01`。**

呼叫端拿它判兩件事：`v == 0`（一組都編不出來）要換艦種；
`a == 星域擁有者 且 v < 4` 另有一段（還沒讀完）。

## `0FF4:1350(艦隊, 艦種)`：換一個

```
清單 = ds:295C + 艦種 × 6
逐個往下：
    == 0FFh → 結束（回 0FFh ＝ 換不到）
    == 0FEh → 特例（還沒讀）
    0FF4:0E84(候選) != 0 → 回 候選
```

**`ds:295C` 是替代順序表**，倒在
`docs/internals/data/ship-kind-fallback.json`
（`tools/scripts/ship_kind_fallback.py`）：

| 艦種 | 替代順序 |
|---|---|
| 0 | 2 → 4 → **FE** → 3 → 1 |
| 1 | 2 → 0 → 4 → **FE** → 3 |
| 2 | 4 → 0 → **FE** → 3 → 1 |
| 3 | 4 → 2 → **FE** → 0 → 1 |
| 4 | 2 → 0 → **FE** → 3 → 1 |
| 5 | 6 → 4 → 2 → 0 → 3 |
| 6 | 5 → 2 → 4 → 0 → 3 |
| 7 | 1 → 2 → 4 → 3 → 5 → 6 |

一個艦種 6 bytes、`0xFF` 結尾。**艦種 7 的六個 byte 用滿了**，
結尾落在下一格——而下一格的第一個 byte 剛好是 `0xFF`，
所以照 `× 6` 索引仍然讀得對。

`0xFE` 不是艦種，是清單裡的一個特例標記（`0FF4:1350` 對它有獨立分支，
還沒讀）。它只出現在艦種 0–4 的清單裡，位置都在中段。

## 這條鏈現在的樣子

```
樣板 ds:2BC6 給 a                                （docs/re/212）
星域擁有者 == 1 且 a == 0 → a = 1
v = 0FF4:0E84(a)                                 ; 那一格編得出幾組
v == 0 → a = 0FF4:1350(艦隊, a)                  ; 照 ds:295C 換一個
         a == 0FFh → 這一支就編到這裡為止
槽[i] ← 艦種 a，艦艇由 2AD2:0029 產生             （docs/re/215）
   艘數 = min(星域存量, 滿編)，並從星域扣掉
```

**兩張表都進版控了**（`fleet-composition-templates.json`、
`ship-kind-fallback.json`），所以就算後面兩個小分支還沒讀，
資料本身不會過期。

## 還沒讀的兩個小分支

- `0FF4:1350` 對 `0xFE` 的處理。
- `0FF4:11F4` 裡 `a == 星域擁有者 且 v < 4` 那一段。

兩個都在「換不換艦種」這一層，不影響已經定下來的存量算式。

## 一條方法

**「不夠就換」這種規則，換的順序通常是一張表，不是一段 if。**
先假設有表、去找一個以參數為索引的區塊，比逐行讀分支快得多——
這一輪從 `mul 6` 那一行就直接跳到 `ds:295C` 把表倒出來了。

---

> 「星域擁有者 == 1 且 a == 0 → a = 1」讀錯了：`es:[bx+0x12]` 的 `bx`
> 是**艦隊記錄**，那一格是第 0 組（旗艦）的 `[2]` ＝ 旗艦的艦種
> （`docs/re/224`）。收據裡三支同格同擁有者、旗艦艦種不同，直接分得開。
> 留下的「`a == 星域擁有者 且 v < 4`」那一段也一起讀完了，比的同樣是
> 旗艦艦種。
