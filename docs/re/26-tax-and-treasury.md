## 軍事費與總稅收住在哪

一樣從畫面往回追。命令階段第二行的格式字串在 `ds:06CD`：

```
"軍事費  %10ld  總稅收  %8lu"
```

用它的那一處（線性 `0534E`）：

```
8A 1E 1D 8F   mov bl,[8F1D]      ; 玩家陣營
D1 E3 D1 E3   shl bx,1; shl bx,1 ; ×4
FF B7 6C 8F   push [bx+8F6C]     ; 總稅收 高字
FF B7 6A 8F   push [bx+8F6A]     ; 總稅收 低字
FF B7 54 8F   push [bx+8F54]     ; 軍事費 高字
FF B7 52 8F   push [bx+8F52]     ; 軍事費 低字
```

- **軍事費**：32 位元，`ds:8F52 + 陣營×4`
- **總稅收**：32 位元，`ds:8F6A + 陣營×4`

796 年 1 月 1 日讀出來：帝國 45592／10341、同盟 50000／11087，與畫面相同。

## 稅率是每個星域各自的（confirmed）

先前以為 3.2% 是全國統一的——**不是**，那是首都的。
星域記錄的 `+0x26` 就是該星域的稅率，單位是千分之一：

```
26 8A 4C 26   mov cl,es:[si+26]     ; 稅率
…             32 位元乘法（3CC9:0009）
BE E8 03      mov si,03E8           ; 1000
…             32 位元除法（3CC9:0020）
```

所以 **徵稅額 ＝ 經濟力 × `+0x26` / 1000（捨去）**。
瓦爾哈拉 82302 × 32 / 1000 ＝ 2633，與畫面相同。

`+0x27` 是上個月的那一份：月底結算時程式把 `+0x26` 抄過去。

## 總稅收 ＝ 自己擁有的星域徵稅額相加（confirmed）

月底那一支（線性 `273E0`）：

```
C7 87 6A 8F 00 00   mov word [bx+8F6A],0     ; 總稅收歸零
…
26 8A 47 12         mov al,es:[bx+12]        ; 星域擁有者
3A 06 1D 8F         cmp al,[8F1D]            ; ＝ 玩家陣營？
75 1B               jne …                    ; 不是就跳過
9A B8 0A 03 27      call far 2703:0AB8       ; 算這個星域的稅並累加
26 8A 47 26         mov al,es:[bx+26]
26 88 47 27         mov es:[bx+27],al        ; 稅率抄到 +0x27
83 46 00 7E         add word [bp+00],126     ; 下一筆
…
8B B7 6A 8F         mov si,[bx+8F6A]
01 B7 52 8F         add [bx+8F52],si         ; ← 軍事費 += 總稅收
11 8F 54 8F         adc [bx+8F54],cx
```

拿 32 筆執行期記錄照這個算，**兩個陣營都逐元相符**：

| 陣營 | 算出來 | 畫面 |
|---|---:|---:|
| 帝國 | 10341 | 10341 |
| 同盟 | 11087 | 11087 |

（用全國統一的 3.2% 去算會得到 8980，差很多——這就是「稅率是每個星域各自的」
這件事的反證。）

## 月底的軍事費（未解）

`軍事費 += 總稅收` 是 confirmed 的，但那不是全部。實測：

| | 796/1/1 | 796/2/1 |
|---|---:|---:|
| 軍事費 | 45592 | 42339 |
| 總稅收 | 10341 | 10413 |

`45592 + 10413 = 56005`，而畫面是 42339，差 13666——扣掉的是船艦建造費
那一類支出。徵稅計劃畫面（收據 `tax1e`）自己給的預估是
`預估軍事費 55933 = 45592 + 10341`、`剩餘軍事費 41950 = 55933 − 13983`，
與實際的 42339 差 389。**扣款那一步還沒追。**

順帶驗證：`tax1e` 的「本月份 原定軍事費 60741 − 已支付 船艦建造費 15149
＝ 45592」，正好是目前的軍事費，所以那兩個數字是上個月的結算留下來的。
