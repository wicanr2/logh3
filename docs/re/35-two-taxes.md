## 兩個稅

`docs/re/33` 算出來的十個是 2718、1112、817、239、459、1413、1369、1468、
826、311——六個星域各少 1 或 2，加起來正好 9。

差在哪：**從行星身上扣掉的是逐顆捨去的和，進國庫的是拿星域總和算一次捨去。**

星域 0：成長後四顆是 54132／10329／12624／7935，合計 85020。

```
逐顆捨去：1732 + 330 + 403 + 253 = 2718   ← 從行星的經濟力裡扣掉這個
總和捨去：floor(85020 × 32 / 1000) = 2720 ← 進國庫的是這個
```

## 完整的月底

```
對每一顆行星：
    經濟力 += 經濟力 × 成長率(經濟力, 防衛力) / 1000
    行星稅  = 經濟力 × 星域稅率 / 1000        （捨去）
    經濟力 -= 行星稅
星域經濟力 = Σ 該星域行星的經濟力
進國庫的稅 = (Σ 成長後、扣稅前) × 星域稅率 / 1000    （捨去）
軍事費 += Σ 自己星域進國庫的稅
```

`internal/rules.MonthEndRegion` 照這個改了，十個帝國星域的**經濟力與
進國庫的錢都逐一相符**，合計 10741。
