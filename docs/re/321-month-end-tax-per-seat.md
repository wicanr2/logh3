## 結論

1. **`2703:0AB8(星域, 旗標)`**（線性 `0x27AE8`）：
   - 一進去先擋三種格子：擁有者 `+0x12 == 2`（無主）、`+0x13 & 6`（bit1／bit2）、
     `+0x13 & 1`——這三種**既不估也不扣**；
   - `2AF5:0036(+0x11, 0)` 切到那一格的行星，逐顆：`稅 ＝ 行星[+0x1A] × 星域[+0x26] ÷ 1000`
     （`3CC9:0009` 乘、`3CC9:0020` 除），Σ 累加成長後的經濟力；**旗標 ≠ 0 才
     `行星[+0x1A] −= 稅`**（`+0B5E` `cmp [bp+24h],0` → `+0B70` `sub es:[si],bx`）；
   - 迴圈完 `總稅 ＝ Σ × 稅率 ÷ 1000`（一次捨去，`docs/re/35` 的「進國庫的那個數」），
     擁有者 0 且 **星域 0（瓦爾哈拉）`+0x12 == 0`** → 加進 `ds:8F6A`；擁有者 1 且
     **星域 31（巴拉特）`+0x12 == 1`** → 加進 `ds:8F6E`。首都丟了那一方的總稅收就不再累加
     （`+0BB6` 讀 `ds:A7AE`、`+0BD2` 讀 `ds:B6F0`——兩個位址就是星域 0／31 的 `+0x12`）。
2. **誰用旗標 1**：只有 `2703:03AF`（`docs/re/26` 讀過的那一支）——先 `ds:8FF8[陣營] ←
   ds:8FD4[陣營]`、把 `ds:8F6A[陣營]` 歸零，再掃 32 格、**只對 `+0x12 == ds:8F1D`（這個
   座位的陣營）的格子** `2703:0AB8(星域, 1)` 並 `+0x27 ← +0x26`，最後 `軍事費 += 總稅收`。
   `2703:02E5`（每個座位回合都跑的共同尾巴 `090A:0E6D` 的第一支）對 32 格叫的是旗標 0
   ——只把 `+0x1A` 重寫成行星加總（`2703:034E`）、累加預估、重算未安定度，**不扣**。
3. **所以扣稅是逐座位的**：帝國座位在自己的回合（`04F8:01B9(座位 0)` → `0654:0034`
   閘門）扣帝國的星域，同盟座位在自己的回合扣同盟的，無主星域永遠不扣。單人模式
   帝國玩家看到的月初畫面是「帝國已扣、同盟與中立只有成長」，同盟那一份要等玩家
   按完「實行」、輪到同盟座位才扣。收據：
   - 796/01（開局）：`fcmd-rinfo-ballat`／`-fezzan` 右側面板的經濟力——巴拉特 68282
     ＝ 65100 × 1.0489（只有成長；帝國自己的瓦爾哈拉 82302 是扣過的）、費沙 103100。
     規格 053 原本把那一格列成排除區，這一輪拿掉之後整張逐位元組相同。
   - 796/02 帝國命令階段：`monthwork3`（`mr1820.bin`）32 格逐格——帝國 9 格（星域 9 見
     §四）經濟力／成長率／稅率全同；無主 7 格全同（含 §三的稅率規則）；同盟 13 格的
     `+0x27` 全是**開局那一份稅率**（46／55／44／40…，不是新的 56／70／56／53），證明
     那一趟還沒抄、還沒扣。
   - 796/02 回合 11（玩家按完一次「實行」之後）：`monthwork4`（`mr1990.bin`）——同盟
     座位跑過了，`+0x27` 換成新稅率、經濟力扣過稅（§五）。
4. **無主星域的稅率**（`090A:0B5E` 的第三段 `090A:0DC0(2)`，`docs/re/267` 標「未讀」）：
   對 32 格裡 `+0x12 == 2` 的：成長率 `+0x1E ≤ 0` → `Base[2] × 5 ÷ 100`，否則
   `成長率 × Base[2] ÷ 100`（`Base[2] ＝ 100`，所以就是成長率），寫低位元組、沒有夾限、
   不碰 `+0x27`。一個月一次、跟在兩個陣營的 `090A:0B93` 後面。remake 原本開局算一次
   之後就不再更新（796/02 星域 3 原版 57、remake 停在 58）。
5. **`+0x27` 的三個寫入點**：載入時 `2703:01BD`（`docs/re/44`，全部 32 格 `← +0x26`）、
   自己座位的 `2703:03AF`（只有自己的格子）；無主星域之後再也沒人抄，所以 796/02
   無主格子的 `+0x27` 仍是載入時那一份（58）而 `+0x26` 已是新成長率（57）。remake 的
   `LoadRegionRecords` 原本沒做載入那一抄（`+0x27` 留著 `STELLAR.DTA` 檔案裡的 28）。

## 一、`2703:0AB8` 逐行

```
0AB8  rec = [bp+20h]（far）、flag = [bp+24h]
0AC3  cmp rec[+12h], 2   → jz  0DEB（回）          ; 無主：不估不扣
0ACD  test rec[+13h], 6  → jnz 0DEB
0AD7  test rec[+13h], 1  → jnz 0DEB
0AE1  2AF5:0036(rec[+11h], 0)                      ; 行星切片 ds:CFF8／筆數 ds:CFFC
0B0A  for 每顆行星（+52h 一筆）:
0B16    e = 行星[+1Ah]（32 位元）
0B29    rate = rec[+26h]
0B3B    tax = e × rate（3CC9:0009）÷ 1000（3CC9:0020）
0B58    Σ += e
0B5E    flag == 0 → 跳過扣
0B70    行星[+1Ah] −= tax                           ; 旗標 1 才有
0B80  total = Σ × rate ÷ 1000
0BAF  rec[+12h] == 0 && ds:A7AE == 0 → ds:8F6A += total   ; ds:A7AE ＝ 星域 0 的 +12h
0BC7  rec[+12h] == 1 && ds:B6F0 == 1 → ds:8F6E += total   ; ds:B6F0 ＝ 星域 31 的 +12h
0BE6  2AF5:00B6()
```

## 四、對不上的、不是這一條的

- 星域 9／24／28：remake 在回合 1–9 的叛亂判定把它們翻成無主（原版 796/02 仍是帝國／
  同盟），亂數序列的事，測試跳過那三格。
- 同盟十三格的**經濟力**在 796/02 差 −595～＋88（原版多半較高）——**hypothesis**：
  原版 AI 建的艦隊把維持費的一半與移動費流進行星（`PayIntoRegion`，`docs/re/313`），
  remake 的 AI 決策不同、流進去的錢不同；開原版 AI 之後數字會動（星域 31 從 70412
  變 70482）但沒對齊。`+0x27` 逐格相同，所以「還沒扣稅」這件事不受影響。
- `2703:0AB8` 開頭擋 `+0x13` bit0–bit2 的三個 `test`：讀出來了，沒有收據，remake 沒接
  （`CollectTax` 註解記著）。首都丟了不累加總稅收那兩個 `cmp` 同樣沒接。
