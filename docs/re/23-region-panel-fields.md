# RE 23 — 星域面板那幾個數字從哪來

日期：2026-09-07
執行器：dosgolem-logh3 `8c8af90`
收據：`main1e`、`hovA`、`hovB`、`hovC`、`star1e`、`turnnext`
狀態：**防衛力／行星數／經濟力／徵稅額 confirmed**；治安**未解**。

## 兩塊面板不是同一件事

右側那塊（防衛力、經濟力、成長率、徵稅額、稅率）**一直是自己的首都**
——在星圖上按右鍵換了四個不同的星域，右側四份收據的內容逐字相同，
都是瓦爾哈拉。會跟著換的是**左下角**那塊。

## 執行期的星域記錄

`STELLAR.DT*` 整份載在 `ds:A79C`，一筆 126 bytes（`docs/re/17`）。
把 796 年 1 月 1 日那一刻的記憶體倒出來，六個星域逐欄對畫面：

| 位移 | 內容 | 驗證 |
|---|---|---|
| `+0x12` | 擁有者：0 帝國、1 同盟、2 無主 | 六個星域與地圖顏色一致 |
| `+0x16`／`+0x17`／`+0x18` | 帝國／同盟／其他 各有幾顆行星 | 星域 0 ＝ 4,0,0（畫面「行星 4/4」）；星域 3 ＝ 0,0,3（「行星 0/3」）|
| `+0x1A` | **經濟力**（32 位元）| 星域 0 ＝ 82302，與畫面上的數字相同 |
| `+0x20`／`+0x22` | **防衛力**（同一個值兩份）| 星域 0 ＝ 27300，與畫面相同 |

畫面上的「行星 n/m」＝ **玩家陣營的行星數 / 該星域行星總數**。
中立與敵方的星域分子是 0（星域 3「0/3」、星域 19「0/3」）。

## 防衛力就是行星防衛力相加（confirmed）

`PLADAT.DAT` 的檔頭 64 bytes ＝ 32 個 word，第 k 個就是第 k 個星域有幾顆
行星，合計 81 ＝ 記錄筆數；行星**照星域順序連續存放**。

拿檔案自己算「該星域行星的 `+0x14` 相加」，六個星域與執行期的 `+0x20`
完全相同：

| 星域 | 行星 | 相加 | 執行期 `+0x20` |
|---|---|---:|---:|
| 0 瓦爾哈拉 | 奧丁 9200、布連娜 6300、亞爾斯達 7000、梅莉克 4800 | 27300 | 27300 |
| 2 亞爾提那 | 8200、9800 | 18000 | 18000 |
| 3 卡斯特羅普 | 5800、2300、3200 | 11300 | 11300 |
| 14 費沙 | 8800 | 8800 | 8800 |
| 19 特利布拉 | 4200、4500、6500 | 15200 | 15200 |
| 30 艾流塞拉 | 4500、4000、5600 | 14100 | 14100 |

## 徵稅額 ＝ 經濟力 × 稅率（confirmed）

82302 × 3.2% ＝ 2633.6 → **2633**；跨月之後 83304 × 3.2% ＝ 2665.7 → **2665**。
兩個月都成立，捨去不進位。

## 治安（未解）

星域 0 是 82%、星域 2 是 86%。**星域記錄裡沒有任何一個 byte 同時是這兩個值**
（126 個位移逐一比對過），所以不是直接存的。`+0x1E`（45／52）不是它。

行星那邊也還沒對上：`PLADAT.DAT` 的 `+0x18` 與 `+0x1E` 兩組小數值
（星域 0 的四顆是 2,3,4,4 與 5,3,4,5）看起來像等級，與 82／86 沒有明顯關係。
中立與敵方的星域畫面上寫 `----`，所以治安只對自己這一方算。

## 經濟力的基準對不上檔案（未解）

檔案裡該星域行星的 `+0x1A`（32 位元）相加，星域 0 是 **81300**，
而執行期是 **82302**，差 1002；跨月之後變成 83304，又差 1002。
所以載入時已經先長過一次，成長那一步的算式未解
（成長率畫面上寫 4.5%，但 1002 / 81300 ＝ 1.23%）。
