# 177 — 階段二是「打最近的無主星域」，階段五是收尾指派

`docs/spec/029` 把階段一、二、五標成「不得猜測」，因為六支常式沒讀。
這一輪把六支都讀了，其中五支讀完、一支讀到一半。

## 階段二：`2E54:0EC2`

```
n = 2E54:0F09(&清單)                  ; 收候選
若 n == 0：結束
qsort(清單, n, 1, 2E54:1001)          ; 依距離升冪
2E54:1108(清單[0])                    ; 只處理最近的那一個
```

### `2E54:0F09(&清單) → 筆數`

```
首都 = (ds:8F1D == 0) ? 0 : 31
對 i = 0 … 31：
    若 星域[i][+0x12] != 2：跳過                  ; ★ 擁有者 2 ＝ 無主
    d = 2B99:028F(i, 首都, ds:8F1D)
    星域[i][+0x78] = d                            ; 距離暫存在記錄裡
    若 d >= 0800h：跳過                           ; 走不到
    若 i == 14 且 2E54:0F93() == 0：跳過          ; ★ 星域 14 的特例
    清單[筆數++] = i
```

**擁有者 `2` ＝ 無主**（帝國 0、同盟 1）。這一支就是
`docs/re/161`「無主行星是被打下來的，不是被收編」那條路的起點。

`2E54:1001` 比的是剛存進去的 `+0x78`，**升冪**——所以階段二只打
**走得到的、離自己首都最近的那一個無主星域**。

**星域 14 是全遊戲第二個寫死的星域編號**（第一個是 `docs/re/167` 的
星域 13 ＝ 伊謝爾倫）。它要多過一道 `2E54:0F93()`（未讀）才算候選。

### `2E54:1108(星域)`

```
候選 = []
重複：
    f = 2E54:143F(星域, 2)            ; ★ 模式 2
    若 f == 0:0：跳出
    候選 += f；f[+0x79] = 1
    若 已經兩支：跳出
若 候選少於兩支：什麼都不做
對兩支都：2E54:1B17(f, 1, 星域)       ; 行動 1
```

**打無主星域要湊滿兩支，湊不到就不打。** 這裡是 `2E54:143F`
**模式 2** 唯一的呼叫者（`docs/re/174` 當時還沒找到）——模式 2 的條件
（完整度 80、要求編制滿、主力槽 ≥ 4）比增援的模式 1 更嚴，
但艦隊已經在目標星域時完整度門檻降到 50。

## 階段五：`2E54:119E`

```
2D54:0000()                           ; 重算 ds:D50E ＝ 攻擊目標分
qsort([0…31], 32, 1, 2E54:11F2)       ; 依 ds:D50E 降冪
2E54:1243(清單[0])                    ; 只處理分數最高的那一格
```

`2E54:11F2` 與 `2E54:09EE`（`docs/re/170`）是同一個比較式：
`ds:D50E` 降冪。

### `2E54:1243(星域)` ＝ 收尾指派

```
首都 = 3982:0329(ds:8F1D)
目標 = 2E54:13A8(星域)                        ; 未讀
對 32 個艦隊槽 f：
    f[+0x04] == 0FFh → 跳過
    f[+0x01] != ds:8F1D → 跳過
    f[+0x79] != 0FFh → 跳過                   ; 只處理這回合還沒決定的
    若 f[+0x0F] == f[+0x0E]：2E54:1B17(f, 2, 首都)；下一支
    否則若 2B99:028F(f[+0x06], 目標, 陣營) < 0800h：
        若 f[+0x3C] < 60 或 f[+0x08] == 3：2E54:1B17(f, 3, 目標)
        否則：                              2E54:1B17(f, 0, 目標)
    否則若 2B99:028F(f[+0x06], 首都, 陣營) < 0800h：2E54:1B17(f, 2, 首都)
    否則：…（未讀）
```

前面四個階段挑的都是「最好的那幾支」，**階段五是把剩下沒決定的全部
掃一遍**——所以一回合結束時每一支我方艦隊都會有 `+0x79`。

`+0x0F == +0x0E`（編制滿）的那一支反而被叫回首都，這與
`2E54:143F` 模式 1／2「編制滿才算候選」看起來矛盾，但兩者處理的是不同
集合：模式 1／2 挑的是**還沒決定**的最佳候選，階段五處理的是**輪到
最後還沒被挑走**的。

## 階段一：`2E54:0513(n)`（讀到一半）

```
若 首都星域[+0x12] != ds:8F1D：不做
筆數 = 28E0:0103(&緩衝, 首都, 25h, 0)         ; 四支清單常式之一（docs/re/43）
若 筆數 == 0：結束
qsort(緩衝, 筆數, 1, 2E54:063C)
…（後半未讀）
```

`28E0:0103` 帶的 `0x25`（37）是什麼還沒解。`2E54:0513` 的位置是
「守首都還缺 n 支的時候叫的」，形狀像**新編一支艦隊**，但沒有證據。

## 還沒讀

`2E54:0F93`（星域 14 的特例條件）、`2E54:13A8`（階段五的目標）、
`2E54:063C` 與 `2E54:0513` 的後半、`2D54:0163` 與 `2D54:0000` 的中段。
