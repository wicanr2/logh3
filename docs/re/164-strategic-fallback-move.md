# 164 — `2E54:1955` 是回防：往自己首都的方向退一格

`docs/re/163` 讀完「這支艦隊這回合有沒有事做」。回 0 的那一支會走
`2E54:1955`（`docs/re/79`）。這一輪把它讀完了。

## 整支

```
2E54:1955(艦隊far)
    星域far = ds:A79C + 艦隊[+0x06] × 126
    若 星域[+0x12] == ds:8F1D 且 星域[+0x13] bit2 沒設：
        艦隊[+0x08] = 5          ; 不動
        艦隊[+0x07] = 0FFh       ; 沒有目的地
        艦隊[+0x79] = 3          ; 決定好了
                                 ; ↓ 不 return，下面還是會找

    最佳距離 = 0FFFFh ; 最佳目的地 = 0FFh
    鄰居 = 2B99:03D9(&清單, 艦隊[+0x06], 艦隊[+0x01])
    我方首都 = 3982:0329(艦隊[+0x01])
    對每個鄰居 c：
        d = 2B99:028F(c, 我方首都, 艦隊[+0x01])      ; c 到自己首都幾步
        若 d < 最佳距離 且 鄰居星域[+0x12] == 艦隊[+0x01]：
            最佳目的地 = c ; 最佳距離 = d

    若 最佳目的地 != 0FFh：艦隊[+0x08] = 0 ; 艦隊[+0x07] = 最佳目的地
    否則：                艦隊[+0x08] = 5 ; 艦隊[+0x07] = 0FFh
```

**沒事做的艦隊往回退一格**：在相鄰星域裡挑**自己的**、而且**離自己
首都最近**的那一格；找不到就原地不動。距離查的是每個陣營一張的路徑表
（`2B99:028F`，`docs/internals/26`），首都由 `3982:0329(陣營)` 給
（帝國 0 瓦爾哈拉、同盟 31 巴拉特）。

`+0x08` 這裡出現兩個值：**0 ＝ 會走**、**5 ＝ 不動**，與
`docs/internals/33` 記的一致。

## 開頭那個區塊為什麼不 return

它先把「不動」寫進去當**預設**，再讓下面的搜尋有機會覆蓋掉。條件是
「這一格是自己的，而且 `+0x13` 的 bit2 沒設」——bit2 是什麼還沒解
（`docs/re/79` 那一層也在看 `+0x13` 的 bit2／bit4）。

## 這樣一來，AI 的守勢那一半是完整的

| 情況 | 結果 |
|---|---|
| `2E54:16F5` 回 1 | `+0x79 = 3`，`[星域×2 − 0x2A32]` 那一格 ++ |
| 回 0 | `2E54:1955`：退往離首都最近的自家鄰格，或原地不動；`+0x79 = 0` |

**還沒解的是攻勢**：`+0x07` 被設成**敵方**星域是哪一支寫的。
`[星域×2 − 0x2A32]` 那張 word 表在「有事做」的時候被 ++，看起來是
下一趟的輸入（**待驗**）。
