# 215 — 新艦隊的艦艇從星域存量扣出來：`2703:1433` 取 `min(存量, 滿編)`

`docs/re/213`／`214` 把建艦隊的呼叫鏈讀到 `2AD2:0029`（產生一筆艦艇）
就停了。這一輪讀完，**「分到艦艇」整條齊了**。

## 完整的鏈

```
2D76:0611(提督編號):
    297B:0066(提督)                       ; 初始化艦隊記錄（docs/re/214）
        艦隊[+0x0E] = 297B:0209(等級)     ; 應有組數
        編制槽[0][0..1] = 2AD2:0029(艦隊, 提督[+0x08] & 0Fh, 0)   ; 旗艦
    0FF4:11F4(艦隊, 類別鍵)                ; 第 1 .. +0x0E−1 組（docs/re/212、213）
        槽[i][2..3] = ds:2BC6 樣板
        槽[i][0..1] = 2AD2:0029(艦隊, 艦種, 0)
        排序（0FF4:0FF2）

2AD2:0029(艦隊, 艦種, p3):
    索引 = 2AD2:0151()                    ; 找一個空的艦艇池槽
    艦艇 = ds:CFB4 遠指標 + 索引 × 78
    艦艇[+0x00] = 艦隊[+0x01]              ; 陣營
    艦艇[+0x01] = 艦隊[+0x03]
    艦艇[+0x02] = 艦隊[+0x06]              ; 星域
    艦艇[+0x03] = p3
    艦艇[+0x04] = 艦種
    艦艇[+0x0E..0x15]、[+0x38]、[+0x3A] = 0
    艦艇[+0x0A] = 艦種表[陣營][艦種] 的 word 0     ; 滿編艘數
    艦種 == 7 → 艦艇[+0x08] = 艦艇[+0x0C] = 艦種 7 的滿編艘數
    否則      → 艦艇[+0x08] = 艦艇[+0x0C] = 2703:1433(星域, 陣營, 艦種)
    回 索引

2703:1433(星域, 陣營, 艦種):
    欄位 = 星域[+0x30 + 陣營 × 28 + 艦種 × 4]        ; 32 位元存量
    滿編 = 艦種表[陣營][艦種] 的 word 0
    n    = min(欄位, 滿編)
    欄位 -= n                                        ; ★ 從存量扣掉
    回 n
```

## 三件事定下來

- **一組編制 ＝ 一筆艦艇，艘數是 `min(星域存量, 滿編艘數)`**，而且
  **當場從星域的存量扣掉**。存量在星域記錄 `+0x30` 起，一個陣營 28
  bytes、一個艦種 4 bytes（32 位元），與 `docs/internals/22` 記的版面相同。
- **艦種 7 不走存量**：直接拿滿編艘數，不扣任何東西。
  （七個艦種是 0–6，`docs/internals/40`；`7` 是表裡多出來的那一列。）
- **`+0x0A` 是滿編、`+0x08` 是現有、`+0x0C` 與 `+0x08` 同值**——
  `docs/internals/38` 記的「`+0x0C` 是修理補得回來的上限」
  （`docs/re/131`）在**新造**的時候就是滿的，一致。

## 為什麼 AI 建到第三支就停

`docs/re/209` 的答案是「維持費追上稅收」。這一層補上另一半：
**每建一支就從首都的存量搬走幾組艦艇**，所以存量與維持費是同一件事的
兩面——建得越多，存量越少、維持費越高。

## remake 做了什麼

`rules.TakeRegionShips(record, faction, kind, full)` ＝ `2703:1433`：
取 `min` 並就地扣。有測試釘住「取滿」「存量不足」「扣完變 0」三種。

**還沒接上去**：要讓 `ai.NewFleet` 真的長出編制，remake 得先有
**新遊戲時的艦艇池**——`Game.slot` 在新遊戲是 nil，沒有地方放艦艇記錄
（原版的新遊戲樣板也沒有 `SHIP.DTX`，`docs/re/200`，艦艇是玩家或 AI
造出來的）。那是 `internal/game` 的結構改動，比這一輪大。

## 一條方法

**扣存量這種副作用，要在讀完那一層才看得到。** 前三輪都在問「艘數從
哪來」，答案是「從星域搬過來」——**問題本身問偏了**：不是產生，是移動。
一個 `sub es:[bx], di` 把整條鏈的意義改了：AI 建艦隊不是憑空變出戰力，
是把首都的庫存編成部隊。
