## 結論

1. **占領（作戰第 1 項）走移動那條目的地迴圈**，只差允許表換成
   `(3982:0250(陣營) ＝ 敵方, 2 ＝ 中立)`：從瓦爾哈拉出發，可達表裡的敵方與中立
   星域（卡斯特羅普、杜威爾格、優茲黑姆、費沙、艾爾‧法西爾、亞斯提）都能點，
   自己的星域反而是「這是無法前往的星系。」決定之後 `+0x08 ← 1`、`+0x07 ← r`，
   清單那一列印**紅☆**，再開視窗第 5 列印「占領戰鬥」。
2. **目的地是費沙時先跳參謀提醒**（`1213:0003`，只在費沙事件還沒發生過、
   `ds:8F48 == 0` 時）：與費沙事件的報告同一支 `1213:01B8`——24×5 的視窗、
   軍事專任參謀的頭像、兩頁文字（帝國看 `ds:3016`、同盟看 `ds:301E` 那一對），
   每頁一次點擊或逾時翻頁；翻完才到「要占領中立軍費沙星系嗎？」。
3. `3765:006C(n)` 的逾時是把 `ds:8EFE ← n` 交給計時器倒數；這條收據鏈
   （`-tick 20000`）量到一頁停 36M 步 ＝ 1800 個 IRQ，而 n ＝ 訊息速度 90 × 2 ＝ 180
   ——倒數與 IRQ 的比例量到是 1 : 10（減法在 int08 的哪一拍沒讀，§六）。
4. **作戰選單的停用旗標**（`docs/re/312` §7.6 讀出、本輪錄到）：所在星域有戰鬥
   或不是自己的 → 只剩「移動」；艦隊 `+0x00` bit0 → 占領與輸送關掉。停用項色 8、
   游標停在上面**不畫反白**、點了**只關選單**——與戰場命令選單同一套 `3667`。
5. 同一個「有戰鬥」旗標另外牽動三處：清單那一列的記號紅▼（`313` 已知）、艦隊視窗
   「作戰」列紅字「戰鬥中」（`312` 已知）、**「變更」鈕不畫**（`0DEA:0040` 開頭清掉
   熱區表 `ds:21C0` 第 1 筆的啟用旗標；不是自己的星域也一樣）、以及
   **左下角星域名後面印「處於戰鬥狀態」**（紅）——那支列印常式依 `+0x13` 挑一句：
   bit2 戰鬥 ＞ bit4 占領 ＞ bit0 孤立（色 5）＞ 空白，而且「艦隊 a：b」的「：」
   沿用那一句留下的顏色。

## 一、占領（`0DEA:12CC(艦隊, 1, "占領")` → `113A:0003`）

允許表（`113A:00BE`）：`可達 ∧ (擁有者 == 敵方 ∨ 擁有者 == 2 ∨ i == 現在位置)`。
地圖著色與移動相同（現在位置 `{6,5,7}[擁有者]`、不允許 3、其餘 `{1,12,7}[擁有者]`），
所以 `fcmd-occupy-pick` 上亮的是敵方橘（12）與中立灰（7），自己的星域全暗。

點目的地 `113A:01AB`：允許 → `1213:0003(星域)`（§二，永遠回 1）→ `113A:023B`
確認框「要占領<陣營色><陣營名>◇<星域名>星系嗎？」（`fcmd-occupy-confirm`：
「同盟軍」色 5）。決定 → `0DEA:1037` 區塊 A：`+0x08 ← 1`、`+0x07 ← 16`、關窗
（`fcmd-occupy-done/fleet0.bin`：`+0x07` FF→10、`+0x08` 05→01）。清單記號紅☆
（`ds:1A66[1]`，色 2）。再開視窗（`fcmd-occupy-reopen`）：「占領戰鬥／現在位置
瓦爾哈拉／移動目標 亞斯提」（`ds:68EA[1]`「占領」＋「戰鬥」）。

## 四、左下角的狀態字（`06E8` 段，`fcx0654-lsum.txt` +0EB8 起）

星域名 `%-12s  `（`ds:0DCB`）之後：

```
星域[+0x13] & 4    → 3617:003A(ds:0DD3)   "\x03[146,處於戰鬥狀態\n"      ; 色 0x92 紅
否則 & 0x10       → 3617:003A(ds:0DE7)   "\x03[146,處於占領狀態\n"
否則 & 1          → 3617:003A(ds:0DFB)   "\x03[149,處於孤立狀態\n"      ; 色 0x95
否則              → 3617:003A(ds:0E0F)   "\x03[151,            \n"      ; 色 0x97
視窗[+1] ← 0x97；印「治安    」…
```

那句字串的顏色碼留在視窗上，下一列「艦隊 a：b」的「：」沒有自己的顏色碼，
所以跟著變（`fcmd-battle-base` 的 (272,384)–(287,393) 從 7 變 2）。右側面板的首都
摘要是另一支常式，不印這一句（同一份收據的右側沒有變）。字串位置：格 (13,16)
＝ 畫面 (208,362)，六個全形字。

## 六、沒讀的

- 占領命令在回合裡的效果（`113A:0545` 起走到敵方星域之後、`113A:0899`
  「無法直接到達此星系」「要占領此星系嗎」）——這一輪只錄到下命令那一刻。
- `+0x00` bit0 是誰設的、什麼意思（`docs/internals/33` 只知道它把艦隊分成兩類）。
- `3765:006C` 的倒數在 int08 裡怎麼分拍（每 10 個 IRQ 減一是量出來的，
  沒讀那段程式）。
- 左下角「處於占領狀態」「處於孤立狀態」兩句沒有收據（同一支常式的另兩個分支，
  讀自程式碼）。
