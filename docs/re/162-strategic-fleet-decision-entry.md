## 開頭兩個提早返回

```
2E54:16F5(艦隊far)
    星域   = 艦隊[+0x06]
    星域far = ds:A79C + 星域 × 126
    若 艦隊[+0x01] == 0 且 星域 == 0x00：回 1      ; 帝國在瓦爾哈拉
    若 艦隊[+0x01] == 1 且 星域 == 0x1F：回 1      ; 同盟在巴拉特
```

`+0x01` 陣營、`+0x06` 目前星域都是既有欄位（`docs/internals/33`）；
0 與 31 正是兩邊的首都星域（`3982:0329`，`docs/internals/26`）。
**艦隊待在自己的首都就直接回 1**——回 1 會讓 `docs/re/79` 那一層把
`+0x79` 標成 3。

## 接著數兩邊在這一格有幾支

```
    自軍數 = 297B:131C(&清單A, 星域, 1)
    敵軍數 = 297B:131C(&清單B, 星域, 2)
    ax = 2E54:1876(星域, &清單A, 自軍數, 艦隊[+0x01], …)
    …（還沒讀）
```

`297B:131C(&輸出清單, 星域, 旗標)` 回**收到幾支**（al），輸出是艦隊
索引的陣列。旗標 1 與 2 在這裡成對出現、`20B4:1512` 收自己的艦隊時
用的也是 1（`docs/internals/53`），所以 **1 ＝ 自軍、2 ＝ 敵軍**
（強證據，還沒用收據驗）。
