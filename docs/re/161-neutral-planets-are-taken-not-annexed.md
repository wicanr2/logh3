# 161 — 中立行星不是被「收編」，是被打下來的

`docs/re/57` 查到 796 年 1 月的十個回合裡，三顆無主行星翻成同盟
（威爾勃恩、巴多列斯克、卡札威爾），但沒找到寫入點：把六個已倒出來
的程式段掃一遍，只有兩處寫 `行星[+0x11]`，而且都是寫 **2（無主）**。
結論停在「**選中的規則未解**，在解出來之前不要猜著實作」。

兩件事讓它解開了：**掃描範圍**與**監看**。

## 一、掃全份程式碼，多出兩處

`workplace/codeall.bin` 是後來倒的整段程式（線性 `0x09000`–`0x3E000`）。
掃 `mov [reg+11h], r8` 與 `mov byte [reg+11h], imm8`（含 `es:` 前綴、
八種 mod=01 定址）：

| 位址 | 指令 | 是什麼 |
|---|---|---|
| `20B4:03D6`（lin `2110C`）| `mov es:[si+11h], al` | 戰場的打行星（`20B4:0503` 那一支的後段）|
| `20B4:17DB`（lin `2231B`）| `mov es:[bx+11h], al` | **戰略地圖的打行星** |
| `2703:1AE6` | `mov byte es:[bx+11h], 2` | 打下來之後改成無主 |
| `28xx:0B16` | 同上 | 同上 |

`docs/re/57` 掃的六個段裡沒有 `20B4`，所以那兩處看不到。

## 二、監看抓到了

`docs/re/57` 監看行星的擁有者位元組時「沒有報出任何寫入」，並且
預測是服務層的寫入對當時的監看隱形、修好之後要重測。重測：

```
tools/oracle.sh annex1 … -steps 900000000 -watch 54429-54429
```

（行星表在線性 `0x53132`、一筆 82 bytes，威爾勃恩是第 59 筆，
擁有者在 `+0x11` → `0x54429`。）

```
[watch] #66162333  54429: 00 → 65  ← 63A1:002D     載入前的搬檔
[watch] #68381735  54429: 65 → 00  ← 63A1:011B
[watch] #68675202  54429: 00 → 02  ← 3D08:001A     載入時填成無主
[watch] #583364349 54429: 02 → 01  ← 20B4:17DF     ← 翻成同盟
```

`20B4:17DF` 正是上表第二處寫入的下一道指令。**現在的執行器看得到了。**

## 三、那一支是戰略地圖的打行星

寫入點所在的函式從 `20B4:1662` 開始：

```
20B4:1662(…, 行星far [bp+2E], 艦隊索引清單 [bp+32], 幾支 [bp+36], …)
    行星的區內索引 = (行星far − ds:CFF8) ÷ 82        ; 星域的行星切片
    對清單裡的每一支艦隊（ds:C074 + 索引 × 122）：
        0DEA:1759(艦隊, 行星索引)
        艦隊[+0x07] = 行星索引
        艦隊[+0x48] = 1                              ; 行動 ＝ 戰鬥
        若 [bp+2A][+0x12] != 2：20B4:18C2(艦隊)
    …扣血（20B4:0D96）…
    若 20B4:0E2C(行星, 攻擊力)：                     ; 攻擊力追上剩餘防衛力
        行星[+0x11] = [bp+18][+0x00]                 ; ← 換手
        memset(行星 + 0x20, 0, 28)                   ; 七個艦種的補充存量
        行星[+0x3C] >>= 1 ; 行星[+0x3E] >>= 1
```

`122` 是艦隊記錄的長度、`ds:CFF8` 是星域的行星切片、`20B4:0D96` 與
`20B4:0E2C` 就是打行星那條的扣血與換手判定（`docs/re/148`–`152`）。
戰場那條走 `20B4:0503`，戰略地圖這條走 `20B4:1662`，**換手的動作是
同一套**。

## 所以

**沒有「收編」這條規則。** 那三顆是同盟的艦隊在戰略回合裡打下來的，
走的是與戰場一樣的打行星結算。「為什麼是這三顆」＝ 同盟的艦隊開到了
那裡；「帝國為什麼一顆都沒有」＝ 這一局帝國是玩家，沒有下過那個命令，
帝國的 AI 也沒有動。

remake 要補的不是一條猜出來的收編規則，而是**戰略層的 AI 派艦隊 ＋
把既有的 `rules.PlanetAssault` 接到戰略回合上**。

## 上面那一層

`20B4:1662` 只有一個呼叫者：`20B4:1512(星域, 回呼far, 陣營, ?)`——
一個星域、一個陣營，收該陣營在那裡的艦隊（`297B:131C`），然後對切片裡
每一顆**不屬於自己**的行星叫一次 `20B4:1662`。`20B4:1512` 自己有兩個
呼叫點，差在傳進去的回呼（`185C:0B18` 與 `20B4:1922`）。整條鏈整理進
[`docs/internals/53`](../internals/53-strategic-planet-assault.md)。
