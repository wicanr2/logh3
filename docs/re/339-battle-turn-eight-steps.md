## 一、骨架與執行期時間線

### 1.1 撤退分支走不到 **P（位元組）**

`12AA:000E` 的迴圈（`r8-12AA.txt`）：

```
+00B4  9a bd 02 aa 12   call far 12AA:02BD           ; 電腦座位
+00B9  80 3e 7e 9b 00   cmp byte ds:9B7E, 0
+00BE  75 1b            jnz +00DB                    ; 撤退 → 185C:0ADA（不進 181B:000A）
+00C0  … 9a 03 00 e5 26 26E5:0003(FF, 0, 0)
+00D0  9a 0a 00 1b 18   call far 181B:000A
+00D5  09 c0 / 74 09    or ax,ax / jz +00E2          ; 0 → ds:8F1A++、下一回合
+00D9  eb 0d            jmp +00E8                    ; 非 0 → 離開戰鬥
```

所以 `181B:000A` **只在 `ds:9B7E == 0` 時被呼叫**，它自己開頭那個 `cmp ds:9B7E,0 / jnz`
是防禦性的死分支（`farcall_to` 也只有 `12AA:00D0` 一個呼叫者）。**P（位元組）**

### 1.2 回合尾巴的回傳值就是「戰鬥要不要結束」 **P（位元組）**

`181B:000A` 的 `retf` 前沒有設 AX；`+0039 call 181B:03F0` → `181B:0410 retf` 同樣不設；
`181B:040B call 185C:0001` → `185C:0001` 是 `56 / …五個 call… / 5E / CB`，AX 是最後一支
`185C:09BF` 的回傳。所以：

```
185C:09BF 回 1 → 181B:000A 回非 0 → 12AA:00D5 跳出戰鬥迴圈
185C:09BF 回 0 → ds:8F1A++ 再打一個回合（上限 9，docs/re/92）
```

## 九、子步 8-1 的全滅分支：執行期收據 **P（執行期）**

§七 說「本輪沒有跑到」的那一條，這一節補上。照規格 014 造局面：從 `eng-t5`（S3 巴米利恩
第五個戰術回合）在 **#1187.90M**（第 ⑦ 步跑完、第 ⑧ 步還沒進）把帝國槽 12
（第１３艦隊 舒坦梅茲，`lin:6115C`）第 0 組的艦艇艘數寫成 0：

```
f[+0x10] = 80（第 0 組的艦艇池索引）
艦艇 80 = lin 668B2 + 80×78 = lin 68112
艘數 +0x08 → -poke lin:6811A@1187900000=00,00
```

收據 `eng-annihilate`（#1188.10M，`tools/engagement_receipts.sh` 第 7 段）：
`3826:0405` 的臨時視窗印「帝國軍第13艦隊舒坦梅茲」換行「已經全滅。」，右側階段名是「最後階段」，
戰場上那一支的分隊已經消失。

**等待在報告裡面，不在後面**：`185C:028E` 開窗之後等滿 `ds:8F38` ＝ 90 tick（18M 步）才回來跑
`185C:00F0`。第一次把 mem-out 錄在 #1189.8M，**一個 byte 都沒變**——看起來像「全滅什麼都沒做」，
其實只是還停在報告上。（同一個坑第七輪在戰略那條踩過一次，成因不同：那次是 `35D1:0102` 的長迴圈。）

`eng-annihilate-mem`：mem-in #1187.91M、mem-out #1234.0M，1 MB 逐位元組比，只有這些變：

| 位置 | 變化 | 誰做的 |
|---|---|---|
| 艦隊槽 12 `+0x04`／`+0x05` | `0C 1C` → `FF FF` | `297B:034A` 提督與副官脫離 |
| 提督 12（`ds:B77C+12×28`）`+0x00`／`+0x09` | `FF`→`80`、`0C`→`8C` | 同上，失蹤旗標 |
| 提督 28（副官）`+0x00`／`+0x09` | 同上 | 同上 |
| 艦艇 80（第 0 組）`+0x01` | `0C` → `FF` | `2AD2:01EF` 作廢 |
| 艦艇 81（索敵分遣隊）`+0x01` | `0C` → `FF` | `185C:00F0` 尾巴那一筆（`f[+0x38]`，**不看 `+0x3A`**）|
| `ds:9894` 戰場艦隊數 | 7 → 6 | `12AA:03BC` 重建 |
| `ds:9896` 戰場艦艇數 | 0x37 → 0x2E（55 → 46，少 9 ＝ 8 組 ＋ 索敵那一筆）| 同上 |
| `ds:9898` 戰場艦隊清單 | `0C 10 11 1C 1D 1E 1F` → `10 11 1C 1D 1E 1F` | 同上 |
| 星域 26 `+0x28`（帝國艦隊數）| 1 → 0 | `297B:034A` |

**艦隊記錄本身除了 `+0x04`／`+0x05` 沒有別的欄位被改**——`+0x01`（作廢）沒有設、
`+0x0F`（組數）沒有歸零。戰略那一條（`0374:073F`）同樣如此（規格 060）。

mem-in／mem-out 的 SHA-256 記在 `workplace/oracle/eng-annihilate-mem/meta.txt`。
