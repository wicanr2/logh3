## `2E54:1876(星域, 艦隊索引清單, 幾支, 陣營)` ＝ 戰力總和

```
總和 = 0（32 位元）
對清單裡的每一個艦隊索引：
    艦隊 = ds:C074 + 索引 × 122
    若 艦隊[+0x00] bit0 有設：跳過            ; 無法戰鬥
    對 j = 0 … 艦隊[+0x0F] − 1：              ; +0x0F ＝ 分隊數
        艦艇 = ds:CFB4 + 艦隊[+0x10 + j×4] × 78
        總和 += ds:6032[艦艇[+0x04]] × 艦艇[+0x08] × 1000 ÷ 艦艇[+0x0A]
回 總和
```

也就是**每個分隊：艦種權重 × 現有艘數 × 1000 ÷ 滿編艘數**。
`ds:6032` 依艦種 0–7 是

```
4  3  3  3  2  1  3  0
```

（艦種 7 ＝ 索敵分遣隊權重 0，不算戰力。）乘除都走 Borland 的 32 位元
輔助函式（`3CC9:0009` 乘、`3CC9:0020` 無號除，`docs/internals/51`）。

## `2E54:16F5(艦隊)` ＝ 這支艦隊這回合有沒有事做

```
星域 = 艦隊[+0x06]
若 艦隊[+0x01] == 0 且 星域 == 0x00：回 1        ; 帝國在瓦爾哈拉
若 艦隊[+0x01] == 1 且 星域 == 0x1F：回 1        ; 同盟在巴拉特

我方 = 2E54:1876(星域, 297B:131C(…, 星域, 1), …, 艦隊[+0x01])
敵方 = 2E54:1876(星域, 297B:131C(…, 星域, 2), …, 3982:0250(艦隊[+0x01]))

依 星域[+0x12]（擁有者）：
    == 艦隊的陣營（自己的）：
        我方 × 4 ≥ 敵方            → 1
        否則 艦隊[+0x3C] == 100     → 1        ; 編制完整
        否則                        → 0
    == 2（無主）：
        我方 × 2 > 敵方             → 1，否則 0
    其他（敵方的）：
        我方 > 敵方                 → 1，否則 0
```

三個門檻一路收緊：**守自己的地方只要有敵人四分之一的戰力就留下，
打無主的要兩倍，打敵人的地方只要贏就上**。回 0 的那一支在
`docs/re/79` 那一層會走 `2E54:1955`（另一條處置，還沒讀）。

`3982:0250(陣營)` 回對方的陣營；`297B:131C(&清單, 星域, 旗標)` 收那一格
的艦隊索引，旗標 1 ＝ 自軍、2 ＝ 敵軍（`20B4:1512` 收自己的艦隊用的
也是 1，`docs/internals/53`）。

## 為什麼「守」的門檻是四倍

`艦隊[+0x3C]` 是編制完整度（`docs/re/153`）。守方那一支的第二個條件
說：**就算戰力比不上，只要編制還是滿的（100）就留下**——所以剛打完、
編制掉下來的艦隊才會被叫走。
