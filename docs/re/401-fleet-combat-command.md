## 防禦仍產生交戰排序

proven：030F先以03A1收參戰艦隊全部一般分隊，再以0421生成SHIP+42優先值。
本艦隊有8筆，即使只提交防禦，也先消耗16次亂數。
04CB、04E7每池各一次；055C比較+42，較大者優先。
排序後才在037F／0383跳過武器FF／3，其他分隊進05D7。

這16次亂數屬交戰排序，不能稱為演出位置或演出初始化亂數。
研究400的零亂數結論限Out不符合7F、沒有可進命令的入口案例；不含本次有效防禦。
不因此新增整回合精確骰序門檻。
