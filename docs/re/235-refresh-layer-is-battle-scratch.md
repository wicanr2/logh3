# 235 — 編制改完之後那一層重算，產出的全是戰鬥用的暫存

`docs/re/230` 讀出「編制一改，後面還有三支要跑」，列了五支沒讀。
五支都讀了。結論是一個**否定的結果**：那一層算出來的東西，
remake 的策略層一項都不需要。

## `297B:0546(艦隊)` 的兩支

### `297B:05B2(艦隊, 提督, 副官)` — 已在 `docs/re/233`

`艦隊[+0x0E] = 297B:0209(提督[+0x06])`，再把提督與副官的
`+0x0F`／`+0x10`／`+0x11`／`+0x13`… 揉成艦隊 `+0x3D`…`+0x47`。

### `297B:0E8B(艦隊)`

線性 `0x2A63B`。逐組把**艦艇的戰鬥數值**算出來：

```
對每一組：
    艦艇 = 艦艇池 + 組[0..1] × 78
    艦種列 = ds:4E3A + 艦艇[+0x00] × 208 + 艦艇[+0x04] × 26
    艦艇[+0x1F] = 艦種列[+0x08] × 艦隊[+0x43] / 100
    艦艇[+0x21] = 艦種列[+0x06] × 艦隊[+0x42] / 80
    艦艇[+0x22] = 艦種列[+0x07] × 艦隊[+0x??] / 60
    …
```

**艦種取的是艦艇記錄的 `+0x04`，不是組 `[2]`**——兩者一直同值
（`docs/re/224`），但寫入端是艦艇那一份。

## `297B:08D8(艦隊, a, b)` 的其餘部分

線性 `0x2A088`。前半（`docs/re/230` 已記）清掉艦隊的 `+0x3A`／`+0x3B`／
`+0x48`／`+0x5A`／`+0x5B`。其餘：

### `297B:0ABF(艦隊, a, b)`

線性 `0x2A26F`。**`a` 與 `b` 都是 `0FFh` 時整段跳過**；否則呼叫
`113A:0D2C` 把星域座標換算成地圖座標，寫進艦隊的 `+0x5C`／`+0x5E`
（打行星時算距離用的現在座標，`docs/internals/33`）。

整補走的是 `297B:03EB(艦隊編號, 0)` → `297B:08D8(艦隊, 0FFh, 0FFh)`，
**所以這一段在整補的路徑上不會執行**。

### 逐組迴圈

線性 `0x2A0D8`：對每一組叫 `297B:0D99(艦隊, 艦艇)`，再把該筆艦艇的
`+0x16 = 0`、`+0x17 = 0`、`+0x19 = 3Fh`、`+0x1E = 7Fh`。

### `1588:00F6(星域)`

線性 `0x15976`。第一次呼叫時 `malloc(0x3300)`（13056 bytes）存進
`ds:3C1A`，之後拿 `ds:3C18` 當快取鍵——**同一格就不重載**。載的是那一格
的戰場地圖資料。

### `2BE1:0000(艦隊)`

線性 `0x2BE10`：對每一組叫 `2BE1:0059(艦隊, 艦艇)`。`2BE1:0328`
（「編隊」）是同一段的鄰居（`docs/re/130`），所以這一支是隊形相關的重置。

## 對 remake 的意義

四類產出，remake 的策略層一項都不用：

| 產出 | remake 怎麼處理 |
|---|---|
| 艦隊 `+0x0E`、`+0x3D`…`+0x47` | `rules.FleetSlots` 與 `fleetOperations` 已經算得出來，而且整補不換提督副官所以值不變 |
| 艦艇 `+0x1F`／`+0x21`／`+0x22` 等戰鬥數值 | remake 打起來的時候現算，沒有快取欄位 |
| 艦隊 `+0x5C`／`+0x5E` 地圖座標 | 整補走 `0FFh, 0FFh` 這一路，**原版自己也不算** |
| 艦艇 `+0x16`／`+0x17`／`+0x19`／`+0x1E`、戰場地圖緩衝 | 戰鬥開始時才有意義；remake 進戰鬥是另一條路 |

所以 `Game.refitFleets` 改完編制之後**不需要任何後續重算**——
這不是省略，是讀完之後確認的。

## 一條方法

**「還有 N 支沒讀」不等於「還有 N 個缺口」。** 這五支讀完的價值不是
拿到新規則，是拿到「不必實作」這個有根據的答案。在那之前，
`docs/spec/031` 只能寫「這一輪不動」——聽起來像偷懶，其實是不知道。
**把未讀的東西讀成「確認不需要」，和讀成「要實作」一樣是進度。**

## 2026-10-03第50輪勘誤

[研究388](388-fleet-arrival-placement.md)以原版正常S3到達九艦隊的雙跑與IDA五函式核對，
推翻「策略層一項都不用」的整體斷言。113A:0648在過場結束後呼叫08D8，
非戰場星域25的兩支艦隊也更新航向、現在位置及分隊集結點。
正式存檔與稍後戰場都會讀這些活池資料，不能延至戰場用近似佈陣替代。

0ABF在任一FF時跳過的是入口查找，後半碰撞避讓與航向仍執行。
舊文「整段跳過」不成立。這輪只核有效入口的正式路徑；整補FF及缺入口fallback
沒有新增動態驗收，保留舊紀錄以回查當時判讀，不用新結論宣稱整補已完全同態。
