# 255 — 月底閘門在 `0654:0034`：`ds:8FF4[陣營]` ＋ 回合數整除 10

`docs/re/254` 找到月底結算的主體 `2703:02E5`，但追不到誰決定它「這個月要不要
跑」。這一篇把閘門讀出來，順帶更正 `docs/re/254` 的呼叫者位址。

## 怎麼找的：斷點命中時把堆疊倒出來

呼叫者走模組管理器的間接向量，靜態掃描一律回 0 處（`docs/re/04`）。不必再掃
——**斷點命中的那一刻 `SS:SP` 指的就是回傳位址**，倒一份記憶體就讀得到。

批次 `monthcaller`：`-regs-at 2703:02E5 -regs-max 4` 命中時 `SS:SP = 63EB:1FB6`
（線性 `0x65E66`），配 `-dump-mem-at '330061123:lin:65E00:512:…'` 倒出堆疊：

```
SP+00 = 0E72   SP+02 = 090A     → 回傳位址 090A:0E72
SP+04 = 0123   SP+06 = 0654     → 上一層   0654:0123
```

兩件事同時掉出來：

1. `2703:02E5` 的呼叫者是 **`090A:0E6D`**（線性 `0x09F0D`）。
2. 上一層在段 `0654`。那是**常駐低段**——`monthblend`、`s3ai6`、`t260_post`
   三份不同批次的 1 MB 傾印在 `0x6570`–`0x6680` 逐位元組相同，位址不受模組
   重定位影響，可以直接讀 bytes。

## `0654:0034`：月底結算

`0654:0123` 是 `0x6663`，往回找到函式開頭 `0x6574` ＝ **`0654:0034`**：

```

06575  8a 1e 1d 8f        mov  bl, [8F1D]          ; 處理中的陣營
06579  30 ff              xor  bh, bh
0657B  80 bf f4 8f 00     cmp  byte [bx+8FF4], 0   ; ← 閘門其一
06580  75 03              jnz  06585
06582  e9 d9 00           jmp  0665E               ; 旗標是 0 → 只跑共同尾巴
06585  a1 18 8f           mov  ax, [8F18]          ; 回合計數器
06588  b9 0a 00           mov  cx, 10

0658D  f7 f1              div  cx                  ; ← 閘門其二
0658F  09 d2              or   dx, dx

065C4  9a 03 01 5f 2b     call far 2B5F:0103       ; 旗標 1 → ax:bx

065DF  9a af 03 03 27     call far 2703:03AF       ; 旗標 1 那一趟：軍事費 += 總稅收
065E4  …                  ds:8F62/64[陣營] = ds:8F52/54[陣營]   ; 原定軍事費留一份
065FE  …                  ds:8F52/54[陣營] −= ds:8F5A/5C[陣營]
06618  …                  ds:8F94/96[陣營] = ds:8F5A/5C[陣營]
06632  …                  ds:8F7A/7C[陣營] = 0     ; 累計已付維持費歸零
0664A  …                  ds:8F8A/8C[陣營] = 0     ; 已支付移動經費歸零
0665E  9a 6d 0e 0a 09     call far 090A:0E6D       ; ← 兩條路徑的匯流點
06663  8a 1e 1d 8f        mov  bl, [8F1D]
06669  c6 87 f4 8f 00     mov  byte [bx+8FF4], 0   ; 清掉自己那一格的旗標
0666E  5e cb              pop si; retf
```

**閘門是兩個條件的 and**：

- `ds:8FF4[陣營] != 0`——主迴圈在 `inc [8F18]` 之後把 `ds:8FF4`／`ds:8FF5`
  都設成 1（`0x03B1E`，`docs/re/251`），這一支跑完就把自己那一格清掉。
  作用是「一個陣營一個回合只結算一次」。
- `ds:8F18 mod 10 == 0`——一個月十回合。

任一條不成立就 `jmp 0x0665E`：**共同尾巴照跑**。也就是說 `090A:0E6D`
（`2703:02E5` 的成長／收稅／未安定重算，再加雙方維持費）**每個回合都會跑**，
被閘住的只有錢的結算與三支月報。

## 閘門開著時 `090A:0E6D` 跑兩次

`0654:0034` 裡有兩處 `call far 090A:0E6D`——`0x065A7`（閘門內）與 `0x0665E`
（兩條路徑的匯流點），閘門開著時兩處都會跑。

批次 `monthgateD` 把座位 0 poke 成電腦（`ds:8F23[0] = 1`），三支月報就直接
返回，本體可以無頭跑完。`-regs-at 0654:0034` **只命中一次**（`#243674283`），
而總稅收 `ds:8F6A` 被歸零**三次**：

```
#243674670  2703:02F7 歸零   ← 第一趟 2703:02E5（0x065A7）
            2703:0BC1 累加 20 筆 → 0x334B
#243956899  2703:03D5 歸零   ← 2703:03AF（旗標 1）
            2703:0BC1 累加 20 筆 → 0x334B
#243982943  2703:02F7 歸零   ← 第二趟 2703:02E5（0x0665E，共同尾巴）
            2703:0BC1 累加 20 筆 → 值全部不同
```

三件事掉出來：

1. **成長／收稅／未安定度在月底那個回合跑兩次**，中間夾著 `2703:03AF` 的
   `軍事費 += 總稅收`。第二趟的用途是把畫面要看的「下個月預估」重算成
   結算之後的值——`090A:0E88` 也跟著重算維持費與 `ds:8F5A`。
2. **第二趟的逐筆值與第一趟全都不同**。兩趟之間動過兩件事：成長又跑了一次、
   `2703:03AF` 把星域的 `+0x26` 抄進 `+0x27`（稅率）。哪一件造成多少還沒拆開。
3. **`2703:02E5` 與 `2703:03AF` 加總的是同一組行星**——中間那一趟的 20 筆
   逐筆累加值與第一趟逐筆相同。這局面裡帝國只有 10 個星域、同盟 13 個
   （`ds:B75C`），所以旗標 0 那一趟不是真的把 32 格的稅都收進來，
   `2703:0AB8` 自己會看擁有者。**旗標 0／1 的差別不在被加總的集合**
   ——`docs/re/35` 量到的「兩種稅差 9」仍未解釋。

```
  ds:8F1F = ds:8F29[座位]
```

## `0654:0007`：另一支十回合閘門

`04F8:000E` 在逐座位之前先呼叫它（`0x04F94`）：

```

0654C  74 25              jz  06573              ; → retf
0654E  80 3e f5 8f 00     cmp byte [8FF5], 0     ; 陣營 1 的旗標
06553  74 1e              jz  06573              ; → retf

0655A  a1 18 8f  b9 0a 00 f7 f1  09 d2           ; ds:8F18 mod 10

06569  9a f2 0b 03 27     call far 2703:0BF2
```

同一組條件，差別是它要求**兩個陣營的旗標都還在**——所以它跑在任何一個座位
的 `0654:0034` 把旗標清掉之前，一個月只會有一次。內容（`2703:0BF2` 與
`090A:0B5E`）還沒讀。

## 更正 `docs/re/254`

- 呼叫者是 `090A:0E6D`（`0x09F0D`），不是 `090A:0E6A`。`0x09F0A` 是前一支
  函式的 `pop si`（`5e 5d cb` ＝ pop si／pop bp／retf）。
- 因此「`2703:02E5` 有不只一條進入路徑」不成立。那個結論來自斷點下錯位址
  ——斷在 `pop si` 上只會在前一支函式跑的時候命中，於是看起來像「另有一條
  路徑」。把 `9a e5 02 03 27` 拿去掃 1 MB 傾印，全區**只有 `0x09F0D` 一處**。

## 一條方法

**`-regs-at` 的目標一定要落在函式的第一個 byte；下斷點前先 `hexat` 看四個
byte，確認開場是 `55`（push bp）或 `56`（push si）那一類。** 斷在 epilogue
上照樣會命中，命中次數看起來還很合理——`pop bp`／`pop si` 屬於前一支函式，
它跑幾次就命中幾次。

這是同一種錯的第二次：`docs/re/252` 斷在 `pop bp`（差 2 個 byte），這次是
`pop si`（差 3 個 byte）。兩次都不是位址算錯，是**往回找函式開頭時少退了
一格**。
