# RE 30 — 星域的經濟力是行星加出來的

日期：2026-09-07
執行器：dosgolem-logh3 `8c8af90`
收據：`turnnext`（十一次「實行」，2,250,000,000 步）
狀態：累加來源 **confirmed**；月底的成長算式 **未解**。

`docs/re/29` 留下的問題是「實際收稅那一刻的經濟力既不是月初的、也不是結算後的」。
在星域 0 的經濟力（線性 `5F2E6`，32 位元）上設監看跑同一段，答案就出來了：
**那一刻的經濟力比顯示值高，而高出來的部分正好就是收走的稅。**

## 監看到什麼

整段兩千兩百五十億步裡，星域 0 的經濟力只在三個時機被寫：載入一次、
兩次跨月各一次。每一次都是「四次累加 ＋ 一次覆寫」。

載入（第 68,678,403 – 68,679,920 步，寫入者 `2703:00F8`）：

```
0 → 52000 → 61800 → 73800 → 81300
```

第二次跨月（第 1,656,765,193 – 1,656,766,653 步，寫入者 `2703:0CA8`）：

```
0 → 54548 → 65086 → 78442 → 86057      ← 累加，四次
      86057 → 83304                     ← 覆寫，寫入者 2703:0324
```

`2703:0C50`／`0C54` 先把它歸零，`0CA8` 累加，`0CAC` 進位到第 3 個 byte。

## 四次不是巧合：星域 0 有四顆行星

`PLADAT.DAT` 的 64 bytes 檔頭是 32 個 word，第 k 個 ＝ 第 k 個星域有幾顆行星
（`[4, 3, 2, 3, 1, 2, 3, 3, 4, 3, 2, 2, 1, 1, 1, 2, 3, 2, 3, 3, 3, 4, 2, 2, 1, 3, 3, 2, 3, 2, 3, 5]`，
合計 81 ＝ 筆數）。**星域 0 是 4**，正好對上四次累加。

而且載入那一輪的四個中間值是可以直接對出來的——`PLADAT.DAT` 前四筆的
`+0x1A`（32 位元）是 **52000、9800、12000、7500**，前綴和就是
52000 / 61800 / 73800 / 81300。

```
星域經濟力 ＝ Σ 該星域每顆行星的 +0x1A
```

行星記錄與星域記錄的經濟力放在同一個位移（`+0x1A`），兩邊都是 32 位元。
載入時 `2703:00F8` 算一次，之後每個月底 `2703:0CA8` 再算一次——
`STELLAR.DT*` 檔案裡的 `+0x1A` 從來沒被用過，載入當下就被蓋掉。

## 覆寫的那一下：稅是從重算值裡扣掉的

第二次跨月重算出 **86057**，`2703:0324` 隨即寫成 **83304**，而 83304 正是
796/2 畫面上的經濟力。差 **2753** —— `docs/re/29` 在總稅收上量到的第一趟
第一筆增量就是 2753。

```
E′        ＝ Σ 行星經濟力（已成長）
這個月的稅 ＝ floor(E′ × 稅率 / 1000)     86057 × 32 / 1000 → 2753
顯示的經濟力 ＝ E′ − 這個月的稅            86057 − 2753 = 83304
```

`docs/re/29` 說「第一趟對不上任何一組」的原因就在這裡：稅是在**扣款之前**
的經濟力上算的，而畫面上看到的是扣完的。

## 只有星域 0 是量到的

把同一個模型反推到帝國另外九個星域（解 `E′ − floor(E′ × 稅率/1000) ＝ 顯示值`）
會得到唯一的 `E′`，但增量合計是 **10892**，量到的第一趟是 **10813**。
五個有量到的星域裡，0（2753）、2（828）、5（467）對得上，
1（模型 1130 vs 量到 1099）與 4（243 vs 232）對不上。

所以「稅從重算值裡扣掉」目前**只在星域 0 上是量到的**，
其他星域的推導不算證據。差在哪還沒查。

## 第一次跨月也對不上

同一支程式在第一次跨月（產生 796/1 那一次）重算出 **84508**，寫回 **82302**，
差 2206。用 796/1 顯示的稅率 32‰ 算是 2704，用 26‰ 是 2197、27‰ 是 2281
——沒有一個整數千分率能給出 2206。開局的稅率不等於 796/1 顯示的稅率
（`STELLAR.DTA` 裡星域 0 是 22‰），而 `+0x26` 在結算過程中還會被改，
要再拿一次監看才知道扣款當下讀的是哪一格。

## 成長那一步：每顆行星各走各的

同一顆行星在兩次跨月的累加增量：

| 行星 | 初始 | 第一次跨月 | 第二次跨月 |
|---|---:|---:|---:|
| 0 | 52000 | 54132 | 54548 |
| 1 | 9800 | 10329 | 10538 |
| 2 | 12000 | 12624 | 13356 |
| 3 | 7500 | 7423 | 7615 |

（第一次跨月那一欄是前綴和相減得到的：54132 / 10329 / 12624 / 7423。）

比例分別是 1.041、1.054、1.052、**0.990** ——**第四顆縮水了**。
星域的成長率 45‰ 顯然不是直接乘上去的，每顆行星有自己的變化，
而且可以是負的。行星記錄的 `+0x1E`（星域 0 的四顆是 5、3、4、5）
是下一個要查的候選。

## 行星記錄的欄位（本輪確認的部分）

`PLADAT.DAT`：64 bytes 檔頭（32 個 word ＝ 每星域行星數）＋ 81 筆 × 82 bytes。

| 位移 | 內容 |
|---|---|
| +0 起 | Big5（倚天）名稱 |
| `+0x11` | 擁有者（`docs/re/17`）|
| `+0x14`／`+0x16` | 防衛力（同一個值兩份）|
| `+0x18` | 未知（星域 0 的四顆：2、3、4、4）|
| `+0x1A` | **經濟力（32 位元）** |
| `+0x1E` | 未知（5、3、4、5）——成長相關的候選 |
| `+0x20`–`+0x3B` | 81 顆裡只有 25 顆有值（`0, 4, 7, 12, 13, 15, 18, 21, 25, 33, 35, 37, 40, 42, 45, 47, 48, 50, 51, 55, 66, 71, 73, 79, 80`），其餘全 0。多數是各星域的第一顆，但不是規則——未解 |
