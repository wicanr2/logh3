# RE 28 — 星域之間有距離：兩張 32×32 的路徑表（在 EMS 裡）

日期：2026-09-07
執行器：dosgolem-logh3 `8c8af90`
狀態：**機制 confirmed**；表的內容還讀不到（在未映射的 EMS 頁裡）。

## 從未安定度那一支追下來

`docs/re/24` 找到算未安定度的那一段（線性 `27E60`–`27F23`），
裡面對每顆行星扣掉一個函式傳回值的兩倍。把那幾支子函式讀完：

### `3982:0329` — 陣營的首都星域編號

```
8A 4E 06   mov cl,[bp+06]
08 C9      or cl,cl
75 04      jnz +4
31 C0      xor ax,ax     ; 陣營 0（帝國）→ 0
EB 03      jmp
B8 1F 00   mov ax,001F   ; 否則 → 31
```

回 0 或 31。星域 0 是瓦爾哈拉（帝國首都）、星域 31 是巴拉特（同盟首都）
——所以這是**「這個陣營的首都在哪一個星域」**。

### `2B99:0450` — 兩個星域之間走幾步

```
C6 46 00 00   mov byte [bp+00],0     ; 步數 = 0
8A 46 08      mov al,[bp+08]
3A 46 0A      cmp al,[bp+0A]
74 16         je 結束                 ; 走到了
…             call far 2B99:0302     ; 下一跳
88 46 0A      mov [bp+0A],al         ; 前進一步
FE 46 00      inc byte [bp+00]       ; 步數++
EB E2         jmp 迴圈
8A 46 00      mov al,[bp+00]         ; 回步數
```

一步一步走到目的地，回**步數**——星域之間的距離。

### `2B99:0302` → `2B99:0349` — 查表拿下一跳

```
80 7E 10 00   cmp byte [bp+10],0      ; 陣營
75 09         jne …
A1 6C D0      mov ax,[D06C]           ; 陣營 0 的表（far ptr 的段）
8B 1E 6A D0   mov bx,[D06A]           ;                （位移）
EB 07         jmp
A1 70 D0      mov ax,[D070]           ; 陣營 1 的表
8B 1E 6E D0   mov bx,[D06E]
…             call far 2B99:0349
```

`2B99:0349`：

```
8A 5E 0C   mov bl,[bp+0C]
B9 05 00   mov cx,5
D3 E3      shl bx,cl        ; ×32
C4 76 0E   les si,[bp+0E]
03 F3      add si,bx        ; 表 + 起點×32
8A 46 0A   mov al,[bp+0A]   ; 終點
```

**`表[起點 × 32 + 終點]`**——32 × 32 的矩陣，每個陣營各一張。

## 表在 EMS 裡

`ds:D06A`／`ds:D06C` 指到 `E000:1000`、`ds:D06E`／`ds:D070` 指到 `E000:1400`
——`0xE0000` 是 EMS 的分頁框。把 `A0000`–`FFFFF` 倒出來看那兩個位址，
內容是 `FF C0 E0 F0 F8` 這種遮罩圖樣，明顯是圖形資料：**倒的那一刻那一頁
映射的是別的東西**。表是真的，但要在那支常式執行的當下才讀得到。

## 這件事為什麼重要

- **未安定度跟「離首都多遠」有關**：算式裡對每顆行星扣掉
  `2 × 距離(該陣營首都, …)`。
- remake 之後要做艦隊移動，需要的就是這張圖。目前只知道它是
  32 × 32、每個陣營一張、存在 EMS。
