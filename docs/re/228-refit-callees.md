# 228 — 整補那一層被呼叫的四支

`docs/re/227` 把 `2D76:0732` 的骨架讀出來，留下四支沒讀。四支都讀了，
其中三支完全讀完。

## `2D76:0CAF` ＝ `0FF4:0FF2` 的另一份

線性 `0x2E40F` 起 0x91 個位元組與 `0x10F32`（`docs/re/225`）**逐位元組
相同**：先比 `[2]` 升冪、相同再比 `[3]` 升冪，四次比較都是無號。
同一個比較器在兩個段各有一份，`2D76:07BA` 與 `2D76:0A44` 用近的那份。

## `2AD2:018C(星域, 艦艇索引)`：把一筆艦艇還掉

線性 `0x2AEAC`：

```
艦艇 = 艦艇池 + 索引 × 78
艦艇[+0x04] != 7 → 2703:155B(星域, 艦艇)        ; 艘數還回星域待命部隊
艦艇[+0x38..3B]（遠指標）不為 0 → 35D1:0102(它)  ; free
艦艇[+0x01] = 0FFh                              ; 這一筆作廢
```

艦種 7 不還——與 `2AD2:0029` 產生它時**不從星域存量扣**是同一條例外
（`docs/re/215` 的 `shipKindStandalone`）。`2703:155B` 是
`2703:1433`（從存量拿）的反向。

## `297B:03EB(艦隊編號, 0)`：把組序同步回艦艇記錄

線性 `0x29B9B`：

```
艦隊 = ds:C074 + 編號 × 122
對 i = 0..艦隊[+0x0F]−1：
    艦艇 = 艦艇池 + 組[i][0..1] × 78
    艦艇[+0x03] = i               ; 組序
    艦艇[+0x05] = 組[i][3]        ; 隊形槽
    艦艇[+0x02] = 艦隊[+0x06]     ; 所在星域
（迴圈之後還有一段用 艦隊[+0x38] 那一筆，沒讀）
```

收據對得上：`turn260mem` 裡提督 52 那一支的四筆艦艇是
`01 1c 1f 00 00 14`、`01 1c 1f 01 00 0a`、`… 02 …`、`… 03 …`
——`+0x02` 全是 `1f`（星域 31）、`+0x03` 是 0 1 2 3、`+0x05` 是那幾組的
`[3]`。**所以編制一動就要重跑這一支**，不然艦艇記錄裡的組序會過期。

## `2D76:0A44` 的迴圈本體

線性 `0x2E1F8` 起。每補一組：

```
a = 樣板[0] == 0 ? 旗艦艦種 : 樣板[0]
n = 2D76:0C4F(艦隊, a, 樣板槽)         ; 回槽號或 −1
n == −1 → 結束
0FF4:0E5A(星域, a) != 0 → 最終艦種 = a
否則                    → 最終艦種 = 0FF4:131E(艦隊, a)
最終艦種 == 0FFh → 結束

n != 0            → 2AD2:018C(星域, 組[n] 的艦艇)；目標槽 = n
n == 0 且 已滿    → n2 = 2D76:0D40(艦隊)；n2 != 0FFh 就拆掉它；目標槽 = n2
n == 0 且 沒滿    → 目標槽 = 艦隊[+0x0F]；艦隊[+0x0F]++

組[目標槽][2] = 最終艦種
組[目標槽][3] = 樣板[1]
組[目標槽][0..1] = 2AD2:0029(艦隊, 最終艦種, 0)
qsort(艦隊+14h, …, 2D76:0CAF)
```

**「樣板給 0 就用旗艦艦種」在這裡是無條件的**，與建艦隊那條
（`0FF4:11F4`：只有旗艦艦種 **是 1** 的時候才把 0 換成 1，`docs/re/224`）
**不一樣**。兩支是不同的常式，這不是同一段程式碼的兩種讀法——
remake 的 `BuildComposition` 對的是 `0FF4:11F4`，維持原樣。

## 仍然沒讀

`2D76:0C4F`（挑要覆蓋哪一槽）、`0FF4:0E5A`（那一格有沒有這個艦種）、
`0FF4:131E`（另一支替代）、`2D76:0D40`（滿了要犧牲哪一槽）、
`297B:03EB` 迴圈之後那一段。

## remake

**這一輪仍然不實作整補。** 缺的四支都在「挑哪一槽」這一層，決定的是
補到哪裡、犧牲誰；沒有它們，接上去的版本會在編制順序與槽位上偏離原版，
而整補**沒有收據**可以裁決。已經確定的三件事先記進
`docs/internals/33`：艦艇 `+0x02`／`+0x03`／`+0x05` 由 `297B:03EB` 同步、
艦種 7 不還存量、比較器兩份相同。

## 一條方法

**「同一個規則」在兩支常式裡可以真的不同。** `0FF4:11F4` 與
`2D76:0A44` 對「樣板給 0」的處理差一個條件（前者只在旗艦艦種是 1 時換）。
看到兩處長得像的程式碼，要先確認它們是不是同一支被呼叫兩次，
再決定能不能共用一份結論。
