## 結論

1. 「變更」開一個兩項小選單 副官／編組（`ds:2232`），同一套 `3667`。寬度傳的是
   第一項標籤的**位元組長度** 4（`3C9E:0001`），所以框是四格寬、反白帶 64 像素
   ——作戰那張傳常數 2。
2. 「副官」→ `297B:04EF(艦隊)` → `07F9:043F(&艦隊[+4])`：**艦隊編成那張視窗的
   變體**，同一個版面、少「艦隊編號」、「確認」印成「結束」；結束或右鍵回來時
   副官抄自提督記錄 `+0x07`、重算能力與費用（`297B:0546`）、重印副官與費用那幾列，
   最後 `073F:0522` 把右下角清單**重畫成沒按下的樣子**（那一列底色回 8）。
3. 「編組」→ `0FF4:000A(艦隊)`：這一支的**艦隊組成**（與出擊那條路同一張），
   中止／決定都回艦隊視窗（沒改編制時記錄不動）；右鍵什麼都不做。
4. 艦隊組成的「中止」（出擊那條路）**整支作廢回戰略地圖**，不是回艦隊編成；
   右鍵不認。首都戰艦的待命艘數開局是 **78000**（不是 75000）：進艦隊組成那一刻
   扣掉旗艦那一組 3000，決定之後留 75000，中止退回 78000。舊資料
   `region-ships-796-01.json` 的 75000 量自艦隊組成開著的傾印。

退回。哪一支扣（`0FF4:0094`？）、退（`0FF4:1127`？）沒讀——remake 照時序做
（`Game.provisional`／`takeProvisional`／`refundProvisional`），開局表改 78000。
`docs/spec/015` 的 75000 與 `region-ships-796-01.json` 舊值都是艦隊組成開著時量的。
