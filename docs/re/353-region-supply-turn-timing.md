## 追加：回充讀的是尚未刷新經濟力的星域池（proven）

修正分配／彙總後，正常完整回合仍有同盟首都兩池各差 704。
原版 `refill-before.bin`／`refill-after.bin` 的首都經濟力均為 65826，
防衛力 27500，回充後池 93326；`command.bin` 的經濟力才變成 66530。
remake 回合尾巴原先把直接 `2703:0DA1` 與共同 `02E5` 混成一支，提前刷新
經濟力；依規格 042 已保存的三個呼叫端及本輪直接記憶體，拆開純未安定度
與共同重算。規格 039 審查條款追加後才實作，原版池差異歸零。

## 最終驗收與完整表限制

分配後全 6642 bytes 行星相同；補給後星域 0 整筆與行星整表相同；無艦隊
星域也命中彙總／分配。下一座位回充後全 4032 bytes 星域相同，行星整表不動。
正常回合全部星域 2304／行星 2916 bytes 庫存相同，正常存檔及取進度通過。
原有開局全表與全產品套件、跨月交付、回合／戰鬥／AI 測試全部通過。

跨月交付測試原先把開局未分配的行星分布與十回合後比較，錯把中間分配當成
交付效果。改為先完成九回合再比較交付前後，與既有交付收據的時點契約一致，
同容器乾淨重跑通過；沒有改交付公式或交付落點。

未注入正式 GUI 的完整色號與 RGB 零差異，另抽驗正常移動與對戰交棒通過。
原版兩組批次各重播兩輪；原版執行前實讀種子與 remake 固定種子均為
`0xD3DC167E`。不宣稱跨整段亂數呼叫序列一致。
