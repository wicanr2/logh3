# 120 — 艦隊「移動／戰鬥」的選點範圍

`docs/re/119` 停在「兩支選點迴圈還沒讀」。這一輪讀了艦隊層那支
（`2583:0003`），並且用收據把它畫出來的範圍**量到像素**。

## 艦隊層的選點

```
2583:0003(艦隊 far ptr, 速度A, 速度B)
  di  = 速度B × 8
  ax  = di ÷ 3                                  ; 內圈的半徑參數
  165F:0003(→[bp+8],  艦隊, ax)                  ; 建內圈
  165F:004D(→[bp+18], 艦隊, di, 速度A)           ; 建外形
  3870:001A(...) ×2                              ; 兩個都掛上去畫，各拿一個代號
  2583:013D(→x, →y, 艦隊 +0x4A, 0)               ; 共用的互動選點
  若不是取消：
      艦隊 +0x60／+0x62 ← 艦隊 +0x5C／+0x5E       ; 現在的位置先備份
      艦隊 +0x64／+0x66 ← 選到的點                ; 要去的點
      艦隊 +0x4C        ← 回傳值的低位元組        ; 目標朝向
  3870:0072(代號) ×2                             ; 收掉那兩個圖形
```

| 命令 | 速度A | 速度B | 額外做的事 |
|---|---|---|---|
| 移動（`1CC5:0813`）| `+0x4D` 回轉 | `+0x4E` 巡航 | — |
| 戰鬥（`1CC5:08BD`）| `+0x4D` 回轉 | `+0x4F` 戰鬥 | 成功後 `+0x48 ← 1` |

「索敵」（`1CC5:0966`）不走這一支：先把 `+0x3A`／`+0x3B` 清成 0，
再拿 `+0x38` 當艦艇池索引去擺索敵分遣隊——與 `docs/re/117` 記的
「`+0x3A` 不是 `0xFF` 或 `+0x3B` 不是 0 就關掉索敵」對稱。

## 內圈：讀出來的公式與量到的像素一致

`165F:0003` 填的是一個很小的描述結構：

```
[+0] = 艦隊 +0x5C ＋ 8      ; 圓心 x（＋8 ＝ 圖塊中心）
[+2] = 艦隊 +0x5E ＋ 8      ; 圓心 y
[+4] = 0        [+5] = 5        [+6] = 1        [+7] = 1
[+8] = 半徑參數 ＋ 8
```

也就是 **圓心 ＝ 旗艦的圖塊中心，半徑 ＝ (速度B × 8) ÷ 3 ＋ 8**。

收據 `s3cmdrange`（點第 28 艦隊旗艦 → 點「移動」，停在選點狀態）：
那一支的 `+0x4E`（巡航）是 30，所以預測 **(30 × 8) ÷ 3 ＋ 8 ＝ 88**。
畫面上色 6 的連續弧擬圓：

```
圓心 (298.0, 408.6)   半徑 88.1   最大偏差 0.4
旗艦圖塊在 (290,401) → 中心 (298,409)
```

**圓心與半徑都對上，偏差 0.4 個像素。**

## 外形：量到了，公式還沒解

同一張畫面上另有一圈色 2 的弧（432 個連續點）：

```
圓心 (295.4, 362.9)   半徑 188.2   最大偏差 4.9
相對旗艦中心的位移 (−2.6, −45.7)：距離 45.8、畫面角度 266.8°
```

那支艦隊的 `+0x4A`（朝向）是 190，一整圈 256（`docs/internals/41`），
190 × 360 ÷ 256 ＝ **267.19°**——與量到的 266.8° 相符。所以**外形的中心
是沿著艦隊朝向往前 46 個像素**。

半徑 188.2 與「速度B × 8 ＝ 240」的關係還沒解（240 − 188 ＝ 52，
46 ＋ 188 ＝ 234）。最大偏差 4.9 比內圈的 0.4 大一個數量級，所以它
**大概不是正圓**，而是 `165F:004D` 用 `ds:9C1A` 那張點表生出來的多邊形
（那支常式的迴圈這一輪沒讀）。看起來是「受回轉速度限制的可達範圍」，
但**這是待驗假設，不是結論**。

## 還沒解

- `165F:004D` 的多邊形怎麼生（半徑與 46 這個前移量的算式）。
- `2583:013D` 的互動迴圈怎麼把游標夾進範圍裡、`2583:022B` 對選到的點做什麼。
- 分隊層那支（`2583:00DE`）沒有速度參數，也沒有畫範圍——`docs/re/119`
  量到它寫進 `+0x28`／`+0x2A` 的值就是點到的世界座標，沒有夾。

## 收據

`s3cmdrange`：與 `s3cmdfl3` 同一條前置序列與注入
（`-poke lin:689E8@1394000000=00`），多一下點在艦隊選單第一項
「移動」上（滑鼠 (304,310)），之後不再點，畫面就停在選點狀態。
