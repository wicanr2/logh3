# 128 — 行程額度的帳終於算平（並且解釋了艦隊為什麼沒動）

> 這一篇的結論（20 步、轉向不扣、殘差 0.02 是開根號捨去）已被
> `docs/re/129` 取代：轉向與前進在同一次呼叫裡，第一步用的是轉到一半的
> 朝向，算出來與收據逐位元相同。下面保留當時的推導過程。

`docs/re/127` 的三個數字對不平，成因猜了兩個。這一輪替 dosgolem 加了
`-dump-mem-at`（同一次執行裡在幾個時點各倒一份記憶體），十個時點就把它
講清楚了——**兩次獨立執行去比是分不開的**。

## 十個時點

收據 `s3fltseq`（第 28 艦隊，下了移動命令之後按實行）：

| 步數（百萬）| 行動 | 朝向 | 每回合 | 剩餘 |
|---|---|---|---|---|
| 1560 | 0 | 190 | 240.00 | 6.57 |
| 1566 | 0 | 190 | 240.00 | 6.57 |
| **1572** | **1** | 190 | **160.00** | 6.57 |
| **1578** | 1 | **163** | 160.00 | **50.66** |
| **1584** | 1 | 163 | 160.00 | **3.80** |
| 1590–1620 | 1 | 163 | 160.00 | 3.80 |

三件事分開了：**行動先改（1572）、朝向與補滿在同一格（1578）、
然後燒完（1584）**，而且位置從頭到尾沒變。

## 帳算平了

補滿是**取代**，不是累加——艦隊那份的補法在 `1C03:0040`：
`艦隊 +0x58:+0x56 ← +0x54:+0x52`，無條件覆蓋。
（有「不足一步就累加」那條規則的是**分隊**那份，`1C61:0005`。）

朝向 163 時走一步是 `2BE1:026F(8)` ＝ 位移 **(−5,−6)**，距離 √61 ≈ 7.8102。
拿三種假設去對實測的 3.8011：

| 假設 | 算出來的剩餘 | 與實測差 |
|---|---|---|
| 取代成 160.0、**20 次前進**、轉向不扣 | 3.7796 | **0.02** |
| 取代成 160.0、19 次前進、轉向扣 8.0 | 3.6053 | 0.20 |
| 累加（6.57 ＋ 160）、20 次前進 | 2.3630 | 1.44 |

第一個吻合，而那 0.02 正好是**定點開根號的捨去**在 20 步上累積起來的量
（每步約 0.001）。所以：

```
每回合開頭：剩餘 ← 每回合行程（取代）
前進一步：扣掉「那一步實際走的距離」——不是 8，是取整後的 (−5,−6) 的長度
```

## 為什麼位置沒變：**失敗的一步也扣**

`1C03:02C6` 的順序是

```
新位置 = 沿朝向走 8
距離   = 3310:0006(現在, 新位置)
剩餘  −= 距離                    ← 先扣
if 2583:040C(新位置, 陣營) == 0：現在位置 ← 新位置    ← 才檢查
```

**扣在檢查前面。** 這一回合走了 20 次、每次都被 `2583:040C` 擋掉，
所以額度燒光而位置一格沒動。這就是收據看到的樣子。

被擋的原因（地形還是有東西佔著）還沒分開——`2583:040C` 兩條都會回非 0。

## 轉向那一步的成本

實測支持「**轉向沒有扣**」（差 0.02 對 0.20）。反組譯裡不扣的是
「一次轉到位」那條分支（`|角差| ≤ 回轉速度`），但這一次的角差是 27、
回轉速度 15，照理該走「轉滿一步並扣 8」那條。**所以 `2BE1:021B`
（算角差那支）回的東西不是單純的差**，或者中間還有一步把角差先夾住。
那支還沒讀。

## 對 remake 的影響

這一段（艦隊層的移動）還沒實作，所以沒有現成程式碼要改。規則記在這裡
與 `docs/internals/33`，等旗艦的「移動」要接的時候直接用。

`-dump-mem-at` 是這一輪替 dosgolem 加的（`ef5be47`）：純新增旗標，
不碰輸入、時序與顯示語意。為了確認，重跑了收據 `s3cmdsq3`
（→ `s3cmdsq3v`），`screen.bin` 的 SHA-256 完全相同。
