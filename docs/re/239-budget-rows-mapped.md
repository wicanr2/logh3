# 239 — 預算畫面那四格對到哪三個全域，以及預估軍事費的算式

`docs/spec/003` 把預算畫面的十列排出來了，但其中四列在兩張收據上**都是
0**，所以對應是照標籤猜的，「次月份那兩格從哪來」還掛著。
把全域 poke 成互不相同的值，畫面自己會說。

## 收據 `fiscalrows5`

`budget1` 的輸入序列（`-clicks '…;432,300,130000000,300000'`）加上

```
lin:5DAA2（ds:8F72）= 11111
lin:5DAAA（ds:8F7A）= 22222
lin:5DAB2（ds:8F82）= 33333
```

在 `#129.0M`–`#131.1M` 之間每 50k 條注入一次。畫面：

```
本月份  原定軍事費 ：       0
已支付  船艦建造費 ：       0
        艦隊維持費 ：   22222      ← ds:8F7A
        移動經費   ：       0
本次    艦隊維持費 ：   11111      ← ds:8F72
預定    移動經費   ：   33333      ← ds:8F82
次月份  預估徵稅額 ：   10741  普通
預定    預估軍事費 ：   −5925
        船艦建造費 ：   15185  25%
        剩餘軍事費 ：  −21110
```

## 對應

| 畫面列 | 全域 | 語意 |
|---|---|---|
| 已支付 艦隊維持費 | **`ds:8F7A`** | 累計已付的維持費（`docs/re/238`）|
| 已支付 移動經費 | 還沒找到 | 量到的都是 0 |
| 本次預定 艦隊維持費 | **`ds:8F72`** | Σ 艦隊 `+0x0A` |
| 本次預定 移動經費 | **`ds:8F82`** | Σ **會動的**艦隊 `+0x0C` |

`docs/spec/003` 原本把 202 記成 `ds:8F72`、222 記成 `ds:8F7A`，
242／262 記成「次月份、來源未查」——**整組錯位一格**，已改。

`ds:8F82` 的那個「會動的」來自 `297B:12FB(艦隊)`（線性 `0x2AAAB`）：

```
艦隊[+0x08] == 2 或 == 5 → 回 0        ; 不動
否則                     → 回 艦隊[+0x0C]
```

`ds:8F72` 與 `ds:8F82` 由同一支 `297B:10DE(陣營)` 一起算：掃 32 個槽、
陣營相符的逐支加 `297B:116C(艦隊)` 與 `297B:12FB(艦隊)`，前者當回傳值
（呼叫端存進 `ds:8F72`）、後者直接寫進 `ds:8F82[陣營]`。

## 三條算式

```
預估軍事費 = 國庫 + 預估徵稅額 − 那四格加起來
           = 60741 − (22222 + 11111 + 33333) = −5925
船艦建造費 = （國庫 + 預估徵稅額）× 百分比        ← **扣之前**的數
           = 60741 × 25% = 15185
剩餘軍事費 = 預估軍事費 − 船艦建造費
           = −5925 − 15185 = −21110
```

**船艦建造費用的是扣之前的數**——預估軍事費被壓成負的，那一格仍然是
15185。負數印成紅色。

這也解掉 `rules.Treasury.Remaining()` 註解裡「同盟那邊對不上」的問題：
四格裡有兩格是**本回合的預定額**、一格是**累計已付**，混在同一條減法
裡本來就不是同一種東西。

## remake

`rules.Treasury` 拆成四格（`FleetUpkeep`／`Movement`／`NextUpkeep`／
`NextMovement`），`Treasury.Paid()` 是四格的和；`BudgetPanel.Draw` 的
`military` 與 `rest` 兩列照上面的算式改。既有的兩張收據四格都是 0，
所以逐位元組對拍不受影響；`TestTreasuryPaidMatchesReceipt` 釘新的算式。

## 一條方法

**四次才問對。** 前三跑的注入分別落在 `#156M`／`#155.5M`／`#131M–164M`，
畫面都沒變——因為那張報告在點擊（`#130M`）之後**馬上**就畫好了，
三次都太晚。把範圍往回推到點擊前後掃細網格才中。
**注入要對準的是「畫面被畫出來的那一刻」，不是「資料被算出來的那一刻」**；
兩者可以差很遠，而且前者才是唯一有輸出可看的。
