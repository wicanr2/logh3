# 跨過月底之後，地圖上有兩個星域換了顏色

按十次「實行」從 796 年 1 月走到 2 月（收據 `turnnext`），
戰略地圖上**馬爾•亞迪特（星域 24）與巴米利恩（星域 28）從色 3 變成色 12**。

勢力色的對應早就釘住了（`../internals/13`）：帝國 ＝ 色 1、同盟 ＝ 色 12、
無主 ＝ 色 3，首都另外重塗成色 6。所以這兩格的意思是
**無主 → 同盟**。

## 量到的數字

星域遮罩（`STRMAP.RGN`）內每個顏色的像素數：

| 收據 | 星域 | 色 3 | 色 12 |
|---|---|---:|---:|
| `main1e`（796/1/1）| 24 | 2664 | 44 |
| `turnnext`（796/2/1）| 24 | 1647 | 1061 |
| `main1e` | 28 | 1444 | 11 |
| `turnnext` | 28 | 999 | 456 |

兩格各有 1017 與 445 個像素整批從 3 翻成 12，其餘顏色（星點、航路、
邊界）一個都沒動。地圖區（`0,40`–`319,339`）其他 30 個星域**完全沒變**：
`main1e` 與 `turn450`（796/1/4，第一次實行之後）在地圖區是
**0 個像素不同**，`turn450` 與 `turnnext` 差的 1462 點全部落在這兩格裡。

## 這兩格在 796/1 的組成

星域的擁有者是**從行星算出來的**（`17`）：全部屬同一方才算那一方，
只要混雜就是無主。

| 星域 | 帝國行星 | 同盟行星 | 無主行星 | 796/1 擁有者 |
|---|---:|---:|---:|---|
| 24 馬爾•亞迪特 | 0 | 0 | 1 | 2（無主）|
| 28 巴米利恩 | 0 | 0 | 3 | 2（無主）|
| 3 卡斯特羅普 | 0 | 0 | 3 | 2（無主）|
| 14 費沙 | 0 | 0 | 1 | 2（無主）|

**四格的組成同型，只有 24 與 28 翻了。** 所以不是「無主的行星到期就歸誰」
這種一律成立的規則——差別在別的地方，還沒找到。

## 擁有者欄位真的被改回來了

星域表在執行期是 `ds:A79C` ＝ 線性 `5F2CC`，32 筆 × 126 bytes，擁有者在
`+18`（`../internals/22`）。跑到 620,000,000 步（十次「實行」）把整張表
倒出來（收據 `rgndump` 的 `regions.bin`）：

```
載入時算出來的（remake）  [0 0 0 2 0 0 0 0 0 0 2 2 2 0 2 1 1 1 1 1 1 1 1 2 2 2 1 1 2 1 1 1]
620M 步時的原版           [0 0 0 2 0 0 0 0 0 0 2 2 2 0 2 1 1 1 1 1 1 1 1 2 1 2 1 1 2 1 1 1]
                                                                        ↑ 星域 24
```

**32 格裡只有星域 24 不同**，2（無主）→ 1（同盟）；星域 28 在這個時間點
還是 2。所以兩格不是一起翻的，也不是月底一次翻——是**各自在某個回合翻**。

順帶把載入時的重算整份驗過了：其餘 31 格與 remake 的
`Planets.RegionOwner` 完全相同。

`STELLAR.DTX` 檔案裡星域 24／28 都是 1；載入時 `2703:15CD` 把它們寫成 2
（監看 `5FEAE`／`600A6` 抓到 `01 → 02`，步 #68,745,903 與 #68,758,321），
這就是 `44` 說的「新遊戲整份重算」。

## 狀態

- `proven`：這兩格的顏色在遊戲進行中改變，其餘地圖不動；擁有者欄位
  從 2 被改回 1。
- `proven`：兩格翻的時間不同（620M 步時只有 24 翻了）。
- `unknown`：**哪一段程式把它改回去、依據是什麼**。監看整段太慢
  （開 `-watch` 之後執行速度掉到約 30 萬步/秒，15 分鐘只跑到 268M），
  已改成只監看 `5FEAE` 一個位元組、跑滿 620M 抓寫入者。

remake 現在跨月只做逐行星成長與收稅（`33`、`35`），不動任何擁有者，
所以 796/2 的地圖與原版差這兩格。右側面板那兩個數字也對不上，
但那一項另有已知的成因（經濟力差 1，`33`）——**兩件事不要混在一起看**。
