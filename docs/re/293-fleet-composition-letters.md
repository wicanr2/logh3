## 怎麼找到那段程式

「□」的字碼 `A1BC` 在整份傾印裡搜不到——因為 Big5 字串是**高位元組在前**
存的，要搜的是 `A1 BC`（小端讀成 `BCA1`）。搜對之後整份 1 MB 只有兩處，
兩處都緊跟在一條 `"\x03[%d,%s"` 後面：

```
ds:24E8 "\x03[%d,%s"   ds:24F0 "□"     ← 戰略地圖的艦隊詳細資料
ds:2AD4 "\x01[%d,%d,"  ds:2ADD "編隊﹕"  ds:2AE4 "□"   ← 艦隊組成
```

`ds:2ADD` 就是畫面上那三個字，所以 `0FF4:03B5` 那一支是要找的。
同一塊字串區還有 `ds:2A96 "艦隊組成"`、`ds:2AF3 "部隊數  ﹕ %2d/%2d"`、
`ds:2B0F "機動力  ﹕  %3u%%"`，整張畫面的每一行都在。

字母表是反過來找的：搜「把某個 disp16 當遠指標表推進印字常式」的形狀
`ff b7 74 61 / ff b7 72 61`（`push [bx+6174h]` ＋ `push [bx+6172h]`），
全圖五處，五處的 `bx` 都是 `某個 byte 欄位 × 4`：

| 位置 | 索引來自 | 是哪一張畫面 |
|---|---|---|
| `0FF4:046D`（線性 `0x103AD`）| `ds:981E[i]` 的 `[2]` | **艦隊組成的編隊那一行** |
| `0DEA:0678`（線性 `0x0E518`）| 艦隊 `+0x10 + i×4` 的 `[2]` | 戰略地圖的艦隊詳細資料「狀態　部隊組成」 |
| 線性 `0x0B717`、`0x1469A` | 艦艇 `+0x04` | 另兩張畫面（未追）|
| 線性 `0x07C05` | 一個 0–6 的迴圈計數 | 七個艦種當欄名的那張（未追）|

`ds:6172` 的八筆遠指標直接讀傾印就是 Ｂ Ｈ Ｃ Ａ Ｄ Ｔ Ｅ Ｐ
（`A2D0 A2D6 A2D1 A2CF A2D2 A2E2 A2D3 A2DE`），與 `BHCADTE` 前七個
逐一相同——**兩張表是從不同地方讀出來的**，這一步是互相驗證，
不是把同一件事講兩遍。

## 「八格」是巧合

畫幾格由 `ds:984B ＋ ds:984C` 決定，而 `0FF4:0768` 寫的是

```
ds:984C ← 艦隊[+0x0E] − ds:984B
```

所以總格數恆等於 `+0x0E` ＝ 編制槽的應有數。收據 `fok` 那一支的提督
（萊因哈特）等級落在 29–33，`297B:0209` 給 8（`docs/re/214`），
畫面才印 8 格、部隊數才是 `1／8`。**`fleet-composition-panel.json`
原本把 8 寫成常數，那是把一個收據的值當成規則。**這一輪把
`units.slots` 與 `formation.slots` 兩個常數都拿掉了。

## 順手解掉的：格盤的圖塊也是算的

`0FF4:0EF1(隊形槽, 艦種)` 換格盤那一格的圖形：

```
圖塊 = (艦種 == 0xFF) ? ds:984D : ds:984E + 艦種
```

`ds:984D`／`ds:984E` 在 `0FF4:0098` 依陣營選：帝國 44／36、同盟 74／66。
規格 015 原本寫的「空位第 44 張、中央第 36 張」是這條規則在
「帝國、艦種 0」的特例，**照抄會讓同盟那一邊整片畫錯**。

格子位置是常數表 `ds:28B8`（41 × 4 bytes 的 x, y）。它與戰場的隊形槽表
`ds:59BA` 差一個 90 度：`ds:28B8[i] == (ds:59BA[i].y, −ds:59BA[i].x)`
**41 筆全中**，反向那個旋向 41 筆錯 40 筆（只有正中央那一筆兩邊都對）。
兩張表排列順序不同——`ds:59BA` 逐欄、`ds:28B8` 逐列——所以拿其中一張
去推另一張的「第 i 個槽是第幾格」會得到一個自洽但錯的答案。

## 方法：三個坑

1. **Big5 字串是高位元組在前。** 搜 `A1BC` 搜不到「□」，要搜 `A1 BC`。
   第一次掃出 0 處的時候差點寫成「這個字碼不在程式裡，應該是算出來的」
   ——那不是結論，是搜錯了位元組序。
2. **IDA 的線性反組譯會在 `d1 e3 d1 e3` 這種地方錯開一個位元組**
   （把 `shl bx,1` 的第一個 byte 當成 db）。它自己在幾條之後會同步回來，
   所以拿它當唯一來源會漏掉「`bx` 乘了 4」這件事——而那正是「表的一筆
   是 4 bytes」的證據。逐位元組核對過才算。
3. **同樣是 41 筆、同樣中央是 20 的兩張表，排列順序可以不同。**
   `ds:59BA` 與 `ds:28B8` 就是。只比對「槽 20 在正中央」會覺得一樣。
