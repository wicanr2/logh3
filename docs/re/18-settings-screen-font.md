# RE 18 — 遊戲設定畫面用的不是 `GRAPH.IMG`

日期：2026-09-07
執行器：dosgolem-logh3 `82f430e`
收據：`settings1e`
狀態：**未解**（字型來源）。

## 現象

遊戲設定畫面（系統指令 → 設定）的標籤——「遊戲設定」「音源」「BGM」
「戰鬥BGM」「訊息速度」「動畫效果」「動畫速度」——**一個都掃不出來**。
其餘畫面用同一支 `read_line` 都讀得到。

## 不是位置問題

起點掃過 x 164–240、基線掃過 y 56–67，全部回 0 格。把那一格的點陣
（`ink = 7`，16 × 15）拿去跟整張字型表比，最接近的一個差 **76 個位元**
——不是「差一點」，是完全不同的字。

## 是字形本身不同

把畫面上 (176,61) 那一格與字型表裡的「遊」（Big5 `A9C3`）並排：

```
字型表                  畫面
...#........#...        ................
...#.#########..        ##....##...##...
...#.....#......        .##...##..##....
.#.##....#......        ....###########.
.#.#.#...#......        #######.........
.#.#.....#..#...        ...############.
#..#..#..#####..        ..##.##.##..##..
```

畫面上的筆畫**每一劃都是兩個像素寬**，而且整個字往下擠了一列，
第 15 列是一條實心橫線（那是框的邊，不屬於字）。

看起來是**另一套字型**，或者同一套字型的加粗／放大版本。來源未確認：
`GRAPH.IMG` 之外，目前已知的字型檔只有 `BU16IBM.RGB`（那是調色盤，
不是字型，見 `CONTEXT.md` 的已被推翻表）。

## 影響

`screen-settings` 的規格量得出框與橫條，但標籤文字缺，
差 10,839 / 307,200，**沒有進對拍表**。收據 `settings1e` 留著。

下一步：在原版讀檔紀錄裡找設定畫面開啟前後讀了什麼——
字型如果是另一個檔，那一刻應該會被 seek。
