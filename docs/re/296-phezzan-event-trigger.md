## 觸發鏈

### 一、易主時登記：`1213:007B(星域記錄)`

```
1213:007B  55 89 e5
  007E  80 3e 48 8f 00     cmp ds:8F48, 0        ; 事件已經發生過 → 回
  0083  75 0f              jnz 回
  0085  c4 5e 06           les bx, [bp+6]
  0088  26 80 7f 11 0e     cmp es:[bx+11h], 0Eh  ; 星域 +0x11 ＝ 自己的編號；14 ＝ 費沙
  008D  75 05              jnz 回
  008F  c6 06 8e 98 01     mov ds:988E, 1        ; 「費沙易主了」待辦旗標
  0094  5d cb
```

兩個呼叫端：

**戰略層（回合尾巴）**：`056A:0855(星域記錄, 舊擁有者)` 是「星域易主」的通知，
先對兩個人類座位各跑一次報告 `056A:089D`（[`250`](250-flip-report-routine.md)），
**最後一行不看座位**，無條件 `call 1213:007B`：

```
056A:088E  ff 76 08 / ff 76 06
056A:0894  9a 7b 00 13 12     call 1213:007B
```

`056A:0855` 只由 `056A:078E` 呼叫：主迴圈回合尾巴那一支
（[`251`](251-turn-loop-and-battle-nesting.md)），逐格 `2703:159B` 依行星重算擁有者，
**有變的才**呼叫 `056A:0855`。所以不論是誰拿下費沙（人類或電腦、戰略層打行星
[`internals/53`](../internals/53-strategic-planet-assault.md)），只要回合尾巴那次重算
讓星域 14 的 `+0x12` 換了值，就會登記。

**戰術層（戰鬥中占領）**：戰術回合結束 `181B:000A` → `181B:0385`（畫面上「最後階段」，
`ds:3D37`）→ `185C:0001` → `185C:02DA`，對交戰那一格（`ds:8F17`）依行星重算擁有者，
有變就對兩個座位各跑一次 `185C:03C6(座位陣營, 星域記錄, 新擁有者)`，再把新擁有者寫進
`+0x12`：

```
185C:03C6(f, 星域, 新):
    3982:022D(f) != 0（不是人類座位）→ 回
    新 == f → sprintf(ds:3D58 ＝ "%s星系\n已經占領下來。")；1213:007B(星域)
    新 == 2 → 舊擁有者 == f ? ds:3D71「%s星系部分地區已脫離我方統治。」
                           : ds:3D92「我軍已進駐%s星系部分行星。」
    否則    → ds:3DAF「%s星系已經被敵軍奪取。」
    3826:0405(緩衝, f, 0)
```

這一條只在**人類座位自己拿下費沙**時登記。戰鬥裡已經把 `+0x12` 寫成新值，
回合尾巴的重算就看不到「有變」，所以**電腦方在戰術戰鬥裡拿下費沙不會觸發事件**
——要等費沙之後再易主一次（反組譯推得，沒有收據）。

### 四、選目標時的提醒：`1213:0003(星域編號)`

地圖上選艦隊的移動目標（`113A:01AB`；`113A` 是艦隊移動那一段，挑到走不到的格子
印 `ds:2DDC`「這是無法前往的星系。」）挑到的格子先過 `1213:0003`：

```
星域 != 14 或 ds:8F48 != 0 → 回 1
3603:0006(…) 開視窗；ds:8F1D == 0 ? ds:3016 : ds:301E（兩頁）；3603:00B4
回 1
```

帝國看到「占領費沙自治領地可能會導致費沙的經濟力流向同盟軍。而且，強硬的占領政策
可能會造成邊境星系的情勢惡化。」；同盟看到「破壞和平條約將會使費沙龐大的經濟力流向
帝國軍那一方。而且有可能會使得同盟星系發生叛亂。你確定要占領費沙嗎？」——
**但兩條路都 `mov ax, 1` 回 1**，呼叫端的 `or ax,ax / jz` 永遠不跳。
同盟那一句問「你確定要占領費沙嗎？」，程式不收答案，只是提醒。這是原版的行為，照樣記。

## 規則

```
回合尾巴（056A:078E，每按一次「實行」一趟）：
    逐格依行星重算擁有者；星域 14 的擁有者換了值，而且 ds:8F48 == 0 → 登記
    （戰術戰鬥結束時的重算：人類座位自己拿下費沙 → 登記）
    逐格跑完之後：有登記而且 ds:8F48 == 0 → 費沙事件（一局只一次）
```

**觸發條件就是「費沙那一格第一次易主」**，沒有回合數、沒有伊謝爾倫、沒有亂數。
伊謝爾倫與回合數 238／318 那道門檻（`2E54:0F93`，[`178`](178-ai-advance-routes.md)）
是電腦**願不願意去打**費沙，不是事件的條件。人類玩家把費沙選成移動目標時只會看到提醒
（`1213:0003` 恆回 1）。事件在回合尾巴重算出星域 14 的新擁有者那一刻發生——費沙只有一顆行星，
也就是那顆行星換手之後的第一個回合尾巴。

## 對 remake 的意義

- 觸發點要接在回合尾巴「逐格重算擁有者」之後、判勝負之前，一個回合最多一次，
  條件是「星域 14 在這次重算裡換了擁有者，而且 `ds:8F48` 還沒設」。
- 戰術戰鬥結束時的重算也要登記，但只在人類座位是新擁有者時。
- `internal/ai` 的 `StateCode(…, phezzanOpen)` 目前永遠傳 false
  （`docs/spec/029`「不能做的」），事件接上之後就有真值可傳。
- 事件的完整規格與資料在 [`internals/57`](../internals/57-phezzan-event.md)。

## 還沒做

- 戰術層那一條（`185C:03C6` → `1213:007B`）沒有收據：要一場在費沙的戰術戰鬥、
  人類座位打下最後一顆行星。
- 同盟拿下費沙、同盟是人類座位（`ds:3268` 那一路、`ds:3284` 八格清單、目標瓦爾哈拉第 0 顆）
  沒有收據；規則與帝國那一路同一支程式，只有常數不同。
- `緩衝[0] == 2`（本體裡要不要印叛亂那一句）的語意。
- `0374:03E8` 的續接路徑（主迴圈 `[bp+0] != 0`，[`251`](251-turn-loop-and-battle-nesting.md)）
  重新進場時也會把 `ds:988E` 歸零。那條路什麼時候走、會不會吃掉戰術層在同一回合的登記，沒有查。

## 方法

**「沒有呼叫者」之前先驗那個位址是不是進入點。** 前一個位元組應該是 `retf`／`ret`
（或段首），那一格應該是 `push bp` 家族；`1213:0235` 落在一條 far call 的中間，
這兩項都不成立。[`295`](295-region-morale-writers.md) 的 `056A:0468`／`0469` 是同一種錯位，
`056A:078B`（[`245`](245-region-flag-bits-one-and-four.md)、`docs/spec/034`）也是
——實際進入點是 `056A:078E`，`078B` 是前一支的 `pop si`。

**傾印切片的長度用算的。** `0x5F2CC + 4032` 是 `0x6028C`，十進位的 4032 不能直接當
十六進位加；少算的那一段不會報錯，只會讓比對安靜地少比十三格。
