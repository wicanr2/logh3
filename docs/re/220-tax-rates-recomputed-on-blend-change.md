# 220 — 稅率是 `Blend` 一變就整批重算的，那 2747 的稅收落差就是它

`docs/re/219` 留下最後一個差異：原版那一趟裡同盟的總稅收從 10599 掉到
7852，remake 沒有那個下降，於是多建了一支。查出來了。

## 掉的是稅率，不是別的

比對 `turn260mem` 的 pre／post 兩份傾印，**13 個同盟星域的 `+0x26`
（稅率）全部下降**，而經濟力（`+0x1A`）一格沒變、擁有者（`+0x12`）
也一格沒變：

| 星域 | 稅率 | 稅額 |
|---|---|---|
| 15 | 46 → 44 | 549 → 525 |
| 22 | 87 → **65** | 372 → 278 |
| 26 | 50 → **38** | 573 → 435 |
| 29 | 41 → **30** | 680 → 497 |
| 31 | 36 → **27** | 2369 → 1777 |

幅度不一致——高稅率砍得多（87 砍 25%、46 只砍 4%），像是往某個目標調。

## 誰改的：`090A:0B93`

對星域 31 的 `+0x26`（線性 `0x60234`）設監看（收據 `taxrate`）：

```
[watch] #68676477  60234: 00 → 05  ← 3D08:001A     ; 載檔案
[watch] #70885065  60234: 05 → 24  ← 090A:0DAF     ; 開局重算 → 36
[watch] #212219335 60234: 24 → 1B  ← 090A:0DAF     ; ★ 這一次 → 27
[watch] #214005767 60234: 1B → 23  ← 090A:0DAF
[watch] #214197638 60234: 23 → 17  ← 090A:0DAF
```

**每一次都是 `090A:0DAF`**，那是 `090A:0B93` 的迴圈尾：

```
090A:0B93(等級):
    統治者 = ds:B77C + ds:8F4F[陣營] × 28
    對 32 個星域：擁有者 == ds:8F1D 才算
        …（一串 32 位元乘除，輸入含 ds:147E[參數] 與統治者的能力）…
        夾在 [1, 200]
        星域[+0x26] = 值
```

## 觸發它的是 `Blend` 變動

`090A:0B93` 的唯一呼叫點在線性 `0x0945D`——**就是 `ds:8FD4`
（＝ 未安定度公式的 `Blend`）真的變動之後那一段**（`docs/re/206`、
`docs/re/207`）：

```
f(delta):  ±1、夾在 0–4
    真的變了 → 090A:0B93(新值) → 090A:0E6D()   ; 顯示層，跳訊息
```

兩份傾印對得上：

| | 帝國 | 同盟 |
|---|---|---|
| pre（#211000000）| 2 | **2** |
| post（#214000000）| 2 | **1** |

**同盟的 `Blend` 在那個窗口從 2 掉到 1**，而稅率的那一次改寫
（#212219335）正落在裡面。

## 整條鏈

```
（未知事件）→ ds:8FD4[同盟] 2 → 1
           → 090A:0B93 重算同盟每個星域的稅率（+0x26）
           → 總稅收 10599 → 7852
           → 建艦隊的閘門提早收手：3 支而不是 4 支
```

`docs/re/219` 那個「原因未解」的落差因此解掉了，
而 `docs/spec/006` 問的「`Blend` 從哪來」也更完整：**它會動，
而且一動就重算全國稅率**。

## 還沒解的一格

**什麼事件讓 `Blend` 升降。** `0x09413` 在整份 1 MB 傾印裡一個呼叫者都
沒有（far／near 都掃過，`docs/re/207`），與費沙事件的觸發點同一個形狀
——多半在沒載入的 overlay。

## 對 remake 的意義

remake 沒有 `Blend`，也沒有稅率重算，所以稅收停在開局值 10599，
建艦隊的閘門晚一步收手（4 支對 3 支）。**要對上得先有 `Blend` 的
升降事件**，那一項還沒解——所以這一支差距**目前補不了**，
不是實作沒做。

## 一條方法

**「數字掉了」先問掉的是哪一個因子。** 稅額 ＝ 經濟力 × 稅率 ÷ 1000，
兩個因子攤開來比，一眼就看到經濟力沒動、稅率全掉——省掉了「是不是丟了
星域」「是不是經濟被打壞」那幾條岔路。**先分解再追來源。**
