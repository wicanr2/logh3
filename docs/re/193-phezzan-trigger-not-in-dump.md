# 193 — 費沙事件的觸發點不在這份傾印裡

`docs/re/192` 讀完費沙事件的本體（`1213:025D` ＝ `0x1238D`），
剩下「誰觸發它」。這一輪掃完，答案是**掃不到**——而這件事本身要記下來。

## 直接呼叫者：一個三行的包裝

```
1213:0235（0x12365）:
    1213:025D(四個 word)          ; 費沙事件本體（docs/re/192）
    1213:03F5()
    090A:0E6D()
```

`090A:*` 是低位的顯示層（`workplace/code090A.bin` 那一段）。
緊接在前面的常式是印訊息用的——它 push `ds:3297`，內容是
`0C "%s" 00`（`0x0C` 是清畫面，後面一個字串），再走 `3617:000A`。
所以費沙事件跑完會**跳一段文字出來**，形狀與月底報告那類事件一致。

## 包裝的呼叫者掃不到

掃描範圍與結果（照 `docs/re/175` 的教訓，把範圍寫清楚）：

| 掃法 | 範圍 | 命中 |
|---|---|---|
| 遠指標（`off, seg` 解出 `0x12365`）| **整份 1 MB 傾印** | **0** |
| `9a` far call 到 `0x12365` | 整份 1 MB 傾印 | 0 |
| `e8` near call 到 `0x12365` | 段 `1213` 全部 **64 KB** | 0 |
| `e8` near call 到 `0x1238D`（本體）| 段 `1213` 全部 64 KB | 0 |

`0x1238D` 唯一的呼叫者就是 `0x1237A`，也就是那個包裝自己。

**所以觸發點不在 `workplace/s3ai6.bin` 這份傾印裡。** 最可能的兩種：

1. 它在一段**還沒載入的 overlay** 裡（這款遊戲用 EMS 換頁，
   `docs/re/183`／`docs/re/185` 已經看過中點矩陣與距離表都在 EMS）。
2. 呼叫走的是**執行期才填的遠指標表**（`ff 1e` 這類間接呼叫），
   靜態掃描結構上看不到（同 `~/.claude/knowledge-base/retro/pce-huc6280-re-toolkit.md`
   記的那個坑）。

## 下一步

要找觸發條件，靜態掃描不夠，得動態取：對 `1213:025D` 設
`-regs-at`，在一個**真的會發生費沙事件**的局面上跑，讀堆疊上的返回位址。
而那個局面本身也要先造得出來——費沙的門檻是
「伊謝爾倫不在敵方手上，或回合數過 238／318」（`docs/re/178`），
所以最省事的做法是 `-poke` 直接把伊謝爾倫的擁有者改掉再推幾個回合。

## 一條方法

**回報「找不到呼叫者」時，把掃過的四種形狀與範圍一起寫出來。**
「0 處」在靜態掃描裡有四種意思：真的沒有、範圍不夠、
形狀沒涵蓋（間接呼叫）、或那段程式碼當下不在記憶體裡。
這一輪是後兩種之一，而區分它們要靠動態。
