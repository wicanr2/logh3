## 二、時序

### 2.1 計時器（P）

- `39C8:000E` 裝 int 08h（`39C8:008A`）並把 PIT 通道 0 設成分頻 `0x0800`（582.6 Hz）。
- ISR：`ds:8EF2` 每 10 次歸零並呼叫 `39C8:00CA`：`ds:8EFC`、`ds:8EFE` 非 0 就各減 1，`ds:8EF8:8EFA` 32 位元加 1；
  `ds:8EEE` 每 32 次轉呼叫原 BIOS 向量（18.2 Hz）。所以 **1 tick ＝ 10 次 IRQ0 ＝ 1/58.26 s ≈ 17.16 ms**。
- dosgolem `-tick 20000` 釘住的間隔下，1 tick ＝ 200,000 步；`-watch 5DA2E` 量到的遞減落在 `#…145018` 相位、每 200,000 步一次。
- `348A:0281`（每一格之前，含 `01DC` 的單格與 `ANI_PNL1` 底圖）：`while ds:8EFE != 0`（忙等，不讀輸入）；
  然後 `ds:8EFE = ds:8F10[ds:8F37]` 才畫這一格。→ **格的間隔從上一格畫下去算起**，第一格若上一次計時已過期就不等。
- `ds:8F10 = 08 04 00`；`ds:8F37` 由設定畫面寫：普通 0／快速 1／最快 2（`screen-settings.json`，線性 `047A4/047BA/047D0`）→ **8／4／0 tick**。
- `3765:006C(n)`：`ds:8EFE = n`，迴圈 `3765:00BF(&事件, 0)` 取事件；`8EFE == 0` 或事件種類 1／2 就結束，最後 `8EFE = 0`。
  `ds:8F38` ＝ 設定畫面的「訊息速度」（10–300，步進 10），開機 `0x5A` ＝ 90（線性 `039E1`）。
