## 六、探測的坑：移動與按鍵同一瞬間，那一下會被丟掉

`-clicks step:x:y` 把游標搬過去並在同一步按下。游標從一列搬到**會換反白的**另一列時，
清單迴圈的游標處理（`0591` → `0284`、`073F:0008`、`0418`）正在跑，按鍵事件到了卻沒進迴圈
（`fcx-lst-star-row0`／`fcx-lst-star-r1`：`0D05:0141` 0 次；先 `-mouse-at` 搬過去、10M 步之後
再按就收得到：`fcx-lst-star-r0b`、`fcx-lst-adm-rr`）。同一件事解釋了 `docs/re/318` §六
「從副官進來的清單右鍵不關」：那一批的右鍵與游標搬到地圖上是同一瞬間，游標處理
`0591(FF)` 正在清左下角。**成因沒讀**（事件佇列 `ds:F184` 那一圈在重畫期間掉事件的位置）
——第 20 段一律先搬再按（`mvc`／`mvr`）。這不是遊戲規則，remake 不重現。
