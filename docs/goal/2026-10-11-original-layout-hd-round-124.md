# 第124輪：原介面加強與地圖HD

2026-10-11。使用者明示「HD部份 我只是希望在原來的操作界面上加強 我選擇A 另外地圖也要hd化」。這項決定修正第123輪試樣方向。A指深藍金色、方框與典雅艦橋質感；前輪HTML的重排配置未獲採用。沿用正式640×480邏輯畫布、4:3比例及現有1920×1440顯示，視窗、按鈕、疊窗及操作流程沿原版面加強。

## 製作順序

| 批次 | 工作 | 驗收 |
|---|---|---|
| 原配置試樣 | 由現行畫面JSON、財政按鈕矩形與正常S1截圖生成A試樣。參考切換放遊戲畫面外 | 原矩形、比例與疊窗位置相同；箭頭、返回、星域選取可操作；高解析字體不得超出原文字格 |
| 介面正式製作 | 面框、按鈕、清楚文字、游標、選單與戰術資訊；從財政及戰略命令切片開始 | 同一來源驅動繪製與命中；兩陣營七列、返回、正常入口與存讀抽驗 |
| 戰略星圖 | 分開重繪背景、星域、航路、星名、星球與勢力標記 | 32遮罩、航路拓撲、勢力／治安等不同著色模式及選取不變；缺圖回退 |
| 戰術地圖與小地圖 | 盤點四組128圖塊的共用關係；按圖塊重繪星雲、空間與地形接縫，小地圖另作清晰呈現 | 32張CMP實際格號、圖塊接縫與鏡頭邊界；標記、朝向、可見範圍與視野框；不把裝飾當作新地形 |
| 動畫試片與擴批 | 原段索引、幀序與事件點先核，再做S1光線砲／命中，之後擴批 | 艦型、朝向、光影連續；開火、命中、結算、完成與跳過閘門保持；補錄正式HD實際戰鬥 |
| 交付 | 定版美術接正常遊戲後重建三平台完整／引擎包及雙旗故事影片 | 揭露各類重繪覆蓋率，正常S1讀檔進場及實際交火；封包與影音沿既有交付契約 |

盤點檔案數不能當作獨立畫作數或工期。地圖原始資料、規則、存檔格式及戰鬥事件不隨美化改動。需要新正式替換契約時另走DRAFT、證據審查、READY與CONFORMED，試樣不進正式路徑。

## 本輪試樣與檢查

可操作入口：[原配置A試樣](../../workplace/hd124-original-layout/HD-ORIGINAL-LAYOUT.html)。包含財政、戰略星圖及正常S1戰場版面；對照切換在遊戲畫布外。預算結束與Esc返回月初會計報告。正式選單、參謀資料、財政重算及存檔未接入，只展示按鈕回饋與原文字格。小視窗等比縮小，沒有重排遊戲介面，也沒有宣稱觸控驗收。

- [幾何](../../workplace/hd124-original-layout/GEOMETRY.json)：640×480畫布、128,60,384×340預算視窗與六鈕矩形沿正式來源；32星域共82115個遮罩像素。BIT解碼的74445個非零色號與既有匯出相同，這只核對解碼，不代表新美術與原版逐像素相同。
- [瀏覽器收據](../../workplace/hd124-original-layout/BROWSER.json)：Chromium 154，1440像素的財政／戰略／戰場及800、390像素財政共五組。檢查六鈕、稅率／比例回饋、結束／Esc、32星域選取、原圖切換、字位安全、4:3及水平溢出。五張截圖已目視。
- [來源雜湊](../../workplace/hd124-original-layout/SOURCES.json)：原截圖、BIT／RGN、畫面JSON、工具及HTML SHA-256。星圖使用原遮罩及暫留前景，戰場沿正常S1截圖；本輪先示範面材與文字，未完成航路、星名、地形及部隊圖示重繪。
