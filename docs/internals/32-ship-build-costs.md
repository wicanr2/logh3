# 船艦建造：單價、一單位幾艘與捨去規則

建造計劃七列各代表一種艦種。一列的預算只能買整數「單位」，除不盡的
零頭退回餘額——餘額那一列印的就是這些零頭的和，不是
「建造費 × 餘額百分比」。

    金額   a = 建造費 × 百分比 / 100        （捨去）
    船艦數 = ⌊a / 單價⌋ × 10
    實際花掉 = a − a mod 單價
    部隊   = 船艦數 / 一單位艘數            （捨去）
    餘額   = 建造費 − Σ 各列實際花掉

## 一單位幾艘（strong inference，仍在區間裡）

艦艇記錄（`SHIP.DT?`）的 `+0x08` 依「艦種 × 陣營」查表，**兩個陣營的值
相同**（[`data/ship-types.json`](data/ship-types.json)）。畫面上的「部隊」
欄只給得出區間：

| 列 | 區間 | 目前用的值 |
|---:|---|---:|
| 0 戰艦 | (1895, 3390] | 3000 |
| 1 高速戰艦 | > 1260 | 3000 |
| 2 巡航艦 | (3415, 5490] | 4000 |
| 3 航空母艦 | > 660 | 2000 |
| 4 驅逐艦 | (2275, 3050] | 3000 |
| 5 運補艦 | (1635, 3250] | 3000 |
| 6 修護艦 | (950, 1030] | 1000 |

`+0x08` 讀到的值（3000/3000/4000/2000/3000/3000/1000）落在每一個區間內，
所以兩邊互相支持；但畫面本身還沒把第 1、3 列夾住。

## 百分比

一格是 1%（不是 2%）。箭頭按住會連發，按越久改越多。開局兩個陣營的
分配相同：20/10/18/10/12/15/15，加起來剛好 100，所以左欄的加號按下去
沒有反應——不是壞掉，是沒得加。
