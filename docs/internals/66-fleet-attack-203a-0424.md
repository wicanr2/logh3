# 66：戰略艦隊攻擊力 `203A:0424` 的精確語意

證據等級：confirmed。反組譯逐行讀出，並經 5006 案差異測試（[`docs/re/443`](../re/443-fleet-attack-differential-test.md)）。
C 參考實作在 `decomp/src/f_203A_0424.c`。

## 呼叫

far 呼叫，一個參數：艦隊記錄的 far 指標（位移在低 word、段在高 word）。回傳 `AX`。
不讀亂數、不寫記憶體（只用堆疊）。艦艇池基底讀 `ds:CFB4`（位移）與 `ds:CFB6`（段）。

## 步驟

```
合計 ← 0                                         ; 16 位元
for i ← 0; i < 艦隊[+0x0F]; i++                  ; i 是 byte
    索引 ← word(艦隊[+0x10 + i × 4])
    艦艇 ← 池基底 + (索引 × 78) mod 65536
    若 艦艇[+0x04] 是 0 或 1：合計 ← (合計 + word(艦艇[+0x08])) mod 65536
積 ← 合計 × 艦隊[+0x40]                           ; 32 位元乘（3CC9:0009）
商 ← 積 ÷ 100                                     ; 32 位元無號除（3CC9:0020）
低 ← 商 的低 16 位元                              ; mov [bp+4],bx
回傳 ← (低 ÷ 15 ＋ 250) mod 65536                 ; 16 位元除與加
```

## 與一般寫法不同的地方

| 位置 | 原版 | 以 `int` 計算的結果 |
|---|---|---|
| 艘數合計 | 16 位元回繞 | 不回繞 |
| 第一次除法的商 | 只留低 16 位元 | 保留全部 |
| `+250` | 16 位元 | 同值，因為 `低 ÷ 15 ＋ 250` 不會超過 65535 |

兩者只在 `艘數合計 >= 65536` 或 `艘數合計 × 能力 ÷ 100 >= 65536` 時不同。

## 輸入域

槽數 0 到 12（艦隊記錄 `+0x10` 到 `+0x3F` 容納 12 槽，`+0x40` 是能力），池索引小於 352。
槽數更大時，原版會讀過記錄尾端並把 byte 計數回繞，這個行為沒有驗證。
