# 原版素材清單

來源：`org_game/银河英雄传说3SP.zip`（SHA-256 見 `CONTEXT.md`）解出的
`org_game/extracted/`，共 162 個檔。所有檔案時間戳都是 2021-12-11，
那是打包者的時間，不是原版發行日期。

「開機到主選單會開」欄位標 `v` 的，是 dosgolem 從 `GIN3.COM` 一路跑到
主選單的過程中實際開啟過的檔（`docs/re/06` 的執行報告）。沒有標記不代表
沒用到，只代表在那條路徑上沒被開啟。

用途欄的等級：**confirmed**（有實測或反組譯證據）、**假說**（由檔名、
大小或副檔名推測）、**未知**。推測不得升格，除非補上證據。

## 值得記下來的細節

- **`WPRK.DT9`**：`WORK.DT9` 的錯字，原版就長這樣（`WORK.DT8`／`WORK.DTA`
  拼寫正常，只有 `.DT9` 這一份是 `WPRK`）。發行版裡的錯字是原始物件的一部分，
  不修正、不改名。
- **`KEIREKI.DAT`**：日文羅馬字（経歴）的檔名留在中文版裡，是這個中文版
  由日文原版改製的直接痕跡。
- **`.A98`**：PC-9801 版的素材命名混在同一個資料夾。判讀任何畫面或格式時要
  先確認檔案屬於哪個平台版本，不能因為在同一包裡就當成 DOS 版證據。
- **`.MDS` 的 `_F`／`_M`**：同一首曲子兩份，尺寸不同。假說是兩種音源各一份，
  尚未驗證哪個對應哪個。
- **`SPTIT.RGB` 與 `TITSPT.RGB`**：兩個互為顛倒的名字，各 48 bytes，
  但**內容不同**——是兩份調色盤，不是重複檔。
- **`IBM16.350`（1,764,911 bytes）**：整包最大的檔，比第二大的
  `GIN3PS.EXE` 還大一個級距。強證據為中文點陣字型。
- **`.350` 不是單一格式**：`IBM16.350` 1.76 MB、`SPTIT.350` 33 KB、
  `IBMFLS16.350` 748 bytes，三者用途顯然不同，副檔名只是命名習慣。
