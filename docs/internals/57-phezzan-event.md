# 費沙事件

資料：[`data/phezzan-event.json`](data/phezzan-event.json)
證據：[`../re/192`](../re/192-phezzan-event.md)（本體前半）、

費沙（星域 14，只有一顆行星：行星表第 34 筆）開局無主。**它第一次易主時**，
原版在那個回合尾巴跑一次「費沙事件」：費沙八成的經濟力流向對手首都、
拿下費沙那一方的邊境星域沒駐軍的整格叛離；拿下的一方是人類座位時，
其餘星域的經濟力再被砍一截、民心一律變成 100。一局只發生一次。

| 項目 | 等級 |
|---|---|
| 觸發（回合尾巴的易主 → 登記 → 發動）| confirmed（反組譯 ＋ 收據 `pzx296`／`pzx296n`／`pzx296g`）|
| 本體、懲罰、`090A:0E6D` 重算經濟力 | confirmed（反組譯 ＋ `pzx296` 逐位元組重播，`tools/scripts/phezzan_event_check.py`）|
| 戰術戰鬥中占領那一條登記路徑 | confirmed（反組譯），沒有收據 |
| 同盟拿下費沙那一路的常數（`ds:3268`／`ds:3270`／`ds:3284`、目標奧丁）| confirmed（反組譯，同一支程式），沒有收據 |
| 本體裡 `視窗[0] == 2` 的意思 | 未知 |

## 觸發

兩個全域：

| 變數 | 意思 | 寫入者 |
|---|---|---|
| `ds:8F48` | 事件已發生（非 0）| 新遊戲初始化清 0；事件本體第一行設 1。存檔 `WORK.DT?` 的 `+0x34` 帶著它；出貨的 `WORK.DTA`（回合 380，費沙已是帝國的）是 `0xFF` |
| `ds:988E` | 這個回合費沙易主了（待辦）| 逐格開戰那一圈（`0374:03E8`）每次進場清 0；登記那一支設 1。不在存檔裡 |

```
登記（1213:007B，參數：星域記錄）：
    ds:8F48 != 0 → 回
    星域[+0x11] != 14 → 回                ; +0x11 ＝ 星域自己的編號
    ds:988E = 1
```

登記有兩個呼叫端：

1. **回合尾巴的易主通知** `056A:0855(星域記錄, 舊擁有者)`：兩個人類座位各跳一次易主報告
   （[`../spec/034`](../spec/034-region-flip-report.md)）之後，**不看座位**呼叫登記。
   它由回合尾巴 `056A:078E` 在「`2703:159B` 依行星重算出的擁有者與 `+0x12` 不同」時呼叫。
   不論人類或電腦、不論怎麼拿下的，只要回合尾巴那次重算讓費沙換了擁有者就登記。
2. **戰術戰鬥結束時的重算**（`181B:0385`「最後階段」→ `185C:02DA`）：交戰那一格換了擁有者，
   對兩個座位各跑 `185C:03C6(座位陣營, 星域, 新擁有者)`；那一支只在**人類座位**而且
   **新擁有者就是這個座位**時印「%s星系\n已經占領下來。」並登記。戰鬥裡已經寫好 `+0x12`，
   回合尾巴的重算看不到「有變」，所以**電腦方在戰術戰鬥裡拿下費沙不會觸發**。

```
發動（1213:0096，回合尾巴 056A:078E 逐格重算完之後、2703:08DE 與判勝負之前）：
    ds:8F48 != 0 → 回
    ds:988E == 0 → 回
    開訊息視窗
    擁 = 費沙[+0x12]；對 = (擁 == 0) ? 1 : 0
    擁是人類座位 → 兩頁訊息 (擁 == 0 ? ds:3260 : ds:3268)，頭像陣營 擁
    對是人類座位 → 兩頁訊息 (擁 == 0 ? ds:3278 : ds:3270)，頭像陣營 對
    本體(視窗, 費沙) → 懲罰() → 090A:0E6D()
    關視窗
```

「人類座位」＝ `3982:022D(陣營) == 0`：陣營 2 回 `0xFF`；否則回 `ds:8F21[ds:8F25 == 陣營 ? 0 : 1]`
（`ds:8F21`／`8F22` 是兩個座位是否為電腦，`ds:8F25` 是座位 0 的陣營）。
每一頁停「訊息速度 `ds:8F38` × 2」個計時器 tick，或一次點擊。

**觸發條件裡沒有回合數、伊謝爾倫、亂數。** 伊謝爾倫與回合 238／318 那道門檻
（`2E54:0F93`，[`54`](54-strategic-ai-decision.md)）只決定電腦要不要去打費沙。
人類玩家把費沙選成移動目標時會看到一段提醒（`1213:0003`，見最後一節），不擋。

## 本體（`1213:025D(視窗, 費沙星域記錄)`）

```
ds:8F48 = 1
擁 = 費沙[+0x12]
擁 == 0 → 目標 = 星域 31 切片第 4 顆（海尼森，行星 80），清單 = ds:3280
否則     → 目標 = 星域 0 切片第 0 顆（奧丁，行星 0），   清單 = ds:3284
v = 費沙行星[+0x1A] × 80 ÷ 100                     ; 32 位元，截斷
費沙行星[+0x1A] −= v
目標行星[+0x1A] += v
清單（0xFF 結尾）每一格 i：
    星域 i[+0x12] == 擁 而且 星域 i[+0x28 + 擁] == 0（擁方在那一格沒有艦隊）→
        2703:1908(i, 1)                             ; 整格行星叛離（docs/re/292）
        視窗[0] == 2 → 「%s星系上」＋「發生叛亂。」，停 ds:8F38 個 tick
```

| 清單 | 星域 |
|---|---|
| `ds:3280`（帝國拿下費沙）| 10 杜威爾格、11 優茲黑姆、12 赫爾森 |
| `ds:3284`（其他）| 15 艾爾•法西爾、22 蘭提馬利歐、23 波列多、24 馬爾•亞迪特、25 干達巴爾、28 巴米利恩、29 流卡斯、30 艾流塞拉 |

方向是反的：費沙落在誰手上，錢流向**對手**的首都；叛離的是**拿下費沙那一方**的邊境。
開局 10／11／12 都是無主，所以帝國在開局附近拿下費沙時清單不會命中任何一格。

`2703:1908(i, 1)`：星域 `+0x12 ← 2`；整格每顆行星（照切片順序）`+0x11 ← 2`、
經濟力剩三分之二（`e − e ÷ 3`）、防衛力 `+0x14` 扣上限 `+0x16` 的三分之一（`×3` 不到上限就歸零）。

## 懲罰（`1213:03F5`）

```
擁 = 費沙[+0x12]
擁不是人類座位 → 結束                               ; 電腦拿到費沙不受罰
t = ds:8F18（回合計數）
pct = t >= 600 ? 0 : ds:328E[t ÷ 100]
每一格 i（i != 14）、星域 i[+0x12] == 擁：
    每顆行星 [+0x1A] −= [+0x1A] × pct ÷ 100          ; 32 位元，截斷
    星域 i[+0x7C]（民心）= 100
```

`ds:328E` ＝ `32 28 1E 14 0A` ＝ 50／40／30／20／10。索引到 5（回合 500–599）時讀到下一個字串
`ds:3293` 的第一個 byte `0x0C` ＝ **12%**——原版的越界讀，照原樣。
本體裡已經叛離的格子擁有者是 2，不在懲罰範圍內。

## 收尾（`090A:0E6D`）

包裝的第三支，與每個座位回合都跑的那一支相同（[`../spec/035`](../spec/035-month-end-gate.md)）：
`2703:02E5` 逐格把星域經濟力 `+0x1A` 重算成行星加總、重算預估稅與未安定度 `+0x7D`。
所以事件的經濟力變化**當回合**就反映在星域經濟力與未安定度（民心 100 改變了 `f2`）上。

## 選費沙當移動目標時的提醒（`1213:0003(星域編號)`）

艦隊移動選目標（`113A:01AB`）挑到的格子先過這一支：

```
星域 != 14 或 ds:8F48 != 0 → 回 1
開視窗；兩頁訊息 (ds:8F1D == 0 ? ds:3016 : ds:301E)；關視窗
回 1
```

兩條路都回 1，呼叫端永遠放行。同盟那兩頁的最後一句是「你確定要占領費沙嗎？」，
但程式不收答案。
