# 情報收集畫面的三個分頁與「確認」

證據等級：**confirmed**（`docs/re/342`，含附錄 A／B；收據 `fcmd-info-*`）。
資料：[`data/info-panel.json`](data/info-panel.json)（三頁的標題與五行圖例，Big5 位元組）。
實作：`internal/game/infoscreen.go`、`internal/screen/infopanel.go`。

熱區清單 `ds:1738`（五筆）。**動作碼與畫面上鈕的順序不一樣**：

| 鈕（由左至右）| 畫面像素 | 動作碼 | 存進 `ds:8F2F[座位]` |
|---|---|---:|---:|
| 治安 | (336,158) 50×22 | 0 | 0 |
| 勢力 | (400,158) 50×22 | 2 | 2 |
| 敵艦 | (464,158) 50×22 | 1 | 1 |
| 參謀 | (525,378) 38×22 | 3 | — |

點一個分頁 ＝ 寫 `ds:8F2F[ds:8F1E]`，再整塊重畫核取方塊、標題、五行圖例，
並替 32 個星域重新著色。**游標經過不反白**（原版沒有 hover 分支）。

## 地圖著色

三頁共用同一張色表 `ds:1780`：等級 0–4 → 色 **6／1／5／2／3**（與治安那張相同）。

- **治安**：不是自己的星域固定 4；否則 `未安定度 × 100 ÷ 除數 ÷ 50` 分四段。
- **勢力**：把這一格上**自己**的艦隊編制組數（`+0x0F`）加總——
  ≥30 → 0、≥20 → 1、≥10 → 2、>0 → 3、0 → 4。**不看士氣**。
- **敵艦**：先過一道門檻 `0A02:0672(星域) = 表[陣營][基準星域][星域] >> 10`：
  - `< 2` → 掃艦隊表算**敵方**編制組數（`+0x00` bit0 士氣低落的不算）：≥20 → 3、>0 → 2、0 → 0；
  - `>= 2` → 只看星域 `+0x13` bit4：設起來 → 1、沒設 → 4。

  那張表就是**距離表**（`docs/re/347`）：遠指標在 `ds:0D062`（帝國）／`ds:0D066`（同盟），
  指到 EMS 分頁框，所以拿線性位址傾印讀到的是當時映射的那一頁。表的數值在
  `docs/internals/data/star-distance.json`，值 ＝ `0x400 × 踏過幾條不全是自己的邊 ＋ 小成本`
  （`docs/re/241`／`298`），所以 `>> 10` 就是**踏過幾條**。門檻 `< 2` ＝「自己的地盤
  加外面那一圈」，與戰略 AI 的 `2B99:0392`（`ai.CapitalReach`，規格 043）同一張表。

艦隊表的謂詞（`297B:131C` 那一族）：在用 ＝ `+0x04 != 0xFF`、在這一格 ＝ `+0x06 == 星域`、
敵方 ＝ `+0x01 != ds:8F1D`（己方是 `==`），加總的是 `+0x0F`。

## 「確認」與分頁的記憶

「確認」把熱區閃一下選中色、**不重繪內容**，直接關窗回底下那一層。
**`ds:8F2F` 不會被關窗清掉**——切到敵艦按確認再重開，還停在敵艦那一頁；
右鍵關窗也一樣（兩條路的重開畫面逐位元組相同）。
