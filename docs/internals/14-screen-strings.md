# 畫面文字表與熱區

證據等級：**confirmed**（熱區座標系由反組譯 ＋ 實測點擊驗證；
文字表逐筆可解成 Big5 且與畫面上的字相符）
資料：`docs/internals/data/screen-strings.json`

## 熱區

遊戲的可點區域是一張清單，執行期在 `DS:09D6`。每筆 12 bytes：

| 位移 | 內容 |
|---|---|
| +0 | 格子 x |
| +1 | 格子 y |
| +2 | 寬（格） |
| +3 | 高（格） |
| +4 | 啟用旗標，0 ＝ 跳過這筆 |
| +8 | far 指標 |

`FF FF` 是清單結束。

**座標是格子，而且相對視窗原點**（換算見 `docs/re/09`）：

```
格子 x ＝ 像素 x / 16 − 視窗原點格子 x
格子 y ＝ 像素 y / 20 − 視窗原點格子 y
```

視窗原點存在視窗結構的 `+5`／`+6`。會計報告那個畫面的原點是 `(10,3)`，
所以清單裡的 `(17,12)` 與 `(17,13)` 換算成像素是 `(432,300)–(463,319)`
與 `(432,320)–(463,339)`。

## 文字表

畫面上的字不是寫死在繪圖程式裡，而是一張表：`\0` 分隔，多數前面帶一個
`\x01` ＋ 排版格式字串。格式字串同時說明了數值怎麼排：

```
[%d,%d,    '會計報告\n內政專任參謀'
[%d,%d,    '軍事費餘額：%12ld\n'
[%d,%d,    '成長率    %3u.%1u%%'
[%d,%d,    '徵稅額  %10lu  稅率       %2d.%1d%%'
```

`%3u.%1u%%` 對應畫面上的「4.5%」——**成長率在資料裡是 45**，
不是浮點數。

執行期資料段（64 KB）裡掃出 850 筆左右，涵蓋：

| 類別 | 例子 |
|---|---|
| 畫面標題 | 會計報告、船艦訂造報告、船艦接收報告、次月份船艦建造計劃 |
| 欄位 | 造艦數、部隊數、防衛力、成長率、徵稅額、待命船艦、編隊、機動力 |
| 情報用語 | 完全沒有問題／大致上還算平靜／治安正逐漸惡化／處於危險狀態 |
| 敵情 | 沒有出現敵方艦隊／可能有敵方的艦隊出沒／出現大規模的敵方艦隊 |
| 星系名 | 馬爾•亞迪特、干達巴爾、達希利、流卡斯… |
| 戰報 | 發現敵方艦隊。／已經全滅。／的消息已經斷絕。 |

JSON 裡仍有少量誤判（把二進位資料讀成 Big5）；已濾掉私用區，
但沒有逐筆人工核對。

## 對 remake 的意義

畫面內容是資料驅動的，所以**不必逐畫面量測文字**：拿表裡的字串與格式，
配上熱區清單的格子座標，就能組出一個畫面。目前三個對拍過的畫面是
逐畫面量出來的；下一批應該走這條路。
