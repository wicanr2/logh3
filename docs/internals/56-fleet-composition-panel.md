# 56 — 艦隊組成畫面的工作區（編隊那一行與格盤）

證據等級：**confirmed**（反組譯；字碼與槽位表直接從執行期傾印讀出來，
與收據 `fok` 的畫面逐位元組相符）。逆向過程見
[`../re/293`](../re/293-fleet-composition-letters.md)。
版面在 [`data/fleet-composition-panel.json`](data/fleet-composition-panel.json)、
[`data/screen-fleet-composition.json`](data/screen-fleet-composition.json)，
規格是 [`../spec/015`](../spec/015-fleet-composition.md)。

「艦隊組成」是段 `0FF4` 那一整支畫的（`0FF4:0098` 起）。它**不直接讀艦隊
記錄**——開畫面時先把艦隊 `+0x10` 起的編制抄成兩張 DS 工作表，畫面上的
編隊那一行與格盤都只看工作表。

## 工作表

| 位址 | 內容 |
|---|---|
| `ds:977A` | **41 × 4 bytes，索引 ＝ 隊形槽**。開畫面時整片填 `0xFF`（`0FF4:0098` 那一支的 `memset(977A, 0FFh, 164)`），再照編制填進去 |
| `ds:981E` | **10 × 4 bytes，緊接在 `ds:977A` 之後**（`977A + 41×4 = 981E`），是同一批編制**壓實並排序**後的樣子 |
| `ds:984B` | 已編成的組數（編隊那一行印幾個字母、部隊數的分子）|
| `ds:984C` | 還缺幾組（印幾個「□」）＝ 艦隊 `+0x0E` − `ds:984B` |
| `ds:984D` | 格盤空位的圖塊編號 |
| `ds:984E` | 格盤有部隊時的圖塊**基底** |
| `ds:9850` | 遠指標，41 × 40 bytes 的格盤顯示物件（`0FF4:0618` 配置）|
| `ds:28B8` | 41 × 4 bytes 的 (x, y)：每個隊形槽畫在格盤的哪一格（唯讀常數表）|

一筆 4 bytes 的編制與艦隊記錄 `+0x10` 起的那十組同版面
（[`33-fleet-table.md`](33-fleet-table.md)）：`[0..1]` 艦艇池索引、
`[2]` 艦種、`[3]` 隊形槽。

## 開畫面時怎麼填（`0FF4:06C3`）

```
ds:984B ← 0
for i = 0 .. 艦隊[+0x0F] − 1:            ; 現有組數
    組 = 艦隊 + 0x10 + i×4
    if 組[2] == 0xFF: continue           ; 空的不算
    ds:984B++
    ds:977A[組[3]] ← 組（整個 4 bytes）   ; 照隊形槽放
    0FF4:0EF1(組[3], 組[2])              ; 換格盤那一格的圖塊
ds:984C ← 艦隊[+0x0E] − ds:984B          ; 應有組數減現有
```

`0FF4:0F6F` 接著把 `ds:977A` 壓成 `ds:981E`：

```
ds:981E[0] ← ds:977A[20]，但 [3] 改寫成 20     ; 旗艦固定排第一
for i = 0 .. 40:
    if ds:977A[i][2] == 0xFF or i == 20: continue
    追加到 ds:9822（＝ ds:981E + 4）
qsort(ds:9822, ds:984B − 1, 4, 0FF4:0FF2)      ; [2] 升冪、相同再比 [3] 升冪
```

比較器 `0FF4:0FF2` 與艦隊記錄用的那一支是同一個（`docs/re/213`、
`docs/re/225`），所以 `ds:981E` 的順序與艦隊記錄裡的編制順序一致。

## 編隊那一行（`0FF4:03B5`）

```
3617:003A(視窗, ds:2AD4 "\x01[%d,%d,", 1, 11)   ; 游標移到 (欄 1, 列 11)
3617:003A(視窗, ds:2ADD "編隊﹕")
for i = 0 .. ds:984B − 1:
    艦艇 = 艦艇池[ ds:981E[i][0..1] ]            ; ds:CFB4 遠指標，一筆 78 bytes
    視窗[+1] ← 艦艇[+0x08] == 艦艇[+0x0A] ? 151
             : 艦艇[+0x08] × 2 < 艦艇[+0x0A] ? 146 : 149
    3617:003A(視窗, ds:6172[ ds:981E[i][2] ])    ; 全形代號字母
視窗[+1] ← 151
for i = ds:984B .. ds:984B + ds:984C − 1:
    3617:003A(視窗, ds:2AE4 "□")
```

要點三條：

- **格數不是 8，是艦隊 `+0x0E`**（編制槽的應有數，由提督等級算出來，
  `docs/re/214`）。收據 `fok` 那一支剛好是 8。
- **字母只看編制組的 `[2]`（艦種）**，與隊形槽、組序、艦艇池索引無關。
- **顏色是那一組的艘數**：`151`／`149`／`146` 是視窗顏色位元組
  （高四位底色 9、低四位字色，[`49-text-engine.md`](49-text-engine.md)），
  也就是字色 **7 滿編、5 半編以上、2 半編以下**；印完字母設回 7 再印「□」。

同一條規則在**戰略地圖的艦隊詳細資料**上還有一份（`0DEA:05DD` 的
「狀態　部隊組成」那一行，格式字串 `ds:24E8 "\x03[%d,%s"` ＋
`ds:24F0 "□"`）：那一支直接走艦隊記錄 `+0x10`＋、界線用 `+0x0F` 與
`+0x0E`，字母表與顏色三段完全相同。

## 字母表 `ds:6172`

八筆遠指標，各指一個 NUL 結尾的全形字母字串（索引 ＝ 艦種）：

| 艦種 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 字母 | Ｂ | Ｈ | Ｃ | Ａ | Ｄ | Ｔ | Ｅ | Ｐ |
| 字碼 | `A2D0` | `A2D6` | `A2D1` | `A2CF` | `A2D2` | `A2E2` | `A2D3` | `A2DE` |

字串本體在 `ds:615A` 起，一個 3 bytes。前七個就是
[`40-ship-kind-table.md`](40-ship-kind-table.md) 那條半形 `BHCADTE`
（線性 `0x5D94A`）的全形版；**第八個Ｐ是艦種 7 偵察隊**，半形那一條
沒有它（`docs/re/290`）。

隔壁 `ds:613A` 是同樣八筆的**艦種名**（`docs/re/143`）——兩張表同索引、
同筆數，指的字串就在同一塊。

## 格盤（`0FF4:0618`、`0FF4:0EF1`）

41 個 16 × 16 的顯示物件，一個 40 bytes，位置取自常數表 `ds:28B8`
（`物件[+6] = 表[槽].x + 0x58`、`物件[+8] = 表[槽].y + 0x5C`）。圖形是
`ds:F12C` 遠指標加上「圖塊編號 × 128」（16 × 16 的 4bpp ＝ 128 bytes）。

```
0FF4:0EF1(隊形槽, 艦種):
    物件 = ds:9850 + 隊形槽 × 40
    圖塊 = (艦種 == 0xFF) ? ds:984D : ds:984E + 艦種
    物件[+0E]/[+10] ← ds:F12C + 圖塊 × 128
    物件[+1] ← 1                       ; 標髒
```

`ds:984D`／`ds:984E` 在 `0FF4:0098` 依 `ds:8F1D`（目前陣營）選一組：

| 陣營 | 空位 `ds:984D` | 基底 `ds:984E` |
|---|---:|---:|
| 0 帝國 | 44 | 36 |
| 1 同盟 | 74 | 66 |

所以 `SPRITE.SPR` 第 36–43 張是帝國的Ｂ Ｈ Ｃ Ａ Ｄ Ｔ Ｅ Ｐ、
第 66–73 張是同盟的同一組——與
[`10-sprite-spr.md`](10-sprite-spr.md) 記的「同盟（藍底）與帝國（紅底）
各一組：數字 1–16 與字母 Ｂ Ｈ Ｃ Ａ Ｄ Ｔ Ｅ Ｐ」對上。
規格 015 原本寫的「中央 (4,4) 第 36 張」**是這條規則在艦種 0 的特例**。

`ds:28B8` 與戰場的隊形槽表 `ds:59BA`（[`38-battle-units.md`](38-battle-units.md)、
`data/battle-formation-slots.json`）是同一組槽的兩個朝向：

```
ds:28B8[i] = ( ds:59BA[i].y , −ds:59BA[i].x )      ; 41 筆全中
```

——差一個 90 度。**不要拿其中一張去推另一張的排列順序**：`ds:59BA` 是
逐欄排（同一個 x 連續五筆），`ds:28B8` 是逐列排（同一個 y 連續五筆），
只看槽 20 都在正中央會以為兩張一樣。
