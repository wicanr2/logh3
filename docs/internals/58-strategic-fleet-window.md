## 艦隊視窗

`3603:0006(0, 0x97, 格x 7, 格y 0, 寬 25, 高 17, 旗標 1)`：外框佔字元平面
欄 7–33、列 0–18（畫面 x 112–543、y 40–419），內容 25×17 在欄 8–32、列 1–17。
內容由 `0DEA:0040` 與五支子常式印（`0DEA:0918` 副官、`03F9` 作戰兩列、
`04C0` 現在位置那一列右邊、`05DD` 部隊組成、`06FE` 飛彈／戰鬥機、
`0A80` 費用與十二格），格式字串逐位元組在 `data/fleet-window.json`
（`formats`，順序就是呼叫順序）。字元平面的樣子見 `re/312` §二。

| 項目 | 來源 |
|---|---|
| 陣營名（色 6）、第 N 艦隊 | `ds:60F4[陣營]`（帶顏色跳脫碼）、艦隊 `+0x02` |
| 提督／副官 姓名＋軍階、等級、經驗值 | 提督記錄（副官 ＝ 艦隊 `+0x05`）|
| 作戰 待命戰鬥／待命中 | `+0x08 == 5` 那一種；`ds:68EA[+0x08]` 是六種移動狀態名 |
| 現在位置 | `3982:0263(星域, −16, 擁有者)` 印星域名（色 ＝ 擁有者）|
| 部隊組成 | 每組一個艦種字母 `ds:6172[艦種]`，空槽到 `+0x0E` 印 □ |
| 飛彈／戰鬥機 % | 逐組：上限 += 艦種列 `+0x10`／`+0x14` × 艘數，現量 += 艦艇 `+0x0E`／`+0x12`；上限 0 印 `----`（`re/312` §7.5）|
| 維持費／移動經費 | 艦隊 `+0x0A`／`+0x0C`（色 5 ＝ 副官在營運比提督高）|
| 十二格能力 | 艦隊 `+0x3C`–`+0x47`；三個速度 ＝ 各組 `297B:0E8B(艦種, 能力)` 的最小值，依組數照 `ds:4E2E` 打折 |
| 頭像 | `3958:0215(提督索引, 0x38, 5)`，約 x 448–527、y 58–157 |
| 作戰／變更／結束 | 熱區 `ds:21C0`：格 (22,14)／(22,15)／(22,16) 各 2×1；色 0x87、按下 0x27 |

底線旗標（樣式 `0x01`）寫在格子裡：分隔列 7、9、11、12 整列 25 格，列 4
只有 20 格（`rule` 字串 40 個半形空白）。畫在格子最後一列、色 15
（[`25-text-rendering.md`](25-text-rendering.md)）。

## 作戰選單（`0DEA:1037`）

五項 移動／占領／駐留／輸送／待命（`ds:21F0` 起，每項 5 bytes），選單表
`ds:220A` 每項 6 bytes、第一個 byte 是啟用旗標：

```
全部 ← 1
星域 = 艦隊[+0x06]；若 星域[+0x13] & 6（有戰鬥）或 星域[+0x12] != 艦隊[+0x01]：項 1–4 ← 0
若 艦隊[+0x00] & 1：項 1（占領）、項 3（輸送）← 0
3667:0004(&選單, ds:220A, 欄 0x1D, 列 0x0C, 5, 寬 2, 9, 色 0x97, 反白 0x27, 停用 0x98)
```

版面與戰場命令選單同一套（[`44-battle-command-menus.md`](44-battle-command-menus.md)），
夾在戰略板子裡 `clamp_rows 17`；反白跟著游標；點在項目外或右鍵只關選單。
選了第 n 項：0–3 → `0DEA:12CC(艦隊, n, 動詞)` → `113A:0003` 目的地選取；
4 → `0DEA:1320` 指定待命行星（沒讀）。

| n | 動詞（`ds:22CE` 指標表）| 允許的擁有者 (A, B) | 決定後 `+0x08` |
|---|---|---|---|
| 0 移動 | `22A8` 移動至 | (自己, 0xFF) | 0 |
| 1 占領 | `22AF` 占領 | (敵方, 中立 2) | — |
| 2 駐留 | `22B4` 駐留在 | (自己, 0xFF) | 2 |
| 3 輸送 | `22BB` 輸送物資至 | (自己, 0xFF) | 3 |
| 4 待命 | `22C6` 待命於 | — | 5，`+0x07` ← 行星 |

## 目的地選取（`113A:0003`）

```
113A:00BE：341B:02A3(ds:F144)、341B:02A3(ds:953A)   ; 地圖與左下角提到最上層 → 蓋掉視窗左半
          2B99:0392(艦隊[+0x06], 艦隊[+0x01], &允許)  ; 可達表（k ≤ 1），起點 = 艦隊所在
          允許[i] = 可達[i] 且（擁有者[i] == A 或 == B 或 i == 現在位置）
          顏色：現在位置 → ds:2DA6[擁有者] {6,5,7}；不允許 → 3；其餘 → ds:2DAA[擁有者] {1,12,7}
迴圈：左鍵 → 113A:01AB；右鍵 → 0xFF；移動 → 113A:02DB（左下角摘要）
113A:01AB：最上層不是地圖視窗 → 0xFF；星域 0xFF → 0xFF；
          不允許 → 3826:0005(0, 0x97, ds:2DDC「這是無法前往的星系。」) → 0xFF
          1213:0003(星域) == 0 → 0xFF（沒讀）
          113A:023B(星域)：動詞 = 現在位置 ? ds:2DF1「待命」 : ds:9884；
                            ds:2DF6「要%s\x03[%d,%s\x03[%d,%s星系嗎？  \n」（顏色 = ds:6092[擁有者]|0x90、陣營名 ds:60AE、0x97、星域名）
                            3826:0005(1, …) 中止／決定，回 0 = 決定
```

回來的 r：0xFF 不動；r == 現在位置 → `+0x08 ← 5`、`+0x07 ← 0xFF`（取消
既有命令）；否則 `+0x08 ← n`、`+0x07 ← r`。結尾 `090A:0E6D`（未安定度重算）。

## 清單那一列印什麼（`0AD0` 段的列印常式，`docs/re/313` §一）

欄 21「  」（樣式 `0x80`）→ 欄 22 記號 → 「第Ｎ艦隊」（色 `0x80|ds:6092[陣營]`）→
提督姓名 `%-18s`（色 0x87）→ **士氣值** `+0x3C`（`%3d `，低於 50 色 2）。記號依
`+0x08` 查 `ds:1A66` 那張 3 bytes 一格的表：0 移動 ☆（A1B8，色 0）、1 占領 ☆（色 2）、
2 駐留 ＊（A1AF）、3 輸送 ◎（A1B7）、4 返航 ○（A1B3）；5 停駐時看星域 `+0x13`：
bit2 有戰鬥 ▼（A1BF，色 2）、bit4 ▽（A1BE，色 2）、否則空白。

## 選了項目之後（`0DEA:1037`，`docs/re/313` §二）

| 項目 | 目的地 r ＝ 現在位置 | r ＝ 別的星域 | 之後 |
|---|---|---|---|
| 移動／占領／輸送 | `+0x08 != 5` 就寫 5、`+0x07 ← 0xFF`（取消命令）；**不算有改** | `+0x08 ← n`、`+0x07 ← r`，有改 | 有改才關窗，否則視窗留著 |
| 駐留 | 一律 `+0x08 ← 2`、`+0x07 ← r`，有改 | 同左 | 關窗 |
| 待命 | `0DEA:1320` 選行星：有選 → `+0x08 ← 5`、`+0x07 ← 行星序號`，有改；回 0xFF（中止、沒選就決定）→ 不改、不算有改 | — | 有改才關窗 |

尾巴一律 `090A:0E6D`。

## 占領與費沙提醒（`docs/re/315` §一、§二）

占領走移動那條目的地迴圈，允許表的擁有者換成 `(敵方, 2)`；決定寫 `+0x08 ← 1`。
目的地是費沙而且 `ds:8F48 == 0`（費沙事件沒發生過）時，`113A:01AB` 在確認框之前
先叫 `1213:0003`：`3603:0006(…, 0x97, 7, 6, 24, 5, 1)` 開窗，`1213:01B8` 印兩頁
（帝國 `ds:3016`、同盟 `ds:301E`；與費沙事件報告同一支，頭像 `ds:8F4B[陣營]`），
每頁 `3765:006C(ds:8F38 × 2)`——把 `ds:8EFE` 交給計時器倒數，或事件碼 1／2 就結束。
兩頁翻完關窗，回 1，接著才是「要占領…費沙星系嗎？」。

## 「變更」（`0DEA:17A9`，`docs/re/316`）

```
w = 3C9E:0001(第一項標籤) ＝ 4                    ; 位元組長度當寬度 → 四格寬
3667:0004(&選單, ds:2232, 欄 0x1D, 列 0x0F, 2 項, w, 9, 0x97, 0x27, 0x98)
n = 3667:00F2：0 副官 → 0DEA:1846；1 編組 → 0DEA:189F；0xFF 取消
0DEA:1846：297B:04EF(艦隊)（07F9:043F(&艦隊[+4]) 艦隊編成視窗的變體：沒有艦隊編號、確認印成結束；
           回來 艦隊[+5] ← 提督[+7]、297B:0546 重算）→ 重印 0918／0A80、頭像 → 073F:0522 清單重畫（列底色 8）
0DEA:189F：r = 0FF4:000A(艦隊)（艦隊組成）；r != −1 → 297B:03EB(艦隊, 0)、0DEA:05DD
```

艦隊組成的中止／決定都回艦隊視窗；出擊那條路的中止則整支作廢回戰略地圖，
旗艦那一組在進艦隊組成時從存量扣、中止退回（首都戰艦開局 78000）。

## 指定待命行星（`0DEA:1320`，`docs/re/314`）

疊在艦隊視窗上的 18×11 視窗（格 (8,4)，色 0x97，`fleet-standby-panel.json`）：

```
\x0c指定待命行星\n
%s第Ｎ艦隊  提督姓名            ; 3982:00B6：陣營名帶色（ds:60F4），編號全形
\n      星系      星域名\n        ; 不換色
鈕：行星 i（格 (9,4+i) 8 寬，只畫 i < 顆數的）、決定 (15,10)、中止 (12,10)；色 0x87、反白 0x27
小圖：MAP<nn>.CMP 縮成 128×128 貼在 (152,220)，bit 1 → 色 1、bit 0 → 色 3；外框 (151,219)-(280,348) 色 7
引線：每顆行星從 (288, 230+20i) 到 (152 + X/16, 220 + Y/16)，擁有者陣營色，先畫 (−1,−1) 的色 3 影子
```

- 小圖：欄不縮、列 `來源 = py − ⌊py/5⌋`（102 列拉成 128 列，最後一列讀到緩衝區外）；
  一格有東西 ＝ 圖塊 ∉ {0, 1, 5}，格線（列 %12 ＝ 0、欄 %15 ＝ 0 的空格）算有東西
  （`1588:073C`／`078C` 載入時塞進圖塊 3／4／2）。
- 開窗時 `+0x08 == 5` 且 `+0x07 != 0xFF` 那一顆先反白。點行星：舊的改回 0x87、新的
  0x27，`341B:02E5` 只重畫變過的格子（點過的鈕蓋在引線上）。決定與右鍵回反白那一顆
  （沒有 → 0xFF）；中止清掉反白再回 0xFF。
- 寫入之後 `0DEA:1759` 把行星 `+0x46`／`+0x48` 抄進艦隊 `+0x5C`／`+0x5E`（remake 沒有這兩格）。
- 艦隊視窗第 7 列（`0DEA:04C0`）：`+0x08 == 5` 且 `+0x07 != 0xFF` → 「待命行星 」＋
  行星名（擁有者色），行星 ＝ `2AF5:0036(+0x06)` 之後的 `ds:CFF8 + 0x52 × +0x07`。

## 面板的更新時機

- 清單那一列在視窗開著時反白（底色 2），關窗還原。
- 左下角那塊只在「游標底下那一格變了」才重寫，地圖迴圈與目的地選取迴圈
  各記各的「上一次那一格」；寫進去的是那一刻的文字，之後局面變了不會跟著
  變（`re/312` §7.7–7.8；規格 [`001`](../spec/001-region-summary-panel.md) 規則 4–7）。
- 右側面板的首都摘要同樣是回合開頭印的文字：編成艦隊之後整條 `fcmd-*` 鏈
  仍寫「艦隊 0：0」，星域記錄 `+0x28` 卻已經是 1。

## 玩家編的艦隊（`fcmd-win/fleet0.bin`）

`+0x09 ＝ 0xFF`（沒有類別鍵）、`+0x0E ＝ 8`、`+0x0F ＝ 1`、
`+0x10 ＝ 00 00 00 14`（艦艇池 0、艦種 0、隊形槽 20）、`+0x0A ＝ 22`、
`+0x0C ＝ 26`、`+0x3C ＝ 100`、`+0x4D..4F ＝ 18／42／26`。
決定「移動至亞爾提那」之後只有 `+0x07 ← 2`、`+0x08 ← 0` 兩個 byte 變
（`fcmd-done/fleet0.bin`）。
