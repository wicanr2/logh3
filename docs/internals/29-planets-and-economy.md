# `PLADAT.DAT` 與經濟力

資料：[`data/pladat.json`](data/pladat.json)
證據等級：檔頭、`+0x11`、`+0x14`／`+0x16`、`+0x1A` 與「星域經濟力 ＝ 行星加總」
**confirmed**（`docs/re/17`、[`docs/re/30`](../re/30-region-economy-from-planets.md)）；
成長算式 **未解**。

## 版面

6,706 bytes ＝ **64 bytes 檔頭 ＋ 81 筆 × 82 bytes**。

檔頭是 32 個 word，第 k 個是第 k 個星域有幾顆行星：

```
4 3 2 3 1 2 3 3 4 3 2 2 1 1 1 2 3 2 3 3 3 4 2 2 1 3 3 2 3 2 3 5   （合計 81）
```

行星按星域順序排，所以第 k 個星域的行星是「前 k 個數量加起來」開始的那一段。

切片由 `2AF5:0036(星域, 旗標)` 設定：`ds:CFF8/CFFA ← ds:5336/5338 ＋ (前面星域的行星數總和) × 82`、`ds:CFFC ← ds:CFB8[星域]`，舊值備份到 `ds:51B0/51B2` 與 `ds:CFFD`。`ds:CFB8` 那 32 個 word 與 `PLADAT.DAT` 的檔頭相同，`ds:5336/5338` 是整張行星表的遠指標（[`docs/re/264`](../re/264-ship-delivery-destination.md)）。

**`ds:CFF8`／`ds:CFFA` 那個遠指標不是整張表，是「目前星域的行星切片」**
（`ds:CFFC` 是那個星域有幾顆）：戰略地圖上選著星域 0 時是 `5313:0002`／4，
S3 戰場（星域 26）時是 `5313:1430`／3，正好是上面檔頭的第 0 與第 26 項。
跟著它走的迴圈（要塞砲的 `181B:0385`／`2264:000A`、打行星的 `20B4:0059`）
**只掃目前那個星域**，而艦隊記錄 `+0x5A` 存的是**切片內的序號**
（[`docs/re/150`](../re/150-planet-capture-receipt.md)）。

執行期的行星表在段 `5313` 的 offset 2 起（線性 `53132`），**沒有檔頭**，
81 筆 82 bytes 排在一起（位址已用倒出來的表與 `PLADAT.DAT` 逐筆對名稱
驗過，`docs/re/57`）。存檔的 `PLANET.DT?` 與那張表逐位元組相同
（[`docs/internals/30`](30-save-format.md)），所以中局的行星擁有者與
經濟力直接讀存檔就有——`PLADAT.DAT` 只是開局那一份。

## 戰略地圖的行星情報視窗（`2AF5:0226`，`docs/re/319` §三）

開局電腦座位首都的行星艦艇會乘二；人類座位保持原始存量。這是
`2703:046A` → `04A3` 的初始化，並非行星情報窗的比例分配。

2026-10-01，完整回合庫存（proven，指定 S1 首回合）：移動後從星域池分配，
逐格補給再彙總／補艦艇／分配，下一回合回充只寫星域。首都四顆行星在
回充前後全表不動；不能每次回充都立即改行星 `+0x3C`／`+0x40`。
所有 81 顆行星七種艦艇及兩種補給 `+0x20`–`+0x43`，共 2916 bytes，
正常回合與原版全部相同。研究及原始定位見 [353](../re/353-region-supply-turn-timing.md)，
收據／雜湊見 [資料索引](data/region-supply-turn-timing.json) 與
[對拍 026](../playtest/026-region-supply-turn.md)。完整正常回合表尚有首都四顆
行星 `+0x46`–`+0x49` 共 15 bytes 差異，由 #85 追查，語意保留 `unknown`。
寫入證據、五組整表對拍及兩輪重播見 [研究 352](../re/352-opening-runtime-tables.md) 與
[資料索引](data/opening-runtime-tables.json)。

右下角清單「行星」分頁點一列開的那張（格 (9,5) 起 23 × 11）：先 `2703:0540(星域)`
把星域層的存量分回行星，再印經濟力／成長率、防衛力／回復率、七個艦種的
**補充存量 ÷ 滿編**（`3CC9:0020` 長除法）、飛彈、戰鬥機；不是自己的行星印 `----`。
格式字串倒在 `docs/internals/data/planet-info-strategic.json`。

## 星域的經濟力是行星加出來的

星域記錄的 `+0x1A` 不是從 `STELLAR.DT*` 讀來的，是**現算的**：

```
星域經濟力 ＝ Σ 該星域每顆行星的 +0x1A
```

載入時算一次（`2703:00F8`），之後每個月底再算一次（`2703:0C26`，
由 `2703:0BF2` 逐格呼叫，`docs/re/267`）——**月底那一支同時用實際成長重算
星域的成長率 `+0x1E`**，接著 `090A:0B5E` 重算稅率，然後才收稅。
`STELLAR.DT*` 檔案裡的 `+0x1A` 載入當下就被蓋掉，從來沒被用過。
另外 **`090A:0E6D` 每跑一次也重加總一次**（`2703:02E5` → `2703:034E`，同一支
順便把兩邊的預估稅 `ds:8F6A`／`8F6E` 歸零重累、再算未安定度；`docs/spec/042`）
——所以月中花進行星的錢下一次重算就反映到星域與徵稅額（`docs/re/313` §3.1）。

## 軍事費花出去的錢流進行星（`2703:1C11`）

`2703:1C11(星域, 金額)`：對那一格每顆行星 `+0x1A += 金額 × +0x13 ÷ 100`
（`+0x13` ＝ 佔該星域經濟力的整數百分比），餘數全加到百分比最大的那一顆
（相同時取後面那顆）。兩個呼叫者：

| 呼叫者 | 付多少 | 付給哪一格 |
|---|---|---|
| `056A:0A8D`（維持費，每回合逐支）| 艦隊 `+0x0A ÷ 2` | 艦隊所在星域，**且 `+0x12` 擁有者 == 艦隊陣營**才付 |
| `113A:0786`（`113A:06C3`，走一格）| 艦隊 `+0x0C` 整筆 | 自己擁有離開的那一格就付給它，否則付給走到的那一格 |

收據 `fcmd-exec`：第１艦隊（維持費 22、移動費 26）從首都走一格，首都四顆行星
共 +37（11 ＋ 26），星域經濟力 82302 → 82339。remake：`Planets.PayIntoRegion`。

星域 0（奧丁、布倫希爾、亞爾斯達、梅薩克）四顆行星的初值
52000 / 9800 / 12000 / 7500 相加 ＝ 81300，就是開局的星域經濟力。

## 月底：成長與收稅都是**逐行星**做的

```
對每一顆行星：
    經濟力 += 經濟力 × 成長率(經濟力, 防衛力) / 1000
    稅      = 經濟力 × 該星域稅率 / 1000        （捨去）
    經濟力 -= 稅
    總稅收 += 稅
星域經濟力 = Σ 該星域行星的經濟力
```

**兩個稅不是同一個數**（`docs/re/35`）：從行星身上扣掉的是逐顆捨去的和
（星域 0 是 2718），進國庫的是拿星域總和算一次捨去（2720）：

```
進國庫的稅 = (Σ 成長後、扣稅前的行星經濟力) × 星域稅率 / 1000   （捨去）
```

十個帝國星域結算後的經濟力與進國庫的錢都逐一相符
（`internal/rules.TestMonthEndEmpireTotal`，合計 10741）。

星域記錄的成長率 `+0x1E` 是**算出來的結果**，不是輸入：它等於
`Σ 成長量 × 1000 / Σ 經濟力`（星域 0：3720×1000/81300 ＝ 45.7 → 45，
畫面上的 4.5%）。

## 成長率階梯表

資料：[`data/growth-table.json`](data/growth-table.json)（`ds:4A68`，
一列 6 bytes ＝ 門檻 32 位元 ＋ 成長率 16 位元，32 列）。

查法照原版那支迴圈：**找到第一列 i 使得第 i+1 列的門檻 >= 經濟力**，
取第 i 列的成長率。經濟力越大長得越慢：

```
0→90‰  1000→82  …  10000→52  …  50000→41  …  100000→30  120000→26
180000→18  200000→0
```

行星防衛力（記錄 `+0x16`）低於 3000 時成長率再 ×3/2——這一條是從
程式讀出來的，還沒實測到。

五個實測點逐一相符（`docs/re/33`）：52000→41、9800→54、12000→52、
7500→58、16000→50。

## 費沙事件會搬走八成經濟力

`0x1238D`（設 `ds:8F48 = 1` 的那一支，`docs/re/192`）把**費沙那顆行星
`+0x1A` 的 80%** 搬到對手陣營首都的一顆行星上：

| 費沙的擁有者 | 目標 |
|---|---|
| 帝國 | 星域 31（巴拉特）第 4 顆行星 |
| 其餘 | 星域 0（瓦爾哈拉）第 0 顆行星 |

方向是**反的**——費沙落在誰手上，錢就流向對手的首都。
觸發條件、叛離與懲罰見 [`57-phezzan-event.md`](57-phezzan-event.md)。
