## 提督篩選器與其他小函式（`28E0`）

八支篩選器（`28E0:0227`、`028E`、`02F5`、`035C`、`03B6`、`0410`、`047E`、`04E3`）對提督編號清單原地壓縮，回傳保留個數；項數與比較值只取低位元組；提督記錄 `ds:B77C` 起每筆 28 bytes。
呼叫者 `28E0:0103` 只存 `AL`，`v` 是它傳入的 `ds:8F1D`。

| 函式 | 保留條件 |
|---|---|
| `0227` | `+0x0A == v` |
| `028E` | `+0x01 == v` |
| `02F5` | `+0x01 != v` |
| `035C` | `+0x00 == 0xFF` |
| `03B6` | `+0x00 != 0` |
| `0410` | `(+0x09 & 0x80) == 0` 且 `+0x09 != 0x7F` |
| `047E` | `+0x09` 的 bit7 有設 |
| `04E3` | `+0x06 < v`（無號 byte） |

其他：`28E0:054A` 在 `+0x09` 的 bit7 沒設時 `|= 0x80`；`05CC` 寫 `+0x09 ← 0x7F`；`057F` 做 `+0x09 |= 0x80`、`+0x00 ← (旗標低位元組 == 0) ? 0x80 : 0`、清 `+0x02`/`+0x04` 兩個 word。
`28E0:0096` 是 12 段門檻表（`2 4 6 8 0C 10 14 18 1D 22 27`）。`docs/internals/08` 第 217 行把門檻表記在 `28E0:004F`，實際在 `0096`，`004F` 是呼叫者（用等級查字串表，只用 `AL`）。
`28E0:095C`：`v >= 0xC8` 回 0 且不取亂數；其餘 `span = (v < 0x64) ? 甲 : 乙`，`d = span + 1`，連續兩次 `rand`，回 `(r1 % d + r2 % d) / 100`。`span` 為 `0xFFFF` 時原版 #DE。
`docs/re/43` 第 198 到 202 行與 `docs/re/208` 第 17 到 21 行原標「未讀」的 `02F5`、`03B6`、`0410`，條件如上。

基底狀態：`1930`、`1AAB`、`1C61`、`1DD6`、`1F6F` 這批用 `fcmd-s3-base.state`（SHA-256 `0155f63e373582b76a3b7ee54eccbef5ae2626481e09a68550b5fddc580146d7`，艦隊表有 20 多支真實艦隊，艦艇池有艦種 0 到 7）。
在場分隊清單（`ds:9896`、`ds:98BA`）在所有可用基底狀態裡都是空的，`1AAB:000E`、`1F6F:000F`、`1F6F:0B0A` 的清單由描述檔 seeds 的 pokes 造；池資料是真實的。
