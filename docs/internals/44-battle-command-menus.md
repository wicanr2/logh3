## 選單是全域的一套

主程式所有選單走同一支開啟常式，參數是

```
開選單(結構, 表, x, y, 項目數, 內寬, 9, 0x97, 0x27, 0x98)
```

後面四個常數在**每一張選單都一樣**，所以配色與框線是全域的；一張選單
只由（位置、項目數、內寬、表）決定。整支遊戲 22 張選單的內容在
[`data/menus.json`](data/menus.json)。

一筆選單項目六個位元組：

| 位移 | 內容 |
|---|---|
| `+0x00` | 可選旗標（byte）。0 ＝ 畫成不可選 |
| `+0x01` | 0 |
| `+0x02` | 名稱的遠指標（位移:段），段是資料段 |

旗標是用位元組寫的，所以「誰把某一項關掉」要搜 `C6 06 <位移>`。

## 可選旗標的規則

艦隊選單：

```
三項先全開
艦隊 +0x00 bit0 → 關掉「戰鬥」與「索敵」
艦隊 +0x3A != 0xFF 或 +0x3B != 0 → 關掉「索敵」
```

分隊選單（四張共用同一段判斷）：

```
「移動」開 = 艦艇 +0x1E 不是 0（移動）也不是 3（歸隊）
```

「歸隊」沒有子常式，選下去就是 `艦艇 +0x1E ← 3`。

## 每一項按下去做什麼

| 項目 | 進入點 | 目前知道的 |
|---|---|---|
| 移動（分隊）| `1CC5:0D1C` → `2583:00DE` | 選一個點寫進艦艇 `+0x28`／`+0x2A`，再把 `+0x1E` 設成 0。沒有速度上限、沒有畫範圍（`docs/re/119`、`docs/spec/024`）|
| 移動（艦隊）| `1CC5:0813` → `2583:0003` | 畫兩個範圍圖形（提示用，不擋點擊），選點之後**再選抵達朝向**；寫 `+0x60`／`+0x62`（原位置備份）、`+0x64`／`+0x66`（目的地）、`+0x4C`（目標朝向）（`docs/re/120`–`122`）|
| 戰鬥 | `1CC5:08BD` → `2583:0003` | 同上，但範圍用戰鬥速度 `+0x4F`，成功後 `+0x48 ← 1` |
| 索敵 | `1CC5:0966` | `+0x3A`／`+0x3B` ← 0（＝ 放過了）；`+0x38` 那一筆艦艇的 `+0x1E` ← 3（歸隊）、`+0x19` ← 0x80（畫航跡），然後**直接接分隊「移動」的選點常式** `1CC5:0D1C`（`docs/re/132`）|
| 編隊 | `2BE1:0328` | 41 格的隊形槽畫成 16×16 標記讓玩家點一格，選完寫艦艇 `+0x05`、艦隊分組表 `[3]`、`+0x1E` ← 0x7F，並立刻算出新目的地（`docs/re/130`、`docs/internals/46`）|
| 補給 | `1930:05EC` | 半徑 ＝ 艦種 5 那一列 `+0x06` × 6.4；搬飛彈與艦載機，上限 ＝ 艦種列 `+0x10`／`+0x14` × **現有**艘數（`docs/re/131`）|
| 修理 | `1AAB:0583` | 半徑 ＝ 艦種 6 那一列 `+0x06` × 6.4；把 `+0x08` 補到 `+0x0C`，扣修理艦自己的 `+0x0E`（`docs/re/131`）|
| 歸隊 | — | `艦艇 +0x1E ← 3` |

選點的檢查鏈（兩種選點共用）：畫面→世界換算、世界 `x` 0–2031／`y` 0–2023、
`1588:04EA` 的地形判斷；不合法就跳 `ds:4A24`「這是無法行動的地方。」
（`docs/re/121`）。

## 版面公式

> `(內寬×16＋30)` 與 `(列數×20＋38)` 這兩個常數的來源在 `3603:0006`
> （`docs/re/137`）：視窗系統在旗標非 0 時把格數各加 2，實際尺寸是
> `格數×16−2` 與 `格數×20−2`。所以
> `(內寬＋2)×16−2 ＝ 內寬×16＋30`、`(列數＋2)×20−2 ＝ 列數×20＋38`。
> **選單與訊息框是同一個視窗系統。**


位置是**格**不是像素（原版那兩個輸出是 byte）：

```
框左上角 = (格x × 16 + 1, 格y × 20 + 1)
格       = 游標所在格 − (1,1)，再夾進戰場可視範圍（格y ≤ 19 − 項目數）
框大小   = (內寬 × 16 + 30) × (項目數 × 20 + 38)
反白帶   = 框 + (15,19)，大小 (內寬 × 16) × 20
文字     = 反白帶 + (0,2)，欄距 16、列距 20
底色 9、字色 7、立體邊 3、反白色 2、框用 FRAME.BLK 起始碼 9 的八張圖塊
```

內寬的單位是 16 像素。戰術選單的內寬由第一項的**位元組數**算出來
（`實行  ` ＝ 6 → 96 像素），單位選單寫死 2（＝「移動」的寬度）。

驗算過三張：戰術 126×178、分隊 62×78、艦隊 62×98。
