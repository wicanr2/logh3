# 46 — 戰場「編隊」的選格子畫面

分隊命令選單的「編隊」（`docs/internals/44`）開的是一個模態的選格子
畫面：把艦隊 41 個隊形槽裡**還沒有人**的那些畫成 16×16 的標記，玩家點
一個，那個分隊就換到那一格。整支流程與位址見 `docs/re/130`。

## 畫面表 `ds:D072`

41 筆 × 10 bytes，每次進這個畫面重算：

| 位移 | 型別 | 內容 |
|---|---|---|
| `+0` | word | 那一格的**世界座標 x** |
| `+2` | word | 那一格的**世界座標 y** |
| `+4` | byte | `0` ＝ 可以選，非 0 ＝ 已經有分隊站著 |
| `+6` | far ptr | 這一格的顯示物件（只有可選的格子才配）|

座標怎麼來：

```
(ox, oy) = ds:59BA 第 i 筆                 ; 隊形槽偏移，見 docs/internals/38
(rx, ry) = 依艦隊 +0x4A 旋轉(ox, oy)        ; 加 512 再算術右移 10 位
x = clamp(艦隊 +0x5C + rx, 0, 0x7FF)
y = clamp(艦隊 +0x5E + ry, 0, 0x7F7)
```

夾值上限是 **0x7FF／0x7E7 之外的另一組 0x7FF／0x7F7**——與走一步的
`2BE1:026F`（0x7EF／0x7E7）不同。捨去與夾值一律看呼叫點，不要跨處套用。

`+4` 的填法：全部先填 0，再照艦隊分組表（`+0x10` 起每組 4 bytes 的 `[3]`）
把有人的格子改成 1，最後**把發令那個分隊自己的格子改回 0**——所以
「留在原地」是合法選項。

## 標記怎麼畫

每個 `+4 == 0` 的格子配一個 40 bytes 的顯示物件：

| 物件位移 | 值 |
|---|---|
| `+1` | `0xFF` |
| `+2` | `ds:9B9E` |
| `+3` | `0xFF` |
| `+6` | 格子 x − `ds:9BF4`（視野原點）|
| `+8` | 格子 y − `ds:9BF6` |
| `+0x0A`／`+0x0B` | 16／16 |
| `+0x0C` | 圖塊編號 **11** |
| `+0x0E` | `3982:0001(11)` 取回來的圖形資料 |

掛進顯示串列之後整張重畫。座標換算與分隊本身同一套（世界座標減視野
原點，左上角對齊）。

圖塊 11 就是 **`SPRITE.SPR` 的第 11 塊**：16×16 的空心框，用色號 3 與 5
交錯，**色號 0 透空**（那 118 個位置在收據 `s3form` 上留著戰場底色 3）。
收據上 35 個空格子有 30 個是完整的標記、逐位元組相同；另外五個底下有
東西——三個坐著分隊（分隊畫在自己**現在的位置**，不是隊形位置，所以
會壓在標記上），兩個被滑鼠游標壓到。**分隊畫在標記之後**。

> 「透空」與「色號 0 換成 3」在這份收據上分不開：沒有一個空格子壓在
> 色 6 的格線上。remake 照透空做。

## 點擊怎麼判

畫面座標先用 `1588:0362` 換成世界座標，然後**從槽 0 掃到槽 40，先中先贏**：

```
+4 == 0
且 格子.x <= 世界x < 格子.x + 16
且 格子.y <= 世界y < 格子.y + 16
```

沒中、右鍵、或點到戰場以外的分層，一律當取消。

## 選完寫哪裡

| 位址 | 寫什麼 |
|---|---|
| 艦隊 `+0x10 + i×4 + 3` | 選到的槽（`i` ＝ 這個分隊在分組表的第幾筆）|
| 艦艇 `+0x05` | 選到的槽 |
| 艦艇 `+0x1E` | `0x7F`（分隊行動清成「沒有」）|

然後立刻叫 `2BE1:0059(艦隊, 艦艇)` 依新槽算出目的地——所以下完「編隊」
分隊就會朝新位置走，不必再下「移動」。
