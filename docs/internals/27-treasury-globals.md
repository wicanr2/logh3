# 財政的全域變數

證據等級：**confirmed**（位址與意義各拿兩個時間點對過畫面）；
調查過程見 [`docs/re/26`](../re/26-tax-and-treasury.md)、
[`docs/re/29`](../re/29-month-rollover-data.md)。

月初預算操作後的實際結算：
[研究 351](../re/351-budget-settlement-after-reports.md)、
[五組完整收據索引](data/budget-settlement-receipts.json)。
**proven**：單人月初的預算／會計／訂造報告期間尚未實際扣稅；
訂造報告關閉後才收稅及扣除實付建造費。稅率及建造比例的箭頭會影響這次結算，
共同尾巴再重算下期預估。不得把命令階段的扣稅後資料用來重畫月初預算。

整張執行期資料的非財政差異尚未分類，見
[差異索引](data/budget-table-differences.json) 及
[Issue #83](https://github.com/wicanr2/logh3/issues/83)。財政一致不等於整表一致。

## 版面

每一項都是「32 位元 × 2（陣營）」的小陣列，索引是 `陣營 × 4`。
陣營 0 ＝ 帝國、1 ＝ 同盟；目前操作的陣營在 `ds:8F1D`。

| 位移 | 內容 | 796/1 帝國 | 796/2 帝國 |
|---|---|---:|---:|
| `ds:8F52` | **軍事費**（手上還有多少）| 45592 | 42339 |
| `ds:8F5A` | **船艦建造費**（下個月預定）| 13983 | 13188 |
| `ds:8F62` | **原定軍事費**（這個月一開始有多少）| 60741 | 56405 |
| `ds:8F6A` | **總稅收**（每個座位回合 `2703:02E5` 重算的預估；月底自己座位的 `2703:03AF` 歸零再只累加自己格子的實收。**首都丟了就不再累加**：`2703:0AB8` 看星域 0／31 的擁有者，`docs/re/321`）| 10341 | 10413 |
| `ds:8F72` | **艦隊維持費** ＝ Σ `297B:116C(艦隊)`（自己陣營、在用的每一支；那一支走艦隊 `+0x0F` 組編制到艦艇池）| 0 | 0 |
| `ds:8F8A` | **已支付的移動經費**（預算畫面 y ＝ 222，`docs/re/240`）| 0 | 0 |
| `ds:8F7A` | **累計已支付的艦隊維持費**（`056A:09EB` 每回合逐支 `+= 艦隊[+0x0A]`；同盟在 `monthblend` 是 426 ＋ 528 ＝ 954，`docs/re/236`、`238`）| 0 | 0 |
| `ds:8F82` | **本回合的移動經費** ＝ Σ 艦隊 `+0x0C`（＝ Σ `297B:12FB(艦隊)`，與維持費同一個形狀）。`t260_post` 的 492 正是監看到的三筆移動扣款總和（`docs/re/237`、`238`）| 0 | 0 |

`ds:8F72` 與 `ds:8F82` 由同一支 `297B:10DE(陣營)` 一起算出來
（`docs/re/211`）。收據 `turn260mem` 上同盟建三支之後 `ds:8F72` ＝ 426。
| `ds:8F94` | **已支付的船艦建造費** | 15149 | 14066 |
| `ds:8F92` | **造船百分比**（**一個 byte 一個陣營**，不是 32 位元陣列）| 25 | 25 |
| `ds:8F9C` | **建造中的船艦**：`2 陣營 × 7 艦種 × 32 位元 ＝ 56 bytes`。月底 `2B5F:001F` 把它整組加進首都行星與首都星域，然後訂造畫面重填（[`docs/re/264`](../re/264-ship-delivery-destination.md)）| — | — |

`ds:8F5A` 的算式（`090A:0E88(陣營)`，`docs/re/256`）：

```
基數 ＝ max(0, ds:8F52 ＋ ds:8F6A − ds:8F72 − ds:8F82)
ds:8F5A ＝ 基數 × ds:8F92[陣營] ÷ 100
          （基數 ≥ 0147AE14h ＝ 2³¹÷100 時先除再乘，避開溢位）
```

**維持費與移動經費只進建造費的基數，不進畫面上的預估軍事費。**
796/1 那兩欄兩項都是 0，所以看不出差別；S3 開局分得開——帝國
`160000 ＋ 13131 − 2342 − 665 ＝ 170124`（×0% ＝ 0）、同盟
`30000 ＋ 9748 − 951 − 1133 ＝ 37664`（×20% ＝ 7532），兩個都與收據
`monthmoney` 逐一相符。

`ds:8F92` 各局面：新遊戲 25／25（`63A1:0074` 設的）、S3 開局 0／20
（劇本 `3D08:001A` 載入的）、`s3aicomp` 0／7、`monthblend` 25／11。

**電腦那一方在回合收尾自己改**（`2D10:0038` 尾段，`docs/re/257`）：

```
ds:8F92[陣營] = min(總稅收 ÷ 900, 35)
```

讀的是 `2D10:0319(0)` 重算稅率**之後**的總稅收。`s3aicomp` 的
`6378 ÷ 900 = 7`、`monthblend` 的 `10213 ÷ 900 = 11`，都與傾印相同。
電腦只寫 `ds:8F1D` 那一格。

同一支接著把**七個艦種的分配**也寫回去（`ds:8FD6[陣營 × 7 ＋ 列]`，
每個陣營七個 byte）：帝國 `30 30 8 5 9 9 9`、同盟 `30 25 10 5 10 10 10`，
兩排都剛好 100，是逐格寫的固定表不是算出來的。同盟那一排在
`monthblend` 與 `s3aicomp` 兩份傾印上逐格相符；帝國那一排只從立即值
讀出來，手上的傾印裡帝國一直是玩家。玩家那一份就是生產計劃畫面改的那七格
（開局 `20 10 18 10 12 15 15`）。

畫面上的對照（徵稅計劃，收據 `tax1e`）：

```
本月份  原定軍事費  60741      ← ds:8F62
已支付  船艦建造費  15149      ← ds:8F94
        艦隊維持費      0
        移動經費        0
次月份  預估徵稅額  10341      ← ds:8F6A
        預估軍事費  55933      ＝ 45592 + 10341
        船艦建造費  13983 25%  ← ds:8F5A
        剩餘軍事費  41950
```

`60741 − 15149 ＝ 45592`，正好是目前的軍事費；下一個月
`56405 − 14066 ＝ 42339` 同樣成立。**玩家這兩個月除了造船沒有別的支出**，
所以只看得到這一項。

完整的等式是（`docs/re/258`）：

```
軍事費 ＝ 原定軍事費 − 已付建造費 − 累計已付維持費 − 已付移動經費
ds:8F52 ＝ ds:8F62 − ds:8F94 − ds:8F7A − ds:8F8A
```

扣的是三個**累計**欄位；`ds:8F72`（本回合維持費）與 `ds:8F82`（本回合移動
經費）不在裡面——它們是下一回合的預估，混進來會重複算。三格存檔 ×
兩個陣營六組全中：`WORK.DT8` 帝國 `120533 − 8801 − 15155 − 6577 ＝ 90000`、
同盟 `47942 − 9030 − 12412 − 11500 ＝ 15000`，`WORK.DT9` 是
`178563 − 8957 − 14238 − 5368 ＝ 150000` 與
`49957 − 9035 − 7992 − 2930 ＝ 30000`。

## 月底：閘門與順序

每個座位取得控制之前都會跑一次 `0654:0034`（`04F8:01B9`，玩家與電腦兩條
路徑都跑）。它自己帶閘門，兩個條件要同時成立才做結算：

| 條件 | 意思 |
|---|---|
| `ds:8FF4[陣營] != 0` | 主迴圈在 `inc [8F18]` 之後把 `ds:8FF4`、`ds:8FF5` 都設成 1；`0654:0034` 做完就清掉自己那一格。作用是一個陣營一個回合只結算一次 |
| `ds:8F18 mod 10 == 0` | 一個月十回合 |

任一條不成立就直接跳到共同尾巴。**共同尾巴每個回合都會跑**：

```
090A:0E6D()
    2703:02E5()          ; 32 格全部：成長 → 收稅（旗標 0，累加到 ds:8F6A）→ 未安定度
    090A:0E88(0)         ; 帝國：297B:10DE 算維持費 → ds:8F72／ds:8F82
    090A:0E88(1)         ; 同盟：ds:8F52 + ds:8F6A − ds:8F72 − ds:8F82 → ds:8F5A
ds:8FF4[陣營] ← 0
```

閘門開著時，在共同尾巴之前多做這一段（`docs/re/255`）：

```
2B5F:001F()                        ; ds:8F18 != 0 才跑；交付建造中的船艦
0654:0130()                        ; 月報：船艦接收（參數 ds:8F18 − 1 ＝ 上個月）
090A:0E6D()                        ; ← 共同尾巴那一支，這裡先跑一次
0654:0486()                        ; 月報
2B5F:0103(0)
0654:02E0()                        ; 月報
ds:8F5A/5C[陣營] ← 2B5F:0103(1)    ; 換成**實付總額**（原本是預算）
2703:03AF()                        ; 旗標 1 那一趟：只掃自己的星域，軍事費 += 總稅收
ds:8F62/64[陣營] ← ds:8F52/54[陣營] ; 原定軍事費留一份
ds:8F52/54[陣營] −= ds:8F5A/5C[陣營] ; 軍事費 −= 船艦建造費
ds:8F94/96[陣營] ← ds:8F5A/5C[陣營] ; 已支付的船艦建造費
ds:8F7A/7C[陣營] ← 0                ; 累計已付維持費歸零
ds:8F8A/8C[陣營] ← 0                ; 已支付移動經費歸零
```

`2B5F:001F` 把 `ds:8F9C[陣營]` 那七個數**加**進自己首都行星的 `+0x20`
與首都星域記錄的 `+0x30`（帝國 ＝ 奧丁／星域 0，同盟 ＝ 海尼森／星域 31），
七個艦種一次做完、不打折。接在後面的 `0654:0130` 就是把同一組數字
印成「船艦接收報告」（[`docs/re/264`](../re/264-ship-delivery-destination.md)）。

`2B5F:0103(旗標)` 算次月份的建造計劃（`2B5F:014D`）：讀 `ds:8F5A[陣營]` 當
預算、`ds:8FD6` 當百分比，把各列金額寫 `ds:D002`、艘數寫 `ds:D01E`、餘額
百分比寫 `ds:D03A`，**回傳實付總額**。旗標 1 那一趟另外把 `ds:D01E` 那 28
bytes 複製進 `ds:8F9C[陣營]`（就是下個月底要交的那組）。所以後面兩行
`ds:8F52 −= ds:8F5A`、`ds:8F94 ← ds:8F5A` 扣的與記的都是**實付**，不是預算；
`ds:8F5A` 每回合再由 `090A:0E88` 重算成預算。單價不是常數——
⌊艦種基價 × 100 ÷ 軍事專任參謀的營運⌋（[`docs/re/265`](../re/265-unit-price-comes-from-staff.md)）。

**`ds:8F5A` 有兩個執行期寫入者，語意不同**（收據 `monthwork2` 的監看，
[`docs/re/266`](../re/266-month-end-work-block.md)）：

| 寫入者 | 是什麼 |
|---|---|
| `090A:0F7E`（在 `090A:0E88` 內）| 下一期的**預估**建造費，每個座位回合都寫 |
| `0654:009F`（月底本體，上面那一行）| `2B5F:0103(1)` 回傳的**實付總額** |

所以讀這一格要看時點：回合之間是預估，月底本體中途是實付。
按步數取樣的傾印會呈現兩種讀法，那不是算式有兩個版本。

三支月報（`0654:0130`、`0654:02E0`、`0654:0486`）開頭都先看
`ds:8F23[ds:8F1E]`——**只有玩家座位看得到，電腦座位直接返回**。

`090A:0E6D` 在這一趟裡出現兩次（閘門內一次、共同尾巴一次），所以
**月底那個回合的成長／收稅／未安定度會跑兩次**，中間夾著 `2703:03AF` 的
`軍事費 += 總稅收`。第二趟把畫面要看的「下個月預估徵稅額」（`ds:8F6A`）
與 `ds:8F5A` 重算成結算之後的值。收據 `monthgateD`：`0654:0034` 只命中
一次，`ds:8F6A` 被歸零三次（`2703:02F7` → `2703:03D5` → `2703:02F7`），
第三趟的逐筆累加值與前兩趟全都不同。

`0654:0034` 之外還有一支 `0654:0007`，由 `04F8:000E` 在逐座位之前呼叫。
它自己帶**兩層**閘門：外層要求 `ds:8FF4` 與 `ds:8FF5` **都**還沒被清掉
（逐座位的 `0654:0034` 各清自己那一格），所以**一個回合跑一次**；內層才是
十回合那道。內容是：

```
2B5F:02B2()                          ; 每回合：32 格回充飛彈與艦載機存量
if ds:8F18 mod 10 != 0: return       ; ← 只有下面兩支是月底限定
2703:0BF2()                          ; 32 格成長 ＋ 用實際成長重算成長率 +0x1E
090A:0B5E()                          ; 重算稅率（帝國／同盟／無主三段）
```

`2B5F:02B2` 不碰錢，它補的是星域記錄的 `+0x68`／`+0x70`（飛彈／艦載機存量，
[`docs/internals/22`](22-stellar-dt.md)）：每回合 `⌊(經濟力＋防衛力) ÷ 10⌋`，
夾在經濟力＋防衛力，無主星域與補給線被切斷的星域跳過
（[`docs/re/273`](../re/273-region-supply-pool-refill.md)）。

**所以月底是「先長、重算成長率、重算稅率，然後各座位才收稅」**
（[`docs/re/267`](../re/267-monthly-growth-and-tax-rate-recompute.md)、
[`docs/spec/038`](../spec/038-monthly-growth-and-tax-rate.md)）。
