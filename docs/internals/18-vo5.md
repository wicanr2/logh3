# `.VO5` — 結局圖

資料：`docs/internals/data/vo5.json`
素材：`assets/original/vo5/*.png`（50 張，進版控；
以 `tools/py.sh tools/scripts/vo5_export.py` 從自備原版重建；清單與雜湊見 [`assets/original/README.md`](../../assets/original/README.md)）
實作：`tools/scripts/vo5_decode.py`
證據等級：**confirmed**（解碼常式來自反組譯；50 個檔用掉的位元組數與檔案
長度完全相同；其中一張的兩個 plane 與 dosgolem `e0b6a03` 原版畫面逐位元組相同）。

## 版面

```
+0  u8   寬（bytes，×8 ＝ 像素寬），全部是 0x50 ＝ 640 像素
+1  u16  高（列），200 或 400
+3  …    壓縮資料
```

四個 plane 依序解，**共用同一個來源指標**——第一個 plane 解完之後接著
往下讀第二個。

## 壓縮：相等即重複（逐 byte）

原版的解碼常式在 `ENDING.EXE`：`sub_102EC` 拆檔頭並呼叫四次
`sub_10364`，一次一個 plane。

```
lodsb                    ; 取一個 byte
loc_10371:
mov es:[di], al          ; 寫下去
add di, [bp+arg_0]       ; 往下一列（arg_0 ＝ 一列幾 bytes）
mov bh, al               ; 記成「上一個值」
dec dx / jnz             ; 這一直行還剩幾列
  mov dx, [bp+arg_2]     ; 走完一直行 → 重設
  sub di, [bp+arg_4]     ; arg_4 ＝ w*h-1，回到頂端往右一格
  dec bl / jz done       ; 直行用完就結束
lodsb
cmp al, bh
jnz loc_10371            ; 不相等 ⇒ 一般的 byte
xor ax,ax / lodsb        ; 相等 ⇒ 重複組，次數是 1 byte
and al,al / jnz +        ;   次數是 0 的話改讀一個 word
lodsw
dec ax                   ; 第一個已經寫過了
```

所以 `v v n` 代表 **v 總共出現 n 次**（第一個 v 是前面那個一般 byte）。
與 `.AMG` 同源，差別是 `.AMG` 以 word 為單位、`.VO5` 以 byte 為單位。

**填法是直行**：寫一個 byte 之後位址加一列的 bytes 數往下走，
走完整個高度就回到頂端往右一格。

## 驗證

- 50 個檔全部「用掉的位元組數 ＝ 檔案長度」，一個不多一個不少。
- `ENDT30.VO5` 解出來的 plane 2 與 plane 3，與原版畫到畫面上的
  對應 plane **逐位元組相同**（各 256,000 bytes，位置 `(0,40)`）。
  這是 dosgolem `e0b6a03` 新收據；舊記錄的 `(0,80)` 來自會覆寫程式碼的
  錯誤執行器，勘誤與全 50 張素材反對照見 [`docs/re/301`](../re/301-ending-image-y-is-40.md)。

plane 0 與 1 對不上，因為原版那一幕是好幾張圖疊出來的。那個畫面
從第 45,000,000 道指令到第 70,000,000 道逐位元組不變，**不是畫到一半**；
單純的「一張給 plane 0/1、另一張給 plane 2/3」也對不上（差 46,101 像素）。
每一張畫在哪、怎麼疊，**未解**。

## 怎麼讓 `ENDING.EXE` 跑起來

它靠命令列參數決定要演哪一個結局，參數不對就只印一行
`Derdensagen Vom Kosmosinset III SP` 然後結束（IDA：`_main` 先
`atox(argv[1])` 比 9、再 `atox(argv[2])` 比 1 或 2）。

```
tools/go.sh run ./cmd/probe -exe /orig/ENDING.EXE -root /orig \
  -cmdline " 9 1" -steps 40000000
```

`-cmdline` 是為此加進 dosgolem 的（把命令列尾巴寫進最外層程式的
`PSP+80h`；EXEC 出來的子程式本來就拿得到，最外層原本沒有地方放）。

`9` 是防呆守衛，`1` ＝ 帝國勝利、`2` ＝ 同盟勝利。
