# `COMANI.BMG` — 戰鬥動畫封存檔

資料：`docs/internals/data/comani-bmg.json`
產生：`tools/py.sh tools/scripts/bmg_export.py`
證據等級：目錄結構 **confirmed**（位移可用累加逐筆驗證）；每一段的編碼 **未解**。

## 目錄

```
+0      u16      第一段資料的位移（2540）
+2 起   每筆 10 bytes：
          +0  char[4]  名稱
          +4  u16      長度
          +6  u32      位移
```

**253 筆**，目錄在 2532 結束，之後 8 bytes 補到 2540。驗證方式是把每一筆
的「位移 ＋ 長度」拿去比下一筆的位移——253 筆一路接得起來，中間沒有洞。
檔尾還有 1,732 bytes 不在目錄裡，內容看起來與其他段同型（第 254 段）。

## 名稱的結構

四個位元組拆成三段：

| 位置 | 值 | 猜測 |
|---|---|---|
| `[0]` | `E`／`F`／`P` | 陣營或艦種大類 |
| `[1]` | `A`–`Z` 的一部分，以及 `0xB1`–`0xC0`、`0xDD` | 單位代碼（不全是 ASCII）|
| `[2..3]` | `AB`／`AF`／`AM`／`D0`／`D1`／`D2` | 同一個單位的六個畫格 |

六個畫格 × 42 個單位 ≈ 253 筆，數量對得上。

## 每一段的編碼未解

段內沒有明顯的寬高檔頭，開頭幾個位元組每段都不一樣。遊戲在開機時
就把整個檔案打開（`docs/re/03` 的開檔清單有它），但目前走得到的畫面
都沒有用到它——要先能進到戰鬥畫面，才有原版畫出來的東西可以對。
