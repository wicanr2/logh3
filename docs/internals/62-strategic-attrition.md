# 62 — 戰略階段的耗損與艦隊全滅

逐次調查：`docs/re/336` §九、`docs/re/329` §二、`docs/re/334`。規格：`docs/spec/060`。

## 在回合裡的位置（confirmed）

`0374:03E8` 逐格（`ds:8F17` 是格號）：這一格 `+0x13` bit2（這回合有戰鬥）→ 戰場，不跑下面；否則 `0374:0556`：

```
1930:1572 → 1AAB:0FAF（補充） → 0374:0608（耗損與全滅） → 0374:0919 → 0374:0AF2 → bit4 ? 20B4:1497（打行星） : 2703:1B48/1CD7/1D85
```

## `0374:0608(星域)`（confirmed）

| 項目 | 內容 |
|---|---|
| 條件 | 艦隊表 32 筆逐筆：`+0x04 ≠ FF`、`+0x06 == 星域`、`+0x01 ≠ 星域[+0x12]`（byte）、`+0x00 & 1` |
| 扣兵 `0374:06BC` | 現有每組 `n = min(⌊艦艇[+0x0A] ÷ 6⌋, 艦艇[+0x08])`（16 位元無號），`203A:0593(艦艇, n, NULL)` |
| `203A:0593` | 艦種 7 直接回；`+0x08 −= k`、`+0x0C −= k²÷滿編`、`+0x0E`／`+0x12` 按剩餘比例；`1261:0067(f, 0)`；對手 `ds:8FE4`／`8FEC += k ÷ 20` |
| 判定 | 只看第 0 組 `+0x08 == 0`：是 → `073F`；否 → `0896` |
| 亂數 | 沒有（閉包 214 支） |

## 全滅 `0374:073F` ＋ `297B:034A`（confirmed）

| 步驟 | 內容 |
|---|---|
| 報告 | `ds:01CD`「`\x03%s第`」＋`3982:0073` 編號＋`ds:01D3`「`艦隊\n%s%s\n`」＋`ds:01DE`「`已經全滅。    \n`」→ `3826:0307(buf, FFFF, 提督)`；開頭的 `\x03` 讓整窗畫成花紋 |
| 作廢 | 每組與 `+0x38` 那筆 `2AD2:01EF`：`+0x38` 遠指標非 0 就釋放、`+0x01 ← FF`；**不還存量** |
| `297B:034A` | `+0x6C` 遠指標非 0 → `35D1:0102`（沒進過戰場的艦隊是 `FFFFFFFF`，見 `docs/re/334`）；提督與副官 `28E0:057F(…, 0)`：`+0x09 |= 80`、`+0x00 ← 80`、`+0x02..+0x05 ← 0`；`+0x04`／`+0x05 ← FF`；星域 `+0x28[陣營]` 減一；`090A:0E6D`；`ds:8F49[陣營]` 減一 |

## 沒全滅 `0374:0896`

解包後的原碼：`for i < 組數`：`艦艇[+0x08] ≠ 0 → i++`；否則 `2AD2:01EF` 作廢、`0374:0A70(f, i)` 移除（後面往前搬、不清最後一格），
最後 `297B:0546(f)`（strong inference：與戰場的 `185C:0177` 同形）。dosgolem 上這支中間 16 bytes 被 GIN3 鍵盤常式的 `0400h` bug 寫壞（#76）。
