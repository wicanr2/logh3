資料：[`data/star-graph.json`](data/star-graph.json)、
[`data/star-distance.json`](data/star-distance.json)
產生：在路徑計算執行的當下倒出 EMS 那 8 KB，再跑
`tools/py.sh tools/scripts/star_graph_export.py`（中點矩陣）與
`tools/py.sh tools/scripts/distance_table.py`（距離矩陣）
證據等級：**confirmed**——四張表都能從 `ds:533A` 的邊權表逐格重算出來，
`tools/py.sh tools/scripts/distance_build.py` 對 1024×4 格全部相同；

## 形狀

32 個星域，**四張表**擠在同一個 EMS 分頁裡（段取自 `ds:937A`，位移寫死），
`2B99:0003` 配置，far ptr 放在資料段：

| 表 | far ptr | 分頁內位移 | 大小 |
|---|---|---|---|
| 帝國距離矩陣 | `ds:D062`／`ds:D064` | `+0x0000` | 32×32 word |
| 同盟距離矩陣 | `ds:D066`／`ds:D068` | `+0x0800` | 32×32 word |
| 帝國中點矩陣 | `ds:D06A`／`ds:D06C` | `+0x1000` | 32×32 byte |
| 同盟中點矩陣 | `ds:D06E`／`ds:D070` | `+0x1400` | 32×32 byte |

```
T[i][j] == 255   → i 與 j 直接相連
否則              → T[i][j] 是中繼點，path(i,j) = path(i,T) + path(T,j)
```

查表的地方是 `2B99:0349`：`bl = 起點; shl bx,5; les si,[表]; add si,bx`
——`表[起點 × 32 + 終點]`。

## 邊權與距離矩陣

相鄰關係的來源是 `ds:533A` 的 **32×32 位元組邊權表**（`0xFF` ＝ 不相鄰、
對角線 0），值域 10–18。原版每次重建路徑表都跑兩支
（`docs/re/243`）：

```
2B99:007D(陣營)   建初始矩陣：
                    邊權 0xFF                     → 0x7FFF（不相鄰）
                    否則 w ＝ 邊權；
                    擁有者(i) 或 擁有者(j) 不是自己 → w += 0x400
2B99:01B1(距離表, 中點矩陣)
                  Floyd–Warshall；中點矩陣先填 0xFF、對角線歸零，
                  鬆弛成功就把 k 寫進中點矩陣。比較是**無號**的，
                  所以 0x7FFF 當無限大不會溢位誤鬆弛。
```

擁有者取自星域記錄 `ds:A79C` 的 `+0x12`（`docs/internals/22`），所以
**擁有者一變、路徑表就得重建**。距離矩陣的值因此可以分解成

```
距離[i][j] = 1024 × k + Σ 沿途邊權
k = 路徑上「兩端不全屬於該陣營」的**邊**數
```

`ds:533A` 有一格不對稱：`[2][6] = 15`、`[6][2] = 13`（90 條邊裡唯一一條）。
它是距離矩陣裡全部 186 格不對稱的唯一來源——把 `2→6` 也當成 13 重跑，
兩張矩陣就完全對稱。旁邊的 `[6][3]` 同樣是 13，看起來是原始資料的手誤。

## 原版的路不是步數最短，是成本最短

同一張圖上廣度優先最遠 **9** 步；照原版的中點矩陣展開，帝國那張最遠 **10**
步、同盟那張 **12** 步。差別在於中點矩陣是**成本**最短路的見證矩陣，而成本裡
有那個 1024 的罰則——路徑會繞遠去走自己的地盤。**remake 要跟原版一致就得
照表走**，不能自己算步數最短路。

## 誰在用

- 未安定度的開局值：算式裡對每顆行星扣掉 `2 × 距離(該陣營首都, …)`
  （`docs/re/24`、`docs/re/28`）。首都是帝國 0（瓦爾哈拉）、同盟 31（巴拉特）。
- 未安定度的另一條分支拿距離矩陣的值與 `0x800` 比（也就是 `k >= 2`）
  把治安度砍半（`docs/spec/006`）。載入的當下整張矩陣是 0——它是路徑計算
  跑過才填的（`docs/re/43`），所以那條分支開局不會走到、中局會。
- 每個星域的 `+0x24` ＝ 到自己陣營首都的路徑成本，`+0x13` 的 bit0 ＝ 那個
  成本 `>= 0x400`（`2703:0933`、`docs/re/244`）。
- 「從首都走得到嗎」（`2B99:0392`）是把 `2B99:028F(首都, i, 陣營) < 0x800`
  攤成 32 格布林（`docs/re/185`）。
- 艦隊移動還沒做到，但要的就是這張圖。

## 什麼時候重建

`2B99:0003` 有三個呼叫點：載入、新遊戲，以及 `2703:08DE`——後者在**回合
結束**、逐格重算擁有者與處理易主之後跑，重建完再對 32 個星域各跑一圈態勢
重算（`docs/re/244`）。**路徑表是擁有者的函數**，星域易主之後不重建就會走
到過期的路。

## 鄰居清單是從路徑表反推的

`2B99:03D9(星域, &out, 陣營)` 列鄰居的判準是**中點矩陣 == 255**，不是查
`ds:533A`；而且 `mid[i][i]` 永遠是 255，所以**這一格自己也在清單裡**。

領土罰則不會讓某條直接邊從清單裡消失：一條路上每條邊都沒被罰，需要路上
每一格都屬於該陣營，那首尾兩格也屬於該陣營、直接邊同樣不會被罰。所以直接
邊被罰時任何路都至少帶一個罰則，而「直接邊 ＝ 1024 ＋ 最多 18」永遠小於
「其他路 ＝ 至少 1024 ＋ 10 ＋ 10」。判準是 `2 × 最小邊權 > 最大邊權`，
實際是 **20 > 18**，只差 2。
