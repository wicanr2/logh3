# 星域之間的相鄰關係與路徑表

資料：[`data/star-graph.json`](data/star-graph.json)
產生：在路徑計算執行的當下倒出 EMS 那 2 KB，再跑
`tools/py.sh tools/scripts/star_graph_export.py`
證據等級：**confirmed**（1024 對逐一驗過每一步都相鄰）；調查過程見
[`docs/re/28`](../re/28-region-graph-and-distance.md)。

## 形狀

32 個星域，**兩張 32 × 32 的中點矩陣**（每個陣營一張），
原版存在 EMS 裡，far ptr 在 `ds:D06A`／`ds:D06C`（帝國）與
`ds:D06E`／`ds:D070`（同盟）。

```
T[i][j] == 255   → i 與 j 直接相連
否則              → T[i][j] 是中繼點，path(i,j) = path(i,T) + path(T,j)
```

查表的地方是 `2B99:0349`：`bl = 起點; shl bx,5; les si,[表]; add si,bx`
——`表[起點 × 32 + 終點]`。

## 原版的路不一定是最短路

同一張圖上廣度優先最遠 **9** 步；照原版的中點矩陣展開，帝國那張最遠 **10**
步、同盟那張 **12** 步。**remake 要跟原版一致就得照表走**，不能自己算最短路。
