# 54：戰略 AI 決定一支艦隊要不要動

證據等級：**confirmed**（反組譯位元組，`docs/re/79`、`docs/re/162`、
`docs/re/163`）。目的地怎麼選還沒解。

按下「實行」之後，`2E54:005D` 逐艦隊跑一趟（只處理 `ds:8F1D` 那個陣營），
把每支艦隊的 `+0x79` 標成「這回合的決定」：`0xFF` 未定 → 0 或 3。
判斷交給 `2E54:16F5`。

## 戰力：`2E54:1876(星域, 索引清單, 幾支, 陣營)`

```
Σ（清單裡每支能戰的艦隊）Σ（它的每個分隊）
      ds:6032[艦種] × 現有艘數 × 1000 ÷ 滿編艘數
```

- 艦隊 `+0x00` bit0 有設（無法戰鬥）整支跳過。
- 分隊數在艦隊 `+0x0F`，池索引在 `+0x10` 起一組 4 bytes 的第一個 word。
- 艦艇的現有／滿編是 `+0x08`／`+0x0A`，艦種是 `+0x04`。
- 權重表 `ds:6032`：

| 艦種 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 權重 | 4 | 3 | 3 | 3 | 2 | 1 | 3 | 0 |

## 決定：`2E54:16F5(艦隊)`

| 情況 | 回 1 的條件 |
|---|---|
| 在自己陣營的首都星域（帝國 0、同盟 31）| 無條件 |
| 這一格是自己的 | 我方 × 4 ≥ 敵方，或 艦隊 `+0x3C` ＝ 100（編制滿）|
| 這一格無主（擁有者 2）| 我方 × 2 > 敵方 |
| 這一格是敵方的 | 我方 > 敵方 |

「我方」「敵方」是上面那個戰力總和，成員用
`297B:131C(&清單, 星域, 旗標)` 收（旗標 1 自軍、2 敵軍）。
對方陣營用 `3982:0250(陣營)` 換算。

回 1 → `+0x79 = 3`，同時 `[星域×2 − 0x2A32]` 那一格 ++；
回 0 → 走 `2E54:1955`、`+0x79 = 0`（`docs/re/79`）。

## 沒事做就回防：`2E54:1955(艦隊)`

```
若 這一格是自己的 且 星域[+0x13] bit2 沒設：
    先寫預設 +0x08 = 5（不動）、+0x07 = 0FFh、+0x79 = 3
在相鄰星域（2B99:03D9）裡挑「擁有者 ＝ 自己」而且
    2B99:028F(候選, 3982:0329(陣營), 陣營)（到自己首都幾步）最小的那一格
找到 → +0x08 = 0（會走）、+0x07 = 那一格
找不到 → +0x08 = 5、+0x07 = 0FFh
```

`+0x08`：**0 ＝ 會走、5 ＝ 不動**（`docs/internals/33`）。
**攻勢那一半還沒解**——`+0x07` 被設成敵方星域是哪一支寫的（`docs/re/164`）。

## 一趟裡的四張星域表

開頭連著三個 memset 清掉 `ds:D50E`／`ds:D54E`／`ds:D5CE`（word × 32），
`2E54:0730` 再算出 `ds:D58E`（byte × 32）＝ **這一格還缺幾支**：

```
若 星域擁有者 != ds:8F1D：那一格不算
缺幾支 = （ds:D5CE[r] >= ds:D54E[r]） ? 0 : (ds:D54E[r] − ds:D5CE[r]) >> 2
缺幾支 += min(ds:D50E[r] >> 1, 1)
```

`ds:D5CE[r]` 是「這一格已經有幾支艦隊有事做」（決定迴圈裡 ++）。
`2E54:08E3` 是同形狀的第二支，最後一步改成 ÷5。之後有四個回 ±1 的
比較器拿 `ds:D58E`／`ds:D50E` 排序——形狀是「**算缺口 → 排序 → 分配**」，
分配那一步還沒讀（`docs/re/165`）。

## 分配：`2E54:0CD2(目標星域, 艦隊指標陣列, 幾支)`

```
集結點 = 目標星域的鄰居（2B99:03D9）裡「擁有者 ＝ ds:8F1D」
         而且 2B99:028F(鄰居, 我方首都, 陣營) 最小的那一格
對每一支艦隊：
    若 2B99:028F(艦隊[+0x06], 集結點, 艦隊[+0x01]) >= 0x800：跳過（走不到）
    艦隊[+0x08] = (艦隊[+0x06] == 我方首都) ? 3 : 0
    艦隊[+0x07] = 集結點
    艦隊[+0x79] = 0
```

**派去的是集結點，不是目標本身**（`docs/re/166`）。

## 艦隊槽是固定分陣營的

`ds:C074` 32 槽 × 122 bytes：**0–15 帝國、16–31 同盟**，沒在用的
`+0x01` 是 `0xFF`（`2E54:03C3` 的起點 ＝ `(ds:8F1D == 0) ? 0 : 16`、
迴圈 16 次；`dm_pre.bin` 的 32 個槽驗過）。

`+0x08`（行動）目前見到三個值：**0 移動、3 從首都出擊／就地戰鬥、5 不動**。

## 每個星域派幾支：`2E54:0AAB(星域)`

先用 `2E54:143F` 逐一取候選艦隊，`2B99:0450(星域, 艦隊星域, 陣營) <= 1`
（就在那一格或隔壁）就記成「已到」並停止收集；其餘標成候選。

| 條件 | 做什麼 |
|---|---|
| 已到 < 缺幾支、已到 ＋ `ds:D60E` < 16、(缺幾支 − 候選數) < 3 | `2E54:0CD2` 分配 |
| 同上但差 ≥ 3 | `rand() < 0x2000`（1/4）才叫 `2E54:0DE3` |
| 其餘 | `2E54:0BEB(&清單, 要派, 星域)` |

最後一條有一個**寫死的特例**：目標是**星域 13（伊謝爾倫）**時丟一次
銅板（`rand() & 1`），中了就只派已經到的那幾支，否則照缺口派滿。
全遊戲的 AI 裡目前只有這一個寫死的星域編號（`docs/re/167`）。

`+0x79`（這回合的決定）目前見到四個值：**0 沒事做、3 有事做／就地待命、
4 候選、6 已經到了**。
