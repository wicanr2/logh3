# 52：畫點的三支常式與那 40 列的畫布偏移

證據等級：**confirmed**（反組譯位元組 ＋ 收據 `s3fight` 逐點驗算，
`docs/re/154`）。

## 邏輯畫布是 640×400，實體畫面是 640×480

所有經過 `3C5B:00B2` 的繪圖都吃**邏輯座標**，實體位置要再往下 40 列：

```
3C5B:00B2(bx = x, cx = y)
  ax = cx << 4          ; y × 16
  cx = ax
  ax = ax << 2 + cx     ; y × 80
  bx = (bx >> 3) + ax + 0C80h
  retf                  ; bx ＝ framebuffer 位移（一列 80 位元組）
```

`0x0C80` ＝ 3200 ＝ 40 × 80 ＝ 第 40 條掃描線。畫面圖塊表（
`docs/internals/42`）用同一個常數當起點，底圖 `ANI_PNL0.A98` 也畫在
y ＝ 40（`docs/internals/37`），滑鼠是 `screen_y = mouse_y + 40`
（`docs/re/52`）。

換算時要小心 `docs/` 裡的座標寫的是哪一套：

| 講法 | 例子 |
|---|---|
| 邏輯（`3C5B:00B2` 的參數）| 戰場左上角 (16, 20)（`3870:0296` 算出來的，`docs/re/135`）|
| 實體（收據 PNG 上量的）| 戰場左上角 (16, 60)（`docs/internals/34`）|

## `39D7:08F4(x, y, 色)`：畫一個點

```
36AD:013D()                 ; 進臨界區
di = 3C5B:00B2(x, y)
2376:1810(ah = 色)          ; 設 EGA 暫存器
out 3CE, (80h >> (x & 7)):08 ; index 8 Bit Mask ← 只開這一位
es = 0A000h
or es:[di], al              ; al ＝ 0：讀取載入 latch，寫入走 Set/Reset
2376:1852()                 ; 還原 EGA 暫存器
36AD:0117()                 ; 離開臨界區
```

`or es:[di], al` 的 `al` 是 0——真正決定顏色的是 Set/Reset，寫入的資料
本身無關。這是 EGA 寫入模式 0 的標準寫法。

## `2376:1810(ah = 色)`：把寫入設成 XOR

| index | 值 | 意思 |
|---|---|---|
| 5 | `0x00` | Mode ← 寫入模式 0、讀取模式 0 |
| 0 | 色 | Set/Reset ← 顏色 |
| 1 | `0x0F` | Enable Set/Reset ← 四個平面都取 Set/Reset |
| 3 | `0x18` | Data Rotate/Function：rotate 0、function ＝ 11b ＝ **XOR** |

所以每一個經過這一支的像素都是「底下的值 XOR 顏色」，**同一點同一個
顏色寫兩次會還原**。原版用這個性質做可擦除的疊圖：小地圖上的分隊點
（`docs/internals/38`）、要塞砲的射程橢圓（`docs/internals/50`）都是。

`2376:1852` 是收尾：sequencer Map Mask ← `0x0F`，graphics index 0 ← 0
等，把暫存器放回預設。

## `39D7:0936(x0, y0, x1, y1, 色, 遮罩)`：畫一條線

一樣 `di = 3C5B:00B2(x0, y0)` 起手、`2376:1810` 設 XOR，另外把
`ds:8F0E` 當 8 位元的虛線圖樣。**呼叫端 `3870:0833` 先把兩端按 x 排好**
（`x0 ≤ x1`），因為次要軸的除法是無號的。依 `|Δx|` 與 `|Δy|` 分四支：

| 情形 | 進入點 | 迴圈次數 | 次要軸 |
|---|---|---|---|
| `Δx > \|Δy\|` | `+09FC` | `Δx + 1` | y 累加 `(\|Δy\| << 16) ÷ Δx` |
| `Δx = \|Δy\|` | `+0A6F` | `Δx + 1` | 每步都走（正對角）|
| `Δx = 0` | `+0B06` | `\|Δy\| + 1` | 不動（垂直）|
| 其餘 | `+0AAE` | `\|Δy\| + 1` | x 累加 `(Δx << 16) ÷ \|Δy\|` |

累加器是 **0.16 定點、起始值 `0x8000`**（等於四捨五入），
**每畫完一點才累加**，進位才走一格。往上或往下走是靠自我修改程式碼：
`83 C7 50`（`add di, 80`）的 modrm 被改成 `EF` 就變成 `sub di, 80`。

虛線圖樣在橫向那一支是先 `ror ds:8F0E, x0 & 7` 對齊，再與整個位元組的
遮罩 `and` 起來；縱向那三支是每畫一列 `rol` 一位。遮罩 `0xFF` ＝ 實線。

## `3870:08FF`：畫線之前先裁切端點

Cohen–Sutherland。`3870:09F1` 算 outcode（1 左、2 右、8 上、4 下），
`3870:0A30` 把落在外面的那一端拉到邊界上：

```
上／下：x += (邊界y − y) × (x − 另一端x) ÷ (y − 另一端y)；y = 邊界y
左／右：y += (邊界x − x) × (y − 另一端y) ÷ (x − 另一端x)；x = 邊界x
```

除法是 `3CC9:70`，**往零截斷**。矩形在 `ds:8D6A`（xmin）、`ds:8D6C`
（ymin）、`ds:8D6E`（xmax）、`ds:8D70`（ymax），兩端都含；戰場那一組
是 (16,60)–(463,419)。

**裁切換掉的是端點，不是「畫的時候跳過畫面外的點」**：接下來的累加
從新端點起算，斜率的相位跟著變（`docs/re/155` 量到差兩個像素）。
