# 31 — 全螢幕字元平面與字形繪製

原版的所有文字都不是直接畫到 VRAM，而是先寫進一塊 40 欄 × 20 列的
**字元平面**，再由刷新常式把「髒」的格子畫成像素。視窗元件（`docs/internals/32`）
各自有一份小的字元緩衝區，`34CB:07EE` 把它疊進這塊全螢幕平面。

平面在 `ds:0D81E`（線性位址隨 DS 走，不要記死）。

## 格子（6 位元組）

| 位移 | 意思 |
|---|---|
| `+0` | 低 5 位 ＝ 擁有這一格的視窗編號；`0x80` ＝ 髒（待重畫）；`0x40` ＝ 用快取字形（`+4/+5` 當指標）；`0x10` ＝ 走彩色文字路徑 |
| `+1` | 模式旗標，bit0 ＝ 半形字 |
| `+2` | 字碼低位元組 |
| `+3` | 字碼高位元組。Big5 的**首**位元組放這裡；`0xFF??` 是內建的框線／捲軸圖形 |
| `+4` | 屬性：高 4 位底色、低 4 位字色 |
| `+5` | 樣式旗標（見下） |

一格 16×20 像素。畫面是 640×400 置中放進 640×480，所以

    第 c 欄的螢幕 x ＝ 16c
    第 r 列的螢幕 y ＝ 40 ＋ 20r

`+0` 的低 5 位是**擁有權**：`34CB:07EE` 疊圖時只碰擁有者對得上的格子，
所以視窗互相蓋住時不會把別人的內容擦掉。

## 字碼的三條路

`2376:0E0D` 依 `+3`（字碼高位元組）分三條：

| `+3` | 路徑 |
|---|---|
| `0xFF` | 內建圖形：`ds:6BF4 ＋ (低位元組 − 1) × 0xA0`，每張 20 列 × 4 plane。框線、捲軸箭頭、核取方塊都走這裡 |
| `≥ 0x80` | Big5：算出檔案位移，`int 21h` LSEEK ＋ READ 讀 30 位元組（16×15 點陣）進 `ds:82A0` |
| `< 0x80` | 半形：`+2` 與 `+3` 各一個 8×15 的字，兩個塞進同一格 |

Big5 的位移換算在 `2376:0F2F`：首位元組減 `0xA1`、次位元組分 `0x40..0x7E`
與 `0xA1..0xFE` 兩段，湊成線性序號之後乘 30，再依序號落在哪一段加不同的基底
（`0x0F00`／`0x6996`／`0x3ED0`）。

## 字形怎麼畫（`2376:10B7`）

1. 用 `+4` 的高 4 位填滿整格 16×20（VGA write mode 2）。
2. 切 write mode 3 ＋ read mode 1，set/reset ＝ 色號 3，把字形**往左上各移一格**
   畫一趟——這就是每個字左上角那圈立體邊。
3. set/reset 換成 `+4` 的低 4 位，原位再畫一趟。

第 2、3 步都是 `and es:[di], al`：read mode 1 配 color don't care ＝ 0 時
讀回 `0xFF`，遮罩就等於字形本身（`docs/re/49`）。

## 樣式旗標（`+5`）

| 位元 | 效果 | 常式 |
|---|---|---|
| `0x01` | 底線 | `2376:1180` |
| `0x02` | 網點（隔點挖空，畫成灰掉的樣子） | `2376:116C` |
| `0x04` | 加粗（字形每列與右移一位 OR 起來） | `2376:1155` |
| `0x08` | 上緣兩列畫色號 7、下緣兩列畫色號 3 ＝ 橫向立體條 | `2376:11B9` |
| `0x10` | 左緣的立體邊（按鈕左端） | `2376:11F1` |
| `0x20` | 右緣的立體邊（按鈕右端） | `2376:121B` |
| `0x80` | 上緣的立體邊 | `2376:1245` |
| `0x40` | 立體邊改用色號 7（不設就是 3） | `2376:10CB` |

一顆按鈕就是「左端格（`0x10`）＋ 文字格（`0x08`）＋ 右端格（`0x20`）」，
底色 8、字色 7。例如戰略地圖介面第 4 列的三顆按鈕：

| 欄 | 內容 | 底色 | 樣式 |
|---|---|---|---|
| 21 | 空白 | 15 | `0x10` |
| 22–25 | 戰略命令 | 8 | `0x08` |
| 26 | 空白 | 15 | `0x20` |
| 27 | 空白 | 15 | `0x10` |
| 28–31 | 一覽表＋空白 | 8 | `0x08` |
| 32 | 空白 | 15 | `0x20` |
| 33 | 空白 | 15 | `0x10` |
| 34–37 | 系統指令 | 8 | `0x08` |
| 38 | 空白 | 15 | `0x20` |

## 怎麼把任何一張畫面的文字量出來

`tools/scripts/plane_json.py` 把 `-dump-mem` 倒下來的平面解成 JSON
（每格的字、座標、字色、底色、樣式）：

```
tools/oracle.sh <批次> <該批次的旗標> -dump-mem lin:<平面線性位址>:4800:/src/workplace/x.bin
tools/py.sh tools/scripts/plane_json.py /work/workplace/x.bin /work/workplace/x.json
```

這比從像素反推版面可靠：座標、顏色與樣式都是原版自己記著的值。
