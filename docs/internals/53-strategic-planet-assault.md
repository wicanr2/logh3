# 53：戰略回合裡的打行星

證據等級：呼叫鏈與記錄長度 **confirmed**（反組譯位元組 ＋ 收據 `annex1`
的監看抓到換手那一下，`docs/re/161`）；參數的名字標在下面，未逐一驗過的
寫「**待驗**」。

戰場上的打行星走 `20B4:0503`（`docs/internals/29`、`docs/spec/019`）。
**戰略地圖上還有一條**，換手的動作與戰場那條是同一套，但驅動的人不同
——不開戰場畫面，在「實行」推進的過程中就結算掉。中立行星翻成同盟
就是這條做的。

## 呼叫鏈

```
20B4:1512(星域, 回呼far, 陣營, ?)            ; 一個星域、一個陣營
    ds:8F1D ← 陣營                           ; 暫時換掉「目前陣營」，做完還原
    幾支 = 297B:131C(&艦隊索引清單, 星域, 1) ; 收該陣營在這個星域的艦隊
    星域far = ds:A79C + 星域 × 126
    行星far = ds:CFF8（該星域的行星切片）
    對切片裡的每一顆：
        若 行星[+0x11] == 陣營：跳過（換下一顆）
        20B4:1662(星域far, 行星far, &艦隊索引清單, 幾支, 回呼far, …)

20B4:1662(…)
    行星的區內索引 = (行星far − ds:CFF8) ÷ 82
    對清單裡的每一支艦隊（ds:C074 + 索引 × 122）：
        0DEA:1759(艦隊, 行星索引)
        艦隊[+0x07] = 行星索引
        艦隊[+0x48] = 1                      ; 行動 ＝ 戰鬥
        若 …[+0x12] != 2：20B4:18C2(艦隊)
    …20B4:0D96 扣血…
    若 20B4:0E2C(行星, 攻擊力)：             ; 攻擊力追上剩餘防衛力
        行星[+0x11] = 攻方的陣營              ; ← 換手
        memset(行星 + 0x20, 0, 28)            ; 七個艦種的補充存量清掉
        行星[+0x3C] >>= 1
        行星[+0x3E] >>= 1
```

`122` 是艦隊記錄的長度、`126` 是星域記錄的長度、`82` 是行星記錄的長度
（`docs/internals/29`、`33`）。`20B4:0D96`（扣血）與 `20B4:0E2C`
（換手判定）就是戰場那條在用的兩支（`docs/re/151`、`docs/re/152`），
remake 的 `rules.PlanetAssault` 已經照它們實作並對過拍。

## 兩個入口，差在回呼

| 呼叫點 | 傳進去的回呼 | 待驗 |
|---|---|---|
| `185C` 那支小包裝（lin `190B9`）| `185C:0B18` | 星域取 `ds:8F17`、陣營是它自己的參數、第四個參數取 `ds:8F1A` |
| 段 `20B4` 內（lin `22040` 之前）| `20B4:1922` | 先叫 `297B:14F8` 決定一個 0／1 旗標再進來 |

回呼一路傳到 `20B4:1662`，看起來是「打完要報告什麼」用的（**待驗**）。

## 對 remake 的意義

中立行星換手不需要另一條規則——需要的是**戰略層把艦隊派出去**，
再把已經寫好的 `rules.PlanetAssault` 接到「實行」上。判定與換手的
數字都已經對過拍，缺的是上面那一層的決策。
