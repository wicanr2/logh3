# 65 — 戰場第一階段的自動補給與修理

事實來源與完整雜湊：[研究367](../re/367-battle-preparation.md)、
[分級指令索引](data/battle-preparation-semantics.json)、[十六案欄位](data/battle-preparation.json)。
只保存解出的規則；原始 dump、資料庫及完整注入 bytes 留在本機。

- **已證實**：先運補艦／行星補彈藥，再修護艦／行星補艦數，重算士氣並即時報告，最後回復防衛力。
- **已證實**：運補艦自動初選半徑取6.4倍速度的整數部分；修護艦取速度×6。
  修護艦後續篩選仍比6.4倍定點半徑，初選排掉者不會重新加入。
- **已證實**：修護艦可修運補艦；自動行星補艦數無手動選取的種類5／6排除。
- **已證實**：同艦隊依分隊序處理，庫存不足時前面的先取。
- **已證實**：行星實際補 `n` 艘時，艘數增加 `n`、該種類32位庫存減 `n`，
  修理上限以16位加 `n` 再以滿編夾限。沒有實際補充時不動修理上限。
- **已證實**：防衛力不足上限才回復；增量為乘積低16位再除100。
  現有值以16位加法回繞再比上限；無主也適用，已超上限原樣保留。
- **未知**：跨艦隊競爭的完整排序、行星沿用 donor 全域指標的持續狀態。

長期定位使用切段雜湊及原始指令簽章，不把執行期段值當固定結構位址。
代表簽章：`31 D2`（乘積高位清零）、`26 01 07`（防衛力16位加法）；
完整位置、bytes、等級與來源由分級索引自動合併到 IDA 匯出。
