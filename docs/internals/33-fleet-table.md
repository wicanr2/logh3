# 執行期艦隊表（`ds:C074`）

資料：無獨立檔案——這張表是執行期結構，`SHIP.DT?`／存檔另有各自的版面
（`docs/internals/30`）。
證據等級：長度與筆數 **confirmed**（`docs/re/66`）；下面標 confirmed 的
欄位來自對寫入設監看（`docs/re/70`），其餘 **未知**。

## 版面

`ds:C074` 起 **32 筆 × 122 bytes**。開局時第 0 筆全是 `0xFF`
（`docs/re/66`：那時整張表沒有任何艦隊）。

## 能力那 11 個 byte 的順序

`ADMIRAL.DT*` 的位移依序是
`+15`、`+16`、`+17`、`+19`、`+18`、`+12`、`+13`、`+20`、`+22`、`+23`、`+14`
（第 3 與第 10 個都是 126，哪一個是 `+19` 哪一個是 `+14` 分不出來）。

十四個能力欄位裡沒被抄進來的是 `+11`（統率力）、`+21`、`+24`。

## 戰力值怎麼算（`2E54:1876`，`docs/re/79`）

一群艦隊的戰力 ＝ 每一支每一組編制的

```
    ds:6032[艦種 +0x04] × 艦種 +0x08（一單位幾艘）× 1000 ÷ 艦種 +0x0A
```

加總（32 位元）。`+0x00` bit0 有設的艦隊不算。原版拿它比較兩個陣營在
某一帶的強弱。

## 誰把整張表跑過一遍

`056A:03E0`：`i` 從 0 到 31，指標每次 `+0x7A`（122），`+0x04` 是 `0xFF`
就跳過，其餘呼叫 `113A:0350`。**版面那三件事（位址、筆數、每筆長度）
在這一支裡一次全證實**（`docs/re/78`）。

## 移動要花的就是軍事費

`ds:8F52`（每個陣營一份的 32 位元存量）在載入 S2 的畫面上寫著
**軍事費 150,000**——與 dump 裡的值相同（收據 `s2ai0`）。所以移動扣的
是軍事費，不是另一種資源。

## 移動要花錢

`113A:047D` 寫 `+0x06` 之前先呼叫 `113A:06C3`：拿每個陣營一份的 32 位元
存量（`ds:8F52`，陣營 ×4）比艦隊記錄的 `+0x0C`（這一支移動的花費，
量到 183–288），不夠就不能動，夠就扣掉。存量在四份 dump 裡是
150,000／160,000（帝國）與 30,000（同盟），而且**沒移動的一方也在減**
——它不只被移動扣（`docs/re/77`）。

## 移動那兩支函式

| 位址 | 做什麼 |
|---|---|
| `113A:0350` | 這一支這回合要不要動：看 `+0x08`，順便處理「到了」 |
| `113A:047D` | 走一格：查下一跳（`2B99:0302`）、比擁有者、寫 `+0x06` 與提督表 |

反組譯與逐行說明在 `docs/re/77`。呼叫 `113A:0350` 的地方在線性 `05AD7`，
還沒追。

| 位址 | 寫什麼 | 來源 |

| `113A:05CE` | `+0x06` 所在星域 | 收據 `s2move` 的監看 |
| `297B:0B03` | `+0x5C` 座標 | 同上 |
| `297B:0BAB`／`0BAF`／`0BB3` | `+0x4A`／`+0x4C`／`+0x4B` | 同上 |

之後五次都沒有任何寫入，而移動命令還留在 `+0x07`。

## 寫入時機

分兩批：開「艦隊組成」畫面時寫一批（副官、機動力那些），按「決定」時
再寫一批（能力值與座標那些）。細節與位址見 `docs/re/70`。
