# 戰術（戰鬥）畫面

證據等級：**版面 confirmed**（收據 `s3ai6`／`s3bat1`／`s3bat2`，
`tools/scripts/runs.py`／`window_list.py` 量的）；**內容與規則未解**。

## 怎麼走到

載入 S3「巴米利恩會戰」，按六次「實行」——兩邊的艦隊會合在達希利（26），
畫面直接切進戰術畫面（`docs/re/77`）。整條路是決定性的：

```
主選單第 3 列「取進度」×2 → 防拷（打什麼都行）→ S3（滑鼠 300,282）
→ 陣營選帝國（318,168）→ 系統指令／實行 ×6
```

**不必先解 `COMANI.BMG`**——那個檔與能不能走到這裡無關。

## 版面

畫面外圈是一整套金屬邊框（與戰略畫面完全不同的一套），中間分三塊：

| 塊 | 像素範圍 | 說明 |
|---|---|---|
| 戰場 | (16,60)–(463,419) | 黑底 ＋ 藍色虛線格線 |
| 小地圖 | x 465–621、y 60–210 一帶 | 藍底，白框標出目前視野 |
| 狀態欄 | (464,220)–(623,419) | 底色 9 |

戰場裡的虛線格線量到縱向在 **x ＝ 160、400**、橫向在 **y ＝ 180**；
中央畫一顆行星（色 1 那一塊，`s3ai6` 在 (269,284) 一帶）。

**戰場是圖塊鋪的**：28 欄 × 18 列的 16×20 圖塊（`docs/internals/35`）。
格線與行星都是圖塊。實際鋪這一場的是 `BLOCK_2.BLK`，`BLOCK_3.BLK` 是
另一套；地形本身來自 `MAP26.CMP`——**一個星域一張**（`docs/re/81`）。

## 吃點擊的只有兩個視窗

`tools/scripts/window_list.py` 讀 `s3ai6` 的視窗串列：

| # | 視窗像素 | 命中範圍（滑鼠座標）|
|---|---|---|
| 0 | (464,220) 160×200 | x 464–623、y 180–379 |
| 1 | (16,60) 448×360 | x 16–463、y 20–379 |

**小地圖不在串列裡**，不吃點擊。

## 命令選單

點戰場或狀態欄**任何一處**都會在滑鼠所在位置開出選單（收據 `s3bat1`
點狀態欄、`s3bat2` 點戰場，開出來的是同一份）：

```
實行  資料  撤退  取進度  存進度  設定  結束
```

第一項「實行」正好落在游標底下，所以**同一點連點兩下 ＝ 結束我方輸入**。
這條路寫得進腳本。

## 狀態欄的內容

```
帝國軍：  輸入
宇宙曆：  799 03 01        （年份色 7、月色 6、日色 5）
第 1 回合
勝利點：  0
帝國軍：  0
同盟軍：  0

達希利
```

## 戰場座標在艦隊記錄裡

參戰的艦隊記錄（`docs/internals/33`）的 `+0x5C`／`+0x5E` 是一組 word，
`+0x64`／`+0x66` 有第二份一模一樣的：

| 艦隊 | `+0x5C` | `+0x5E` |
|---|---:|---:|
| 帝國 12 | 416 | 280 |
| 同盟 16 | 1536 | 1840 |
| 同盟 17 | 1536 | 1808 |

數字遠大於戰場那 448×360 的視窗——**戰場比看得到的那一塊大很多**，
右上角小地圖上的白框就是視野。兩邊開場相距一千多。

進入戰鬥時還會填 `+0x6A`（帝國 1、同盟 9）、`+0x6E`（1）、`+0x6F`（113），
星域記錄的 `+0x13` 從 8 變 12（`docs/re/77`）。

## 一個戰鬥回合怎麼推進

同一點連點兩下（選單開在游標處、第一項就是「實行」）＝ 結束我方輸入。
`s3turn2` 連點兩次兩回，畫面從第 1 回合走到第 3 回合。

推進之後**敵方六支全部朝我方移動，其中四支指向同一個點**
（`docs/re/80`）——戰術層的電腦會集中兵力。座標欄位：

| 位移 | 是什麼 |
|---|---|
| `+0x5C`／`+0x5E` | 現在的位置 |
| `+0x64`／`+0x66` | 要去的點；剛進戰鬥時與現在位置相同 |

## 還沒解

- 戰場的座標系（一格多少、視野怎麼跟著誰）。
- 單位怎麼下令、一回合能走多遠、戰鬥怎麼結算。
- 外圈那套金屬邊框：候選是 `ANI_PNL0.A98`（戰鬥時載的，`docs/re/81`），
  還沒驗。`FRAME.BLK` 與兩個 `BLOCK_?.BLK` 都比過，沒中。
- `MAP<nn>.CMP` 的編碼（一個星域一張戰場，32 個檔，`docs/re/81`）。
- 一回合能走多遠（量到 233 與 325 兩個值，可能跟機動力 `+0x3C` 有關）。
- 戰術層的 AI 怎麼挑那個集中點。
