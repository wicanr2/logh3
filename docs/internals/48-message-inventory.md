# 48：訊息框說了什麼

證據等級：呼叫端與字串位址由整份程式碼傾印掃出（`tools/scripts/msgbox_sites.py`），
`2BE1` 那五處另外反組譯確認（[`docs/re/139`](../re/139-message-inventory.md)）。
字串本身是原版資料段的 Big5，逐位元組抄出來的。

訊息框的機制見 [`47`](47-window-frame-tiles.md)；版面見
[`data/message-box.json`](data/message-box.json)，這一份完整資料在
[`data/message-sites.json`](data/message-sites.json)。

**顏色一律 `0x97`**（底 9、字 7）。種類決定樣板與按鈕：0／2 一顆「確認」，
1／3 兩顆（「中止」＋「決定」）。種類 0 與 1 開在格 (8,7)，2 與 3 開在
格 (4,7)——**同樣的訊息、不同的位置**，差別是哪一張畫面在用。

## 幾件看得出來的事

- **「沒有需要補給的船艦。」有兩份**（`ds:3F14` 與 `ds:3FB0`，後者尾巴多
  四個半形空白）。前者在**艦艇**的「補給」裡（`1930:0699` 落在
  `1930:05EC`），後者在**行星**的「補給」裡（`1930:0E2B` 落在
  `1930:0DA2`，`docs/re/134`）。兩支各存一份自己的字串。
- **`%s`／`%d`／`\x03` 這些是格式字串**：訊息框走的是一支 printf
  （`3ACA:0079`，輸出回呼 `3617:0099`），控制碼另有兩張跳表
  （`ds:6BCC`、`ds:6BDC`）。`要%s\x03[%d,%s…星系嗎？` 那一句就是靠它
  把星系名與顏色塞進去的。
- **`2BE1` 的三處是通用包裝**：四個參數原封不動往下傳，訊息由更上層決定。
  另外兩處是磁碟片錯誤，種類取 `ds:D20C`（變數），因為讀取失敗時畫面
  可能在任何地方。
- **原版自己的排版習慣**：好幾句用半形空白補到固定寬度
  （`無法撤離旗艦。` 後面 18 個空白、`      您確定要結束這個遊戲嗎？`
  前面 6 個）。這是**置中的做法**——沒有置中功能，就用空白湊。
