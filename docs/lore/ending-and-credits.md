# 結局與職員表

《銀河英雄傳說III SP》PC DOS 中文版的兩個結局台詞與完整職員表，逐字取自
原版 `ENDING.EXE`。原版用全形空白排版，這裡把連續空白收成一格。

中文版由亨和企業．微波軟體代理發行。職員表是原版檔案裡唯一記下中文化
工作者姓名的地方。

| 來源 | 值 |
|---|---|
| 檔案 | `ENDING.EXE`，64,677 bytes（未打包 MZ）|
| 字串區 | 0x63FE–0x765C，`\0` 分隔 |
| 編碼 | Big5（倚天） |
| 資料 | `docs/internals/data/ending-text.json` |

## 結局

### 帝國勝利

銀河帝國大軍

佔領了同盟的首都海尼森

使自由行星同盟政府

對全軍下達無條件停戰的命令。

而自由行星同盟

根據「巴拉特和約」裡的條文

從此歸屬於帝國的領土。

銀河系中出現了新的統治者

他的名字叫做萊因哈特．馮．羅嚴克拉姆。


### 同盟勝利

在自由行星同盟的長途遠征之下

終於推翻了銀河帝國。

並且在帝國領土上實行了民主政治

使各地充滿了廣大民眾的歡呼聲。

後來，完全統一後的人類社會

寫下空前未有的繁榮歷史。


### 尾聲

萊因哈特閣下。

我們終於將整個宇宙掌握在手中了。

有一半都是你的哦．．．吉爾菲艾斯。

楊提督。

過一會兒我們將到達帝國的首都－奧丁。

戰爭結束以後

從此應該進入了新的歷史吧。

可以給我一杯紅茶，好嗎？

好的。
