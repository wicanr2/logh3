## 為什麼需要這一條

星域的擁有者是**行星擁有者的函數**，而且只在載入劇本時重算一次
（`docs/re/106`）：

```
同盟行星 == 0 且 無主 == 0  → 帝國
帝國行星 == 0 且 無主 == 0  → 同盟
否則                        → 無主
```

戰鬥打完**不會**改變星域歸屬——量過了（`docs/re/105`）。所以要讓地圖上的
勢力範圍會變、要讓一局遊戲能分出勝負，缺的就是**行星換手**這一條。

## 挑艦隊（部分 confirmed）

逐一走過艦隊表（`ds:C074`，一筆 122）：

| 判準 | 狀態 |
|---|---|
| 第一組的艦艇 `+0x08`（存活艘數）不為 0 | confirmed |
| 行星 `+0x11`（擁有者）≠ 艦隊 `+0x01`（陣營）| confirmed |
| 距離 ＝ `3310:0006(行星 +0x46/+0x48, 艦隊 +0x5C/+0x5E)` ≤ **150.0**（16.16）| confirmed |
| 艦隊 `+0x00` bit0 ＝ 0 | confirmed（bit0 的語意未解，`docs/re/79`）|
| 艦隊 `+0x48` 低四位 ＝ 1 | confirmed（值的語意未解，見下）|

符合就 `艦隊[+0x70] |= 1`、`艦隊[+0x5A] = 行星索引`。

第二種分支（`+0x70 |= 2`）的門檻是傳進來的參數，**來源未解**；
附帶條件是「行星 `+0x12` ＝ 0，或行星 `+0x45` ≠ 3」。

### `+0x48` 的低四位

收據 `s3tgt` 的傾印：不在戰鬥裡的艦隊是 **4**，正在戰鬥的六支是 **0**
（`docs/re/80` 記過它在戰鬥中 4→0）。**1 沒有出現過**——所以那一場
沒有任何一支符合條件，`+0x5A` 全部是 `0xFF`，與「現有收據裡沒有任何
一次行星換手」互相印證。

**入口找到了**（部分）：整份記憶體裡寫 `+0x48` 的立即值只有 0、1、4 三種，
寫 **1** 的有四處——線性 `1D541`、`2220E`、`316A4`、`31CE4`。

`1D541` 那一支的樣子（函式起點 `1D50D`）：

```
if 2583:0003(艦隊, 艦隊[+0x4F], 艦隊[+0x4D]) != 0:
        艦隊[+0x48] ← 1
```

`+0x4D`／`+0x4F` 正是 `docs/re/102` 裡與 `+0x4E`（每回合步數）同一批算出來
的姊妹欄位。`2583:0003` 開頭把參數 ×8 與 ×8÷3 當成兩個半徑，再往下搜
（`165F:0003`）——**看起來是「以艦隊為中心、用自己的射程搜一圈」**，
細節還沒讀完，所以先不寫成定論。

`2220E` 那一處就在打下行星的那支函式裡（`0x2231B` 換手），所以**打下之後
艦隊也會進入狀態 1**。另外兩處在戰鬥子系統，還沒讀。

`20B4:0503` 回值 > 0（拿下）之後：

```
行星[+0x11]        ← 艦隊[+0x01]              陣營
行星[+0x20..+0x3B] ← 0（28 個 byte，3C9C:000A）
行星[+0x3C..+0x3F] >>= 1                       32 位元右移一位
行星[+0x40] ← 0 ; 行星[+0x42] ← 0
ds:8FE4[陣營 × 4] += 行星[+0x16] ÷ 10          分數（docs/re/92 的那兩個）
```

另有一支（線性 `0x28B16`）把 `行星[+0x11]` 寫成 **2（無主）**，
呼叫者未解。

## 開火：這一輪打掉多少防衛力（部分 confirmed）

`20B4:0681(艦隊, 行星)`：

```
若 !(艦隊[+0x70] & 1)：回 0xFFFF        ; 這一支不參與
A ＝ 203A:0424(艦隊, …)                  ; 未解
B ＝ 20B4:0D96(艦隊, 行星, …)            ; 未解
C ＝ 203A:04D1(行星, …) ÷ 6              ; 行星附近艦種 0／1 的存活艘數（docs/re/99）
量 ＝ (B ≥ C ? B − C : 0) ＋ rand() % 100
量 ＝ min(量, 行星[+0x14])               ; 夾在防衛力以下
（接著是幾支繪圖常式：321F:0D11／321F:0DF7／20B4:1269／20B4:0A26／20B4:0C4E）
```

**與戰鬥的總損失共用同一支 `203A:04D1`**——打行星不是另一套系統。
`A`（`203A:0424`）在這一段裡算出來但還沒看到用在哪；`B` 的來源
`20B4:0D96` 還沒讀，`20B4:08B1` 也還沒讀。

## 兩道閘門也解了（[`docs/re/149`](../re/149-planet-assault-gating.md)）

`2583:0003` 不是搜尋，是玩家的「移動／戰鬥」選點迴圈（那兩個半徑是畫在
畫面上的兩個圖形，`docs/re/120`）；`+0x48` ← 1 只是「玩家成功下了戰鬥
命令」，與 `docs/spec/027` 同一件事。

艦隊 `+0x70` 的兩個位元是兩個距離帶（`20B4:0091`）：

```
bit 0：離行星 ≤ 150 像素、且 (艦隊[+0x48] & 0x0F) == 1、且 艦隊[+0x00] bit0 為 0
bit 1：再加「≤ rules.PlanetQueryRadius(防衛力)」且那顆不是「要塞砲已瞄準」的要塞
```

`20B4:08B1`（實際打）要的是 **bit 1**——所以**瞄好的要塞砲會讓敵方那一
回合打不到這顆行星**。開場由 `20B4:000C` 把 `+0x70` 清 0、`+0x5A` 設
0xFF；`20B4:01C1` 把 `+0x5A != 0xFF` 的艦隊排序（比較函式 `20B4:02A4`）
再逐一結算。在場艦隊的清單在 `ds:9898`、筆數在 `ds:9894`。

## 收據有了（[`docs/re/150`](../re/150-planet-capture-receipt.md)）

`s3assault`：S3 不必 poke 任何東西——雷奧米爾（全域第 63 顆）在第八個
回合被同盟打下來。上面「換手的效果」那一節**逐一相符**：`+0x11` ← 1、
`+0x3C` 右移一位（40000 → 20000）、`+0x40` ← 0。

兩件跟著修正的：

- **`ds:CFF8` 是「目前星域的行星切片」，不是整張表**（`ds:CFFC` 是那個
  星域的行星數）。所有走它的迴圈只掃這個星域，而艦隊 `+0x5A` 是**切片
  內的序號**——這一份收據裡四支艦隊都是 0，換手的是全域第 63 顆。
- **換手不是「防衛力歸零」**：打完還有 428。條件在 `20B4:0503`。

## 換手的條件與分數的組成也解了（[`docs/re/151`](../re/151-planet-capture-condition.md)）

```
20B4:0503(艦隊, 行星)：
    if 行星[+0x11] == 艦隊[+0x01]: 回
    門檻 ＝ 行星[+0x14] × 100 ÷ 行星[+0x16]        ; 防衛力還剩幾成
    if 艦隊[+0x3C] ≥ 門檻:
        r ＝ 20B4:0681(艦隊, 行星)                 ; 先開火
        if r ≤ 0: 20B4:08B1(艦隊, 行星)            ; 沒打下來才挨反擊
    else:
        20B4:08B1(艦隊, 行星) ; r ＝ 20B4:0681(艦隊, 行星)
    if r != 0xFFFF 且 r != 0: 換手
```

`20B4:0681` 的尾巴是 `行星[+0x14] −= 量`、`ds:8FE4／8FEC[攻方] += 量 ÷ 20`、
`203A:0743(艦隊, 量 ÷ 2)`，**回值 ＝ `A ≥ 行星[+0x14]`（扣完之後）**
——所以換手的條件是「攻擊力追上剩下的防衛力」。收據裡扣完剩 428，
五支艦隊的 A 是 856／406／1450／426／844，三支追上。

分數 ＋449 ＝ 逐支 `量ᵢ ÷ 20`（合計 119）＋ 換手獎金 `+0x16 ÷ 10` ＝ 330。

## 行星的反擊（[`docs/re/152`](../re/152-planet-counter-attack.md)）

```
20B4:0E7E(艦隊, 行星, 旗標)：
    基準 ＝ (203A:04D1(行星) ＋ 行星[+0x14]) ÷ (行星[+0x12] ? 20 : 10)
    基準 −= 基準 × (距離 ÷ 150) ÷ 5
    向   ＝ 3982:0022(|atan2(行星 − 艦隊) − 艦隊[+0x4A]|)      ; 0–7
    基準 ＝ 基準 × ds:47D0[向] ÷ 100        ; 表 ＝ 80 85 90 95 100 95 90 85
    量   ＝ 基準 × 100 ÷ (艦隊[+0x40] × 艦隊[+0x41] ÷ 100) ＋ rand() % 100
    20B4:103D(艦隊, 量, 旗標)
```

方向表的最小值在索引 0（艦隊正面對著行星，80%），最大在 4（背面，100%），
兩側對稱——**被從背後打最痛**。

分攤（`20B4:103D`）：

```
總 ＝ Σ 各分隊艘數
對每個編制槽（依分隊序）：
    這一支 ＝ ⌊量 × ⌊艘數 × 100 ÷ 總⌋ ÷ 100⌋
    旗標 0 時夾成 ≤ 艘數 − 1（不打光）
    實扣 ＝ 203A:0593(艦艇, 這一支, NULL)
餘 ＝ 量 − Σ實扣，丟給**艘數最多**的那一支（同樣夾成 ≤ 艘數 − 1）
```

**兩段整數捨去**（先算百分比再乘）是原版的形狀；換成一次乘除會差幾艘。

## 處理順序

`20B4:01C1` 把鎖上行星的艦隊排序（`20B4:02A4`：先依 `+0x5A` 遞增、
再依 `+0x3C` 遞增），逐顆行星、逐支結算。**打下來之後後面的艦隊直接
跳過**（`行星[+0x11] == 艦隊[+0x01]` 就回），所以誰先動手會改變結果。
