## 什麼時候打

戰場一回合的結算（`181B:000A`）第五步 `181B:0385`：對每一顆
`+0x12 != 0`（有要塞）且 `+0x45 == 3`（已瞄準）的行星呼叫一次
`2264:0248`。

同一回合另有一支 `2264:000A` 把每一顆有要塞、`+0x45 != 0` 的行星減 1，
所以打完之後 3 → 2 → 1 → 0，兩回合填充。

## 打誰

```
候選 ＝ 以行星佔位框中心為心、半徑 長半軸 × 2，兩個陣營各查一次
       （17A0:00AC，即 rules 的範圍查詢）
篩掉 艦艇[+0x08] == 0（沒艘數）與 艦艇[+0x04] == 7（索敵分遣隊）
篩掉 不在射程橢圓裡的：
    距離(16.16) ≤ ℓ ÷ (1 − e × cos Δ)
    a ＝ 行星[+0x16] ÷ 200 ＋ 80、b ＝ a ÷ 4、ℓ ＝ b² ÷ a、e ＝ √(1 − (b/a)²)
    Δ ＝ |atan2(艦艇 − 行星) − 行星[+0x50]|
排序：先依 艦艇[+0x01]（艦隊編號）遞減、再依 艦艇[+0x03] 遞增
      （比較函式看行星陣營：帝國 2264:052F、同盟 2264:0612）
```

**要塞在橢圓的焦點上**，不在中心；中心 ＝ 焦點 ＋ 沿 `+0x50` 走
`⌊a × e⌋`。

## 打掉幾艘

逐筆（已排序）對每一支分隊：

```
列  ＝ 艦種表[艦艇[+0x00]][艦艇[+0x04]]                  ; ds:4E3A ＋ 陣營×0xD0 ＋ 艦種×0x1A
θ   ＝ atan2(行星[+0x46] − 艦艇[+0x34], 行星[+0x48] − 艦艇[+0x36])
Δ   ＝ |θ − 艦隊[+0x4A]|
D   ＝ ⌊ℓ' ÷ (1 − e' × cos Δ)⌋ × 艦隊[+0x3D] ÷ 100      ; a' ＝ 列[+0x16]、b' ＝ 列[+0x18]
基準 ＝ 艦艇[+0x08] × 40 × (行星[+0x16] ÷ D) ÷ 12800
量   ＝ 基準 ＋ rand() % 基準 − 基準 ÷ 2 ＋ rand() % 100   ; 基準 ＝ 0 時第一項當 0
量   夾進 0 … 艦艇[+0x08]
```

再交給實扣：

```
if 艦艇[+0x04] == 7: 不受損
實扣 ＝ min(艦艇[+0x08], 量)
艦艇[+0x0E]、[+0x12] 按 (原艘數 − 實扣) / 原艘數 等比縮減
    （艦種 ≠ 5，而且艦種表對應欄位不是 0xFF）
艦艇[+0x08] −= 實扣
艦艇[+0x0C] −= 實扣² ÷ 艦艇[+0x0A]
ds:8FE4[敵方 × 4] += 實扣 ÷ 20 ; ds:8FEC[敵方 × 4] += 實扣 ÷ 20
```

## 順帶：瞄好的要塞砲會嚇阻攻擊

`20B4:019B`：打行星的目標挑選在較遠的那個距離帶會檢查
「行星有要塞 **且** `+0x45 == 3`」，成立就**不**把那支艦隊標成
「要打這顆行星」（`+0x70 |= 2`）。所以瞄準本身就有防守效果。
