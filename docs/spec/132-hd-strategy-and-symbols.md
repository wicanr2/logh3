# 132：策略星域面材與高解析操作符號

狀態：限定CONFORMED（2026-10-11）。依使用者已選A原配置方向，限呈現。兩陣營正常視窗、32區域色號區別、原色重播、裁切及未知符號回退通過，證據見[交付111](../playtest/111-production-hd.md)。不宣稱原版全遊戲一致。

## 已核來源

策略星圖沿[12](../internals/12-strmap-bit.md)、[13](../internals/13-strmap-rgn.md)與`BuildStarMap`。底圖320×300、32原遮罩、當幀色號及既有畫序均可直接提供，無需從畫面反推勢力。第124輪已示範去除區域底色點陣、保持前景的A面材。

`SPRITE.SPR`實際75張16×16。原匯出逐索引目視：20至35及50至65為1至16；36至43及66至73為B、H、C、A、D、T、E、P；44及74為概略未知符號，不能補艦種。0至7為八向箭頭。來源映射沿`rules.BattleCachedSprite`與[38](../internals/38-battle-units.md)，實際原圖在`assets/original/sprite/`。游標沿`cursor.json`的13×16矩形、熱點及裁切。

## 契約

1. 策略圖另附底圖、32區域覆蓋及本次32色號；`Image.Pix`與存檔不變。正式首次貼圖與目的地選取提層共用同一入口。缺metadata或材質即回原圖。
2. 區域面材在原遮罩內重畫，使用正式32色號。去除底圖0、1、3、6、12的底色點陣；其他原前景及其位置保持。色號各有不同明暗／色相，不能把敵我或情報等級合併。原航路、英文星名、星球與徽章暫留原前景，這一批只算策略面材完成，前景重繪另驗。
3. 已知單位框在原16×16內重畫深色面板、原陣營色邊及原數字／字母，高解析字型仍依來源符號，不讀隱藏的敵艦種或編號。44／74保留原未知符號；缺字或未知索引回退。沿實際選定sprite索引，不用Unit資料猜補。
4. 八向箭頭依已選索引重畫原方向，保留原偏移、可見條件與場域裁切。後畫選取框與陣形標記照原畫序。
5. 游標依原熱點、13×16與原裁切重畫高解析箭頭。形狀不得外溢或改變命中；原模式色號完全保持。

## 驗收

2026-10-11追加READY呈現審查：策略前景沿實際320×300匯出PNG逐點標記32個英文星名與節點位置，不讀未知RGN欄位。標記只用於重畫，不能驅動點選或航路。英文拼字保持原圖，32個節點與徽章不改位置。原圖0、1、3為點陣底色，其餘色號先以連續取樣保留；6／12同時用於星球，不得整類抹掉。32星名用既有HD半形字型壓入原文字矩形，節點沿原類型與大小畫球面。航路、區界與靜態標記沿原像素連續取樣，不能新增連線。

原色重播零差；32遮罩與色號採樣、疊窗順序、已知與未知符號、八向箭頭及游標邊界抽驗。正式正常兩陣營、S1進場／下令與存讀繼續沿130。原版same-state不新增。
