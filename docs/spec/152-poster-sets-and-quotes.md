# 152：三組海報及多語名言

狀態：限定CONFORMED。三組海報由使用者指定，屬remake顯示擴充，不是DOS原版行為。既有外框、中央4:3及座標契約沿151，不改六表存檔。

## 已確認需求

- v1：左萊因哈特、右楊威利，保留既有原圖。
- v2：左帝國將領、右同盟將領群像。
- v3：左萊因哈特親近者，包含安妮羅潔、齊格飛；右楊威利、菲列特利加及親近夥伴。
- v1兩側下方加斜體名言；簡體、繁體、日文、英文、韓語各有文字與可顯示字形。
- 海報預設關閉，新選項沿玩家偏好保存。所有素材、完整提示、參考及生成來源保留本機。

## 查證與待定

官方[帝國人物頁](https://ginei.jp/character_g.php)及[同盟人物頁](https://ginei.jp/character_d.php)提供經典動畫造型與人物關係，僅為美術參考，不作DOS證據。名言需另附可回查出處，翻譯若為本專案所作，明確標示，不冒稱各語官方台詞。

使用者已明確回答「海報名言+遊戲界面」。五語顯示沿[153](153-interface-localization.md)，不得只翻海報便宣稱五語遊戲介面完成。v3右側先採已展示名單：楊威利、菲列特利加、尤里安、卡介倫、亞典波羅、先寇布；左側另含希爾德。v2兩側各五人，左萊因哈特、齊格飛、米達麥亞、羅嚴塔爾、奧貝斯坦；右楊威利、亞典波羅、卡介倫、先寇布、波布蘭。

## 實作契約

- 設定頁海報鈕循環關閉、v1、v2、v3；首次開啟用v1。增加獨立語系鈕，五語共同控制遊戲介面與名言。
- `poster_mode`保留，新增`poster_set`與`locale`偏好鍵。舊偏好缺鍵採v1、繁中；未知語系或組別回報，不改其他鍵。保存失敗不套用。
- v1沿原圖縮放，底部預留名言安全區，人物不被文字遮住；v2／v3優先用窄幅群像，等比例滿高，所有人物臉部留在中央安全區，不把臉裁去。僅有初稿時完整等比例放入側欄並保留深色背景空間，不拉扁人物。初稿及窄幅修訂來源皆保留。
- 六張圖片一次載入、渲染結果快取。缺少某一組時該組不可選，不使其他組失效；所選組缺圖退回可用組，所有組缺圖退回4:3。
- 名言採短引文：萊因哈特「ああ、星はいい……」，來源為[官方堀川亮訪談](https://www.ginei.jp/interview7.php)；楊威利「やはり平和が一番だ」，來源為[動畫台詞整理](https://animemanga33.com/archives/72709)及[獨立引述](https://note.com/tomo_hikonyan/n/n2c53daaca911)。中文、英文、韓文為本專案翻譯，不稱官方譯文。完整出處寫進本機`assets/hd/poster/QUOTE-SOURCES.json`。
- 文字以UTF-8 TSV為唯一來源，由同一字型遮罩繪製五語；名言加斜體，換行、字距與最長英文均須落在側欄底部安全區，無缺字、裁切或覆蓋人物。
