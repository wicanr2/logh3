# 021 — 戰術選單「資料」

狀態：**CONFORMED**（三個分頁的版面；艦隊與行星分頁的內容，
含補給欄）／**未解**（捲動、點某一列開出來的明細）。
證據：`docs/re/109`、`docs/re/111`。
收據：`s3data`、`s3data0`、`s3data_planet`、`s3data_enemy`。

## 它是什麼

戰鬥中按戰術選單第二項「資料」開出來的一層，蓋掉戰場那一塊
（x 16–462、y 60–419）；右邊的小地圖與狀態欄留著不動。上排三個標籤
切三張表：艦隊／行星／敵艦隊。

## 文字（confirmed）

**一行是一條字串，不是逐欄擺位。** 起點固定 x ＝ 48，一格 16 像素：
字碼 ≥ 0x80 是一個全形字，否則是**兩個半形字併成一格**
（`docs/internals/31`）。三張表頭是原版記憶體裡寫死的 48 位元組字串
（線性 `0x580D5` 一帶）：

```
艦隊資料                        艦數  最大  士氣
行星資料          經濟力  防衛力  補給  BHCADTE
敵艦隊資料                      艦數  最大  士氣
```

照這條規則排，量到的七個欄位 x 逐一對上（艦數 304、最大 352、士氣 400、
經濟力 192、防衛力 256、補給 320、BHCADTE 368）。

一列的內容也是字串接出來的：

```
艦隊  第<兩個半形數字>艦隊  <18 個半形寬的名字>  <艦種>  %4u／%4u   %3u
行星  <16 個半形寬的名字>  %6u  %6u  Mo:Fo <七個旗標>
```

`第Ｎ艦隊` 只在該艦隊的第一列印，其餘列從名字那一欄開始。
**最左那一欄用擁有者的陣營色**（帝國 6、同盟 5），其餘色 7。
不是自己的行星，補給那兩欄整段印死字串 `M*:F* *******`。

艦種那一格印的是**全形的代號字母**，一種艦種一個，來自記憶體裡的
字串 `BHCADTE`（戰艦Ｂ／高速戰艦Ｈ／巡航艦Ｃ／航空母艦Ａ／驅逐艦Ｄ／
運補艦Ｔ／修護艦Ｅ，`docs/re/111`）。行星那個分頁的第四欄用同一組
字母當欄名，每一列七格 `o`／`x` 是這顆行星對七種艦艇各能不能補給。

## remake 這一側

`screen.BattleDataSpec`／`DrawBattleData(spec, fb, fnt, tab, rows)`。
`rows` 是一列一列的 `BattleDataRun`（起點 x、顏色、字碼），內容由
呼叫端從戰場狀態算；規格只管版面與三條表頭。

士氣那一欄是**艦艇記錄的 `+0x06`**（一個位元組；`+0x07` 固定 `FF`）。
用 `-poke` 把某一個分隊的 `+0x06` 改成 77，畫面上只有那一列的士氣跟著
變（收據 `s3morale`，`docs/re/111`）。

行星分頁的欄位：名字是行星記錄 `+0x00` 起的 Big5（`00` 結尾）、
經濟力 `+0x1A`、防衛力 `+0x14`、名字的顏色是 `+0x11` 擁有者的陣營色；
列的順序就是 `Planets.Range(星域)`。

補給那一欄（反組譯 `0x140A5` 起，`docs/re/111`）：`+0x11` 不是玩家的
陣營就整段印 `M*:F* *******`；否則 M 看 `+0x3C`、F 看 `+0x40`、
七格看 `+0x20 + 艦種 × 4`，判準一律是「那個 32 位元非不非零」，
非零印 `o`、零印 `x`。七格的順序就是 `BHCADTE`（艦種 0–6）。

對拍三層：`TestBattleDataMatchesOracle`（艦隊分頁的版面）、
`TestBattleDataTabsMatchOracle`（行星、敵艦隊分頁的版面）、
`TestBattleDataContentMatchesOracle`（**內容**——表上每一格都由遊戲從
原版資料檔算出來，艦隊與行星兩個分頁），全部 **0／160,920**，
含原版自己畫的游標。

### 允許差異

**目前是空的**（`Game.battleDataUndecided` 回 nil）。留著這個掛勾是因為
對拍契約要求允許差異必須事先列出確切座標與理由，而規格與測試要讀
同一份座標，不能各記一套。

  的來源還沒對完，所以 remake 還沒畫——目前點一列等同關掉整張。

  「艦隊士氣值　統率力」——點某一列大概還有一層明細，未取證。
- `+0x3C`／`+0x40`／`+0x20`+ 這幾個欄位**本身**是什麼（畫面只用它們
  非不非零）。
