## 正式輸入與合成

- 下方採097的typed場景；保留全部一般分隊，不提前刪掉零艘分隊。
- 上方按陣營索引，採096的分隊文字資料；Ships、Side、Squadron、Detail與可見設定須與選取來源一致。
- 量表是兩側艦隊完整度0..100，不用文字艘數比例代替。
- 圖段列表是已選定的原始四byte名稱、陣營及最後格索引，從第0格順序重播至該格。
  靜圖名稱固定D0，完整攻擊及中彈保留XOR格；缺段或越界回error。
- 武器標題依攻方；結果字色依目標。各自採096格式與色號契約。

## 裁切與計時停止線

目前兩陣營艦種滿編表均為3000／3000／4000／2000／3000／3000／1000／1。
數值直接核固定RAM的DS:4E3A每26byte首word。原版新編艦艇取min(存量,滿編)，
見研究215；正式新編沿BuildComposition與FleetEditor，戰損不增加艘數。
本合成器只接受0..4000艘的下方分隊；選取分隊滿編須1..4000且Ships<=ShipsMax。
這是目前資產及一般編成的支援範圍，不宣稱所有外部修改存檔也在此範圍。

正艘數的堆疊數為1..8；可見Y220..376，方塊頂部最低192，攻擊標籤最低172。
兩者均高於095裁切上緣虛擬Y168，不會產生零高度相切。
零艘時不畫方塊，選取標籤仍依097計算。65,001艘的131塊診斷不因此變成合法域。
此限制不放寬095對未支援裁切的error，也不猜補原版下溢。

1DD6:0152、3958:0005、348A:01DC／0281的原bytes已核對固定RAM。
底圖的每格常式設8／4／0倒數，開場沒有另一個固定八tick等待。
動畫關閉時八tick的既有觀測包含原版繪圖CPU耗時；不能直接在Game加固定八tick。
維持硬體規格近似的tick duration，不深入driver／ISR或換算原版步數為實機秒數。
