## 無戰鬥星域清理

0374:03E8在星域+13 bit2未設時走0556；補充、耗損及0919之後，
0556:058F呼叫0AF2，再判bit4並打行星或處理被動效果／叛亂。
0AF2掃32槽，跳過+04=FF及其他星域；將+48完整byte設4，編制內各艦艇+17清零。
不動獨立偵察隊、索敵旗標、衰減計數或其他座標。戰鬥分支不經此清理。

- typed艦隊切片已排除原版+04=FF槽，編制已依+0F解碼。偵察隊獨立指標不列入。
