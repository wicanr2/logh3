# 025 — 戰場的「編隊」命令

狀態：`CONFORMED`（41 格座標 41／41、標記 30／30 逐位元組；行為面
「留在原地也可選」「選完不必再下移動」照原版）

證據：`docs/re/130`、`docs/internals/46`、收據 `s3form`。

## 觸發

分隊命令選單（`docs/spec/023`）三張分隊表的**第二項**。索敵那張的第二項
是「歸隊」，不算。旗艦（艦隊表）沒有這一項。

## 畫面

進去之後，把這支艦隊 41 個隊形槽裡**沒有分隊佔著的**每一格畫一個
`SPRITE.SPR` 第 11 塊的 16×16 標記（色號 0 透空），位置 ＝ 槽位偏移依
艦隊朝向旋轉、加上艦隊位置、減視野原點。分隊照常畫在標記之後。

**發令的那個分隊自己的格子也算空的**——「留在原地」是合法選項。

## 操作

| 動作 | 結果 |
|---|---|
| 左鍵點在某個空格子的 16×16 上 | 換到那一格 |
| 左鍵點在別處 | 取消 |
| 右鍵 | 取消 |

命中判定從槽 0 掃到槽 40，**先中先贏**（格子會互相重疊，所以順序有意義）。

## 選下去寫什麼

```
艦艇 +0x05 = 槽
艦隊 +0x10 + i×4 + 3 = 槽          ; 同一個值的第二份
艦艇 +0x1E = 0x7F                  ; 行動清成「沒有」
目的地 = 艦隊位置 ＋ 槽位偏移旋轉   ; 立刻算好
```

所以下完「編隊」不必再下「移動」，分隊自己會往新位置走。

  要改回讀艦隊記錄。
