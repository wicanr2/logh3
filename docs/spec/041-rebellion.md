## 原版做什麼

### 什麼時候

一次「實行」裡分兩段，**判定全部跑完才輪到效果**：

```
056A:000C（命令階段那一串）
  … 056A:09EB 扣維持費 → 056A:0AA5 民心 → 056A:03E0 艦隊移動
  → 2703:051D → 2703:0853 重數艦隊（+0x28／+0x29）
  → 056A:0469：逐格清 bit1｜bit2｜bit4 再重填
               bit2（雙方都有艦隊）、bit4（單方面占據）都沒設的格子才問 2703:1789
               回非 0 → +0x13 |= bit1，並跳一則模態報告 056A:06F3
0374:03E8（逐格開戰）
  for 星域: bit2 → 開戰
            否則 0374:0556 → … 2703:1B48 / 2703:1CD7 / 2703:1D85 …
                             bit1 → 2703:1908(星域, 0)，再清 bit1
056A:078E（回合尾巴：依行星重算擁有者 …）
```

- 戰略 AI（電腦座位的回合）在 `056A:000C` 之前跑完，所以**叛亂抽亂數排在
  AI 之後**。收據 `rbx292` 的 `#216,000,000`（AI 已建完艦隊）與
  `#218,000,000`、`rbx292e` 的 `#218,300,000` 種子都是 AF5AAD71，`rbx297w`
  量到 `056A:0469` 進場（`#218,363,857`）時也是：AI 結束到叛亂之間沒有別的
  東西抽亂數。
- 民心收斂（`056A:0AA5`，`docs/spec/040`）在它之前。門檻讀的未安定度
  `+0x7D` 在同一次「實行」裡整份重算好幾次（AI 回合裡七次），**叛亂讀的是
  命令階段那一串開頭 `056A:09EB` → `090A:0E6D` 那一次**，之後到回合尾巴都
  不再重算（收據 `urx299w`，[`docs/spec/042`](042-region-unrest-recompute.md)）。
- 續接戰鬥的那一圈不跑 `056A:000C`（`docs/re/251`），所以一回合只判一次。

### 判定 `2703:1789(星域, far* 已失格數)`

```
編號 == 0 或 == 31                          → 0     ; 看編號，不看擁有者
星域[+0x12] == 2                            → 0
星域[+0x28 ＋ 擁有者] != 0                  → 0     ; 自己在這一格有艦隊
r1 = 亂數 % 400 ；再抽 4 次丟掉
r2 = 亂數 % 400 ；再抽 4 次丟掉              ; 一格固定十次
u  = 星域[+0x7D]
f  = u<50 ? u÷3 : u<100 ? u÷2 : u<150 ? u×3÷4 : u×4÷3
門檻 = f × 100 ÷ 提督[ds:8F4D[擁有者]][+0x0E] ÷ (已失格數[擁有者] ＋ 1)
r1 ＋ r2 < 門檻 → 1                         ; 無號比較
```

- 除法全是無號 16 位元（`div`，往下取整）。`f × 100` 最大 34000，不溢位。
- `ds:8F4D[陣營]` 是該陣營的**情報專任參謀**；電腦座位每回合在 AI 的尾巴
  會換人（`docs/re/268`），所以用的是**換過之後**那一位。
- **`+0x28 ＋ 擁有者` 是 `2703:0853` 剛重數的值**：照艦隊移動之後的位置，
  每支在用的艦隊（`+0x04 != FF`）都算，不看 `+0x00` bit0（`docs/re/297`）。

### 已失格數 `2703:09DD`

`056A:0469` 開頭算一次，整圈不變：

```
對每一格：現在 == 2、開局 == 2、開局 == 現在 → 跳過；否則 lost[開局]++
```

「開局」是 `ds:B75C`：唯一的寫入點是新遊戲初始化 `2703:0068`，**讀存檔不
重寫它**，所以永遠是 796 年 1 月開局那一份（`docs/re/297`：25 份 S3 起跑的
傾印全部是開局那一份）。被翻成無主的格子不算「丟掉」。

### 效果 `2703:1908(星域, 全部旗標)` → `2703:1ADB(行星)`

```
星域[+0x12] = 2
（依經濟力遞減 qsort 行星指標——結果沒有被用，見下）
n = 全部旗標 || u > 160 ? 整格 : u > 120 ? min(2, 行星數) : 1
u > 80（或走前兩條）→ 從切片第 0 顆往後 n 顆
u ≤ 80              → 最後一顆
每顆：行星[+0x11] = 2
      行星[+0x1A] −= 行星[+0x1A] ÷ 3                        （32 位元）
      (行星[+0x14] × 3) 的低 16 位元 < 行星[+0x16] → 行星[+0x14] = 0
      否則 行星[+0x14] −= 行星[+0x16] ÷ 3                   （16 位元）
```

**qsort 的結果沒有被用**：兩條迴圈都拿 `ds:CFF8` 那個原始切片走，排好的
陣列一個位元組都沒被讀（`docs/re/292`）。翻的是切片的第 0 顆或最後一顆，
不是最有錢那顆——1994 年那份原始碼的 bug，**照原樣保存**。

`+0x12 = 2` 是暫時的：回合尾巴依行星重算擁有者時，一格全同陣營的星域掉
一顆之後混雜，重算出來也是 2，所以**不跳易主報告**（舊值已經是 2）。

## remake

```go
rules.DecideRebellions(rules.RebellionInput{…})  // internal/rules/rebellion.go
rules.DepartNeutralPlanet / RecoverRegionDefences / ResetRegionFortressGuns
rules.Rebel(星域記錄, 行星表, 星域, false)
Game.runRebellions()                            // internal/game/rebellion.go
```

- 接在 `Game.advanceTurn` 艦隊移動（含移動花費）之後、找交戰星域之前。
  判完 32 格後逐格檢查 bit2／bit4 對應態勢；有戰鬥或單方占據就跳過，
  否則依原順序執行 `1B48 → 1CD7 → 1D85 → 1908`。無主格的 `1B48`
  與叛亂共用 `Game.rand94DC()`；防衛力先回復，之後才套叛亂扣除。
- 亂數用 `Game.rand94DC()`，就是戰略 AI 那一份（`strategyRand`，原版
  `ds:94DC`，開局種子 `D3DC167E`）。原版只有一個全域種子，remake 也只留
  一份；`OriginalBrain` 改成從同一支取。
- 駐軍數直接數 `g.fleets`（`rules.CountFleets`，＝ `2703:0853`）；bit2／bit4
  用 `StarGraph.Occupations`（＝ `297B:14F8` 那條，同一圈先算）。
- 開局快照是 `Game.worldStellar` 的 `+0x12`：新遊戲那一份，讀存檔不換。
- 結果留在 `g.rebellions`／`g.rebellionRolls`；**報告畫面還沒有**
  （`strategy-report-screen`）。
- 營運 0 時原版會除以零（INT 0）；出貨資料沒有這種提督，remake 當門檻 0。

### 亂數

**一格固定抽十次**：過了三道閘門的格子抽十次、只用第 1 與第 6 次；沒過的
一次都不抽。收據 `rbx297w` 逐格量過：32 次 `2703:1789` 裡 19 次各抽十個，
整圈 190 次，種子 AF5AAD71 → 936A823B（`docs/re/297`）。

**remake 在叛亂之前的亂數次數與原版相同**：新遊戲第一個 AI 回合原版抽 7 次
（建三支艦隊 × 2 ＋ 階段四伊謝爾倫那一格 1），remake 正式入口（載了進軍路線表）
也是 7 次，叛亂那一圈進場的種子同為 AF5AAD71。階段四只對「從首都走得到」的
敵方格子計分（`2B99:0392`，規格 [`043`](043-ai-capital-reach.md)），那一局
只有伊謝爾倫走得到。**叛亂這一支不補抽、不遷就**：上游 AI 的亂數次數與原版
不同時，叛亂的結果跟著錯位，修法在上游。

## 沒有驗到的

- **效果讀的未安定度**：原版的效果（`2703:1908`）排在逐格開戰那一圈裡，較小
  編號那幾格的戰鬥可能先動到艦隊；remake 判完直接套效果，用的是命令階段那一次
  的值（`docs/spec/042`「沒有驗到的」）。同一回合裡同時有叛亂與戰鬥時才可能不同。
- **報告畫面**：原版每一格叛亂跳一則模態報告（`056A:06F3`，`ds:085D`＋
  `ds:086F`，字色 `ds:6096[擁有者]`、頭像 `ds:8F4D[擁有者]`），滑鼠關；
  remake 的玩家可見切片與剩餘時序限制見
  [`docs/spec/046`](046-rebellion-report.md)。
- **`0374:0556` 的其餘三支**（`2703:1B48` 無主格裡再跑掉一顆行星——**抽亂數**、
  `2703:1CD7` 防衛力回復、`2703:1D85` 要塞砲重置）remake 都沒有
  （`region-turn-upkeep-0556`）。`1CD7` 在同一格排在叛亂效果之前，接上時要
  維持這個順序；`1B48` 接上之前，叛亂之後的亂數序列還會再差。
- **費沙事件**那個呼叫端（`2703:1908(星域, 1)`，整格脫離）跟著
  `phezzan-event-trigger`。
- 對戰模式沒有收據。
