## 開局契約

1. 新遊戲還原原始行星表後、月底成長之前，依 `2703:15D5` 重算星域
   `+0x16`／`+0x17`／`+0x18` 行星數、`+0x14`／`+0x15` 陣營經濟比例，
   行星 `+0x13` ＝ `floor(初始經濟力×100／星域初始總經濟力)`。
   防衛力 `+0x20` 與上限 `+0x22` 分別加總行星 `+0x14` 與 `+0x16`。
2. 清開局態勢旗標，首都路徑成本取新遊戲樣板的 0；再依既有 `2703:0933`
   規則重算旗標與有主星域成本，無主星域保持 0。其餘未證實欄位不推測重設。
3. `2703:046A` 只對 `3982:022D(陣營)==1` 的電腦座位執行：首都星域
   全部行星的七種艦艇 32 位存量左移一位（溢位照 32 位）；不改飛彈／艦載機。
   重彙總首都艦艇。人類座位不加倍，重新開局先還原原始行星資料，不能重複疊加。
4. 按行星初始存量彙總星域飛彈／艦載機，使用初始經濟力＋防衛力回充及夾上限。
   **不分配回行星**。之後開局成長、預算與結算照規格 003／035。
5. 行星情報窗既有的即時分配保持；開局初始化不得拿開啟情報窗後的狀態當作
   命令階段的初值。全回合分配／彙總／回充的時序另行驗證，不能藉本規格宣稱一致。
6. 測試與正式載入器都必須從同一產品流程取得狀態，不硬編原版的最後記錄。
