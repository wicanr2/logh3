# 062 — 戰場一個回合的結算：原版的八步

狀態：**子步 8-1（全滅與士氣報告）READY**；其餘七步與子步 8-2–8-5 **DRAFT**（只有位元組與一份執行期時間線）。
證據：`docs/re/339-battle-turn-eight-steps.md`（位元組 ＋ 執行期時間線）。
原版：`181B:000A`，唯一呼叫者 `12AA:00D0`（回傳非 0 ＝ 整場戰鬥結束）。

## 為什麼要有這一份

remake 的 `AdvanceBattleTurn` 是自己排的順序（移動 → 交火 → 要塞砲 → 打行星 → 收尾）。
原版是八個固定的階段，而且**第 8 步整步沒有實作**——戰場的艦隊全滅、戰鬥中的士氣報告、
提督升級、星域換手、結束判定全部在那一步。要接 #57 的戰場那一條，得先有這張順序表，
否則接上去的東西會落在錯的位置。

## 戰鬥中當場印士氣報告的五個時點

`1261:0104` 印的是**積著的**報告（扣艘數時只設 bit2／bit3，不當場印）；當場印的另有四處：

1. 第 ① 步 `1AAB:0182` → `1261:000B(1)`（修理／補給之後）。
2. 第 ⑧ 步 8-1 的 `185C:008F` → `1261:0104`（沒被消滅的每一支各一次）。
3. 電腦戰術 AI（八步之外）。
4. 修理／補充指令（八步之外）。
5. 撤退 `185C:0D34`（八步之外）。

視窗是 `3826:0405` 的臨時視窗（規格 059）。
