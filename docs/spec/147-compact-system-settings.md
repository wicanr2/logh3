## 證據審查

已證實的remake根因：`internal/game/enemyvisibility.go`將敵軍按鈕放在(176,360)-(304,380)，`cmd/gin3/soundfont.go`其後以音色庫標籤覆蓋(176,360)-(296,380)。`rule_settings.go`另把兩項規則畫在原視窗底部400之外。此為目前程式的繪製覆蓋問題，不是新原版逆向結論。

既有`Game.SetAILevel`支援-1原版與0至3強化，重接現有戰略及戰術策略。`AILevel`可讀回，既有測試涵蓋合法值、拒絕非法值、正常新局與存讀。UI只接現有API，不增加AI演算法或猜補原版行為。DRAFT已完成上述來源及操作審查，據此升READY。

- 顯示敵軍預設關閉，可獨立開關，仍只影響呈現，不寫原版六表。驗收與README必須有實際開啟及戰場可見證據。
