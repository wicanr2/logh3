## 正式實作範圍

- 從`StateBattle`開保存畫面時記錄返回戰場。點有效保存列且`SaveSlot`成功後，直接回`StateBattle`，關閉戰術選單並刷新游標命中。
- 不重新建立戰場，不實行回合，不清除或重建艦隊、分隊、行星、鏡頭、分數、命令與亂數。
- 六表仍走既有`SaveSlot`；保存失敗留在保存畫面並保留既有錯誤回報。原版磁碟錯誤視窗不在本輪新增範圍。
- 戰略入口的返回行為保持既有契約。本輪未取得戰術取消保存的原版實驗，不以保存成功推論取消語意。
- 不改存檔格式，不增加瞬時動畫資料或seed欄位。冷啟動續戰已證實原版可達，但正式讀回重建尚未實作，不由本契約升格。

## 驗收

原版雙跑需逐檔一致。remake以正常S3路徑到戰場，公開保存後立即回原戰場，戰場／回合／鏡頭／命令與seed不變，六表落地；公開實行仍可續下一回合。失敗保存不能假稱成功或離開畫面。
