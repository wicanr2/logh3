# 149：全局提督能力編輯

狀態：限定CONFORMED。使用者核准三分頁草稿、全局共用且新遊戲套用，並將楊威利與萊因哈特的全軍攻擊加成改定為30%。資料、規則、全局保存、Linux正常GUI及重啟／讀檔驗收見[130](../playtest/130-admiral-editor.md)與[來源索引](../images/admiral-editor.json)。標準19套件15 PASS／4無測試。後續v.1.5.0三平台封包、Windows Wine及新版正式包GUI另見[131](../playtest/131-admiral-editor-delivery.md)。本功能是remake擴充，不宣稱原版編輯器或新增加成具有DOS parity；沒有新增Windows／macOS真機驗收。

## 證據與審查

原版十項能力及三項內部能力的結構位移依[能力表08](../internals/08-admiral-dt.md)、[研究287](../re/287-admiral-remaining-fields.md)。已證實用途與未知原版欄名維持分開；不改狀態、陣營、等級、功績、副官或艦隊引用。原始輸入來源及雜湊由本輪草稿`manifest.json`綁定`admiral.json`、`keireki.json`與研究來源；本輪不重跑原版。

現行`RuleOptions`、`writePreferences`已提供獨立全局偏好及原子寫入；`mutableAdmirals`提供原始輸入以外的可寫複本。`FleetAbilities`及升級重算提供既有能力派生公式。正常艦隊交火由`applyFleetSceneDamage`提交，動畫關閉仍走同一命令／傷害流程。新增加成在原公式外明列，不更改未啟用時的原版算式。

## 資料與保存

- `preferences.json`新增`admiral_editor`物件，版本1，按提督索引保存稀疏能力覆寫及特殊能力。沿原子寫入，保留音色、規則及未知鍵。不存在時採現行基本能力及預設特殊能力，壞格式顯示錯誤，不覆寫壞檔。
- 只有使用者編輯的能力持續覆寫；未編輯欄位保留劇本／存檔與升級結果。套用時修改目前遊戲，讀檔及新局套用同一全局覆寫。原版六表格式保持，保存時自然包含當局已套用能力。
- 十項基本能力及三項內部能力使用1至200。營運及內部除數不接受0。換艦率0至100%；移動／攻擊增幅0至200%，0代表沒有加成。無效輸入保留編輯視窗，未套用資料不改Game或偏好。
- 武器能力另以[當前艦種表](../internals/data/ship-kind-table.json)的16艦種／256角度驗證防禦係數，要求取整後始終大於0。[驗證器](../../internal/rules/admiraleditor.go)由正式Game套用及啟動載入呼叫。現行資料的下限為3，低於此值拒絕套用／啟動載入，不能改傷害公式來遷就無效設定。
  下限是各艦種與角度的`ceil(100 / EllipseRadius(a,b,dir).Int())`最大值；沿現有整數公式推導，不使用浮點近似作正式判定。
- 還原本提督將十三項能力還原啟動時原版資料的值，特殊能力回到預設。取消放棄所有未套用變更，套用成功後仍留在編輯頁。寫檔失敗不提交Game改動。

## 特殊能力

### 戰鬥機加成擴充：限定CONFORMED

使用者確認坎普與波布蘭本人艦隊戰鬥機攻擊預設+30%，並補充擔任參謀也生效。人物索引由`keireki.json`核對為10及74。這是使用者指定的remake規則，不推定為原版隱藏效果。

- 新增逐人`fighter_attack`百分比，範圍0至200，預設10及74為30，其他0；沿既有全局特殊能力保存、取消及還原。既有已明確保存的特殊能力物件若沒有此鍵，按0解讀。
- 只在強化模式的戰術艦隊交火生效。從攻擊艦隊的提督與參謀取較高值，不相加，也不作用於友軍其他艦隊。無參謀的255索引不提供加成。本人艦隊存活分隊均適用，旗艦轉移不移除該能力。
- 僅戰鬥機武器2增加攻擊係數；先套全軍攻擊倍率，再套此倍率並各自取整。例如兩者均30%時為1.3×1.3。光線砲、飛彈、防禦、射程、庫存、亂數及動畫速度保持既有流程。動畫開／關共用提交點。
- 特殊能力頁延伸第四列「本艦隊戰鬥機攻擊」，列距40，保持原外框、頭像、分頁與底部操作。說明顯示提督／參謀均生效。兩陣營正常入口驗預設、編輯保存及重啟；規則驗兩角色、其他武器排除、雙提供者取最大值、原版模式及實際傷害／庫存／RNG。

此擴充經READY後實作，r6兩次正常啟動、十一張完整畫面、兩人預設及編輯保存、坎普跨重啟與S1讀回通過。標準19套件15 PASS／4無測試；角色與武器隔離及傷害測試通過。來源、輸入、正式二進位與畫面由[同一索引](../images/admiral-editor.json)綁定，方法與限制見[130](../playtest/130-admiral-editor.md)。沒有新增實戰自然觸發、DOS原版或其他平台真機聲明。

- 預設換艦率：謬拉100%，其他25%。改為逐提督設定，既有轉移旗艦總開關保持。0與100不消耗不必要的成功判定亂數，1至99依原有一次判定。
- 預設移動增幅：提督0萊因哈特及52楊威利50%，其他0%。沿既有名將移動總開關及強化模式閘門。只放大當回合新額度，餘額另加，不累乘；畫面移動範圍同步。
- 預設攻擊增幅：提督0及52為30%，其他0%。只在強化模式套用。
- 全軍加成提供者必須為本場存活且未離場的帶隊旗艦，副官不觸發；同陣營取最高值，不相加。無提供者或原版模式回到原公式。移動與攻擊分別取值，不依名將AI策略枚舉綁定。
- 攻擊增幅作用於戰術艦隊對艦隊的攻擊係數，先取整再沿原有防禦、庫存、亂數、損失、功績與演出。它不增加彈藥、不加速動畫，也不放大要塞砲及行星守軍反擊。戰略自動攻城的獨立公式保持，與既有名將戰術移動範圍一致。

## 介面

沿[本輪狀態表](../goal/2026-10-19-admiral-editor-round-142.md)所列草稿與原圖：640×480邏輯、外框(24,40)-(616,440)，左側陣營與提督清單、右側頭像及三分頁。原設定頁(176,378)-(288,394)新增編輯提督入口，其餘選項保留。

正式繪製、命中、GUI收據共用同一矩形來源。沿現行兩陣營配色、立體框、設定專用字形與正式頭像renderer。主欄12字格，標題14、姓名16、說明10，均由同一設定字庫生成有界遮罩；長字串按整字截斷，不繞過文字安全矩形。64×80頭像取完整原圖縮圖，不裁掉人物。內部能力使用用途標籤並顯示原版欄名未知；說明不宣稱前兩項越高越好。點數值進入輸入框，Enter確定、Escape／右鍵取消；編輯頁右鍵返回設定，未套用變更先確認。畫面不推進回合、鏡頭、局面或亂數。

## 驗收

1. 預設、稀疏覆寫、非法值、取消／還原、寫入失敗、未知偏好鍵及重啟持續。
2. 新局、讀檔、當局能力派生更新及原版資料唯讀；非能力欄位、艦艇池、位置、命令、庫存與功績保持。
3. 逐人換艦率；任意提供者的移動／攻擊、最高值、不累加、離場、原版模式及既有總開關；三武器與動畫關閉共用路徑。
4. 標準測試，正式正常入口進設定後編輯／取消／套用、重啟與新局／讀檔，兩陣營、原版／HD抽樣及完整截圖。單元測試不升格GUI或原版parity。
