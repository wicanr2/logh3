# 120：正常單人啟用既有戰術AI

狀態：**CONFORMED**（2026-10-06，限定本規格的活動政策與既有AI接線）。工作項目：[93](https://github.com/wicanr2/logh3/issues/93)。

驗收：[交付105](../playtest/105-local-full-test-package.md)及[來源索引](../internals/data/local-test-package.json)。正常公開S3兩模式各九回合，46個CPU分隊移動，命令不同；活動傷害回歸及標準13套件通過。Windows／Linux測試包已包含新政策。原版完整決策同態不在本規格範圍。

來源：使用者本輪明示選擇「啟用原版與強化戰術AI」。此決定取代061的正常單人被動政策。068的戰略模式生命週期保持；戰術部分依本規格。

## 證據及審查

- 已證實：`internal/game/aimode.go`的`SetAILevel(-1)`選`OriginalTactic`，0至3選`Encircle`。
- 已證實：`internal/game/battle.go`的`AdvanceBattleTurn`已有AI決策與`applyTacticalMove`，正式移動、索敵、交戰及結算已接線。
- 已證實：原先`passiveComputer`阻止正常CPU下令，還原傷害並凍结移動。移除正常預設阻止即可沿既有引擎執行，不需新造算法。
- 接線缺口：現有`applyTacticalMove`一律寫移動Action0，無法參與092已接的自動交戰。017已定義戰術進攻與集火，修復為共用玩家戰鬥命令的Action1、戰鬥速度及旗艦Action保持，非旗艦自訂位移仍沿既有算法。這是remake接線，不稱原版命令決策已證實。
- `internal/ai/tactical.go`的原版參考點仍有強推論限制，啟用不把它升格為完整原版AI同態。

DRAFT內容依既有程式、061／068與使用者裁決審查。範圍為被動政策預設與既有戰術命令接線，不改AI算法、傷害公式、六表格式或原版判準。具備可明示被動的歷史診斷與正常入口驗收，因此READY。

## 契約

1. 正常Game與CLI預設CPU戰術活動，能下令、移動與造成規則允許的傷害。
2. `-ai -1`走既有原版戰略與戰術；0至3走既有強化戰略及戰術。
   戰術目的地接玩家戰鬥命令；旗艦保留一般分隊狀態，使正式自動武器選擇可在射程內執行。
3. 玩家與雙人座位控制、公開命令、回合結算與存檔格式保持。
4. 明示`SetPassiveBattleComputer(true)`可保留061歷史診斷；新局與載入保持這項執行期選項，不寫入六表。
5. 驗收只要求實作及作用，不新增戰場差異對拍或雙玩家命令驗證。

## 驗收

- 正常S3公開載入與首戰，原版及強化各實際推進至少一個回合；記錄CPU命令、位移、玩家損失。
- 測試新預設不套被動傷害還原，明示被動仍能還原並凍結；不以改寫期望值掩蓋歷史差異。
- 專案標準測試通過，完整版以新修訂版本重建並列明原版AI的推論限制。
