# 154：游標分層、操作hover與工具列字型／AI

狀態：限定CONFORMED。2026-10-25，限[134正常操作、像素及封包驗收](../playtest/134-pointer-toolbar.md)覆蓋的remake顯示與工具列路徑。未作Windows真機或硬體端到端延遲聲明。使用者已明確要求滑鼠回應加快、選項及按鈕hover變色，工具列可調字型與戰略AI；字型選用現有Noto／思源黑體。

## 根因證據

150正式包正常收據顯示設定頁Frame中位16.8ms、整次Draw24.68ms，最高291ms。現行app將游標畫進索引畫布，HD畫面鍵包含這些像素及游標命令；游標移動會使整張CPU重播與1920×1440材質上傳失效。這是程式可核對的已證實路徑，不以60fps影片標示推論回應速度。

[pointer_probe.go](../../tools/scripts/pointer_probe.go)沿正常新局輸入取得主指令及系統選單。系統鈕實際框為(542,120)–(610,140)，DrawPanel角色為空；原hover另沿JSON舊滑鼠y而少40像素，正式點擊則使用commandBar的畫面座標。renderer又只接受ui/button／ui/primary，兩條路都需修正。系統下拉選單依Game的commandBar、barRow與rowHeight點擊，JSON hotspots與boxes皆空，hoverControlBounds沒有接這條路，因此存進度及設定同為0。修正探針主系統鈕7546、存進度4504、設定5907個HD像素變色。probe屬窄幅診斷，不取代正常GUI。

## 實作契約

- 正式Game.Frame、原色像素、輸入座標、1:1滑鼠距離、點擊熱區、六表及遊戲時鐘保持。加速的是顯示回應，不加速動畫或AI回合。
- 游標繪製前保存不含最上層游標的背景與Artwork可見遮罩。app先翻譯／渲染背景，再以GPU繪製原先的原色或HD游標，沿原clip及畫序，游標仍在工具列之下。診斷dump仍使用完整原畫布，不能把新版顯示分層誤稱DOS parity。
- 背景鍵包含原像素、完整命令、字型、陣營、色盤及hover。游標在同一控制內移動不重建背景材質；內容、hover目標、語系或字型變更仍失效。每次背景快取與完整重播須抽樣核對，不以狀態名稱猜測畫面靜止。
- 既有無角色的小框，只在與正式熱區同一列高且包含熱區時可辨為按鈕；不把大資訊窗當按鈕。選單列直接沿commandBar的正式點擊幾何，越界列不亮。文字背景屬控制內補畫時不抹除hover；上層不透明視窗仍遮住底層。
- 其他按鈕沿既有ui/button／ui/primary顯示角色，右下分頁沿既有Tabs幾何，無正式命中時才用可見按鈕回退。原版顯示的反光為GPU疊色，不改原索引像素；工具列遮擋時不點穿。
- 工具列保留F1與F7，新增字型及AI按鈕。字型選單只列已載入的原版點陣、原版強化、Noto／思源宋體及黑體，沿現有FontStyle，不另加字型或重排遊戲字格。與系統設定共享當前選擇。
- AI選單直接選原版／強化0–3，沿既有SetAILevel及本次執行契約，影響其後決策，不更改AI規則與存檔。與系統設定共享數值。
- 工具列及下拉選單共用繪製／命中矩形；開啟、選擇、取消、右鍵或Esc不點穿遊戲，關閉後可繼續操作。五語沿既有譯表，未載入字型不列出；HD不可用時字型鈕灰顯，不套用半載入資產。

## 驗收

有針對性的游標背景／像素重播、透明游標合成、hover遮擋與選單邊界測試；至少一條正常Linux及最終Windows Wine操作，覆蓋海報開／關、兩陣營、字型及AI同步、F1／F7、選單取消、六表存讀。相同容器與滑鼠路徑量測修改前後耗時及背景上傳，不保證所有硬體的固定延遲。標準測試通過後準備可替換的Windows程式，沿新完整版本命名，不覆寫v1.6.0。
