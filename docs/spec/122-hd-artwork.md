## 契約

1. 原圖解碼與 640×480 邏輯畫布保留。可選 HD 顯示使用 3 倍畫布 1920×1440，維持 4:3。視窗倍率仍以 640×480 為基準；滑鼠顯示座標除以 3 後傳入原有遊戲輸入。
2. `-graphics original` 保留既有顯示；`-graphics hd -art <目錄>` 載入 `<目錄>/face/face-NN.png`，按原索引替換。缺少單張 HD 圖時使用原图；明示 HD 但目錄無可用圖或圖損壞時回報錯誤，不冒充已載入。
3. 圖片預先解碼、校驗大小與索引範圍，以原圖尺寸縮放並快取。不得用 83 的預期值取代實際 FACE.AMG 索引數。限制輸入尺寸與檔案大小，避免錯誤檔案造成失控配置。
4. 人體圖片繪製沿原有索引與唯一座標，同時附加可见區域。每次後續 Set 都清除被覆蓋的 HD 區域；同色寫入仍算覆蓋。Clear 清除所有圖片記錄。HD 圖不能越過原本的裁切、蓋住後畫的文字、游標或視窗。
5. 未接 HD 的圖片與文字使用原圖。這個階段不新增字型、寬螢幕版面、按鈕或規則，也不宣稱所有美術已 HD 化。
6. PNG 截圖使用所選顯示模式；色號傾印仍保存原來的 307200 bytes。正常路徑、存檔、規則、AI、音訊與素材原索引不因顯示模式而改變。
