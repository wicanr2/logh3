## 規則

1. **在哪裡跑**：逐格處理 `0374:03E8`。這一格這回合有戰鬥（`+0x13` bit2）就進戰場、**不跑**下面這些；否則 `0374:0556`：
   補充（`1AAB:0FAF`，#71）→ **耗損與全滅（`0374:0608`）** → `0919` → `0AF2` → 單方面占據打行星或被動效果。
2. **誰會扣**：艦隊表順序逐支，`f[+4] ≠ FF`、停在這一格、陣營 `f[+1]` ≠ 擁有者 `星域[+0x12]`（byte 比，無主 2 也算）、
   `f[+0x00]` bit0（士氣低於 50）。士氣掉到 50 以下是在回合尾巴（`1261:00C8`），所以**掉下去那一回合不扣**，下一回合才開始。
3. **扣多少**（`0374:06BC`）：現有每一組 `n = min(⌊滿編 ÷ 6⌋, 艘數)`（16 位元無號），交給 `203A:0593(艦艇, n, NULL)`：
   艘數減 `n`、對手陣營兩個計分器 `ds:8FE4`／`8FEC` 各加 `n ÷ 20`（每組各自除）、每組扣完重算士氣（`1261:0067(f, 0)`，不印）；
   艦種 7 不扣、不重算。整條沒有亂數（S，含正對照）。
4. **全滅判定**：扣完**只看第 0 組**艘數是不是 0。
5. **全滅**（`0374:073F`）：先印報告（`3826:0307` 持久視窗、頭像是那位提督、等 `ds:8F38` 或點擊），**看完**才作廢艦艇
   （`2AD2:01EF`，不還存量）與 `297B:034A`：提督與副官 `28E0:057F(…, 0)`（`+0x09 |= 80`、`+0x00 ← 80` 失蹤、功績
   `+0x02..+0x05 ← 0`）、`f[+4]`／`f[+5] ← FF`、星域 `+0x28[陣營]` 減一、`090A:0E6D` 整份重算、`ds:8F49[陣營]` 減一。
   同一格接著從下一支往下（remake 拿掉那一筆，下一支補進同一個索引）。
6. **沒全滅**（`0374:0896`）：艘數 0 的組作廢並移除、後面往前遞補（語意取自解包後的原碼，與戰場那一支 `185C:0177` 同形），
   最後 `297B:0546(f)`。
