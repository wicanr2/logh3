## 這份規格要解決的問題

`docs/spec/017` 當時的判斷是「原版按『實行』時電腦不下任何命令」，
於是 `internal/ai` 的 `Original` 回 `nil`。那個判斷來自
`docs/re/79` 的量測，而量測的原因是**進入點沒被呼叫**，不是
「AI 決定不動」（`docs/re/175`）。原版有一整套戰略 AI，
收據 `s3aicomp` 證明它跑得起來（`docs/re/176`）。

這份規格描述那一套，並標出哪些部分還不能實作。

## 什麼時候跑

```
若 ds:8F23[ds:8F1E] != 1：不跑          ; 這個座位不是電腦
若 ds:8F46 != 0：清 0，這一次不跑        ; 「跳過一次」旗標
```

remake 對應：`World` 要能回答「這一回合是哪一方、那一方是不是電腦」。
`ds:8F46` 那個一次性跳過的來源（`0x2CCA7`，`[bp+08] >= 8` 之後設）
**還沒解**，remake 先不做。

## 一回合的順序

```
2D76:0002()   建艦隊
2D76:0732()   （未讀）
2E54:000C()   清表 → 逐艦隊決定 → 畫敵方兵力圖 → 算每格優先度
2E54:0344()   五個階段
```

### 清表

`ds:D50E`／`ds:D54E`／`ds:D5CE` 各 32 個 word 清 0，`ds:D60E` 清 0。

### 逐艦隊決定（`2E54:005D`，`docs/re/79`）

每一支先填 `+0x79 = 0xFF`；在**有戰鬥的星域**（`+0x13` bit2）
`2E54:16F5` 回非 0 就 `+0x79 = 3`、`ds:D5CE[所在星域]++`；
否則走 `2E54:1955`（往首都方向退一格）、`+0x79 = 0`。兩條都 `ds:D60E++`。

### 敵方兵力圖（`2E54:1A76`）

```
對每一支敵方艦隊 f（297B:131C(…, 0xFF, 2)）：
    行動 0 或 1 → 格 = 路徑上的下一格
    行動 5      → 格 = f 所在星域
    其餘        → 跳過
    ds:D54E[格] += f[+0x0F]
```

**收據對過**：`s3aicomp` 的四格全中，星域 25 是 69 ＝ 九支艦隊槽數之和。

### 每格優先度（`2E54:019F` → `2E54:0222`）

```
只算「與首都連通」而且「擁有者 ＝ 自己」的格子，其餘 0
ds:D50E[i] = Σ（相鄰、擁有者 ＝ 敵方的 n）:
    (n[+0x13] bit0 == 0 或 ds:D54E[n] > 4) ? 4 : 2
```

## 可以先實作的一塊：階段三

這一塊的每一步都有證據，而且不依賴未讀的常式。

```
對每個擁有者 ＝ 我方的星域 i：
    前線 = (ds:D50E[i] ÷ 2 >= 1) ? 1 : ds:D50E[i] ÷ 2
    缺口 = max(ds:D54E[i] − ds:D5CE[i], 0)
    ds:D58E[i] = 缺口 ÷ 4 + 前線
ds:D5AE[0..31] = 0
重複：
    格 = ds:D58E[g] != 0 之中 (ds:D5AE[g] × 100 ÷ ds:D58E[g]) 最小的那一個
         （ds:D58E[g] <= ds:D5AE[g] 視為 0xFF；首都 0／31 視為 0）
    沒有 → 結束
    艦隊 = 挑分數最高的候選（模式 0：完整度 ≥ 50、不要求編制滿、權重 3 2 8 1、主力門檻 0）
    沒有 → 結束
    若 艦隊[+0x06] == 格：（+0x08 != 5 時）+0x08 = 5、+0x07 = 0xFF
    否則：+0x08 = 0、+0x07 = 格
    ds:D5AE[格]++
```

候選分數（`2E54:1574`）：

```
無法戰鬥（+0x00 bit0）或走不到 → 0
分數 = (Σ 編制槽艦艇[+0x08] ÷ 10) × 艦隊[+0x3C] ÷ 100     ; 32 位元
     × 艦隊[+0x0F] ÷ 艦隊[+0x0E]
     × 權重[ 類別表[艦隊[+0x09]] ]
     × (艦隊[+0x08] != 5 且 艦隊[+0x07] == 目標 ? 2 : 1)
     ÷ (兩格距離 × 2 + 1)
     ÷ (主力槽數 < 主力門檻 ? 4 : 1)
分數 == 0 → 1
```

類別表（`ds:5F52`，16 格）：`0 0 0 0 0 2 0 0 0 0 1 1 2 2 3 3`。

## 不能做的

- **五個階段的骨架都讀完了**，剩下的未讀項（`0x1238D` 的費沙事件結算、
  `2E54:063C` 的排序鍵、`28E0:0103` 的 `0x25`）都不影響主流程的形狀，
  但**在補上之前不得把它們猜出來**——猜出來的行為對不上原版，
  會讓「照原版」這個宣稱失效。
- **`ds:8F48`（費沙進入戰局）由誰設還沒讀完**，所以 remake 先讓它固定為 0，
  並在報告裡寫明態勢碼只會落在 0／4／8。
- **不要用 remake 自己的亂數去湊 `RNG % 4`。** 階段四要對拍就得先把
  原版 RNG（`3CD5:000C`）的呼叫次序完全對上；在那之前階段四只能做
  不含亂數的部分，或整段先不做。
- 預設仍然是**原版**行為；這份規格描述的就是原版，不是強化版
  （強化版在 `docs/spec/017` 的 `Focused`）。

## 要使用者裁決的一件事

證據上的關卡都關了，接下來只剩一個**會改變 remake 行為**的動作：
把 `internal/ai` 的 `Original` 從「什麼都不做」換成這份規格。

- **現況**：`Original` 回 `nil`。那是錯的（`docs/re/175`）——原版有 AI，
  只是既有收據都停在玩家的座位上，所以量不到。
- **換掉之後**：敵方艦隊每回合會動。忠實度變高，但
  `turn260`／`turn320`／`turn450` 那幾張「已經逐位元組對上」的收據
  會不會改變，要重跑才知道。
- **建議**：先把規格實作成另一個 `Brain`（不動預設），重跑受影響的收據、
  保存前後差分，再決定要不要換預設。

在使用者裁決之前，這份規格維持 **DRAFT**，production path 不動。

## 階段二與階段五的已知部分

### 階段二

```
候選 = { i : 星域[i].擁有者 == 無主 且 到首都走得到 }
      （星域 14 另有一道未讀的條件）
若 候選為空：結束
目標 = 候選中「到首都步數」最小的那一個
兩支 = 用模式 2 連取兩次最佳候選（取到就把 +0x79 標成 1）
若 不滿兩支：結束
對兩支都：已經在目標 ? (+0x08 = 5、+0x07 = 0xFF) : (+0x08 = 1、+0x07 = 目標)
```

模式 2 ＝ 完整度門檻 80（艦隊已在目標星域時 50）、要求 `+0x0F == +0x0E`、
權重 `3 4 0 0`、主力門檻 4。

### 階段五

```
目標格 = ds:D50E（攻擊目標分）最大的那一格
目標 = 2E54:13A8(目標格)                  ; ★ 未讀
對每一支 +0x79 還是 0xFF 的我方艦隊 f：
    f[+0x0F] == f[+0x0E]                     → 去首都，行動 2
    否則若 走得到目標：
        f[+0x3C] < 60 或 f[+0x08] == 3       → 去目標，行動 3
        否則                                  → 去目標，行動 0
    否則若 走得到首都                          → 去首都，行動 2
```

`2E54:13A8` 沒讀之前，階段五不能實作——「目標格」與「目標」不是同一個東西。

## 進軍路線表（`docs/re/178`）

攻擊目標分的「累積分」＝ 這一格在該陣營的進軍路線表裡出現幾次。
表在 `docs/internals/data/ai-advance-routes.json`；選哪一組由 `2D54:0163()` 的 **12 種戰略態勢碼**決定——伊謝爾倫（13）在誰
手上、費沙（14）在誰手上、`ds:8F48` 有沒有設（`docs/re/179`）。
**伊謝爾倫不在自己手上時路線表只有 `[13]`**，所以第一目標永遠是它。

費沙（星域 14）的門檻：伊謝爾倫（星域 13）還在敵方手上時不打，
除非回合數過門檻（帝國 238、同盟 318，十次「實行」一個月）。

一個陣營最多 16 支艦隊（`ds:8F49[陣營] < 16`）。

## 階段一的完整形狀（`docs/re/180`–`docs/re/182`）

```
n = min(ds:D54E[首都] ÷ 3 + 1, 16)
n -= 2E54:03C3(n)                       ; 先從現有的湊
若 n > 0：2E54:0513(n)：
    首都不是自己的 → 不做
    清單 = 28E0:0103(&清單, 首都, 25h, 0)      ; 提督編號；依 2E54:063C 排序
    對每個提督（ds:8F49[陣營] < 16 且 n > 0）：
        艦種 = 提督[+0x08] & 0Fh
        若 星域[首都][+0x30 + 陣營×28 + 艦種×4] < ds:4E3A[陣營×208 + 艦種×26]：跳過
        槽 = 提督原本的槽（空著就重用）否則掃自己陣營 16 槽找第一個空的
        提督[+0x09] = 槽（同時清掉 bit7）
        提督[+0x07] 是 0FFh → 從 ds:5F78[編號] 填預設副官
        副官合格（五個條件）→ 副官[+0x09] = 同一個槽
        艦隊[槽][+0x08] = 5、[+0x07] = 0FFh、ds:D60E++、n--
```
