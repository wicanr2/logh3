# 140：名將戰術與戰鬥推廣片

狀態：**CONFORMED，本機限定**。2026-10-12先由使用者確認並標READY，實作及[驗證119](../playtest/119-hero-ai-release-promo.md)後完成名將規則、正常玩家路徑、八封包及有聲影片。GitHub Release尚未發布，真機、人耳、完整登陸及DOS全局同態不在本輪完成聲明內。

已確認：僅強化模式，存活帶隊名將在場時，其陣營全部艦隊移動額度為1.5倍，離場即解除；楊採牽制與兩翼包抄，萊因哈特採集中突擊與側後封鎖。

目前狀態見[計畫130](../goal/2026-10-12-hero-ai-release-round-130.md)。既有[120](120-active-tactical-ai.md)與[139](139-battle-playback-and-settings.md)的活動AI及普通動畫時鐘保持。

## 已知事實

- `docs/internals/data/keireki.json`的原資料名稱對照：提督0萊因哈特、52楊威利。來源是GIN3PS.EXE名稱表與KEIREKI.DAT，不是本輪猜測。
- `rules.Fleet.Admiral`連到帶隊提督；`rules.BattleUnit.Fleet`連到艦隊。戰術加成可從在場且存活的旗艦辨識，不必改存檔格式。
- `ai.Encircle`現按分隊分配八方位，所有強化陣營共用，尚無特定名將協同。
- `Game.AdvanceBattleTurn`按玩家／CPU權限下令，`applyTacticalMove`與正常玩家戰鬥命令共用移動引擎。
- `rules.NewBattleMovement`分別初始化艦隊與分隊的額度；只改艦隊可能讓一般組掉隊。額度與原始巡航／戰鬥速度必須分開，避免累乘或污染保存的能力。

## 使用者已指定

1. 先保留第129輪清理清單，不刪除試包、快取、來源或驗收資料。
2. 強化AI在對方有楊威利或萊因哈特參戰時，明顯加強包圍協同。
3. 這兩人任一在場時，其陣營全部艦隊的當回合新額度乘3/2，不累乘。雙方各有名將時各自加成；不因同陣營重複名將疊加。
4. 推廣片增加真實戰鬥動畫，保留遊戲聲音、兩旗背景、讀S1與正常下令、原版／HD展示，故事聚焦魔術師楊、扭轉局勢及改變歷史。
5. 加入1988年版動畫素材；新繪或概念圖不能冒充舊版動畫。完整版包含可啟動遊戲，三平台獨立驗收。

## 可撤回試樣

[試樣產生器](../../tools/scripts/hero_tactics_preview.py)產生並列HTML，展示通用包圍與名將分翼協同、英雄陣營／雙方加速及1.25／1.5／2倍差異。這是規則示意，非遊戲錄影，不接正式Game、資料與存檔，也不是完成證據。

已核准：只在強化AI模式啟用；依存活在場旗艦計算，退出／死亡／切回原版即取消。這些是remake新增規則，不能稱原版行為。

## 正式實作契約

- 名將必須是本場旗艦所屬艦隊的`Admiral`，旗艦`Squadron == 0`、`Ships > 0`且未`Out`。副官、未參戰或已離場名將不觸發。從目前單位重算，不保存加成旗標。
- 艦隊`PerTurn`、分隊`CruiseSpeed`不改。只把新艦隊額度與新分隊額度乘3/2，再加原本不足一步的分隊餘額。停止、待機、凍結與未啟用索敵隊沿原有分派，不強迫移動。
- 玩家目的地的移動範圍同步顯示加成後行程；回轉角度與地形限制保持。
- 新名將命令按艦隊分組。只對存活旗艦下整隊命令，存活一般分隊回到編隊跟隨；索敵隊維持其命令。目標只選存活敵艦隊，忽略索敵隊。
- 楊的一支前衛牽制，其餘左右分翼。萊因哈特以至少半數艦隊正面集中，其餘左右繞側後。不足三艦隊時只做實際可用的方向，不宣稱完成雙翼。
- 正面與兩翼相對於初始接敵方向配置。遠處兩翼先向側方集結，接近後才繞向側後；每艦隊角色按穩定順序分配，不消耗亂數。可通行的直達點優先，其次可到達集結點，再沿路縮短至可到達點。每一步仍由既有地形與碰撞引擎裁決。
- 原版模式與無名將的強化模式保留既有戰術；強化名將仍沿既有撤退門檻。倍率僅改戰術戰場移動，不改戰略月份、遊戲時鐘與動畫時鐘。

## 驗收

- 兩位名將、無名將、同場、離場／死亡、原版模式與不同難度的觸發及取消。
- 有效的多方向包圍、整隊移動、地形與碰撞、加成不累乘、停止／等待、索敵與保存資料邊界。
- 正常S1／S3實際鍵鼠操作的新實錄，不用局面注入或示意圖代替；原版／強化的同初始資料比較明示比較等級。
- 普通動畫來源格序、音效及結果時點沿139抽測，不能用動畫加速代替移動加成。
- 新版八封包逐檔、manifest、雜湊、三平台啟動／架構，影片聲畫、黑格、凍結、來源、字幕與戰鬥占比核對。
