# 148：系統設定專用清晰字型

狀態：限定CONFORMED。使用者要求強化系統設定內縮小字型的清晰度，屬呈現修正。

## 證據與審查

147的`compactText`以最近鄰丟棄原版16×15字模部分行列，再加左上1像素陰影。正式README截圖可見密集筆畫重疊。HD原版強化又重播這份縮小點陣；宋／黑體則縮既有大圖集。此為remake呈現問題，不是原版行為逆向。

本輪改用已在專案Docker工具鏈與啟動畫面採用的Noto Sans CJK開放字庫，製作設定專用字形。保留147的12×12全形／6×12半形字格與全部控制矩形。12像素原生字形供原色顯示；HD直接用36像素字形，避免先縮再放大。兩者不疊陰影，選取項目用深色文字配亮底。

系統設定所有標籤及選單統一使用這份專用字型。「介面字型」仍切換原版點陣、原版強化、思源宋體與思源黑體，供其他遊戲畫面使用。設定專用字型內嵌於引擎，保留完整OFL授權及可重生來源雜湊，不依賴玩家安裝系統字庫。以上為使用者指定範圍內的呈現選擇，審查後升READY。

## 驗收與停止線

- 實際字元與ASCII完整，原生字形及高解析遮罩有界，繪製與命中沿147同一矩形。
- 原色重播與 framebuffer相同；HD字形在裁切區內，後畫內容可正常遮擋；非設定字形不走專用路徑。
- 標準測試；兩陣營正常片頭至設定、四款遊戲字型、F7、AI選單及敵軍開關抽驗，保留完整960×720截圖並目視。
- README顯示來源更新的實錄及限制；不覆寫已發布tag／Release、舊封包或影片，不宣稱DOS字形parity或新的平台真機驗收。
