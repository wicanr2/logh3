# 085：戰場分隊繪製次序

狀態：**CONFORMED**，限定分隊繪製次序。工作項[#79](https://github.com/wicanr2/logh3/issues/79)，第37輪。
2026-10-02由DRAFT經證據審查：原始比較器、43邊界唯一分隊鍵與可丟棄Field探測相符。
證據：[研究377](../re/377-battle-render-order.md)、[分級索引](../internals/data/battle-draw-order.json)。

限定正式戰場分隊在同一畫面重疊時的先後。不改移動、索敵、選取、存檔或方向圖示。
typed輸入沿用BattleUnit.Fleet與Squadron；只排序繪製用的副本，不改規則迭代次序。

原版比較器35D1:02AB先比較物件+3的unsigned byte，較小先畫；相等時比較+4的unsigned word，較大先畫。
相等傳回0。原版S1全部43邊界135個分隊物件優先值均128；+4低byte是艦隊索引，高byte是分隊序號。
一般分隊0..9，偵察分隊0xFF。排序鍵為uint16(Fleet | Squadron<<8)，由大到小。
缺素材、空圖塊、Out及可見性沿用原契約。相等鍵使用穩定排序，未證實通用排序器的相等鍵置換；
已驗參戰分隊的鍵全部唯一。任意方向物件的相等鍵效果不在此契約內。
