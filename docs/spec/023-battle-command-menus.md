# 023 — 戰場的命令選單

狀態：**CONFORMED**（觸發、五張表、可選規則、版面與不可選的畫法；
三張選單的框逐位元組一致，`TestCommandMenuMatchesOracle`）。
每一項按下去之後做什麼（移動／戰鬥／索敵／編隊／補給／修理）
**不在這一份**；「歸隊」除外，它就是寫一個位元組。
證據：`docs/re/117`、`docs/internals/44`。
收據：`s3cmdsq3`、`s3cmdfl3`、`s3cmdoff`、`s3cmd3`。

## 觸發

戰場左鍵點下去：

1. 找出點到哪一個分隊——單位是 16×16 的圖塊，**左上角對齊世界座標**，
   畫面座標 ＝ 戰場原點 ＋ 世界座標 − 視野位移（與 `DrawBattleUnits`
   同一組幾何）。
2. 點到的分隊 `+0x00`（陣營）等於玩家陣營才算數；不是自己的就當作沒點到。
3. 沒點到任何分隊 → 照舊開戰術選單。
4. 點到了 → 右側換成分隊面板（`docs/re/118`、`docs/internals/45`）並開命令選單。
   面板只在選單開著時換——收據上兩者一起出現，選單關掉之後會不會留著沒有量過。

分隊重疊時取**畫在最上面的那一個**（繪製順序的最後一個）。原版的命中
判定還沒逆向到這一層，這是 remake 的取捨，標 `hypothesis`。

| 艦種 0–4 | `ds:413C` | 移動／編隊 |
| 艦種 5 | `ds:4158` | 移動／編隊／補給 |

字碼在 [`docs/internals/data/battle-command-menus.json`](../internals/data/battle-command-menus.json)，
由 `tools/scripts/battlecmd_spec.py` 從原版記憶體產生。

## 哪一項可選

艦隊選單：

```
三項先全開
艦隊 +0x00 bit0            → 關掉「戰鬥」與「索敵」
艦隊 +0x3A != 0xFF 或 +0x3B != 0 → 關掉「索敵」
```

分隊選單（四張共用）：

```
「移動」可選 = 艦艇 +0x1E 不是 0（移動）也不是 3（歸隊）
```

## 版面

```
框左上角 = (格x × 16 + 1, 格y × 20 + 1)
格       = 游標所在格 − (1,1)，再夾成 格y ≤ 19 − 項目數
框大小   = (內寬 × 16 + 30) × (項目數 × 20 + 38)   內寬固定 2
反白帶   = 框 + (15,19)，大小 32 × 20
文字     = 反白帶 + (0,2)，欄距 16、列距 20
```

框與底色和戰術選單同一套（`ui.MenuFrame`、底色 9）。

| 狀態 | 畫法 |
|---|---|
| 一般 | 字色 7、立體邊 3 |
| 游標所在列 | 先鋪反白帶（色 2），字照舊 |
| **不可選** | 字色 **8**、立體邊 3，游標停在上面**也不畫反白帶** |

不可選那兩條量自收據 `s3cmdoff`（把分隊行動改成 0 讓「移動」關掉）。

## 選了之後

| 項目 | 行為 |
|---|---|
| 歸隊 | 艦艇 `+0x1E ← 3`，選單關掉 |
| 其他 | **本份規格不做**：選單關掉、狀態不動 |

點在選單外面 → 關掉選單，不執行任何一項。

## 驗證

同狀態逐位元組比 `s3cmdsq3`、`s3cmdfl3`、`s3cmdoff` 三張收據的
**選單矩形**（框的外接矩形）。右側面板與小地圖那兩塊在本份規格的
範圍外，比較時排除，座標如下：

分隊面板另外比它的文字區 (480,242) 128×160（框由 `DrawBattleStatusFrame`
畫，先前已對過）。

| 排除區 | 理由 |
|---|---|
| 面板的框 | `DrawBattleStatusFrame` 畫的，另一條測試已對過 |
| 小地圖 | 選中的分隊在小地圖上會不會標出來沒有量過 |
