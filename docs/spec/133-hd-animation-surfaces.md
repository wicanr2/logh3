## 已核事實與審查

片頭沿`IntroPlaybackDecoder`、`IntroPage`與`IntroTicksToFrame`，421播放格由374來源格組成；350列頁面畫在畫布y65。交火沿`BMGFrame.Draw`先解覆寫／XOR，再由`RenderFleetFrame`與`drawEngagementPictures`合成兩個256×102視窗。段名是原四byte，不一定是ASCII。原素材1438張輸出不是1438幅獨立新畫。

已核目前完整`CopyPixels`會抹掉先前高解析文字命令。新合成需保留動畫矩形以外的原命令，並驗全部像素變更是否只在已知矩形。若發現界外變更，保持原完整快照回退，不猜裁切。上下兩路與原色重播皆須核對。

## 契約

1. 解碼、來源段名、幀序、視角、調色盤切換、間隔、音效、傷害及等待／跳過閘門不改。呈現只讀已完成解碼的原色圖。原圖模式完全保持。
2. 片頭與兩個交火視窗附原幀快照及完整原色fallback。兩個交戰消費端共用同一呈現命令；禁止在最終整張畫面上猜動畫位置、覆蓋字幕或量表。
3. 艦殼使用[新生成中性面材](../../assets/hd/material/MANIFEST.json)在原輪廓內取樣，沿原灰白／藍及綠色明暗著色。高解析輪廓取樣與細面材共用固定規則，不逐幀隨機生成，避免艦型與細節閃動。缺材質回退原圖。
4. 光效只從當幀既有亮色取得，重畫高解析核心與有限光暈。光暈只在原動畫矩形內，不新增開火、爆炸或命中事件。黑底保持深黑，不能因新材質產生整個矩形的噪點。
5. 本批是原輪廓上的高解析面材及光效重建，不宣稱1438幀逐幅AI新繪，也不宣稱原版逐像素一致。未接正式流程的登陸分段#48不因材質升級標為完成。
6. 相同原幀與色盤輸出固定，快取有上限。動畫回退不影響原流程；後畫文字、量表、下方投影與游標保持原順序。
