## 為什麼是這一片

規格 051 只到下命令那一刻，實行之後艦隊一格一格走是 `rules.Advance` 早就有的，
但走到別人的星域會怎樣、到了目的地之後命令怎麼收、停駐的艦隊守哪顆行星，都沒接。
這一片把原版每回合對 32 支艦隊各叫一次的 `113A:0350` 讀完，四條分支照接。

## 規則（每回合、每一支艦隊，依編號序）

艦隊記錄 `+0x06` 現在星域、`+0x07` 目的地（或待命行星）、`+0x08` 命令
（0 移動、1 占領、2 駐留、3 輸送、4 輸送回程、5 停駐）、`+0x0C` 移動經費。

1. 命令是 0 或 1 而現在星域 ＝ 目的地 → 改成停駐（`+0x08 ← 5`、`+0x07 ← FF`）。
2. 停駐：`+0x07 == FF` 且所在星域沒有戰鬥（`+0x13` bit2 清）→ `+0x07 ←` 該星域裡
   自己陣營**經濟力（行星 `+0x1A`）最高**的行星切片序號（相同取先出現的；一顆都沒有
   → 留 FF）。**remake：`(*Planets).StandbyPlanet`。**
3. 其餘命令：`next ＝` 路徑表的下一格（`rules.StarGraph.Route` 的第二格，規格 043）。
   - 現在格與下一格都不是自己的 → 「無法前往敵方的星系」：改成停駐，命令消失。
   - 下一格不是自己的且命令不是占領 → 同上。
   - 下一格不是自己的、命令是占領、下一格 ≠ 目的地 → 問「<目的地>無法直接到達此
     星系。<下一格>要占領此星系嗎？」：占領 → `+0x07 ← 下一格` 再走；待命 → 這回合
     不動，命令留著（下回合再問）。電腦座位一律當占領。
   - 軍事費不夠付 `+0x0C` → 「由於移動經費不足無法移動」：不動，命令留著。
   - 走：扣經費（`docs/re/313` §3.1 那條）、`+0x06 ← next`、提督與副官的 `+0x0A ← next`；
     到了目的地：輸送（3）→ `+0x08 ← 4`、`+0x07 ←` 自己的首都星域；駐留（2）→ 整支
     解散（`297B:025D`：提督與副官 `+0x09 |= 0x80`、`+0x0A` 不動；各組艦艇還回那一格的存量，
     艦種 7 不還；星域 `+0x28` −1、`ds:8F49` −1、`090A:0E6D`；`docs/re/329`）；其餘 → 停駐。
     駐留的目的地可以是自己所在的星域：下一格就是這一格，照樣到達解散，**不扣經費**。
     原版玩家介面沒有「解散」鈕，駐留就是解散。
   **remake：`rules.PlanStep`／`BlockByEnemy`／`Arrive`，`Game.stepFleet`。**
4. 32 支走完：每一格重算 `+0x13` bit2（兩邊都在）與 bit4（只有一方在且不是擁有者），
   bit4 的格子跳占據報告（規格 047）。
