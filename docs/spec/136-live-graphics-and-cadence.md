# 規格136：即時HD切換與動畫節奏

狀態：CONFORMED，限定116的正常S1三回合、六次F6及已聲明的快取／時鐘測試。2026-10-11使用者明確要求遊戲中即時切換HD與原版錄影，以及修復戰鬥速度不順。本規格不決定新的美術取捨，不代表第三稿星圖或新版封包已完成。

## 顯示切換

- F6在正常入口雙向切換原版與HD顯示。初始模式沿用命令列選擇。
- HD素材在進入視窗前載入。可用時兩模式共用1920×1440顯示畫布與640×480遊戲座標；原版使用最近鄰放大，視窗、游標及命中矩形不跳動。
- 切換僅改app的顯示狀態，不重新建立Game，不修改六表、存檔、亂數、AI、動畫時間、音樂或音效播放狀態。
- 原版模式仍可在沒有HD資料的引擎包啟動；F6提示素材不可用。明確要求HD但素材無效仍沿用啟動失敗契約。
- 原版倒圖保持640×480原色輸出；HD倒圖為1920×1440。此切換中的「原版」指remake原版呈現，不宣稱DOS全場same-state。

## 節奏修復

- 原版動畫TimerTick及AnimSpeed間隔保持。未經選擇不增加補間、不抽掉原始動畫格，也不加速遊戲時間。
- 正常交火以單調時鐘的實際經過時間傳入既有Game.Tick。首次進入交火重新錨定，不計入讀檔或前一畫面的等待；離開交火及腳本入口沿既有固定步長。這修復Ebitengine 2.8.8在超過5／60秒停頓後重設追趕時鐘、導致更新數少於實際時間的問題，不改17.164ms TimerTick、8／4／0間隔或音效播放完成閘門。
- 先保存正常S1的原始動畫來源變化、遊戲Frame耗時及HD合成耗時。相同視覺內容可快取，但鍵必須包含原圖、調色盤、陣營、命令及Artwork覆蓋資訊。
- 快取命中與未命中圖逐像素一致；文字、游標、覆蓋、陣營、同色異畫法及新動畫格都必須使快取失效。不得只依Framebuffer.Pix判斷HD圖是否相同。
- 行星防衛與艦隊交火均涵蓋。行星分支以完整文字／量表視圖與目前可見BMG序列判斷重畫；時間線以素材、圖段、左右、損失及間隔為鍵。計時器與音效等待仍在原有更新流程執行。
- 實際錄影測量來源格顯示間隔及錄影時間戳。60fps檔案標示不能單獨當作順滑證據。保留來源原有低影格動畫的限制。

## 驗收

標準測試與有針對性的快取／輸入回歸通過。正常X11在戰略星圖、戰場及交火雙向按F6，畫面與對應模式相符，游標與視窗不變。切換前後同次音訊持續，錄影保留正常讀S1、下令及交火。以量測結果限定性能聲明。美術採用另見137及使用者第三稿確認，不由本規格決定。

2026-10-11追加：行星演出0至146 tick逐格比較快取與原合成，像素、命令及Artwork一致；艦隊14個原生素材格同樣比較通過。這是remake快取正確性，不新增DOS原版parity聲明。舊oracle檔缺少的比較仍標skip。

時鐘根因為本機鎖版`github.com/hajimehoshi/ebiten/v2@v2.8.8/internal/clock/clock.go`的calcCountFromTPS：diff超過5／60秒時重設lastSystemTime，不補count。cmd/gin3原先每次Update固定傳1／60秒，實錄r5的HD來源格中位數213.58ms，原版139.19ms，超出原間隔。根因屬已證實的remake執行流程；不當作DOS硬體driver研究。
