# SPEC 050：勝負報告與結局轉場

狀態：**CONFORMED**

證據：[`docs/re/309`](../re/309-victory-report-and-ending-branch.md)、
[`docs/playtest/020`](../playtest/020-victory-report.md)。

## 契約

- 回合尾端、費沙報告與事件之後，檢查星域 0 是否屬同盟、星域 31 是否屬帝國；
  前者為同盟勝，後者為帝國勝。
- 單人模式的 viewer 永遠是玩家；對戰模式的 viewer 是勝方。只顯示一頁。
- 報告使用 `(10,5)`、`20×10` 內容格、style 1 的獨立模態視窗；日期、勝敗文案、
  星系數、勝利點、雙方累積分數與頭像完全使用已保存的原版資料與格式。
- 每場 `battleScore` 在戰場結束時累加到兩陣營的整局分數；以
  `WORK +0xD8/+0xDC` 32 位元欄位保存與載入。
- 滑鼠左右鍵皆關閉報告，並依勝方轉入 `ENDT30.VO5` 或 `ENDD30.VO5` 預覽。

## 驗證與限制

- 帝國勝與帝國敗兩張原版收據的完整報告矩形皆為 0 像素差異。
- 單人勝、單人敗、對戰勝方 viewer、無勝負不開報告、分數解碼與狀態轉場均有測試。
- `ENDT30`／`ENDD30` 路由是強推論；完整結局圖片序列、字幕與換場未納入本規格，
  不宣稱整段結局已重現。
