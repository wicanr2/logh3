# SPEC 017 — 電腦 AI：原版行為與強化版

狀態：**DRAFT**
證據：`docs/re/77`（原版的每回合決策，調查中）
相關：[`docs/internals/26`](../internals/26-star-region-graph.md)（星域圖與路徑表）、
[`docs/internals/33`](../internals/33-fleet-table.md)（執行期艦隊表）

## 這份規格要解決的問題

remake 目前**沒有任何電腦 AI**：按「實行」只推進日期與月底結算，
敵方一動也不動（`internal/game.advanceTurn`）。原版的敵方會做什麼，
還沒有逆向出來。

兩件事要分開：

| | 來源 | 能不能標 `same-state` |
|---|---|---|
| **原版 AI** | 逆向原版執行檔與記憶體 | 可以——與原版對拍 |
| **強化 AI** | 我們自己設計 | **不行**，它本來就與原版不同 |

## 預設是原版，強化是選項

**預設走原版行為**：對拍收據與「與原版逐位元組相同」那個宣稱才站得住。
強化版做成可切換的設定（開局選單／設定檔／啟動旗標），玩家自己開。

```
ai.Profile = Original | Focused
```

`Original` 在原版 AI 逆向完成之前是「什麼都不做」——**不要拿強化版
去填那個洞**，那會讓「原版行為」這四個字失去意義。

## 原版 AI：一層防守型的收攏（`docs/re/79`）

艦隊那一層已經讀出來了（`2E54:005D` → `2E54:1955`）：

> **這一格是自己的而且沒事 → 待著；否則退回「離自己首都最近的、
> 屬於自己的」星域；挑不到就原地不動。**

下命令的那一行是 `2E54:1955` 的 `1A54`：`+0x08 = 0`、`+0x07 = 目標`。

這條路**不會自己挑進攻目標**——只做收攏與待命，所以強化版要補的是
**選目標、集結、進攻**這三件事。

⚠ **但這條路在單人模式沒有跑過**：S2 十二回合、S3 六回合（含走進
戰鬥畫面），`ds:D60E`（決定計數器）一直是 0、每一支的 `+0x79` 都還是
`0xFF`（`docs/re/79`）。所以「原版電腦就是這樣行動」**不成立**——
在玩家走得到的這條路上，電腦不下命令。

這件事對 remake 是好消息：**`Original` ＝「按實行時什麼都不做」現在有
證據了**（兩個局面十八回合），不再是待證的空白。強化版要做的就是把
這個空白填成會打仗的東西。

還沒讀的：建造、徵稅、提督派任那幾層是不是也有對應的決策，以及
戰術畫面裡的那一套。

## 原版 AI 的其餘部分（待逆向）

兩個局面十八回合裡沒看到電腦下任何新命令，但**那兩份收據其實沒有觀察到
AI**：同盟那幾支艦隊的 `+0x08` 一開始就是 5（＝不動），是劇本的設定
（`docs/re/77`）。要看電腦做決策得先找到會動的局面，或直接往上追
`113A:0350` 的呼叫者。

在問清楚之前，`Original` 就是「什麼都不做」，而且那是**待證的空白，
不是結論**。

還不知道的：決策在哪一段程式、每回合做幾件事、有沒有難度參數、
建造與徵稅是不是也由它決定。已知可用的材料：

- 星域圖與距離：兩張 32×32 中點矩陣，每個陣營一張（`docs/re/28`），
  remake 已經有 `rules.StarGraph`。
- 執行期艦隊表 `ds:C074`：`+0x01` 陣營、`+0x04` 在不在用、`+0x06` 所在星域、
  **`+0x07` 要去的星域**、**`+0x08` 動不動（5 ＝ 不動）**
  （`docs/internals/33`）。**下命令 ＝ 寫 `+0x07` 並把 `+0x08` 解開**；
  移動引擎把 `+0x06` 往目的地推，到了同時寫回 `0xFF` 與 5（`docs/re/77`）。
  所以「電腦這回合下了什麼命令」＝ 看誰的 `+0x07`／`+0x08` 被寫。
- 移動的兩支函式：`113A:0350`（要不要動）與 `113A:047D`（走一格，
  查 `2B99:0302` 的下一跳表、比星域擁有者）。
- 「實行」那條呼叫鏈已經追完（`docs/re/78`）：點擊分派 → 跑一趟
  **32 筆艦隊全掃**的處理 → `113A:0350` → `113A:047D`。電腦的艦隊
  一樣會經過那一趟，不動是因為 `+0x08` 是 5。
- **最接近 AI 的一支是 `2E54:005D`**（`docs/re/79`）：逐陣營
  （`ds:8F1D` 選）、逐艦隊，看「這一格是不是自己的、對方有沒有艦隊、
  星域 `+0x13` 的旗標」，寫出一個決定碼到 `+0x79`，其中一條路直接把
  `+0x07` 設成現在的星域（就地待命）。形狀吻合，但**還沒證實它只在
  電腦那一方跑**。
- 星域記錄：`+0x12` 擁有者、`+0x28`–`+0x2B` 艦隊數、`+0x7C` 民心、
  `+0x7D` 未安定度。

## 強化版：包圍 ＋ 單點集中，但要適度

設計目標（使用者指定）：**更會包圍、更會單點集中攻擊，而且要適度**。

### 一、選一個目標，不是每個方向都推

每回合先挑**一個**目標星域，條件依序是：

1. 是敵方或無主，而且與我方控制的星域相鄰；
2. 守軍越弱越好（該星域的敵方艦隊數與防衛力）；
3. 價值越高越好（經濟力、稅收）；
4. 與我方主力的距離越短越好（用原版那張路徑表算，不是幾何距離）。

目標**至少維持 N 回合**，除非被攻下或形勢大變——每回合換目標就是
「到處推一點」，正好是要避免的行為。

### 二、包圍 ＝ 從兩個以上的方向同時到

對目標星域取所有相鄰的我方星域當**進攻位**。派兵時算每一支艦隊
走到各進攻位要幾步，湊出「**同一回合抵達**」的組合：

- 至少兩個不同的進攻位有兵，才算包圍成立；
- 早到的艦隊**等**（停在進攻位），等到約定的回合一起壓上去；
- 等待有上限（例如 3 回合），超過就照現有兵力打——不然會永遠在等。

### 三、集中 ＝ 兵力比達標才動手

合計投入兵力 ÷ 守軍兵力 ≥ 門檻（初值 1.5）才發動；沒到就繼續集結。
分散在多個方向、每個方向都打不贏，是原版 AI 最常被抱怨的地方。

**兵力用原版自己的算式**（`2E54:1876`，`docs/re/79`）：一群艦隊的戰力
＝ 每一組編制的 `ds:6032[艦種+4] × 一單位幾艘 × 1000 ÷ 艦種+0x0A` 加總。
強化版不要自己發明一套戰力公式——用原版的，比較出來的結果才和遊戲
內部一致。

### 四、「適度」調的是節奏，不是拳頭大小

這一款的有效打法是**一次投入大量兵力，在戰術畫面包圍、集中、殲滅**。
所以「適度」不能靠把攻擊部隊砍小——那只會讓 AI 每次都打不贏，變成
「弱又煩」。要留的餘地是**時機與後方**：

| 旋鈕 | 初值 | 為什麼 |
|---|---|---|
| 一次攻勢投入的兵力 | **能集中的都上** | 分批送死是原版最大的毛病，不要重演 |
| 首都與前線星域的常駐守軍 | 各 1 支 | 不會為了進攻把家清空，玩家有反打的路 |
| 兩次攻勢之間的最少間隔 | 3 回合 | 打完要重整，不變成每回合被壓著打 |
| 同時進行的攻勢 | 1 個 | 兩路並進 ＝ 兩路都不夠強 |

難度參數調的是**間隔、守軍下限與兵力比門檻**這三項，不調投入比例。

### 五、不碰的東西

強化版**只改決策**，不改規則：移動一樣照原版的路徑表走幾步、
戰鬥結果一樣照原版的算式。AI 變強是因為它選得好，不是因為它作弊。
### 六、戰術層：包圍、集中、殲滅

戰略上集中過來的兵力，到了戰術畫面要能用出來：

- **不要平均分散**：所有部隊指向同一個敵方單位，先把它打掉再換下一個
  ——集火比全線接觸有效率得多。
- **包圍**：優先繞到目標的側後方，讓多個單位同時與同一個目標接觸。
- **殲滅優先於推進**：敵方單位剩得少的時候，追擊比佔位重要。
- 「適度」在這一層是**撤退門檻**：己方損失到一定程度就照原版的「撤退」
  收手，不打到全滅——被全滅的一方會失去一整批艦隊，那對玩家太痛。

戰術層的細節（座標系、單位怎麼下令、一回合能走多遠）**還沒逆向**，
`docs/re/77` 只走到「進得去戰鬥畫面、命令選單長什麼樣」。


## remake 這一側還缺的地基

AI 的輸出其實只有一種東西：**「哪一支艦隊去哪一個星域」**（寫 `+0x07`）。
但 remake 現在連放它的地方都沒有：

- `internal/game` 的 `fleets` 只是一串「帶隊提督的索引」，**沒有位置、
  沒有目的地**；
- 沒有移動引擎——按「實行」不會有任何艦隊往前走一步。

所以順序是：**艦隊模型（位置 ＋ 目的地）→ 移動引擎（照 `rules.StarGraph`
每回合走一格）→ AI**。前兩件是原版行為，要照原版對拍；AI 才有強化版。

`rules.StarGraph` 已經有 `Route`／`Steps`／`Neighbours`，走一格所需的
下一跳直接從 `Route` 取第二個元素。

## 驗收

- `Original` 這一側：與原版對拍（收據待逆向完成後補）。
- `Focused` 這一側：**不做畫面對拍**，改用可重跑的模擬——固定開局、
  固定隨機種子，跑 N 回合，斷言「同時抵達的次數」「兵力比」「後方
  守軍不低於下限」這些**行為指標**，而不是斷言某一張畫面。

## 還沒決定

- 強化版從哪裡開：主選單、設定畫面，還是啟動旗標。
- 難度參數要不要存進存檔（存了會讓存檔與原版不相容）。
