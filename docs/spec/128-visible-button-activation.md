# 128：可見確認按鈕與月初報告接線

狀態：CONFORMED（2026-10-10，限定remake接線）。使用者要求修正第二畫面與財政畫面的按鈕，再交付 v.1.0.0。修正前失敗、修正後回歸及正式新包四條正常X11路徑通過，詳見[109](../playtest/109-v1-release.md)。

## 證據審查

- `CopyProtSpec.InputBox` 是實際繪製「確認」的矩形，來源為 `screen-copy-protection.json` 的 `(414,260,36,20)`。`Game.Key` 已有完整送出邏輯；`Game.click` 缺少 `StateCopyProtection` 分支。回歸測試修正前停在問答畫面，屬已證實的 remake 接線缺陷。
- 規格016確認雙人報告與單人報告共用內容及按鈕。雙人 `StateVersusAccount`／`StateVersusShipOrder` 有可見按鈕，卻缺少左鍵分支。修正前測試停在雙人會計畫面，屬已證實的 remake 接線缺陷。
- 單人會計、訂造、建造的畫面座標沿規格121，已實際重播28張完整X11視窗零差。本次不重寫該座標契約。

## 行為

1. 問答確認使用繪製矩形判定，呼叫既有 `Key('\r')`。空答案及矩形外無作用；四個主選單目的地與 Enter 相同。
2. 雙人會計及訂造使用各自 `overlay.Boxes` 的可見按鈕。變更開既有預算或建造畫面；確認沿既有右鍵關報告路徑。
3. 預算、建造及待命提督清單返回實際父畫面。以既有 `versus` 區分月初單人與雙人報告，不改金額、結算、AI、存檔格式或換手規則。
4. 原圖640×480與HD1920×1440共用Game座標。按鈕不重複換算顯示倍率或原版滑鼠偏移。
