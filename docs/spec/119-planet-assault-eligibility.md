# 119：行星鎖定與只受反擊

狀態：CONFORMED。2026-10-06，沿[#91](https://github.com/wicanr2/logh3/issues/91)。
本輪先審READY，再改正式規則並完成限定規則與玩家回歸，結果見[099](../playtest/099-planet-eligibility.md)。
本規格修正[019](019-planet-assault.md)的共同閘門及逐行星開場判定。
證據見[439](../re/439-planet-eligibility.md)及[結構化原版事實](../internals/data/planet-eligibility.json)。

## 證據審查

原版40案各兩跑，000C實際清除舊目標及位元，再由0091計算。
120份完整RAM逐位元組相同，全部種子保持12345678。
另從新算目標恢復完整父CPU，正常提示輸入續行第六步；兩跑相同。
反擊扣253艘，行星與庫存不變，沒有121F占領結果，最後種子0B719151。
正式規則修正前15案目標／位元失敗，反擊案沒有任何Hit。
原版CS:IP的分支bytes與IDA9.4舊匯出、原始RAM一致。證據足以限定以下修正。

## 輸入與輸出

- 行星依切片順序，在場艦隊依名冊順序。座標、艘數及防衛力來自原版word欄位。
- BattleFleet.Action保留完整byte；僅登陸判斷讀低四位，不修改Action本身。
- 每次計算先將所有target設為-1、bits設為0。原版分別為FLEET+5A的FF及+70的0。
- 每顆行星先排除同陣營、旗艦零艘的艦隊。
- 登陸bit0：距離不超過150、Flag0為false、Action低四位為1。符合則OR 1並寫target。
- 反擊bit1：距離不超過PlanetQueryRadius，且一般行星或GunState不是3。符合則OR 2並寫target。
- 兩個分支獨立。位元跨行星累積，target保留最後一次符合的行星，不按行星重新清除。
- PlanetQueryRadius沿用防衛力夾至1500至6000後除25，包含距離端點。
- 逐行星結算只要求有人target相符。沒有登陸bit0仍結算反擊；不得增加占領傷害或分數。

## 範圍與驗收

只修PlanetAssaultTargets的兩個分支及PlanetAssault的開場門檻。
算式、順序、RND、庫存、AI政策與存檔格式沿用既有規格。
反擊量表仍使用既有瞬時資料；#48的完整分段與占領文字留在該Issue，不由本規格升格。

- 40案目標及位元符合原版，含Action00／01／04／10／11、Flag0、150／查詢半徑端點、要塞、友軍與多行星。
- 只受反擊案逐分隊艘數、修復上限、庫存、行星、重算完整度及最終種子符合原版。
- 061被動CPU完全不傷玩家；正常戰術、快速戰鬥及公開存讀最小抽測保持。
- 標準18套件13PASS／5無測試，正常S1／S2／S3公開存讀保持；診斷續行不宣稱正常玩家整回合同態。
