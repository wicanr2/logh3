# 150：非戰艦旗艦選項

狀態：**限定CONFORMED**。2026-10-24使用者要求預設關閉，並明確指定開啟後旗艦擊破可轉往
仍存活的艦艇，排除E修護艦與T運補艦。這是使用者指定的remake擴充，不宣稱DOS規則。
沿[146](146-flagship-transfer-and-rule-settings.md)的轉移時機、機率、引用交換及存檔契約。

## 規則及證據審查

| 項目 | 契約 |
|---|---|
| 設定 | 系統設定新增「非戰艦旗艦」，預設關閉，沿preferences.json保存 |
| 關閉 | 新的手動編成／轉移只允許B戰艦、H高速戰艦，沿015及146 |
| 開啟 | 可選B／H／C／A／D，必須有存活艦艇；E、T及非編成艦種P排除 |
| 手動編成 | 放置中央旗艦槽時套用同一艦種政策，取消仍退還原所在地庫存 |
| 擊破後轉移 | 仍需「轉移旗艦」開啟，選存活且未離場的同艦隊一般分隊；艘數最多，並列按原序 |
| 成功率 | 沿現有提督特殊能力與本場亂數，不因放寬艦種而改變，不重擲 |
| 交易 | 候選選擇與實際Slot交易都驗證艦種，先驗證後寫入；不復活、不搬船、不補資源 |
| 相容性 | 不改原版六表格式。關閉選項不改寫已存在或讀入的旗艦，只限制後續選擇 |

艦種索引沿既有`BHCADTE`與程式表：0至4可在開啟後當旗艦，5=T、6=E，7=P不納入。
所有陣營與既有傷害接點共用政策；不改AI建艦隊的原樣板或開局提督旗艦。

## 介面

沿147的原設定框與12像素設定字型。下半部六列以15像素間距容納新開關，
每列14像素高，保留原結束／編輯提督按鈕。繪製、命中、觀測共用控制矩形。
開啟後嘗試以E／T當旗艦時，明示「修護艦與運補艦不能當旗艦。」；關閉時沿原訊息。
這是原介面內的局部增項，沒有新頁面、存檔欄位或額外確認流程。

## 驗收

- 開／關艦種矩陣，E／T不能手動或自動接任；庫存與編制交易失敗不寫入。
- 同池／座標／提督副官、後續清理與六表保存讀回；既有機率及三傷害接點保持。
- 缺偏好鍵預設關閉、開關重啟保留、未知偏好鍵不遺失，設定反白／點擊共用矩形。
- 正常GUI實錄設定、換提督、從駐地領船編成並出發。影片標明實際素材、正常操作與剪輯範圍。
- 標準測試、Windows新本機替換包、影片聲畫／來源／字幕／雜湊及Docker清理。
