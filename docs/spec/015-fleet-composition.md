## 兩欄數字

```
待命部隊 = 該星域的艦艇艘數 ÷ 一單位幾艘
數量     = 一單位幾艘 = [3000, 3000, 4000, 2000, 3000, 3000, 1000]
```

艘數存在星域記錄 `+0x30`（帝國）／`+0x4C`（同盟），各七個 32 位元
（`docs/re/69`）。瓦爾哈拉開局是 **78000**/36000/108000/10000/27000/15000/5000
（`docs/re/316` §四：`-peek` 在地圖上量到 78000）；**進這張畫面那一刻旗艦那一組
（3000）就從存量扣掉**，所以畫面上是 75000 ÷ 3000 ＝ 25、其餘 12/27/5/9/5/5。
「決定」不再扣（`fcmd-win` 之後仍是 75000）；「中止」整支作廢、退回 78000、
回戰略地圖（收據 `fcmd-fok-cancel`），不是回艦隊編成；右鍵什麼都不做
（`fcmd-fok-rclick`）。remake：`Game.provisional`／`takeProvisional`／`refundProvisional`。

「變更 → 編組」從艦隊視窗開的是同一張畫面（規格 [`051`](051-strategic-fleet-command.md)
「變更」一節）：待命部隊照那一支所在的星域、編制照那一支、中止／決定都回艦隊視窗。

## 編隊與部隊數

兩行都由**這一支的編制**算出來，規則與位址見
[`docs/internals/56`](../internals/56-fleet-composition-panel.md)：

```
N     = 艦隊 +0x0E          ; 編制槽的應有數 ＝ rules.FleetSlots(提督等級)
n     = 現有組數            ; 進這張畫面時只有旗艦一組
部隊數 = n／N
編隊   = 前 n 格印 ds:6172[第 i 組的艦種]（全形字母），其餘 N − n 格印「□」
```

字母表 `ds:6172` 是Ｂ Ｈ Ｃ Ａ Ｄ Ｔ Ｅ Ｐ（艦種 0–7），前七個與
`docs/internals/40` 的 `BHCADTE` 相同。字母的顏色是那一組的艘數：
滿編 7、不到滿編一半 2、其餘 5；「□」一律 7。

**`N` 不是常數 8。** 收據 `fok` 那一支的提督剛好給 8
（`docs/re/293`）。

## 格盤

`(欄 + 列)` 為偶數的 41 格畫圖塊，其餘留底色。格子對到哪一個隊形槽由
`ds:28B8` 決定（`fleet-composition-panel.json` 的 `grid_slots`）。圖塊
來自 `SPRITE.SPR`：**空位 `ds:984D`、有部隊的那一格 `ds:984E ＋ 艦種`**
——帝國 44／36、同盟 74／66。收據 `fok` 只有旗艦一組（艦種 0、槽 20），
所以中央 (4,4) 是第 36 張（形狀就是「Ｂ」，與編隊第一格印的字相同）。

## 選取條不是底色

第 0 列（戰艦）框的內部是色 2，而滑鼠停在別的地方——那是**選取**。
七個框的 `layers`／`alt`／`patches` 逐項相同，只有 `fill` 不同，所以
規格裡七個框的底色一律 8，選中的那一個由 `GameWindow.Select` 換色，
畫在框的字**之前**（字印在條子上面）。
