## 兩欄數字

```
待命部隊 = 該星域的艦艇艘數 ÷ 一單位幾艘
數量     = 一單位幾艘 = [3000, 3000, 4000, 2000, 3000, 3000, 1000]
```

艘數存在星域記錄 `+0x30`（帝國）／`+0x4C`（同盟），各七個 32 位元
（`docs/re/69`）。瓦爾哈拉：75000/36000/108000/10000/27000/15000/5000
÷ 上面那七個 ＝ 25/12/27/5/9/5/5。

## 格盤

`(欄 + 列)` 為偶數的 41 格畫圖塊，其餘留底色。圖塊來自 `SPRITE.SPR`：
**空位第 44 張、中央 (4,4) 第 36 張**（形狀就是「Ｂ」，與編隊第一格
印的字相同）。

## 選取條不是底色

第 0 列（戰艦）框的內部是色 2，而滑鼠停在別的地方——那是**選取**。
七個框的 `layers`／`alt`／`patches` 逐項相同，只有 `fill` 不同，所以
規格裡七個框的底色一律 8，選中的那一個由 `GameWindow.Select` 換色，
畫在框的字**之前**（字印在條子上面）。

## 陣形

「陣形」開出 (480,220)–(543,418) 的八列清單：**圓錐／紡錘／半月／Ｕ字／
Ｍ字／Ｔ字／分散／密集**（`screen-formation`，收據 `form1`／`form2`／
`form3`，`docs/re/70`）。反白條跟著滑鼠走，與艦隊編號清單同一種。
