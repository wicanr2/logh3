## 必須保留的狀態（proven）

- 原版戰略 AI 的階段二對全部無主星域寫 `+0x78` word。
  值為帶領土罰則的 `BuildTables` 距離 `[星域][首都]`，不是最少步數。
  寫入先於可達與費沙 gate；非無主記錄不清零。對戰／不跑 AI 時不寫。
- 距離是排序首鍵；完整比較器另讀防衛力及經濟力。候選閘門與排序分支
  需有獨立驗收，不可以只填暫存值就宣稱 AI 完整一致。
  次鍵為現有防衛力升冪，再經濟力降冪，完全相同時保留候選原序；
  不宣稱原版 qsort 的完全平手序列。費沙可納入的條件為事件已發生，或
  帝國座位、伊謝爾倫屬同盟且原版回合計數器 >=238，或同盟座位、
  伊謝爾倫屬帝國且計數器 >=318。先存距離再判這個 gate。
- 載入某星域地圖並要求行星座標時，以既有 `PlanetSites` 規則取得位置，
  按該星域行星順序把 X/Y 寫 `+0x46／+0x48`；其他星域不動。
  只讀行星表、開局預載素材或畫面繪製本身不構成載入事件。
  停駐艦隊尚未指定行星且所在星域無戰鬥時先挑經濟力最高的自家行星；
  有找到才走 `113A:0438` 載圖 → `0454` 呼叫 `2AF5:0036(星域, 1)`。
  開指定待命視窗、星系情報、戰場及戰略打行星同樣使用載入事件，
  寫入後 UI／規則消費同一份位置，不在 Draw 中改狀態。
- 回寫記錄與畫面／戰場使用同一份 typed 座標。存檔保存這些原始欄位；
  讀回不擅自重設其他星域。

## 審查與驗收

1. 已審查：完整比較器 `0198–01F6` 依 Y／X 升冪；停駐 caller
   `113A:0427` 先挑行星，`0454` 再以旗標 1 載入座標。原版實際
   `00CB` 命中 #430266844，堆疊返回 `113A:0459`，符合此控制流。
2. 指定正常編成／實行回合比較星域全 4032／行星全 6642 bytes，無遮罩。
3. 原版與 remake 種子在執行前固定；保留 #84 六項注入的診斷分支，
   另做完全未注入的正常分支。
4. 正常存進度完整寫出兩張表；取進度保留全部行星與新增 AI 距離。
   現況艦隊／艦艇未同步的獨立缺口列 #86，不宣稱完整局面存讀閉環。
   地圖情報、指定待命 GUI 抽驗，戰術／戰略打行星由產品回歸抽驗。
5. 正常 GUI 色號／RGB、全部產品套件及清理檢查通過後才 CONFORMED。

只裁決指定正常回合與明示邊界，不把 full-table 零差異當成整個遊戲 parity。
