# 134：遊戲中切換敵軍全顯示

狀態：CONFORMED（2026-10-11，限定本規格的展示與資料隔離）。使用者明示要求免索敵觀察敵軍AI，可在遊戲中切換。這是remake的可選展示功能，不是原版行為或索敵規則的勘誤。

## 已核事實與審查

- `Game.drawBattle`使用`cachedBattleSprite`、方向快取及`BattleUnit.MarkerFlags/MarkerX/MarkerY`繪製。原版索敵快取還會寫回原始資料，不能為展示呼叫正式索敵流程。
- `refreshBattleHover`目前拒絕敵方摘要；`unitPanelFor`可讀實際分隊與艦隊。展示模式可明示開放敵軍摘要及目的地，關閉時必須立即清除。
- `screen-settings.json`的設定窗內，`(176,360,128,20)`沒有既有按鈕，右方是MIDI介面與結束鈕。新控制可共用單一矩形繪製與命中，不搬移既有操作。
- `SetAILevel(-1)`是remake原版策略及戰術；0至3是Focused及Encircle。它們屬既有政策。本規格不修改其決策或規則。

## 契約

1. 新遊戲程序預設關閉。執行期偏好跨新局及讀檔保留，不加入原版存檔或更改原始六表格式。
2. 遊戲內F7即時切換；系統設定新增「顯示敵軍」狀態鈕。片頭、標題、主選單、防拷不接受F7。戰場開啟時顯示提示及快捷鍵。
3. 開啟時，以顯示副本強制顯示所有未出局敵軍的艦隊編號／艦種、實際位置的小地圖標記及當前朝向。原battleUnits、原色快取、六表、亂數種子均保持。
4. 開啟時滑鼠停在敵軍可讀既有完整分隊摘要及實際目的地。仍不可指揮敵軍。關閉後恢復既有索敵顯示，立即清除敵軍摘要及目的地提示。
5. 不改AI可取得資訊、射程、索敵、命中、傷害、移動、資源、勝負或回合。顯示副本不可回傳AI、存檔或規則層。
6. 影片明示展示模式與兩種AI政策。同初始狀態比較綁定來源劇本、輸入及種子。現有原版策略模式的強推論限制保持，不宣稱DOS完整AI同態。

呈現補正：戰場提示使用`(8,420,160,20)`的平底區，底緣與原HUD的440對齊。先沿原面板色9畫底，再用原字色7畫「顯示敵軍 ON F7」，避免原裝飾線穿過文字。這只影響開啟時的新提示，設定鈕與既有戰場矩形保持。

## 驗收

- 預設關閉；設定鈕及真實X11 F7可開關；關閉後既有戰場恢復。
- 分隊、方向、小地圖及摘要均從實際資料顯示；出局敵軍不重現；己方不受影響。
- 切換／繪製前後完整原始六表、可觀測分隊與亂數保持；同種子、同輸入的正常戰鬥在顯示開關兩側結果相同。
- 相同公開劇本正常進戰場，實際錄製兩種AI；不以診斷進場或合成箭頭取代實戰。
- 跑標準測試及針對性正常玩家路徑，記錄擁有權與Docker清理。驗收入口掛[第126輪計畫](../goal/2026-10-11-original-ui-ai-promo-round-126.md)。
