# 153：五語遊戲介面顯示

狀態：限定CONFORMED。使用者於2026-10-24明確要求簡體、繁體、日文、英文、韓語，範圍包含海報名言與遊戲介面。

## 已查證的輸入與界線

目前程式只有繁中，原版Big5資料及規則鍵值混合於資料來源。`ui.DrawGlyphClipped`、`DrawTextBuffer`、`TextWindow`與設定文字均輸出`gfx.DrawGlyph`，保留字碼、座標、字色、安全裁切及fallback。`gfx.ReplayIndexed`可沿繪製紀錄重建原色畫布；HD則沿`presentation.Renderer.replay`重播。這些是目前程式可直接核對的事實，不作新增原版逆向結論。

本次語系只接顯示邊界。原版檔案、typed data、字碼儲存、命令、比較、人物及星系索引、AI、規則、亂數、六表格式、存檔與路徑維持原識別。故事圖、商標、頭像及圖片內文字不以改原始資料方式翻譯。不得把顯示譯文放回資源查找或存檔。

## 契約

| 項目 | 行為 |
|---|---|
| 語系 | `zh-TW`、`zh-CN`、`ja`、`en`、`ko`，預設繁中；設定可切換並保存，命令列可明確覆蓋 |
| 文案來源 | UTF-8 TSV為唯一正式譯表，穩定key、繁中原文及其他四語；runtime優先讀資料目錄譯表，缺檔沿同源內建版 |
| 原版資料 | Big5字碼只於顯示轉Unicode，譯表匹配只用於顯示紀錄，不回寫資料或遊戲狀態 |
| 文字幾何 | 依同一來源的字位、按鈕clip及欄位界線排版。短欄位用簡短譯詞，文字保留比例；不跨相鄰欄、按鈕或選單 |
| 字型 | Noto CJK合法子集遮罩，五語缺字檢查；原版及HD均可顯示，繁中預設畫序與原字形保持 |
| 動態值 | 數字、艦種字母、排序、欄位值、照片與選中值不因翻譯改變；語系切換立即使顯示快取失效 |
| 未收錄字串 | 明確保留原文並記入可選診斷，不把未覆蓋畫面宣稱完整翻譯；收尾列出實際覆蓋及限制 |
| 海報 | 共享同一語系，v1名言立即切換；v2／v3人物不隨語系重新載入 |
| 失敗 | 無效語系、損壞譯表或偏好保存失敗須回報；不得把空字、錯字或翻譯錯誤當成成功 |

## 驗收與停止線

TSV驗唯一key、欄數、佔位符、五語非空、字型覆蓋及來源雜湊。用與繁中相同資料、等價輸入驗設定、人事、編成、駐地領船、出發抵達、保存讀回，核對六表與狀態相同。正常視窗抽驗五語主選單、戰略、設定、列表、人事與戰術，檢查最長英文與韓文，原版／HD各取樣。字型差異不升格為DOS parity。

進度及來源入口：[150唯一狀態表](../goal/2026-10-24-poster-v160-round-150.md)；海報契約沿[152](152-poster-sets-and-quotes.md)。

限定驗收見[133](../playtest/133-poster-five-language-delivery.md)與[交付索引](../internals/data/v160-delivery.json)。762項譯表、5368字形及最終標準16 PASS／4無測試通過。兩平台正常五語設定、星圖、說明、編輯、海報與存讀通過；另驗英文駐地人事、編成、領船與出發，兩平台結果與六表相同。原版及HD取樣均有字形；未自然走完的其他戰術與長篇原文，不列為全翻譯驗收。圖片內故事、商標、未收錄字串保留原文，這是本次明列的覆蓋限制，不以單元測試推論全遊戲翻譯或DOS parity。
