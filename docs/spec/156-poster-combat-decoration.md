# 156：海報模式戰機與多旗艦裝飾

狀態：**限定CONFORMED**。使用者依序明確指定海報上下裝飾、上方帝國／同盟戰機交戰、下方多艘旗艦，以及輕量循環動畫。前期A／B金屬框prototype已被新方向取代，不據此另加未選定版面。

## 來源與邊界

- 戰略畫面有上下留白，實際HD背景黑列量測為上方0–40及下方418–479。來源圖粗估40／64像素不作繪製常數；工具列浮出位於上方，其他畫面不得假設同樣留白。
- 沿正式renderer已驗HD艦影、`flagships.json`及`engagement-panel.json`的FlagshipCodes，共16種帝國、12種同盟外形。同型旗艦沿同一外形，不宣稱每個名字都有獨特新圖。這是remake裝飾，不改戰術分隊或旗艦規則。
- 戰機使用image_gen產生的透明雙機圖，原PNG、完整提示及來源記錄保存`assets/hd/poster/`；屬銀英題材衍生重構，不稱DOS原始影格或1988逐形精確重現。

## 呈現契約

- 只在海報模式生效，隨原有海報關閉。中央4:3與點擊座標不變，不縮放或挪動遊戲內容，不遮兩側人物與名言，不新增存檔格式或設定鍵。
- 以當幀「無最上層游標」的實際背景，找整列全黑的頂端及底端留白；只在該範圍裁切繪製。上方至少8、最多48個邏輯像素，下方至少20、最多80，避免未知大空白變成過大裝飾。介面主題為空的主選單、開場、標題、結局等不加裝飾。沒有安全留白則不畫，不用固定矩形覆蓋未知畫面。
- 上方每側數架戰機沿固定曲線穿梭，以短光束表現交戰。下方每側最多八艘旗艦、兩列相向，輪流展示可用艦影，輕微漂移與間歇炮火。沒有資料驅動的真實戰局含義，不額外播放音效。
- 動畫以獨立單調時間的15Hz視覺相位控制，與遊戲狀態、RNG、原動畫TimerTick與回合處理分離，不沿低FPS下變慢的Update次數。既有動畫關閉時保留靜態構圖。工具列、說明與游標仍在最上層，裝飾不接受輸入。
- PNG與小圖只在載入時解碼／縮圖，GPU材質重用；動態位置及光束不進HD背景鍵。背景無變化時，不因裝飾相位更新而重新Render或WritePixels整張HD畫面。缺戰機或部分艦影只略過缺項，保持遊戲與海報可用。

## 驗收

標準測試與留白邊界、透明小圖、旗艦去重／缺圖、循環相位及背景快取測試通過。正常入口抽驗兩陣營、三組海報、五語、F1／F7、工具列、名言、靜態動畫設定、戰略及另一類畫面、海報關閉與存讀檔。比較裝飾開／關時只允許已由留白算法得出的矩形有差，遊戲內容及側欄精確相同，不能將此升格為DOS parity。

以正常視窗保存短循環影片與實際PNG，抽測CPU耗時、背景上傳與滑鼠操作，明示容器及真機限制。已交付v1.6.1不覆寫；新程式交付另依版號及dist-all契約。

本規格經使用者明確指示，補充[151](151-poster-widescreen.md)原「中央像素全同」契約：只在已證實空白區加入裝飾，所有遊戲內容、幾何與輸入保持。唯一狀態入口：[154](../goal/2026-10-25-poster-header-footer-round-154.md)。
