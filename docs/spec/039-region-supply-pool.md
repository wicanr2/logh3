## 原版做什麼

每個回合，在逐座位取得控制**之前**、在月底那道十回合閘門**之前**，
`0654:0007` 先呼叫 `2B5F:02B2` 掃一次 32 個星域：

```
for 星域 k in 0..31:
    if 星域[+0x12] == 2:  continue          # 無主星域不補
    if 星域[+0x13] & 1:   continue          # 到自己首都的路徑成本 >= 0x400 → 不補
    上限 = 星域[+0x1A]（經濟力，32 位元）＋ 星域[+0x20]（防衛力，16 位元）
    補   = ⌊上限 ÷ 10⌋
    擁   = 星域[+0x12]
    星域[+0x68 + 擁×4] = min(星域[+0x68 + 擁×4] ＋ 補, 上限)   # 飛彈
    星域[+0x70 + 擁×4] = min(星域[+0x70 + 擁×4] ＋ 補, 上限)   # 艦載機
```

三件事要一起看，少一件就會做出「數字對得上但機制錯」的實作：

1. **只補擁有者那一份。** 每個星域的 `+0x68`／`+0x70` 各有兩格（帝國、同盟），
   補的只有 `星域[+0x12]` 指到的那一格；另一方那一格原封不動。
2. **上限是那個星域自己的經濟力＋防衛力**，不是全國的、也不是行星檔裡
   的原值。`PLADAT.DAT` 給的開局存量遠高於上限（奧丁 200000 vs 108600），
   所以**第一個回合就被夾下來**。
3. **這兩格是雙向的。** 回合尾巴的 `2703:12EB` 會把它們清零、再從每顆行星的
   `+0x3C`／`+0x40` 重新彙總；同一個回合尾巴的 `2703:051D` → `2703:0540`
   → `2703:0590` 則反過來按行星經濟力比例把星域層的量分回行星。
   **回充之所以有意義，是因為分配那一步在同一個回合裡發生**
   （`docs/re/273` §4 有執行期序列）。

| 收據 | 證明什麼 |

## remake 現況

`internal/rules` 與 `internal/game` **完全沒有這一段**：

- 星域記錄的 `+0x68`／`+0x70` 沒有常數、沒有讀寫（`internal/rules/region.go`
  的欄位只到 `+0x7D`）。
- 行星的 `+0x3C`／`+0x40` 有（`internal/rules/planetcmd.go` 的
  `planetMissiles`／`planetFighters`），但只被 `PlanetSupply` 扣，
  沒有任何一處加回去。
- `Game.advanceTurn` → `endOfTurn` → `finishTurn` 沒有對應步驟。

三個後果：

1. 行星的飛彈與艦載機**只減不增**；戰場上用行星補給會寫回行星記錄
   （`docs/spec/019` 已對拍），所以打得越久差越大。
2. 開局水位就偏高——remake 沿用 `PLADAT.DAT` 的原值，原版第一個回合
   就夾成經濟力＋防衛力。
3. 補給線被切斷沒有懲罰。

## remake 要做什麼

1. `internal/rules` 加星域記錄的兩個欄位常數與一支純函式，簽名大致是
   `RefillRegionSupply(record []byte)`：照上面那五行做，**不做別的**
   （擁有者、旗標、上限、補量、夾）。
2. `Game.advanceTurn`（或它呼叫的回合前段）**每個回合**對 32 格各跑一次，
   位置在月底結算之前——原版是 `0654:0007` 裡 `mod 10` 那道閘門之前。
3. 行星的 `+0x3C`／`+0x40` 要跟著動。remake 沒有「星域層存量」這個中間
   狀態，所以有兩種做法，**這一條要使用者裁決**：
   - **照抄兩層**：加一份星域層存量，回合尾巴彙總、回合中分配，與原版
     同構；分配算式得先把 `2703:0590` 讀完。
   - **只留行星層**：直接對每顆行星按同一個比例回充，把星域層當實作細節
     省掉。數字在「沒有人動過存量」的局面下會相同，一旦中途補給過就
     可能分岔（分配是按經濟力比例重新攤，不是各自回各自的）。
4. 驗收：同一個輸入序列跑到回合 1，把 32 格的兩格與 `re273clamp` 的
   `re273_rpost.bin` 逐位元組比。

## 缺口（為什麼還不是 READY）

- `2703:0590` 把星域層的量分回行星的確切算式沒讀完（艦艇那七輪讀完了，
  飛彈與艦載機那兩段只讀到它把值載進區域變數）。第 3 條的裁決要等這個。
- ~~`+0x13` bit0 有設就跳過沒有收據~~ → **有了**（`docs/re/279`，收據
  `re278bit0`）：把星域 0 的 `+0x13` poke 成 `01`，那一格從 108600 →
  108600（沒補），同一條序列不 poke 時是 108600 → 109602。
