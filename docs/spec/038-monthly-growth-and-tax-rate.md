## 原版做什麼

`0654:0007` 由 `04F8:000E` 在**逐座位之前**呼叫，要求 `ds:8FF4` 與
`ds:8FF5` 都還沒被清掉，所以**一個回合跑一次**；本節這兩支被裡面那道
十回合閘門擋著，才是一個月一次：

```
if ds:8FF4 == 0 or ds:8FF5 == 0: return
2B5F:02B2()                          ; 每回合：回充飛彈與艦載機存量（docs/spec/039）
if ds:8F18 mod 10 != 0: return
2703:0BF2()                          ; 32 格：成長 ＋ 重算成長率
090A:0B5E()                          ; 重算稅率
```

`2703:0BF2` 逐格呼叫 `2703:0C26`：讓該星域每顆行星各長一次
（`行星[+0x1A] += 經濟力 × 成長率 ÷ 1000`），把成長後的總和寫進星域記錄的
`+0x1A`，然後

    星域記錄[+0x1E] ＝ (成長後總和 − 成長前總和) × 1000 ÷ 成長前總和

——**用這個月實際長了多少反推成長率**，不是沿用開局那一份。

`090A:0B5E` 分三段重算稅率：帝國（`090A:0B93(ds:8FD4)`）、
同盟（`090A:0B93(ds:8FD5)`）、無主（`090A:0DC0(2)`）。稅率吃成長率，
所以這一步必須在收稅之前。

於是月底的順序是：

```
一個月一次：  32 格成長 → 重算成長率 → 重算稅率
每個座位：    用**新**稅率收稅 → 錢的結算
```

## remake 要做什麼

1. 月底的成長與收稅**拆成兩趟**，不要綁在同一個逐星域迴圈裡。
2. 第一趟成長完就用實際成長重算 `+0x1E`。
3. 兩趟之間重算兩個陣營所有星域的稅率，各自用自己的 `Blend` 當難度下標。
4. 第二趟用新稅率收稅。

## 怎麼驗

收據 `monthwork2`（跨月後把三張月報右鍵關掉才倒 `WORK`）的帝國那一側：
原定軍事費 56405、已付建造費 14066、軍事費 42339、下個月預估 10413、
下期建造費 13188、建造中 `3520 1170 6340 580 4230 3020 960`。
remake 從同一份開局狀態按十次「實行」跨月，這幾格要逐一相同。

**收據不能停在月報上**：那時旗標還是 `1/1`、錢一行都沒結算
（[`docs/re/266`](../re/266-month-end-work-block.md)）。

## 不在這一份裡

- 無主星域的稅率那一支（`090A:0DC0`）還沒讀。那些格子不進任何一方的
  國庫，只影響星域面板上顯示的稅率。
- `2B5F:02B2`（每回合都跑的那一支）不在這一份裡，它與錢無關：
  [`docs/spec/039`](039-region-supply-pool.md)。
- 同盟那一側沒有對拍：那一趟同盟座位在回合 10 的月底一次都沒跑
  （旗標一直是 1）。
- **稅率算式要乘的那位提督（`ds:8F4F + 陣營`，內政專任參謀）不是常數。**
  範本（第 71,200,000 步）同盟那一格是 60，執行期（回合 1 之後）是 63。
  用 63 重算回合 10 的十三個同盟星域稅率 **13/13 全中**、用 60 全錯；
  但 796/1 的 `main1eAlly` 逐位元組要 60。改的時機與規則還沒查，所以
  remake 先留 60，**同盟的月底稅率因此偏低約四分之一**
  （`TestAllianceTaxRateNeedsRuntimeStaff` 把兩半都釘住）。
- 同盟的經濟力對不上是量測的側邊效應：收稅逐座位做，那一趟同盟座位沒跑，
  原版那些格子是「長完但還沒課稅」。要對拍得把收據再往前推。
- 無主星域 R24／R28 的擁有者兩邊算得不一樣（原版算同盟、remake 算無主）。
  **成因已知**：原版在回合 1–9 之間有六顆無主行星被同盟的艦隊打下來
  （[`docs/re/161`](../re/161-neutral-planets-are-taken-not-annexed.md)、
  [`docs/internals/53`](../internals/53-strategic-planet-assault.md)），
  remake 還沒接戰略回合那條打行星。屬於戰略層，不在這一份裡。
