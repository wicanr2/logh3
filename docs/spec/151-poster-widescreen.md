- 網路參考採經典動畫官方[帝國人物頁](https://ginei.jp/character_g.php)、[同盟人物頁](https://ginei.jp/character_d.php)及[官方主視覺頁](https://ginei.club/infoDetail.php?iKey=952)，辨認萊因哈特與楊威利。網頁圖片僅為造型及構圖參考，不稱為遊戲原始資產。
- 使用者已決定左右陣營、站位及新增選項，按此實作；預設關閉保留既有顯示，原版／HD由原有F7選擇。

## 契約

| 項目 | 行為 |
|---|---|
| 設定 | 遊戲設定頁增加「海報」開關，預設關閉，沿preferences.json的poster_mode保存，不改六表 |
| 比例 | 開啟為2560×1440邏輯輸出，中央1920×1440；左右各320×1440，合計16:9 |
| 中央畫面 | 與關閉時同狀態相同，保持完整4:3，無拉寬、裁切或遮擋；原版／HD及功能列照常 |
| 人物 | 左側帝國萊因哈特，右側同盟楊威利；站姿及主要身體完整置於直幅安全區 |
| 輸入 | 只在中央轉回640×480；側欄左右鍵不開選單、不取消、不拖曳或點穿；放開仍清掉按鍵狀態 |
| 視窗 | 切換外框保持當前遊戲高度，調整視窗寬度；手動縮放由同一顯示座標契約處理 |
| 效能 | PNG只載入一次，合成圖及GPU材質重用，不每格解碼或重載人物 |
| 素材 | 沿art/poster/empire.png及alliance.png，本機素材不加入公開Git；完整包或本機更新包才帶入 |
| 缺檔 | 海報不可用時保持4:3及原有遊戲功能，開關灰顯；明確旗標或偏好不造成黑畫面 |

設定標題右側加入獨立小開關，不擠壓既有六列規則與結束／編輯提督按鈕。新增中文字形沿既有12／36字型生成器與授權。
