- 從規則結算點建立有順序的登陸、反擊與占領結果快照，不能由最終Hit反推中間狀態。
- 快照保留原擁有者、完整度、登陸攻擊力、登陸前後防衛力、艘數、結果、seed邊界及圖段。
- 一顆行星只開場／收場一次；逐支攻方按原版名冊排序處理。成功後不再打已換手行星。
- 靜態首格與整段分開排程，保留原版COMANI記錄、音效完成閘門及兩種結果等待。
- 完整單幀由原版資料、正式renderer與typed快照生成，不能借原版入口像素、遮罩或錯誤字庫豁免。
- 上方攻方與下方場景各保留自己的快照。換第二支後，321F:008A／0897重畫前仍是上一支的下方。
- 登陸文字顯示攻擊力；反擊顯示船艦總數。controlled名格式與detail=3名格式分開，編號取低byte。
- 演出資料不改存檔格式，正式戰損與原池同步仍依019／078／106。
