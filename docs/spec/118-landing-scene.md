- 從規則結算點建立有順序的登陸、反擊與占領結果快照，不能由最終Hit反推中間狀態。

- 一顆行星只開場／收場一次；逐支攻方按原版名冊排序處理。成功後不再打已換手行星。
- 靜態首格與整段分開排程，保留原版COMANI記錄、音效完成閘門及兩種結果等待。
- 完整單幀由原版資料、正式renderer與typed快照生成，不能借原版入口像素、遮罩或錯誤字庫豁免。
- 上方攻方與下方場景各保留自己的快照。換第二支後，321F:008A／0897重畫前仍是上一支的下方。
- 登陸文字顯示攻擊力；反擊顯示船艦總數。controlled名格式與detail=3名格式分開，編號取低byte。
- 演出資料不改存檔格式，正式戰損與原池同步仍依019／078／106。

## 分段介面

- 每支結果另有按執行順序保存的瞬時段：登陸、反擊、占領結果。
- 每段保留原行星、艦隊、編制分隊的前／後副本、本次攻擊力、擊毀量及兩端seed。
- 登陸前快照在0681取攻擊力時建立；後快照在扣防衛力後、變更擁有者前建立。
- 反擊前快照在08B1建立；後快照在103D扣艘數後建立，量表採重算完整度及攻擊力。
- bits沒有登陸時不加占領結果；反擊bit未設時不加反擊段；登陸成功省略後續反擊。
- 占領結果單獨一段，保留上一段的文字、量表、圖與下方，只更新中間窗。
- 既有PlanetAssault仍回原Hit；新的觀測介面不改其公式、順序、seed、得分或存檔欄位。
- 正式Game的061被動CPU包裝仍還原玩家分隊及CPU命令；演出有效快照亦須反映還原，不能顯示未實際發生的CPU戰損。

## 完整單幀介面

行星文字、艦隊文字、中間窗、量表、COMANI格歷史與下方各為獨立typed輸入。
上方與下方可來自不同艦隊及不同扣傷害時點。下方未首次重畫時保持底圖。

- 文字格式取固定原版DS資料。controlled及detail=3格式分開，編號取低byte，已知條件只看旗艦。
- 行星名與種類由原表取得，擁有者色保留視窗底色。左右窗依攻方side交換。
- 中間標題／結果色各自指定；結果不內嵌舊假設色碼。占領成功／失敗色4。
- 量表用094，不能用上方文字防衛力覆蓋獨立量表的快照。
- 下方按321F單艦隊加NULL行星投影，unsigned Y／X comb sort；艘數每500、行星防衛力每2000，word加法保留。
- 自軍或detail3旗艦用已知方塊，其餘用未知方塊；行星owner0用帝國未知方塊，其餘用同盟未知方塊。
- 僅畫艦隊箭頭四線，不加兩艦隊交戰的標記、連線或標籤。
- COMANI只重播已提交格，保留覆寫及XOR，不借原版像素。

播放中排入的滑鼠只在下一次結果等待消費一次，不能連續跳過之後所有段。
