# SPEC 001 — 星域摘要面板（左下角）

狀態：**CONFORMED**（已實作；十五份 796 年 1 月的收據除了游標那一塊
逐位元組相同，另一份 799 年 3 月的中局收據面板那一塊逐位元組相同）
證據：`docs/re/22`、`docs/re/23`、`docs/re/24`、`docs/re/30`、`docs/re/41`
資料：[`docs/internals/data/region-panel.json`](../internals/data/region-panel.json)
執行器：dosgolem-logh3 `8c8af90`

## 要做什麼

戰略地圖介面的左下角有一塊 320×80 的面板。對星圖按右鍵會選中一個星域，
這塊就改寫成該星域的摘要。目前 remake 的畫面規格把這塊的文字**量好了畫死**
——換一個星域就不對了。這份規格要求它改由 `internal/rules` 算出來。

面板長這樣（星域 2、亞爾提那）：

```
帝國軍星系亞爾提那
治安  86%   行星 2/2    艦隊 0：0
```

## 版面（量自收據，逐格）

面板矩形 `(0, 340, 320, 80)`，兩行文字。

### 第一行（y ＝ 362）

| 欄位 | 位置 | 色 |
|---|---|---|
| 陣營前綴（五個全形字）| x ＝ 16 起 | 擁有者的陣營色 |
| 星域名 | x ＝ 96 起 | 7 |

三個前綴：

| 擁有者 | 字 | 字碼 | 色 |
|---|---|---|---:|
| 0 帝國 | 帝國軍星系 | `ABD2 B0EA AD78 AC50 A874` | 6 |
| 1 同盟 | 同盟軍星系 | `A650 B7F9 AD78 AC50 A874` | 5 |
| 2 無主 | 中立軍星系 | `A4A4 A5DF AD78 AC50 A874` | 7 |

星域名直接取執行期星域記錄開頭的 Big5 字串（`docs/internals/22`）。

### 第二行（y ＝ 382）

| 欄位 | 位置 | 色 |
|---|---|---|
| 「治安」 | x ＝ 16（`AA76 A677`）| 7 |
| 治安值 | **靠右對齊到 x ＝ 112**，形如 `86%` | 照未安定度分四段 |
| 「行星」 | x ＝ 128（`A6E6 AC50`）| 7 |
| 玩家陣營的行星數 | 靠右對齊到 x ＝ 176 | 玩家的陣營色 |
| `/` | x ＝ 176 | 7 |
| 該星域行星總數 | x ＝ 184 | 7 |
| 「艦隊」 | x ＝ 208（`C4A5 B6A4`）| 7 |
| 自軍艦隊數 | 靠右對齊到 x ＝ 272 | 玩家的陣營色 |
| `：` | x ＝ 272（`A147`）| 7 |
| 敵軍艦隊數 | 靠右對齊到 x ＝ 304 | 敵方的陣營色 |

不屬於玩家陣營的星域，治安印四個 `-`（靠右對齊到 112，色 7），不印百分比。

## 值怎麼算

全部已經在 `internal/rules` 裡（`docs/re/23`、`24`、`30`）：

| 欄位 | 算式 | 來源 |
|---|---|---|
| 擁有者 | 全屬同一方才算那一方，混雜就是無主 | `Planets.RegionOwner` |
| 行星 n/m | 玩家陣營的行星數 / 該星域行星總數 | `Planets.RegionPlanets` |
| 治安 | `(200 − 未安定度) / 2` | `Security` |
| 治安色 | 未安定度分四段 40/80/120 → 色 6/7/5/2 | `SecurityColour` |
| 艦隊 | 帝國玩家看記錄的 `+0x28`／`+0x2B` | `Fleets` |
| 陣營色 | 帝國 6、同盟 5、中立 7 | `FactionColour` |

## 靠右對齊與色段是實測定下來的

收據上看得到的值範圍太窄（治安兩位數、行星與艦隊都是個位數），
所以直接 `-poke` 星域 0 的執行期記錄造局面（`CLAUDE.md` 的硬規則：
**要某個局面就改記憶體，不要靠亂數**）：

| 收據 | 注入 | 看到什麼 | 定下什麼 |
|---|---|---|---|
| `pnlU000` | `lin:5F349 = 00` | `100%` 落在 x ＝ 80/88/96 ＋ `%` 在 104 | 治安靠右對齊到 112 |
| `pnlU200` | `lin:5F349 = C8` | `0%` 落在 x ＝ 96 ＋ `%` 在 104，色 2 | 同上；最差段是色 2 |
| `pnlU100` | `lin:5F349 = 64` | `50%`，色 5 | 第 2 段是色 5 |
| `pnlU150` | `lin:5F349 = 96` | `25%`，色 2 | 第 3 段是色 2 |
| `pnlU040` | `lin:5F349 = 28` | `80%`，色 6 | 未安定度 **40 還算第 0 段** |
| `pnlU041` | `lin:5F349 = 29` | `79%`，色 7 | **41 已經是第 1 段**（門檻是 `<= 40`）|
| `pnlFLT` | `lin:5F2F4 = 0C 22 07 63` | `12：99`，12 在 256/264、99 在 288/296 | 自軍靠右對齊到 272、敵軍到 304；自軍讀 `+0x28`、敵軍讀 `+0x2B` |

`5F349` ＝ 星域 0 的記錄（`ds:A79C`，線性 `5F2CC`）＋ `0x7D`；
`5F2F4` ＝ 同一筆的 `+0x28`。

## 驗收

`internal/screen.TestRegionPanelMatchesOracle`：對每一份收據，用原版檔案
重建命令階段底板、把游標放在收據的滑鼠位置、面板照這份規格畫，
**整張 640×480 逐位元組比對，只跳過游標本身那一塊**（見下）。
`internal/game.TestRegionPanelOnPlayerPath` 再走一次正常玩家路徑
（主選單 → 防拷 → 右鍵兩下 → 對星圖右鍵），比左下角那塊 320×80。

| 收據 | 局面 |
|---|---|
| `hovA`／`hovB`／`hovC`／`rcback` | 右鍵點在四個不同星域（帝國／中立／同盟）|
| `sec1`／`sec5`／`sec7`／`sec9` | 另外四個帝國星域，治安 81／84／78／75 |
| `pnlU000`／`pnlU040`／`pnlU041`／`pnlU100`／`pnlU150`／`pnlU200` | 注入的未安定度 0／40／41／100／150／200 |
| `pnlFLT` | 注入的艦隊數 12：99 |
| `s3rgn` | **中局**：S3「巴米利恩會戰」（799 年 3 月 1 日）右鍵選星域 25 |

796 年 1 月那十五份的執行期狀態這樣湊出來：擁有者、行星數從
`PLADAT.DAT` 現算（`docs/re/17`、`docs/re/23`）、名字從星域資料檔讀、
未安定度取
[`month-rollover-796-01.json`](../internals/data/month-rollover-796-01.json)
量到的那一組。

`s3rgn` 是中局，行星擁有者早就不是開局那一份了，所以改讀那一格存檔：
`PLANET.DTA` 是行星表、`STELLAR.DTA` 是星域表，兩者與執行期的表逐位元組
相同（`docs/re/41`）。

兩條路徑都有一欄要用量到的值：**載入時未安定度怎麼算出來的還沒解**
（`docs/re/24`）。存檔裡雖然有這一欄，載入之後會變成另一個數
——32 個星域裡有 22 個不一樣，量到的那一份在
[`unrest-at-load.json`](../internals/data/unrest-at-load.json)。

`s3rgn` 的底板是 796 年 1 月的，與那個局面的地圖與右側面板都不同，
所以只比面板那塊 `(0, 340, 320, 80)`，不比整張。

## 游標那一塊不比

這幾份收據的最後一個動作是右鍵，而原版右鍵之後**只把游標補回隔列**
（`docs/re/09`；底板規格為了這個挑 `main1c` 而不是 `main1`）。
試過在最後多移動一次滑鼠想拿到完整的游標（收據 `pnlMV`，
`-mouse-x 40 -mouse-y 30 -mouse-at 215000000`）——原版在**舊位置留下殘留**，
新舊兩處都對不上，比不移動更糟。游標的重畫行為要另外查，不在這份規格裡。

所以比對跳過一塊：游標的外接矩形 `(滑鼠 x, 滑鼠 y + 40)` 起、
`cursor.json` 的 `width × height`。**其餘每一個像素都要相同。**

## 底板規格的游標污染（順手修掉的）

量底板（`main1e`）的時候游標壓在清單條那一格上，量框的「角落修正」
把 19 個游標像素當成底板記了下來。把游標搬到別的位置就會多畫出那 19 點。

`cmdscreen_spec.py` 現在改成：那一塊用另一份**游標不在那裡**的收據
（`pnlU000`，游標在星圖上）補乾淨，量完再把差異掛到 `mouse.patches`
——它們本來就是「游標畫在這個位置」的一部分。`main1e` 的對拍不受影響。

## 不在這份規格裡

- 右側那塊面板（防衛力／經濟力／成長率／徵稅額／稅率）——它一直是首都，
  不跟著選取換（`docs/re/23`），另外處理。
- 選取星域時的動畫或閃爍：沒量過。
- 艦隊數 `0xFF`（「看不到」）畫面上印什麼：沒有收據。
