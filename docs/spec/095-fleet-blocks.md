## 輸入與輸出

typed場景是按原版順序排列的操作序列：背景、圖塊或實線。
圖塊參數是已投影X、虛擬Y、重複數與已解碼影像；線段是兩端點及低四位色號。
Y只在合成器加40一次。輸出是原生640×480 logical VGA色號，不轉RGB。
新合成器不取亂數、不修改SHIP投影／排序欄位、不改存檔。
原始資料由玩家合法匯入。原版素材、RAM及PNG留本機；此私有儲存庫的凍結像素不能因此取得公開散布權。

沒有可見裁切面積的圖塊不改遮罩；不預設每筆操作都能到達低層畫法。

3DBLOCK.SPR是1536bytes，四張48×16；COM_FLAG.SPR是1440bytes，五張64×9。

## 合法域與停止線

321F:0513的可見方塊X8..568、虛擬Y220..376。標籤X為投影X-6；
標籤Y為投影Y-4×堆疊數+偏移。095接受X2..568、Y-324..385，
圖塊48×16或64×9、數量1..131；完整面積在畫布之外可跳過。
字型或其他SPR格式不走此解析器。

兩次直接注入未返回必須保留，不能算成功樣本：

- x624在caller可見域之外，右裁切可能使寬度負值。
- x245、Y376、數量131在頂部相切處可能使高度0，低層迴圈未先驗0。
  這是原bytes的強推論；原版正式玩家路徑能否生成此數量尚未知。

合成器遇到原版guard接受、但裁切面積為零的操作，先回error且不改畫布。
這是未支援的原版狀態，不能默默跳過並繼續交戰，也不宣稱修正原版規則。
正式Game接線前由092決定可達性及必要裁決；本規格不授權猜補。

每層核全畫面307200像素及下方區域；保存原版／remake／差分PNG、色號、逐區數字與SHA-256。
PNG用收據的logical→AC→DAC映射色盤，不套MenuPalette；目前Game色盤未因此通過。
一般解碼／畫圖錯誤、非法素材及未支援零面積操作回error，畫布保持原值。
此驗收是使用原版投影參數的same-state合成器收據，不是正常玩家路徑或整場092 CONFORMED。
