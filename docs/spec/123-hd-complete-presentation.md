# 123：剩餘人物與全畫面 HD 顯示

狀態：CONFORMED（2026-10-10，限定下述呈現範圍）。82張人物及單色空格、33個原素材取樣、兩陣營與雙人正常玩家路徑及三平台封包通過，結果見[正式交付109](../playtest/109-v1-release.md)。其餘素材是邊緣細化，未宣稱逐張重繪或原版same-state一致。

## 範圍與裁決

使用者於 2026-10-06 要求「完成剩餘的hd」，沿規格122已確認的原畫風修復方向。82張真實人物逐張以各自原圖修復；FACE.AMG第82號為單色空格，保持空格，不生成第83個人。原始索引事實見內部參考09、研究271與 `amg_export.py`。

艦艇、地圖、演出與其他原有像素圖使用呈現層的三倍邊緣細化。這項處理保留原圖內容及每個邏輯像素的中心，僅在同色相鄰邊構成斜線時細化角落。它不等同逐張 AI 重繪。所有動畫每幀依同一固定規則處理，沒有新增艦型、地形、道路或劇情圖。字庫、文字字碼及版面保持。

## 契約

1. 正式資料、色號畫布仍為640×480。HD顯示為1920×1440。滑鼠映射、原圖模式與存檔格式沿122，不改規則、AI或音訊。
2. 原畫面先展開為每像素3×3。上下左右相鄰像素的色號決定四角：上與左相同、且各自不同於下與右時，左上角採該相邻色；其餘三角按旋轉後同一条件。中心、四邊中點永遠保留中央原色。界外使用最近邊界像素。
3. 沒有相符角落時原像素保持九點。單像素、孤立點、單色區、直線及畫布尺寸保持；不得模糊整張圖或新增色號。取樣只用此幀既有色號和調色盤，因此動態星域著色、戰場捲動、BMG逐幀及片頭調色盤仍即時呈現。
4. 人物HD替換沿122的原索引及可見遮罩，在基底細化後合成。後畫文字、游標、視窗的完整遮擋保持。定版首批5張PNG雜湊保持。
5. 素材匯入器只複製 image_gen 原檔，不修改PNG。每張保存完整提示詞、原圖SHA-256、生成圖SHA-256、尺寸與索引。錯誤比例或損壞圖拒絕；人物核對表只作診斷。

## 驗收

- 逐張核對82張人物的大型特徵；空格仍為空。載入器以真實FACE.AMG索引範圍驗證，不能以清單數量代替實際archive。
- 合成測試驗中心、細線、孤立點、斜角、畫布邊緣、所有色盤色號、同色覆蓋與原圖模式。色號畫布不因取樣改變。
- 抽取實際艦艇、地圖、片頭與演出畫面，記錄細化前後有差異的HD像素與不變的邏輯中心；這是呈現驗收，不新增戰場規則對拍。
- 正常Linux兩陣營經片頭、主選單、預算、一覽與人物資料抽驗；標準測試與三平台封包逐檔核對。Windows Wine與macOS通用架構不能稱為真機驗收。
