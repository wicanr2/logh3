## 正式契約

1. 顯示資料來自當前星域126-byte記錄，依當前觀看座位選兩格。不可重數艦隊表替代。
2. 左欄永遠帝國色、右欄永遠同盟色。FF印`--`，數值包含0及254均照原版顯示。
3. 無效座位或不足44 bytes回讀取失敗，不越界。畫面既有完整記錄檢查保持。
4. 本次不改四格更新者、存檔格式、可見度規則或正式亂數；不發明情報揭露機制。
5. 保存已存在的+2A／+2B，顯示不得覆寫；既有重數+28／+29契約保持。
