## 要做什麼

主選單四列是**陣營**不是劇本：前三列開新遊戲，第四列「取進度」進存檔畫面
（`docs/re/38`）。remake 先前只有前三列那條路，載存檔得在測試裡直接呼叫。
這份規格把第四列接起來。

## 流程

```
主選單第 4 列 → 防拷問答（同一題）→ 存檔畫面 → 點一格 → 選陣營 → 載入
```

主選單點哪一列要記著，防拷答對之後才決定往哪走。原版點兩下才會動
（第一下選、第二下確認），remake 目前一下就走——那是既有的差異，
不在這份規格裡。

## 存檔畫面的列

11 列，一列 20 px。`Game` 這一層一律用**畫面座標**：第 0 格在 y ＝ 122。

收據裡的點擊座標比畫面**少 40**（dosgolem 的虛擬滑鼠座標，`docs/re/09`），
所以量到的 242／262／282 對應畫面的 282／302／322。

```
第 n 格：畫面 y ∈ [122 + 20n, 122 + 20n + 20)
```


```
第 n 格的 y ∈ [82 + 20n, 82 + 20n + 20)
```

三個有內容的格子量到的落點與這條式子相符：

| 收據 | 點的 y | 載進來的是 | 回合數 |
|---|---:|---|---:|
| `slot242` | 242 | 第 8 格 亞姆力札會戰 | 93 |
| `s2empire` | 262 | 第 9 格 諸神的黃昏 | 346 |
| `s3rgn` | 282 | 第 10 格 巴米利恩會戰 | 380 |

（`slot242` 是為了這份規格補的：同一條路點 242，倒 `ds:8F18` 出來是 93。）

空的那八格沒有點過，往上推是 82–241。

## 點下去之後

讀那一格的六個檔（`docs/spec/005`）→ 重算未安定度（`docs/spec/006`，
回合數用存檔裡的）→ 換掉星域表、行星表與提督表 → 日期、軍事費、總稅收
從 `WORK.DT?` 取 → 進命令階段，**不再跑一次月底結算**（存檔存的是結算
之後的狀態）。

## 驗收

`internal/game.TestLoadGamePlayerPath`：主選單第四列 → 打 138 → 存檔畫面 →
點畫面 (300, 302) → 選帝國 (318,208) → 命令階段，日期 798/11/19、軍事費 150000、總稅收 7280
——與 `docs/spec/002` 那份 `s2empire` 收據畫面上印的相同。

## 不在這份規格裡

- **選完格子之後的陣營小選單**（帝國／同盟／對戰，`docs/re/38`）：
  那張畫面還沒量過，remake 目前直接用劇本原本的陣營進去。
- 存檔畫面上那 11 列的**文字**（名稱、日期）目前是規格裡量好畫死的，
  還沒改成從 `SAVEDATA.IDX` 算出來。
- 存檔**寫出**。
