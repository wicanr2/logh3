# SPEC 005 — 讀一格存檔

狀態：**CONFORMED**（已實作，`internal/rules` 對三格原版存檔驗證通過）
證據：[`docs/re/41`](../re/41-save-files-are-the-runtime-tables.md)、
[`docs/re/42`](../re/42-ship-pool.md)、
[`docs/internals/30`](../internals/30-save-format.md)
資料：[`docs/internals/data/unrest-at-load.json`](../internals/data/unrest-at-load.json)

## 要做什麼

remake 目前只會 796 年 1 月那一個局面：星域資料讀 `STELLAR.DTX`、行星讀
`PLADAT.DAT`、軍事費用劇本給的起始值。但原版主選單第四列「取進度」裡有三個
進度（`docs/re/38`），要能畫那些畫面就得讀存檔。

存檔沒有自己的格式——它就是執行期那幾張表原樣寫出去，所以「讀存檔」
等於「把六個檔各自貼回對應的表」。

## 檔案

一格 `n`（0–10，副檔名末字是它的十六進位）由這六個檔組成：

| 檔案 | 大小 | 內容 |
|---|---:|---|
| `STELLAR.DT?` | 4,032 | 星域 32 × 126 |
| `PLANET.DT?` | 6,642 | 行星 81 × 82 |
| `ADMIRAL.DT?` | 2,296 | 提督 82 × 28 |
| `FLEET.DT?` | 3,904 | 艦隊 32 × 122 |
| `SHIP.DT?` | 27,456 | 艦艇池 352 × 78 |
| `WORK.DT?` | 230 | 全域狀態 |

`SAVEDATA.IDX`（528 bytes ＝ 11 格 × 48）是目錄：哪幾格有東西、序號、
回合數與名稱。

行星表存檔**沒有檔頭**。「第 k 個星域有幾顆行星」是靜態的，那 64 bytes
仍然從 `PLADAT.DAT` 借——載入時把它接在 `PLANET.DT?` 前面就是完整的
`PLADAT.DAT` 版面，行星表的程式碼一行都不用改。

## 要取出來的欄位

| 來源 | 位移 | 進哪裡 |
|---|---|---|
| `WORK` | +0x04（16 位元）| 回合數 |
| `WORK` | +0x3E（32 位元）| 軍事費 |
| `WORK` | +0x56（32 位元）| 總稅收 |
| `SAVEDATA.IDX` | +0x0D／+0x0E／+0x14 | 序號／回合數／名稱（Big5，右邊補半形空白）|

艦隊記錄 `+0x04` ＝ `FF` 表示這一格沒在用；`+0x06` 是所在星域；
`+0x10` 起十個 4-byte 的槽，前兩 byte 是艦艇池的索引，`FF` ＝ 空槽。

## 未安定度要另外給

`STELLAR.DT?` 有未安定度那一欄，**原版載入時會重算**：S3 那一格 32 個星域
裡 22 個與檔案不同。算式還沒解（`docs/re/24`），所以 `LoadSlot` 留的是
檔案裡的值，要對畫面的地方得用量到的那一份覆蓋（`Slot.SetUnrest`）。
量到的值在 `unrest-at-load.json`，怎麼量的寫在 `docs/re/41`。

這是目前唯一一個「載進來還不對」的欄位。

## 驗收

`internal/rules`：

- `TestParseSaveIndex`：11 格、前八格空的，後三格的序號、回合數與名稱長度
  與原版相符。
- `TestLoadSlot`：第 9、第 10 格的回合數、軍事費、總稅收與
  `spec/002` 那兩份中局收據**畫面上印的數字**相同（346／150000／7280、
  380／160000／13131）；干達巴爾的擁有者是帝國、三顆行星
  ——開局那份 `PLADAT.DAT` 是三顆中立行星，載存檔才會對。
- `TestSlotShipPool`：十個槽引用的艦艇，加上每支艦隊多出來的那一筆
  （該隊最小索引 ＋1），與池裡有內容的記錄**集合完全相等**（160 與 148 筆），
  而且沒有任何索引被重複引用。

`internal/screen`：`spec/001` 的 `s3rgn` 那一份改走 `rules.LoadSlot`，
面板那塊 320×80 與原版逐位元組相同。

## 不在這份規格裡

- 未安定度的算式（`docs/re/24`）。
- 存檔**寫出去**：還沒查原版存檔時做了什麼。
- `SHIP` 記錄的欄位語意、艦隊槽的第 3／4 個 byte（`docs/re/42`）。
- 第 8 格（亞姆力札會戰）的艦艇索引有四個重複，原因未解；
  `TestSlotShipPool` 沒有涵蓋那一格。
