# SPEC 107：戰術索敵艦燃料與回收

狀態：**READY**。2026-10-04，原版完整雙跑、bytes、caller及原池增量審查通過。
範圍為[#79](https://github.com/wicanr2/logh3/issues/79)、062子步8-3。
證據入口：[研究417](../re/417-scout-fuel.md)、[原版來源](../internals/data/scout-fuel.json)。

1. 8-2所有報告返回後，依戰場艦隊清單順序處理燃料。8-4與8-5另續。
2. Mode為FF：非零State減一；零保持。不回收、不印報告。
3. Mode非FF：State依byte加一，含255回繞0。加一後unsigned值至少4才回收。
4. 回收前，人類艦隊印原版標頭與DS3DC8失去連絡文字。頭像為提督低byte。
   報告期間燃料已加一；位置、Action、Mode仍為回收前值。一次輸入只結束目前報告。
5. 報告返回後，擦戰場圖示與小地圖標記；清SHIP+19 bit7。
   1727擦點僅在bit7與bit6皆設時清bit6，保留顏色及其餘位元。
   將Target與Current XY都移到FLEET+5C／5E；Action整byte寫FF。
   Mode寫FF、State寫3。冷卻三次後才可再次「索敵」。
6. typed艦隊、typed索敵隊與既有FLEET／SHIP同步；不改存檔格式。
   索敵池身份保留，再派出時重用，不新增同池副本。此步不消耗RND。
