# 158：索敵選點、整隊行軍與按需HD圖片

狀態：**限定CONFORMED**。2026-10-30依使用者四項明確要求及現行資料流審查READY，2026-10-31經[驗證141](../playtest/141-scout-formation-lazy-hd.md)完成。限定來源及Linux正常功能，不新增原版完整AI、像素同態或Windows真機聲明。

## 證據與界線

- 原版索敵鏈見[研究132](../re/132-scout-order.md)、[305](../re/305-scout-order-runtime-receipt.md)：派獨立P，再借分隊移動選點。beginScout已接此鏈。
- 024的範圍描述過時且互相矛盾；[120](../re/120-battle-move-range.md)只證實艦隊圖形。P視野半徑250已由[290](../re/290-battle-spotting-solved.md)證實。本輪依使用者要求畫視野提示，不當目的地限制；原版該選點圖形與鏡頭時序仍待重新取證。
- OriginalTactic逐分隊指同點，applyTacticalMove將非旗艦Action設0，繞過080編隊跟隨；普通Encircle亦拆隊。140名將分支已有整隊命令。使用者要求敵我行軍維持隊形，授權統一艦隊層意圖。
- 025／080／081已定義槽位、移動、轉向與避障，不用瞬移或取消碰撞美化隊形。手動獨立命令保留。
- presentation啟動全解碼人物與編輯器縮圖、艦型、海報及五語名言。這些是可重建的呈現資源，與六表規則無關。

## 契約

1. 派P後保存視窗、聚焦P，顯示P資訊與250世界像素視野圈。可用小地圖移動選點鏡頭，圈外合法點仍接受。確認、取消及無效點均收圈並還原視窗。保留P池身份及原版取消後已派出狀態。
2. 原版參考AI、普通強化、名將及撤退均以存活旗艦代表整艦隊下令。沿原有行星／集結／包圍／撤退目標政策，改為各艦隊分配意圖。一般組按槽跟隨，P保持獨立。兩陣營及自動我軍共用；玩家手動艦隊命令不抹除手動分隊命令。
3. 大型圖片啟動只登記受限檔名、尺寸及索引，首用讀取與解碼；有來源雜湊的圖集、字型及定案海報沿原契約驗證。快取以位元組或有限槽管理，淘汰後可重載。錯誤回退原圖／缺圖處理，不panic也不每幀重試。結果與繪製順序保持，可用索引數與已解碼數分開。
4. 發行縮圖只寫新stage，原始HD與既有封包保持。人物預縮正式Scale3尺寸，沿現行雙線性取樣；等尺寸不重複取樣。編輯器由相同正式人物圖衍生。文字圖集、定案海報與來源雜湊綁定圖集不任意縮小，記錄保留理由。
5. HD封包準備呼叫縮圖並入manifest，不覆寫舊版。171的v.1.6.4-20261031已套用並核對三平台共用素材，見[交付142](../playtest/142-v164-full-scout-march-promo.md)。不發布公開完整版，也不宣稱解決169未知閃退。

## 驗收

- 正常GUI索敵選點、跨鏡頭、圈與還原；取消、無效點、回收再派及六表保存回歸。
- 兩陣營及各AI分支的整隊命令；空地直行槽位分離，地形、手動命令及P保持。
- 未用圖片不解碼，首用、命中、淘汰、重載與破損回退；舊新渲染像素比較。
- 同來源／同容器記錄載入時間及記憶體，正常GUI人物、三海報、名言、交火及標準產品測試。
