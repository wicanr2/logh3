# 131：原格號與遮罩的 HD 地圖材質

狀態：限定CONFORMED（2026-10-11）。沿第124輪確認的A原配置地圖範圍。32張64鏡頭、53格號、73組行星及8組灰色天體四格與原色重播通過，證據見[交付111](../playtest/111-production-hd.md)。本規格只改呈現，不新增地形或規則，不宣稱原版同狀態驗收。

## 已核事實

- 編碼、格號與鏡頭契約沿[地圖36](../internals/36-map-cmp.md)、[圖塊35](../internals/35-block3-blk.md)及正式`screen.drawTerrain`。32張CMP各13056格；實際出現53種格號：0、1、5及6至55。正式消費端使用實際解出的BLOCK_2圖塊。
- 逐張核32張CMP，73組以6為左上、8組以22為左上的圖塊，右、下、右下必為索引+1、+8、+9，錯配零組。解碼圖目視前組是行星、後組是灰色天體。這是原圖的視覺分類，不新增灰色天體的玩法語意。
- 星圖沿[12](../internals/12-strmap-bit.md)、[13](../internals/13-strmap-rgn.md)；32原遮罩與當幀勢力／治安色仍由正式資料決定。航路及星名不從遮罩外接矩形推測。
- 小地圖沿`battleMinimapBitmap`的取樣及原128列。單位、行星、視野框後畫，不能改成整張背景後覆蓋掉標記。

## 呈現契約

1. 地圖顯示命令保留原圖fallback、實際圖塊索引、世界座標及原裁切。原色號重播需與正式畫布逐像素相同；缺材質回原圖。素材須通過雜湊及尺寸上限檢查。
2. 空間採深藍黑底。星雲只在原星雲格內使用[共享生成材質](../../assets/hd/material/MANIFEST.json)，以原點密度平滑為透明度，世界座標固定取樣。材質採鏡射環繞，避免依賴生成圖對邊完全相同。相鄰世界格不是星雲時，在本格內四個邏輯像素淡出，不在空格新增裝飾。捲動不得讓材質跟著螢幕移動；不得新增可通行／不可通行區。
3. 行星與灰色天體使用程式原生圓面、明暗與經緯細節。四個原圖塊共用32×40邏輯範圍，依已核四格偏移取樣同一個96×120高解析度天體，不逐格生成不同星球。圓面保持原範圍，不蓋到相鄰地形格。
4. 星圖區域面材只在原遮罩且底圖留白處替換；32區域顏色逐幀取正式結果。既有航路／標記／星名需要獨立前景替換，未完成以前仍回原圖並記錄覆蓋缺口。
5. 小地圖底圖以原bitmap重畫深藍／藍灰，保持每個邏輯點。視野框、單位、行星及選取線繼續照原畫序與投影；不改命中。
6. 正式美術驗收按介面、戰略面材／前景、戰術地形、單位、小地圖及動畫分開記錄。不把共享星雲接線或離線32張鋪圖當作全HD完成。

## 驗收

- 32張CMP格數、真實索引、四格天體排列與素材雜湊核對；地圖原資料保持。
- 所有使用圖塊以及鏡頭四角、部分天體裁切、相鄰星雲接縫抽驗。世界同一點在不同鏡頭下的HD像素相同。
- 星圖32遮罩及所有正式色號可區分；治安與勢力模式跟隨局面。
- 小地圖原投影、標記、視野框保持，原色重播零差。
- 正常S1讀檔、進場、捲動與實際下令，標準測試及正常GUI。沒有原版新same-state聲明。
