# 130：原配置 HD 繪製紀錄

狀態：限定CONFORMED（2026-10-11）。沿使用者已確認的 A 深藍金色風格，保留原配置。兩陣營各32張正常X11完整視窗及原色重播通過，證據見[交付111](../playtest/111-production-hd.md)。範圍限本規格的呈現介面，不宣稱全遊戲原版一致。

## 來源與審查

已核對 `gfx.Framebuffer.Set/FillRect/Clear`、`asset.Image.Draw`、`ui.Frame.Draw`、`ui.TileFrame.Draw` 與 `ui.DrawGlyphClipped/DrawHalfGlyphClipped/DrawCellClipped`。原圖解碼、640×480 色號畫布、16×15 全形／8×15 半形字、原裁切矩形與字碼是既有已證實契約。繪圖順序由目前程式提供，不從最終截圖猜測文字或面板。

使用者於第124輪已確認 A，並要求原介面加強及地圖、動畫 HD。本規格新增獨立的顯示紀錄，供正式 renderer 使用。原幾何、輸入、資料、規則及存檔無需變更。高解析度字型是刻意的 remake 呈現差異，不屬原版字形 parity。

## 契約

1. `Framebuffer.Pix` 的每次寫入、色號與裁切保持既有語意。顯示紀錄只記繪製命令，不能回寫規則、亂數或存檔。原圖模式不使用 HD renderer。
2. 紀錄依實際畫序保存原色矩形、原色像素、影像、面框、介面底色與文字。複合操作可以包住其原有操作，保留完整 fallback。清空與整張取代同時重設紀錄。後畫內容即使同色也必須覆蓋先前內容。
3. HD 畫布固定1920×1440，所有座標乘3。面框、文字及圖片不得移動邏輯矩形。原色矩形及未替換像素保留當幀調色盤；介面底色及面框使用 A 色彩。選中、未選中、警示與陣營的區別必須保持。
4. 文字由原 Big5／半形字碼查合法可散布字型的抗鋸齒遮罩。全形格48×45、半形格24×45，仍沿原 advance 與裁切；字形不得超出原字格。缺遮罩時重播原點陣及陰影，不能安靜留白。原字型仍由玩家提供。
5. 字型來源、授權、SHA-256、Unicode 對照及產生器寫入素材 manifest。字型遮罩是字型排版輸出，不是對原版點陣放大。圖像新繪與編輯另沿 imagegen；本規格不把邊緣細化算作新繪。
6. 圖片仍使用實際解碼尺寸及索引。缺 HD 圖重播同次原圖，不可用相鄰索引或其他素材替代。人物沿122。後續地圖、動畫替換需記原資料與共享素材消費端，保持幀序、鏡頭及事件閘門。
7. 財政四個箭頭的原圖由框的像素修正拼成。HD從正式`planBox`矩形與既有按後轉色旗標記錄向上／向下符號，不從畫面推測方向，也不改變原色號。

## 驗收

- 繪製紀錄重播成色號時，與最終 `Pix` 逐像素相同；覆蓋同色、裁切、負座標、清空、整張取代、複合 fallback 及文字陰影。
- HD 重播依原畫序，文字下面的 HD 圖片／面框不可被原點陣底圖挖空；後畫游標、視窗與同色遮擋不得穿透。
- 真實字型遮罩驗字格範圍、半形、全形、缺字 fallback、頁面與索引上限。確認來源授權與可重現輸出。
- 標準測試、正常主選單、兩陣營月初／財政、選單、公開存讀及 S1 戰場抽驗。單元測試不能取代正常 GUI。
- 地圖、動畫新繪與正式封包另記覆蓋率，未完成以前 #99 保持開放。
