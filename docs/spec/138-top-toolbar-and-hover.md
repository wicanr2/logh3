- F1開關說明，說明顯示操作方式及快捷鍵。說明內的關閉鈕與Escape可返回。說明與功能列攔截自身輸入，不能點穿至遊戲。
- F7切換原版／HD，F8切換敵軍顯示。沿現有素材缺失及啟動畫面敵軍切換限制，不重建Game、音樂、AI、存檔或亂數。
- HD可操作按鈕停留時增加內側亮框與面板反光。矩形沿正式命中資料，停用控制與被遮住的底層控制不得反光。移開恢復原畫面；原版640×480索引不變。
