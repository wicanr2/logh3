# SPEC 010 — 「存進度」畫面

狀態：**CONFORMED**（已實作；`save1e` 整張 640×480 逐位元組相同）
證據：收據 `save1e`、`save3e`
資料：[`docs/internals/data/save-slot-list.json`](../internals/data/save-slot-list.json) 的 `save` 段
執行器：dosgolem-logh3 `8c8af90`

## 這張畫面長什麼樣

八列，畫面 y ＝ 142 起、一列 20 px，內容都是「未使用」——只列沒用到的
那八格（`docs/spec/008` 的「取進度」列的是全部十一格）。

滑鼠停的那一列畫成一條**色號 2 的紅條**（`x=48, w=544, h=20`，
畫面 y ＝ 140 起、一列 20 px），蓋掉那一列的文字。條子跟著滑鼠走，
不是點出來的——`save1e` 一開畫面條子就在滑鼠底下那一列（滑鼠 y ＝ 125、
畫面 165、第 1 列），`save3e` 把滑鼠移到畫面 142 之後條子就在第 0 列。

## 點下去會怎樣

**直接存到那一格，不問名字。** 收據 `save3e` 點了第 0 列之後跳出一個對話框：

```
磁碟片載入時有發生錯誤。
```

——因為對拍時原版目錄是唯讀掛載的（`AGENTS.md` 的素材邊界），寫不進去。
這也順便確認了「點一下就寫檔」這件事。原版那句訊息的用字（存檔失敗卻說
「載入時」）一併留著，那是 1994 年中文版的原樣。

remake 寫去自己的目錄（`Resources.SaveDir`），所以會成功。
