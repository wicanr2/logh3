# SPEC 129：個人存檔與出貨三劇本

狀態：CONFORMED

依據：[007](007-load-game-path.md)、[008](008-save-slot-list.md)、[研究38](../re/38-scenario-slots.md)及原版 `SAVEDATA.IDX`。2026-10-11正式包正常X11讀檔確認第8、9、10格為S1「亞姆力札會戰」、S2「諸神的黃昏」、S3「巴米利恩會戰」。三個日期依序為796/10/10、798/11/19、799/03/01。這是既有資料與玩家路徑，不新增劇本或改動規則。

問題已重現：個人 `SAVEDATA.IDX` 尾三格空白時，`UseSaveDir` 用整份索引覆蓋出貨目錄，三劇本不再可選。`TestBundledScenariosSurvivePersonalIndex`修正前S1、S2、S3均停在StateLoadGame。

- 個人索引第0至7格保持個人資料。
- 第8至10格若為空，從已載入的出貨索引補回；非空的個人記錄保持相容。
- 同一工作階段保存後重畫清單，亦補回缺少的三劇本。
- 六個存檔仍從同一目錄讀取；原版資料唯讀，格式不變。
- 驗收走主選單、防拷、讀檔清單、陣營選擇及正確日期，再保存至第0格並重新選三劇本。

原版證據保持既有等級；本次驗證只聲明remake載入與目錄回退，不聲明新的原版整回合同態。

2026-10-11限定驗收：三案修正前失敗、修正後通過；Linux與Windows Wine正式包各驗個人第0格及S1至S3，保存後再載S3的回合均為380。正式Linux新包另從片頭經主選單、防拷及正常X11讀檔清單載入S1，進入戰場並公開下令。詳[驗收110](../playtest/110-hd-interface-s1-promo.md)；HD介面及動畫重製不在本契約完成範圍內。
