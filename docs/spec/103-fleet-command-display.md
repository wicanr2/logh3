## 原版契約

- 等待目標呼叫165F:034F。一般戰鬥艦種依序掛光線砲、飛彈、戰鬥機及目前位置十字。
- 中心為分隊SHIP+34／36各加8，朝向取FLEET+4A。武器資料共用093的DS4FDA表。
- 光線砲名字FF不畫；飛彈／戰鬥機另要求32-bit庫存非零。
- 光線砲／飛彈是焦點橢圓，色號6／1；戰鬥機是圓，半徑為表+2，色號5。
- 圓形沿39D7:008C，誤差初值為半徑，更新用舊y後才遞增y；八對稱點不合併，重複點照次數XOR。
- 位置十字前／後／側長均2048，色號7。圖形皆XOR、裁到正式FieldClip；型別4依朝向旋轉。
- 開子選單3870:01AC隱藏圖形，返回等待恢復；不能把XOR累積到下一Frame。
- 目前分隊保留SPRITE 10亮標，游標沿正常renderer最後畫。
- 我方摘要只顯示既有面板前四列；後四列供敵方摘要，不顯示我方行動或武器庫存。
- 身份編號沿1629:023B→3982:0038：小於10用全形一格，其餘兩個半形一格。由原版固定bytes與研究143／338交叉確認。
- 敵方摘要只來自100候選16×16半開矩形。純移動更新，空白清除；重疊沿候選次序及102右鍵輪替。
- SHIP+17恰3顯示原身份兩列及艦種／艘數；恰2顯示陣營、未知艦隊／名稱與艦種／艘數；其餘顯示未知艦種／艘數。
- 第八列取兩支SHIP+34／36的整數距離，以DS456F格式顯示；尾四個零是原字串，不改為16.16數值。
- UI不寫SHIP／FLEET／ADML、不消費RND；正式命令及存檔契約保持102。
