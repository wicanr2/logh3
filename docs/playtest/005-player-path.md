# 收據 005 — 正常玩家路徑（主選單 → 防拷問答 → 遊戲本體）

比較等級：**`same-state`**，未核准差異 **0**（三個畫面各自逐位元組一致）。

這一份與 001／003／004 的差別是**怎麼到達那個畫面**：那三份是各自把
畫面畫出來比對，這一份是從主選單開始，用滑鼠與鍵盤一步步走過去，
每一步的畫面都要對得上。診斷用的 direct-entry 不能代替這條路徑。

## 序列

```
tools/go.sh run ./cmd/play -script "move 300 170; click; type 138; enter; click 448 330; click 448 310"
```

| 步 | 輸入 | 狀態 | 對照收據 | 差異 |
|---|---|---|---|---|
| 1 | `move 300 170` | 主選單（第 0 列反白） | `r0` | 0 / 307,200 |
| 2 | `click` | 防拷問答 | `cb1` | 0 / 307,200 |
| 3 | `type 138` | 防拷問答（輸入中） | — | 畫面不變（見未確認） |
| 4 | `enter` | 遊戲本體 | `key1` | 0 / 307,200 |
| 5 | `click 448 330` | 船艦訂造報告 | `ship1` | 0 / 307,200 |
| 6 | `click 448 310` | 次月份船艦建造計劃 | `plan1` | 0 / 307,200 |

回歸測試：`internal/game/game_test.go` 的 `TestPlayerPathReachesGame`。

## 狀態機

`internal/game` 只做「輸入 → 狀態 → 畫面」，不碰渲染後端；畫面永遠是
640×480 的色號陣列，所以同一份邏輯可以無頭跑對拍，也可以接上任何顯示層。

規則來自逆向：

- 主選單的點擊要落在某一列上才算數（`docs/re/08`）。
- 防拷問答的答案是那張照片對應的 `ADMIRAL.DT*` 記錄的 `+11`
  （占領能力，`docs/internals/08`）；照片編號在畫面規格裡。

## 未確認

- **輸入中的數字沒有畫在畫面上**。原版打字時輸入框裡會顯示什麼、
  游標長什麼樣，還沒擷取到那個狀態的收據。
- **答錯會怎樣**沒有逆向出來。目前的實作是清掉重來，那是佔位，
  不是原版規則。
- 主選單的四個選項目前都走同一條路（進防拷問答）。「取進度」之後
  應該是讀檔畫面，還沒做。
- 主畫面另一個熱區 (432,300)、以及建造計劃畫面上的熱區，點下去是什麼
  還沒擷取。
- 建造計劃的預算箭頭還不能按（畫得出來，但按了不會改數字）。

## 命令階段（12 張畫面）

月初報告用右鍵關掉兩層，露出戰略地圖介面，命令列三格各拉出一張選單，
選單每一項各開一張畫面。**十二張都逐位元組相同**，而且都是正常玩家路徑
走到的（`internal/game` 的 `TestCommandPhaseNavigation`）。

```
tools/go.sh run ./cmd/play -script \
  "move 300 170; click; type 138; enter; rclick 300 240; rclick 300 240; \
   click 352 125; click 400 145"
```

| 命令列 | 選單項目（畫面座標）| 畫面 | 收據 |
|---|---|---|---|
| `click 352 125` 戰略命令 | `click 400 125` | 待命中提督資料 | `sortie1e` |
| | `click 400 145` | 戰略情報報告 | `info1e` |
| | `click 400 165` | 次月份預算計劃 | `tax1e` |
| | `click 400 185` | 次月份船艦建造計劃 | `prod1e` |
| `click 448 125` 一覽表 | `click 460 125` | 星系資料 | `star1e` |
| | `click 460 145` | 艦隊資料 | `lst1e` |
| | `click 460 165` | 提督資料 | `lst2e` |
| | `click 460 185` | 敵將資料 | `lst3e` |
| `click 544 125` 系統指令 | `click 560 125` | 實行（推進三天，不開畫面）| `turn260` |
| | `click 560 145` | 取進度 | `load1e` |
| | `click 560 165` | 存進度 | `save1e` |
| | `click 560 185` | 遊戲設定 | `settings1e` |
| | `click 560 205` | 結束（確認對話框）| `quit1e` |

**回程不比像素**：右鍵回到地圖介面之後，原版左下角那塊會顯示游標底下的
星系（收據 `rcback`：右鍵回去之後那塊寫成「同盟軍星系艾流塞拉」），
remake 還沒有那一層模型，所以只驗狀態不比畫面。

⚠ 這裡的座標是**畫面座標**；收據裡的 `-clicks` 是滑鼠座標，兩者差 40
（畫面 y ＝ 滑鼠 y ＋ 40，與游標的 `offset_from_mouse` 一致）。
