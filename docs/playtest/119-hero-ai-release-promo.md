本輪依[規格140](../spec/140-hero-tactics-and-release.md)核對使用者已確認的玩法。版本為`v.1.2.0-20261012`，目前狀態表在[計畫130](../goal/2026-10-12-hero-ai-release-round-130.md)。最終封包與影片身份由[來源索引](../internals/data/hero-ai-release-promo.json)保存，來源索引只在全部本機交付閘門通過後產生。

## 名將規則

僅強化模式啟用。楊威利或萊因哈特必須是存活、在場旗艦的帶隊提督。其陣營全部艦隊的新移動額度為1.5倍；原始速度不改，不累乘，不保存加成旗標。名將離場、死亡或切回原版模式便解除。雙方各有名將時，各自取得加成。

楊以一支前衛牽制，其餘左右分翼；萊因哈特以至少半數主力集中突擊，其餘繞側後。角色按穩定艦隊順序分配，遠處先向側面集結，接近再繞後。整隊命令沿既有地形、碰撞與撤退門檻；索敵隊保留自己的命令。這是使用者核准的remake新增規則，不稱原版行為。

標準命令為`bash tools/gui.sh test ./cmd/... ./internal/...`，19套件為15PASS、4無測試。新增回歸涵蓋兩位名將、雙方同場、副官不觸發、死亡／離場取消、原版模式、整隊跟隨、索敵隊、邊界與地形、無新增亂數消耗、每回合新額度及餘額不累乘。實際移動32至48的案例確認倍率，停止、凍結與未啟用索敵隊保持既有分派。原版存檔格式未改。缺少的歷史oracle fixture沿既有SKIP，不算DOS對拍通過。

## 正常玩家路徑

四條實錄均使用本版Linux正式封包，從片頭、主選單、防拷確認、取進度清單讀S1，選陣營，正常設定顯示敵軍並實行。沒有`-script`、直接進場、局面或種子注入。操作由X11實際鍵鼠完成，狀態觀測只讀。[公開輸入模型](../../tools/scripts/hero_gameplay_model.go)供每回合核對，不能單獨代替實錄。

[正常實錄核對器](../../tools/scripts/hero_gameplay_audit.py)核對16個戰術狀態，艦隊、位置、目的地、移動額度、名將及鏡頭均與公開輸入模型相同。兩個玩家陣營分別驗證原版規則／強化模式的初始實體艦隊完全相同，兩回合後部署不同。敵軍均實際移動。比較等級限定為remake同初始資料與等價操作，不宣稱DOS原版same-state。

S1本身雙方名將均參戰。原版規則模式不產生名將加成，強化模式雙方各自取得加成；玩家艦隊仍由玩家下令，不被強制移動。另一段正常實錄`record-f0-ai1`確認F7實際HD→原版→HD，敵軍顯示只從設定選單操作。

普通動畫開啟、速度8個原生tick；訊息速度由正常選單改成10，縮短結果停頓。三段有交火的本版實錄共102場、1361來源格，其中85場艦隊、17場既有行星。三種艦隊武器、末格後結果及音效閘門通過，沒有倒序或漏格。六場同側行星呈現明列既有#48限制，新推廣片只選完整艦隊場次，沒有用這些行星場次宣稱完整登陸完成。
