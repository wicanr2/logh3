# 120：系統游標、讀檔取消、字型、HD音樂與啟動視窗

2026-10-13。交付版本 `v.1.3.0-20261013`。唯一現行狀態為[第131輪](../goal/2026-10-13-system-dialog-and-polish-round-131.md)，來源、封包及收據雜湊集中於[交付索引](../internals/data/system-dialog-polish.json)。本輪是 remake 修正及核准功能，沒有新增 DOS 同狀態對拍宣稱。

## 原因與修正

| 問題 | 已查證原因 | 結果 |
|---|---|---|
| 讀檔、結束確認像是滑鼠停住 | 發行版仍更新及處理右鍵，但兩張視窗顯示擷取時的固定游標 | 四種系統視窗統一在動態內容後畫即時游標，移除固定游標與局部覆蓋 |
| 主選單讀檔右鍵後進帝國初始局 | 取消固定回戰略，忽略進入來源 | 記住主選單、戰略、戰術父畫面，取消返回入口 |
| 啟動時沒有視窗 | 原版、HD及音訊全部同步載入後才進RunGame | 先開560×220視窗，顯示七個實際階段與人物圖完成張數，完成後同視窗進遊戲 |

游標原始JSON與oracle證據保持。修正前的正常X11收據在 `workplace/modal131/before/`；讀檔與退出的兩次完整視窗相同。修正後原圖與HD均只有一支即時游標。規格[141](../spec/141-system-dialog-cursor.md)及[142](../spec/142-startup-progress.md)限定本輪範圍。

## 字型與音樂

使用者先確認原版強化、思源宋體及思源黑體，預設原版強化，再追加保留原版點陣。四者已接設定，維持原格寬與面板位置；原圖模式仍畫原字模。缺少字集時不列出該選項，缺字回原字模。選擇僅本次執行有效。核准試樣保存在[原提案HTML](../images/font-v130-preview.html)及[決定與雜湊](../images/font-v130-preview.json)，與正式遊戲截圖分開。

HD音樂沿原MDS匯出11首MIDI，逐檔與既有保存MIDI相同。固定GeneralUser GS 2.0.3 commit `684543d5e5efaef08d02be50dcda8d552478fa60`，SF2 SHA-256 `9575028c7a1f589f5770fccc8cff2734566af40cd26ed836944e9a5152688cfe`。FluidSynth 2.3.1以44.1kHz、雙聲道合成，FFmpeg混音與Vorbis q7輸出，音符及速度事件保持。音色的釋放尾音會影響檔案時長，不把新舊OGG長度差稱為改曲速。

11首完整解碼、非靜音，最高樣本峰值−1.387419dB，最大首尾取樣跳變0.0000358324。這些只驗技術品質；人耳聽感、完整遊戲播放及音樂性循環由#69保留。試聽入口為 `workplace/modal131/music-preview/index.html`。設定可切HD／FM、關閉及由HD解除靜音，不修改WORK存檔格式。強化啟動器預設HD音色，原版規則啟動器預設原音色；兩者仍可自行切換。

原版旋律與衍生OGG、字型完整圖集及遊戲HD素材只在本機完整版。引擎只內嵌附完整授權的Noto啟動小字集，來源見[啟動字集索引](../internals/data/startup-font.json)。規格[143](../spec/143-font-and-hd-music.md)限定機械驗收，沒有把技術檢查升為聽感通過。

## 正常玩家驗證

`tools/scripts/system_dialog_gui_check.py` 在既有HD容器以X11公開輸入操作實際Linux完整版啟動器，從載入視窗、片頭與主選單進入，沒有script旗標、狀態注入或測試時鐘。

| 路徑 | 驗證 |
|---|---|
| 帝國強化 `full-f0` | 預設HD音色、主選單讀檔右鍵返回、月初報告、戰略系統視窗、三劇本、存讀、四字型與音色切換、退出0 |
| 同盟原版規則 `full-f1` | 預設原音色，以上同一流程；原圖／HD均抽樣 |
| 讀檔、保存、結束 | 兩陣營各六組原圖／HD移動差分，變動只在新舊游標矩形；確認按鈕上的游標完整 |
| 三劇本及保存 | S1、S2、S3可見列選取、陣營選擇、實際載入；六個保存檔案寫入並讀回 |
| 字型與音源 | 四字型設定、返回與F7後保留選擇，HD／FM／關閉及HD解除靜音；保留完整視窗PNG與唯讀影格紀錄 |
| 缺少原版資料 | 正常入口留下錯誤小視窗，Escape結束碼1，完整錯誤保留stderr |

正式正常收據分別在 `workplace/modal131/full-f0/` 及 `full-f1/`，每批包含RESULT、FRAMES、AUDIO及38張完整視窗。新首頁三張圖取自這兩批，沒有裁切或縮放，見[截圖收據](../images/readme-v130.json)。戰術取消返回有回歸測試，未補正常戰術GUI，不能升格為戰術流程完整驗收。

標準命令 `tools/gui.sh test ./internal/... ./cmd/...` 為19套件，15PASS、4無測試。誤用 `test ./...` 曾掃入workplace及工具探針，屬測試範圍錯誤；改用同一容器的標準範圍重跑通過。GUI腳本初次保存點用了讀檔列的y132，依既有保存TextTop142修正為y152再乾淨重跑；產品座標沒有配合測試修改。

## 打包與平台

1553項凍結輸入建立三平台完整包、來源包及三平台引擎包，共八封包。逐檔manifest、ZIP內容、平台、權限及SHA-256由建置器檢查；[最終核對器](../../tools/scripts/system_dialog_finalize.py)核對全部封包、1553項凍結來源符合BUILD，以及575項非vendor與目前程式相同。vendor只在凍結輸入，不要求主工作樹有另一份。BUILD保留建置時HEAD及髒工作樹，正式commit另外綁定，不宣稱當時由乾淨HEAD建置。

| 平台 | 本輪證據 | 限制 |
|---|---|---|
| Linux | 完整包兩正常路徑；引擎兩啟動器各主選單／財政診斷 | 虛擬顯示及音效卡 |
| Windows | Wine正常片頭，讀檔／結束／黑體三診斷；引擎兩啟動器各主選單／財政診斷 | 本輪音訊停用，非Windows真機 |
| macOS | Intel／Apple Silicon通用Mach-O、系統依賴、11.0部署及ARM簽章全頁雜湊、封包權限 | 未真機、未Apple公證 |

本機完整版在 `dist-all/v.1.3.0-20261013/full/`，引擎包在 `release/`，驗證在 `smoke/`。GitHub只發布四個引擎／來源包及校驗檔；完整包、音樂、HD遊戲素材與動畫不上傳。遠端正式發布後由[發行核對器](../../tools/scripts/release_publish_check.py)實際下載五附件核對，結果寫回同一交付索引。

本輪沒有重做推廣片，`v.1.2.0-20261012/promo/` 保持原身份。完整登陸／占領、DOS整場同態及既有其他未完成Issue保持。容器與擁有權於交接時另存核對收據。
