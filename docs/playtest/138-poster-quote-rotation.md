# v1五組名言輪替

使用者於2026-10-26同意附來源網路語錄。正式v1依[五組五語清單](../../tools/scripts/poster_quote_candidates.json)每60秒同步替換兩人名言，300秒回第一組。語系、原版／HD與選單切換不重設時間，重啟由首組開始；v2／v3不疊v1文字。引用尚未逐字核對尖端舊版，不作官方譯文聲明。

[157規格](../spec/157-poster-galaxy-frame.md)先READY後實作。[唯一狀態表165](../goal/2026-10-26-poster-quote-rotation-round-165.md)記錄交付進度，[來源與輸出索引](../internals/data/poster-quotes.json)記錄完整SHA-256。本功能是remake呈現，沒有DOS對應功能，不能外推原版parity。

## 正常入口結果

Linux來源程式從主選單、正常輸入138保護答案進入遊戲，再以設定頁啟用v1。沒有direct-entry、狀態、seed或時間注入。

- 同盟36張完整1280×720 X11視窗，實際等待第一組至第五組及300秒回首組。每組均以設定頁實際切換繁體、簡體、日文、英文、韓語，25組名言與語系全部截圖。
- 兩人名言同步替換，語系切換保留組別。動畫關閉時第三組仍準時出現，光束相位保持0。完整循環後首組韓語截圖觀測到25份文字材質快取，不會逐幀建立材質。
- 首次閒置輪替，遊戲背景上傳次數19→19，戰略資料保持。第五組回首組截圖的名言時間為301682ms。
- v2／v3文字區與各自原背景完全相同，未混入v1名言。F1、F7原版／HD、公開六表保存、讀回及重啟皆通過。
- 帝國另有正常入口實際60秒、組別切換、F1／F7、存讀與重啟9張抽樣。首次收據通過但容器退出回143，沿相同工具鏈與流程乾淨重跑，第二次收據與容器退出均成功。沒有將程序結束問題記為產品缺陷。
- 兩陣營六表完整檔案雜湊均與164各自基準相同。重啟首組截圖觀測名言時間約1.5秒。

標準`tools/gui.sh test ./cmd/... ./internal/...`共20產品套件，16通過、4無測試。時間邊界含60／120／180／240／300秒及負時間、單組，另有缺輪替清單、缺語系、非法檔名、壞SHA、錯尺寸及壞清單安全退回測試。舊清單仍顯示核准首組，損毀擴充不關閉核准海報。

## 畫面及資產

新增20張2560×400透明文字層，在完整2560×1440外框的y=880位置繪製。字型、人物、姓名位置沿已同意預覽，長句向上排。五組×五語共50個文字框的邊界、與姓名的間距由鎖版Chromium1194檢查，皆位於透明層與人物區內。原九張藝術層與manifest保持原SHA。

將實際X11視窗與對應背景及文字層合成比較，採已確認的Ebitengine 2:1最近鄰奇數像素取樣。25組各86600個文字區像素，共2165000像素，最大通道差1，屬透明合成整數捨入。逐組差分留在`workplace/poster165/diff-quote-<組別>-<語系>.png`，不宣稱全圖逐像素一致。

## 重現與限制

`tools/scripts/poster_quote_export.mjs`從凍結HTML與已同意清單匯出圖層，`poster_quote_install.py`核SHA並安裝，`poster_quote_gui.py`跑正常GUI，`poster_quote_check.py`核25組畫面。皆使用既有Docker工具鏈；逐步觀測、實際命令與工具／來源雜湊記於唯一索引及`workplace/poster165/`。

本輪沒有變更版號、tag、Release或重新打三平台包。Windows／macOS尚未重建或真機驗證這項輪替；既有v1.6.2完整包仍是先前裝飾。
