## 操作

滑鼠移到頂緣顯示功能列，在列上停留保持顯示，離開收起。功能列按鈕與鍵盤共用動作。

| 按鍵 | 動作 |
|---|---|
| F1 | 開關操作說明 |
| F7 | 即時切換原版／HD |
| F8 | 開關敵軍全顯示 |
| F6 | 保留原版／HD切換相容入口 |
| Escape | 關閉操作說明 |

說明及功能列攔截自身輸入，按住左鍵或右鍵拖到遊戲中釋放也不點穿。離開功能列後恢復原遊戲游標。說明不重建遊戲；遊戲的既有計時仍繼續。

HD按鈕命中資料來自正式熱區及財政控制矩形。停留時增加內側金色亮框與面板反光，移開恢復。被其他視窗遮住的控制不反光。文字與游標保持，原版索引畫布及存檔格式不改。

帝國採核准A適度調暗，面板 `#173f70`、按鈕 `#25578e`、主要操作 `#294f7a`、框 `#82a4cb`、漸層7。金字及同盟赤焰戰線保持。核准原PNG的SHA-256為 `855f2d1bd1bdce75c2e705f0973f74910dff1910522175c78059de213b8d3c35`。星圖第三稿、名稱、航路與戰術圖示沿前版。

## 驗證方法

[正常視窗驗收器](../../tools/scripts/toolbar_gui_check.py)從片頭啟動，以X11真實鍵鼠經主選單、防拷確認、會計、財政、訂造、建造至戰略畫面。沒有 `-script`、直接進入畫面或局面注入。兩陣營各保存11張完整960×720視窗及唯讀狀態觀測。

正式抽驗直接呼叫新版 `start-original.sh` 與 `start-enhanced.sh`，從其他工作目錄啟動，使用獨立測試存檔及虛擬PulseAudio。檢查頂緣展開、列內保持、離開收起、F1與關閉鈕、Escape、滑鼠拖出攔截、F7雙向切換、F8與列上開關、第二畫面確認及財政／訂造／建造按鈕。

反光另取遠離游標的會計按鈕區域，量測停留前後亮度與改變像素，避免只有游標移動就通過。單元回歸檢查移開恢復、原索引不變、亮框不溢出、真視窗遮擋與框內補畫文字底色。

標準命令為 `bash tools/gui.sh test ./cmd/... ./internal/...`。以相同凍結來源建立三平台完整版及引擎包，核對六ZIP、兩份來源tar、逐檔manifest、SHA-256、版本、平台、執行權限及素材身份。Windows用Wine抽驗，macOS驗兩架構、最低11.0、系統依賴及ARM簽章頁。純引擎包用自備原版資料抽驗兩種AI啟動器，包含確認與財政操作。

## 修正與限制

初次拖曳測試在送出按下後立刻移動，尚未等遊戲觀測按下位置就離開頂列。測試改成保持120ms並確認列內狀態，再拖出；原始失敗收據保留。這項修正屬輸入腳本時序。

實際截圖另發現會計按鈕的分頁文字底色在框後補畫，被反光呈現器誤判成遮擋。已改為允許框內補畫底色，真正後畫視窗仍攔截反光，並增加回歸測試。修正前後收據分開保存，不覆寫。

使用者先前的v.1.1.3無視窗回報未在隔離測試重現，之後使用者已確認正常。兩個舊啟動器、正常主選單與音訊、目前X11桌面抽驗均有收據。沒有證據確定原始原因，因此不宣稱本輪修好未知啟動缺陷。新版啟動時會立即印出載入提示。

推廣片沿[前版116](116-live-graphics-review.md)的116秒有聲實錄，保留原版號與雜湊。該片為F6顯示切換／F7敵軍，新版改為F7／F8；本輪沒有重錄或重標該片。前版的動畫、S1交火與AI展示驗收維持原範圍。

本輪是remake介面驗收，沒有新增DOS原版對拍。Windows／macOS真機、人耳與完整登陸仍待各自驗收。完整版與影片含原版衍生素材，只留本機。未建立遠端tag或Release。
